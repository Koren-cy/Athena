# 数字信号处理 — 笔记整理规范

## 定位

教科书级系统笔记。完整覆盖课程知识体系，兼顾理论深度与可读性。读者应能不依赖视频、仅凭笔记完成系统学习与复习，同时方便读者期末考试高效速成。

## 基本原则

1. **标题不用编号**。Markdown 标题（`##`、`###`）直接写内容名，不加 `1.`、`1.1` 等序号。
2. **术语先定义后使用**。每个新概念在首次出现时给出正式定义，不依赖读者已掌握。
3. **推导步骤完整**。公式推导不能跳步，每一步标明依据（定义代入、定理引用、代数变形）。关键推导步骤之间用文字说明逻辑衔接。
4. **语句通顺精炼**。写完读一遍。句子之间要有逻辑衔接，不能跳话题。解释性插入语拆成独立句子。
5. **少用括号**。解释性插入语拆成独立句子。数学符号后的中文标注如 "$x(n)$（序列的时域表示）" 可以保留。
6. **举例与例题分离**。演示概念的举例融入正文，不用 callout，不用 `**解：**`。只有满足准入清单的解题活动才用 `[!example]`。
7. **物理意义与数学推导并重**。每引入一个重要结论，紧跟一句话点明其工程/物理含义。公式不应孤立存在。

## 内容取舍

### 必须保留

- **概念定义**：用 `**定义**：` 引导，给出精确的数学表述
- **定理与性质**：用 `**定理**：` 或 `**性质**：` 引导，写明条件和结论
- **公式推导**：从前提条件到最终结论的完整链条
- **典型例题**：满足准入清单的完整解题活动
- **分析方法**：可复用的解题方法论
- **设计步骤**：滤波器设计、系统设计等操作性流程
- **对比辨析**：易混淆概念的异同（如 DTFT vs DFT、z 变换 vs DTFT）
- **几何直觉**：z 平面/频域的几何解释，极零点分析的直观理解
- **应用场景**：结论在实际工程中的用途

### 精简或省略

- 课程行政安排、考试时间安排
- 人物生平、历史故事（超过一句话的）
- 生活类比、过渡段落、纯闲聊
- 教师的个人感悟体会

### 边界情况的处理

- **历史背景**：一句话即可，如「FFT 由 Cooley 与 Tukey 于 1965 年提出，将 DFT 计算量从 $O(N^2)$ 降为 $O(N\log N)$」
- **工程应用举例**：保留，用 `[!info]` 标注
- **与其他课程的联系**：用 `[!note]` 标注，并附 `[[wikilink]]`

## 数学规范

### LaTeX

- 行内公式用 `$...$`，独立公式用 `$$...$$`
- 多行对齐环境 `\begin{aligned}` 等必须放在 `$$...$$` 内
- 序列变量统一用圆括号：$x(n)$、$h(n)$、$y(n)$（不用方括号）
- 频域函数用大写：$X(e^{j\omega})$、$X(z)$、$X(k)$
- 单位脉冲函数：$\delta(n)$
- 单位阶跃函数：$u(n)$
- 卷积和：$x_1(n) * x_2(n)$
- 共轭：$x^*(n)$
- 系统函数：$H(z)$
- 频率响应：$H(e^{j\omega})$ 或 $H(j\Omega)$（模拟域）
- 模拟角频率：大写 $\Omega$（rad/s）
- 数字角频率：小写 $\omega$（rad）
- 求和范围：$n=-\infty$ 到 $\infty$，不可省略
- 变换对符号：$x(n) \leftrightarrow X(e^{j\omega})$

### 定理与性质的标准格式

**定理** 需包含：名称、条件、结论。条件用「若……」引导，结论用「则……」引导。

```
**定理（帕斯维尔定理）**：若 $x(n)$ 绝对可和，则
$$\sum_{n=-\infty}^{\infty} |x(n)|^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} |X(e^{j\omega})|^2 d\omega$$
即时域总能量等于频域总能量。
```

**性质** 以条目列出，每条包含：性质名、条件、数学表达式、一句话解释。

```
### 3. 时移性质

若 $x(n) \leftrightarrow X(e^{j\omega})$，则
$$x(n - n_0) \leftrightarrow e^{-j\omega n_0} X(e^{j\omega})$$

**含义**：时域延迟 $n_0$ 个采样点，频域乘以线性相位因子 $e^{-j\omega n_0}$，幅度谱不变。
```

### 推导过程格式

推导步骤用「由……」引导依据，关键变形另起行：

```
**推导**：

由 DTFT 定义：
$$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x(n) e^{-j\omega n}$$

代入 $x(n) = a^n u(n)$，$u(n)$ 将求和下限改为 $0$：
$$X(e^{j\omega}) = \sum_{n=0}^{\infty} a^n e^{-j\omega n} = \sum_{n=0}^{\infty} (a e^{-j\omega})^n$$

当 $|a e^{-j\omega}| < 1$ 即 $|a| < 1$ 时，由无穷等比级数求和公式：
$$X(e^{j\omega}) = \frac{1}{1 - a e^{-j\omega}}$$
```

### 重要公式编号

课程中反复使用的核心公式（DTFT 定义、z 变换定义、DFT 定义、卷积和公式等）在首次出现处用 `[!important]` 标注。

## Callout 规范

### 标题

- 统一用中文。
- 是对内容的精炼总结，不重复 callout 类型。`[!example]` 标题不写「例：」。

### 类型

| Callout | 用途 |
|---------|------|
| `[!abstract]` | 本讲定位——本讲在课程知识体系中的位置、与前后的衔接 |
| `[!note]` | 补充说明——推导的另一种思路、与相关课程的联系 |
| `[!info]` | 背景知识——工程应用场景、历史背景 |
| `[!tip]` | 记忆技巧——公式的记忆口诀、易混淆概念的区分方法 |
| `[!warning]` | 易错点——常见计算错误、概念混淆、使用条件遗漏 |
| `[!important]` | 核心结论——必记定义、必记公式、必记定理、考试高频考点 |
| `[!example]` | 例题——仅限满足准入清单的完整解题活动 |
| `[!danger]` | 禁止做法——会导致错误或无效的操作、公式的错误用法 |

### callout 嵌套内容规范

`[!note]` 等 callout 内若包含定义和示例，应全部保留在 callout 内，用空行分段：定义 → 示例 → 结论。不要把示例拆到 callout 外面变成孤立的正文。

## 例题规范

### 准入清单（全部满足才是例题）

1. 有明确的已知条件
2. 有明确的待求目标（求/设计/分析/证明/计算）
3. 可独立存在，不依赖上下文叙事
4. 不是推导过程中的论证演示环节
5. 可出成作业题或考题

### 格式

```
> [!example] 内容概括
> 已知……。求/设计/分析……
>
> **解：** 分步骤解答。
```

三部分缺一不可：标题概括 + 问题陈述 + 解答。

### 解答写作

- 推理步骤要有依据，不能跳跃。每一步标明所用定理或性质。
- 多解法标注「法一」「法二」。每个方法的信息归属正确，法一的条件写在法一里。
- 最终答案用独立行标出，如「故 $H(z) = \dfrac{z}{z - 0.5}$」。
- 数值计算类题目，中间结果保留 4 位有效数字，最终结果保留 3 位有效数字。

## 三大变换对比（课程核心）

| 维度 | DTFT | z 变换 | DFT |
|------|------|--------|-----|
| 变换符号 | $X(e^{j\omega})$ | $X(z)$ | $X(k)$ |
| 定义域 | 单位圆 $z=e^{j\omega}$ | 复平面 | 单位圆上等间隔采样 |
| 自变量 | $\omega$（连续，周期 $2\pi$） | $z$（连续复变量） | $k$（离散整数） |
| 收敛要求 | 绝对可和 | ROC 存在 | 有限长序列自动收敛 |
| 适用序列 | 绝对可和序列 | 更广泛的序列 | 有限长序列 |
| 逆变换 | 积分 | 围线积分/部分分式/幂级数 | IDFT 公式 |
| 主要用途 | 频域分析、滤波器频响 | 系统分析、解差分方程 | 数值计算、频谱分析 |

此对比表在三种变换全部讲完后（第22讲附近）完整呈现，并在后续滤波器设计中反复引用。
