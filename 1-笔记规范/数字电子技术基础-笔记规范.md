# 数字电子技术基础 — 笔记整理规范

## 定位

期末速成笔记。精简，直击考点。

## 基本原则

1. **标题不用编号**。Markdown 标题（`##`、`###`）直接写内容名，不加 `1.`、`1.1` 等序号。
2. **语句通顺，不啰嗦**。写完读一遍。句子之间要有逻辑衔接，不能跳话题。
3. **少用括号**。解释性插入语拆成独立句子。课程名称后的标注如 `电路原理（基本电路分析方法）` 可以保留。
4. **举例不是例题**。演示概念的举例融入正文，不用 callout，不用 `**解：**`。只有真正的解题活动才用 `[!example]`。

## 内容取舍

- **保留**：知识点、公式、结论、分析方法、设计步骤、经典例题、易错点、推导过程、原理
- **公式要列全**：视频画面中出现的公式，即使老师口头一带而过，也要完整收录。字幕只记录语音，画面上的公式不会体现在字幕里，但同样是课程内容。只有与课程关联不强、且不用于任何推导或证明的公式，才可以省略。
- **精简或省略**：课程行政安排、人物介绍、历史故事、生活类比、过渡段落、背景铺垫、设计哲学、感悟体会。引入性故事和动机举例精简为一两句话即可。每段下笔前问：这段考吗？不考就不写。
- **老师强调的重点**：用 `[!important]` 突出。

## Callout 规范

### 标题

- 统一用中文。
- 是对内容的精炼总结，不重复 callout 类型。`[!example]` 不写"例："。

### 类型

| Callout | 用途 |
|---------|------|
| `[!abstract]` | 本讲定位 |
| `[!note]` | 补充说明 |
| `[!info]` | 背景知识 |
| `[!tip]` | 记忆技巧 |
| `[!warning]` | 易错点 |
| `[!important]` | 核心结论、必背公式、考点 |
| `[!example]` | 例题（仅限满足准入清单的） |
| `[!danger]` | 禁止做法 |

## 例题规范

### 准入清单（全部满足才是例题）

1. 有明确的已知条件
2. 有明确的待求目标（求/设计/分析/计算）
3. 可独立存在
4. 不是论证演示环节
5. 可出成作业题或考题

### 格式

```
> [!example] 内容概括
> 已知……。求/设计/分析……
>
> **解：** 分步骤解答。
```

三部分缺一不可：标题概括 + 问题陈述 + 解答。

### 解答写作

- 推理步骤要有依据，不能跳跃。
- 多解法标注「法一」「法二」。每个方法的信息归属正确，法一的条件写在法一里。
- 总结句独立成行。

## 补充说明型 callout

`[!note]` 等 callout 内若包含定义和论证示例，应全部留在 callout 内，用空行分段：定义 → 示例 → 结论。不要把示例拆到 callout 外面变成孤立的正文。每段保持句子简短，一个句子说清一件事。

## 本讲小结

- 只列可考的知识点。课程定位、学习方法等不考的内容不放小结。
- 小结不超过 15 条知识点，每条不超过一行。只记结论，不展开推导。
- 对比概念用表格。
- 表格内文字必须完整可读。每行是一句完整的话，多个要点用 `<br>` 分行，禁止用分号、顿号堆砌。
- 表格讲不清的改用文字或列表。不要硬塞进表格，宁可换一种形式让意思明白。

## 格式

- **LaTeX**：行内公式用 `$...$`，独立公式用 `$$...$$`。`\begin{aligned}` 等多行环境必须放在 `$$...$$` 内。取反用 `\overline{A}`（不用 `~A` 或 `!A`）。低电平有效的信号用上划线表示，如 `$\overline{S}$`、`$\overline{EN}$`，不用 Unicode 组合字符（如 S̅̅）。
- **真值表、功能表、对比表** → Markdown 表格
- **状态图** → Mermaid `stateDiagram-v2`
- **流程图** → Mermaid `flowchart`
- **卡诺图** → Markdown 表格 + 文字描述化简过程
- **波形图** → 文字描述关键沿和变化
- **电路图** → 从视频截取关键帧，保存到 `attachments/` 目录，命名格式 `第0X讲-描述.png`。截图后用 `![描述](attachments/第0X讲-描述.png)` 嵌入笔记。

## 文件命名

`第0X讲 精简标题.md`——数字用两位零填充（`第01讲`、`第02讲`……`第10讲`），保证文件列表按讲次正确排序。

## 跨讲关联

前后讲有承接关系的知识点，用 `[[wikilink]]` 链接到对应笔记。例如：「JK 触发器的特性方程见 [[第03讲 触发器]]」。
