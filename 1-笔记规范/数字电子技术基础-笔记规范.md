
# 数字电子技术基础 — 笔记整理规范

## 定位

期末速成笔记。精简，直击考点。无关内容省略，核心内容讲透。

## 基本原则

1. **标题不用编号**。
2. **语句通顺，不啰嗦**。写完读一遍。句子之间要有逻辑衔接，不能跳话题。
3. **少用括号**。解释性插入语拆成独立句子，不要塞进括号里。课程名称后的标注如 `电路原理（基本电路分析方法）` 可以保留。
4. **举例不是例题**。演示概念的举例融入正文，不用 callout，不用 `**解：**`。只有真正的解题活动才用 `[!example]`。

## Callout 规范

### 标题

- callout 标题统一用中文。
- 标题是对内容的**精炼总结**，不重复 callout 类型。`[!example]` 已经表明是例题，标题直接写内容概括，不写"例："。

### 类型

| Callout | 用途 |
|---------|------|
| `[!abstract]` | 本讲定位 |
| `[!note]` | 补充说明 |
| `[!info]` | 背景知识 |
| `[!tip]` | 记忆技巧 |
| `[!warning]` | 易错点 |
| `[!important]` | 核心结论、必背公式、考点 |
| `[!example]` | 例题（仅限满足准入清单的） |
| `[!danger]` | 禁止做法 |

## 例题规范

### 准入清单（全部满足才是例题）

1. 有明确的已知条件
2. 有明确的待求目标（求/设计/分析/计算）
3. 可独立存在
4. 不是论证演示环节
5. 可出成作业题或考题

### 格式

```
> [!example] 内容概括（不写"例："）
> 已知……。求/设计/分析……（完整的已知条件和待求目标）
>
> **解：** 分步骤解答。
```

三个部分缺一不可：标题概括 + 问题陈述 + 解答。

### 解答写作

- 每一步推理要有依据，不能跳跃。读者应能跟随每一步的逻辑。
- 多解法时标注「法一」「法二」。每个方法的信息归属要正确：法一用的条件写在法一里，不要放在外面干扰法二。
- 总结句独立成行，不塞在最后一个方法里。

## 内容取舍

- **保留**：知识点、公式、结论、分析方法、设计步骤、经典例题、易错点、原理、原因、推导过程
- **精简或省略**：课程行政安排、人物介绍、历史故事、生活类比
- **视频中老师强调的重点**：用 `[!important]` 突出
- **过渡段落**：承上启下、章节衔接、背景铺垫等不考的内容，直接删除。每一段落笔前问自己：这段考吗？不考就不写。

## 本讲小结

- 只列可考的知识点。课程定位、学习方法等不考的内容不放小结。
- 对比概念用表格，不用段落。
- 表格内文字必须**完整可读**。学生不看正文也能看懂每一行在说什么。禁止用"二转八三位一组"这种电报式缩写。
- 表格内多个要点用 `<br>` 分行，每行是一句完整的话。

## 格式

- LaTeX：行内 `$...$`，独立 `$$...$$`，取反用 `\overline{A}`
- 真值表、功能表、对比表 → Markdown 表格
- 状态图 → Mermaid `stateDiagram-v2`
- 流程图 → Mermaid `flowchart`
- 卡诺图 → 表格+文字描述
- 波形图 → 文字描述关键沿和变化
