# 第01讲 课程导论


## 一、什么是数字信号处理

> 用**数值计算**的方法对信号进行处理。

核心问题：
- 计算什么？
- 数值从哪里来？

## 二、数字信号的三大来源

### 1. 计算机输入输出
计算机是典型的数字设备。例如键盘按键对应 ASCII 码，字符 'A' 的键值为 `01000001`。

### 2. 数码设备信号
如图像在计算机中以二进制数据存储：
- 黑白图像中：黑 = `0`，白 = `255`（即 `11111111`，8 个 1）
- 本质是二进制数据存储在设备中

### 3. 模拟信号数字化（通信中最常用）
通过**时间离散 + 幅值量化**将模拟信号转为数字信号。

**示例：语音增量编码调制**
1. 用单位信号采样连续信号
2. 采样值与量化值比较：
   - 采样值 > 量化值 → 记为 `1`，量化值 +1
   - 采样值 < 量化值 → 记为 `0`
3. 下一采样周期重复
4. 得到数字信号，按位存储

## 三、数字信号处理的实现方式

### 方式一：软件处理（算法仿真）
- 设计系统仿真模型（如移动通信信道）
- 修正传统参数
- 通过实验不断改进
- 通常称为**算法**

### 方式二：软硬件结合（实际设备）
- 基于 DSP、ARM、FPGA 等芯片
- 算法控制硬件输入输出
- 成为具有特殊功能的实际设备

> 课堂上学的是理论，这些理论可以直接转换成应用。**应用性很强**。

## 四、数字信号处理的特点

| 特点 | 说明 |
|------|------|
| **灵活性强** | 数据存于存储器，改变几个参数就能改变算法结果（如深度学习：算法成熟，不同场景参数不同） |
| **高精度** | 精度取决于位数：8位 → 16位 → 32位 → 64位 |
| **高稳定性** | 与半导体制造技术相关，技术越成熟越稳定 |
| **易于大规模集成** | 数字元件规范性高，可大规模生产 |
| **低频/高频优势** | 模拟电路的电容电感在极低/极高频率不稳定，数字系统参数设定后不受自然因素影响 |

## 六、课程三大知识模块

1. **离散时间信号及运算**
   - 与连续时间信号有很大不同
   - 一开始就要把思路转到离散信号的规律上

2. **三种变换**（易混淆，需对比差异）
   - 傅立叶变换
   - Z 变换
   - 离散傅立叶变换

3. **滤波器设计**
   - 广义的滤波器
   - 不仅可滤波，还可做很多 DSP 处理

## 七、学习方法建议

1. **掌握每类习题的方法** — 每次课对应一个类型的题目
2. **做笔记** — 好记性不如烂笔头
3. **做题** — 针对上课内容做对应作业题
4. **及时复习** — 不是泛泛看书，而是随手拿起题目自己动手做
5. **投入时间** — 学习是从「不熟悉 → 熟悉 → 精通」的过程，花的时间越多越精通

## 📋 关键概念

- **数字信号处理**：用数值计算的方法对信号进行处理
