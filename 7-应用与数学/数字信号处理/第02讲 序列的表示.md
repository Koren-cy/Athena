# 第02讲 序列的表示


## 一、连续时间信号 vs 离散时间信号

| 对比项      | 连续时间信号                   | 离散时间信号（序列）                |
| -------- | ------------------------ | ------------------------- |
| 时域       | $f(t) = \sin\Omega t$    | $x(n) = \sin\omega n$     |
| 自变量      | $t$（连续时间）                | $n$（整数序号，无具体时间概念）         |
| 角频率      | $\Omega = 2\pi f$（模拟角频率） | $\omega$（数字频率）            |
| 频域分析     | 连续信号傅立叶变换                | 序列傅立叶变换（离散信号的傅立叶变换）       |
| 拉普拉斯变换对应 | 拉普拉斯变换                   | Z 变换                      |
| 特有变换     | —                        | DFT（离散傅立叶变换）、FFT（快速傅立叶变换） |

> **FFT 的重要性**：在计算机实现频谱分析时，FFT 是重要的理论基础。例如 4G 通信标准 LTE 中的 OFDM，就是直接使用离散傅立叶变换设计的结果。

## 二、序列的三种表示方法

在数字信号处理中，离散时间信号称为**序列**。序列中的每个元素称为**样值**，$n$ 为序列的自变量（整数序号）。

### 方法 1：集合表示法

用大括号将样值按顺序列出，用逗号分隔。**$n=0$ 的样值下方加下划线**以示标记。

> **示例**：$x(n) = \{1, 2, 3, 4, 5\}$ 表示：
> - $n=0$ 时 $x(0)=1$（下划线标记）
> - $n=1$ 时 $x(1)=2$
> - $n=2$ 时 $x(2)=3$
> - $n=3$ 时 $x(3)=4$
> - $n=4$ 时 $x(4)=5$

特点：
- 顺序固定，不可随意调换
- 样值顺序隐含了自变量 $n$ 的信息

### 方法 2：公式表示法

用数学公式直接表达序列。

> **示例**：
> - 正弦序列：$x(n) = \sin\omega n$
> - 实指数序列：$x(n) = a^n$

### 方法 3：图形表示法

用坐标系图形表示序列：
- **横坐标**：自变量 $n$（只取整数）
- **纵坐标**：样值大小
- 用**火柴梗**（竖直线段）表示每个样值，高度代表样值大小

> 图形表示法直观，但较占篇幅。三种表示方法可任意使用并相互转换。

## 三、三种常用典型序列

### 1. 单位脉冲序列 $\delta(n)$

$$
\delta(n) = \begin{cases}
1, & n = 0 \\
0, & n \neq 0
\end{cases}
$$

- 符号与信号与系统中的单位冲激函数 $\delta(t)$ 相同
- 但**数字领域没有无穷大概念**，$\delta(n)$ 只有一根火柴梗，大小正好为 1
- **集合表示**：$\delta(n) = \{ \underline{1}, 0, 0, 0, \dots \}$

**运算规则**：
- **加权**：$a\delta(n)$ — 在 $\delta(n)$ 前面乘以常数 $a$
- **移位**：$\delta(n - k)$ — 在坐标轴上移动。**左加右减**：
  - $\delta(n + m)$：左移 $m$ 个单位
  - $\delta(n - m)$：右移 $m$ 个单位

> **左加右减规则**：$\delta(n + 2)$ 表示 $\delta(n)$ 左移 2 个单位（$n= -2$ 处值为 1）

### 2. 单位阶跃序列 $u(n)$

$$
u(n) = \begin{cases}
1, & n \geq 0 \\
0, & n < 0
\end{cases}
$$

- 与连续时间单位阶跃信号的区别：
  - 连续阶跃：原点处从 0 到 1 跳变，**无定义**
  - 离散阶跃：$n=0$ 处函数值明确为 1，之后每个整数位置都是 1
- 可加权：$2u(n)$ 幅度翻倍
- 可移位：$u(n + k)$

### 3. 单位矩形序列 $R_N(n)$

$$
R_N(n) = \begin{cases}
1, & 0 \leq n \leq N-1 \\
0, & \text{其他}
\end{cases}
$$

- $N$：样值个数（**大写**）
- $n$：自变量（**小写**）
- 样值范围：从 $n=0$ 到 $n=N-1$，共 $N$ 个样值

> **示例**：$R_4(n)$ 共有 4 个样值，最后 $n=3$

## 四、单位脉冲序列的特殊应用

由于 $\delta(n)$ 只有一根火柴梗，可通过**加权**和**位移**组合，**表示任意序列**。

### 基本原理

任意序列 $x(n)$ 都可以表示为加权、移位的单位脉冲序列之和：

$$
x(n) = \sum_{k=-\infty}^{\infty} x(k) \cdot \delta(n - k)
$$

### 例题

> **例题**：一个由 6 个样值组成的序列图形，用 $\delta(n)$ 的加权和位移表示。

**解题步骤**：

1. 找到第一个样值（$n=-2$ 处）：幅值 = 2，位置为左移 2 单位
   - 表示：$2\delta(n + 2)$

2. 找到第二个样值（$n=-1$ 处）：幅值 = 0.5，位置为左移 1 单位
   - 表示：$0.5\delta(n + 1)$

3. 原点处（$n=0$）样值为 0，可省略不写

4. 后续样值依此类推...

最终结果：序列可写为多个 $a \cdot \delta(n + k)$ 之和

> 同样，单位阶跃序列 $u(n)$ 和单位矩形序列 $R_N(n)$ 也可以用单位脉冲序列 $\delta(n)$ 来表示。

## 关键公式

| 序号  | 公式                                                                         | 说明                  |
| --- | -------------------------------------------------------------------------- | ------------------- |
| 1   | $x(n) = \sin\omega n$                                                      | 正弦序列，$\omega$ 为数字频率 |
| 2   | $\delta(n) = \begin{cases}1, & n=0 \\ 0, & n\neq 0\end{cases}$             | 单位脉冲序列              |
| 3   | $u(n) = \begin{cases}1, & n\geq 0 \\ 0, & n< 0\end{cases}$                 | 单位阶跃序列              |
| 4   | $R_N(n) = \begin{cases}1, & 0\leq n \leq N-1 \\ 0, & \text{其他}\end{cases}$ | 单位矩形序列              |
| 5   | $x(n) = \sum_{k} x(k)\delta(n-k)$                                          | 任意序列的 $\delta$ 展开   |

## 易错点

- $\delta(n)$ **不是**冲激函数 — 它是有限值 1，不是无穷大，不要与连续 $\delta(t)$ 混淆
- 集合表示法中**下划线标记的是 $n=0$ 的样值**，不是第一个元素
- 移位规则：**左加右减**（$\delta(n+2)$ 左移，$\delta(n-2)$ 右移），与直觉相反
- $R_N(n)$ 中样值个数为 $N$，但最后一个序号是 $N-1$（从 0 开始计数）
