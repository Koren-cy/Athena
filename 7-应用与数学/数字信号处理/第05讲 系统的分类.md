# 第05讲 系统的分类


## 一、时域离散系统的基本概念

时域离散系统是将输入序列按所需目的转换成输出序列的运算。

$$ y(n) = T[x(n)] $$

- $y(n)$：输出序列
- $T[\cdot]$：某种特定的运算
- $x(n)$：输入序列

### 基本运算单元

| 单元 | 运算关系 |
|------|---------|
| **加法器** | $y(n) = x_1(n) + x_2(n)$ |
| **乘法器** | $y(n) = x_1(n) \cdot x_2(n)$ |

---

## 二、系统分类总览

| 分类依据            | 类别                |
| --------------- | ----------------- |
| 是否满足齐次性和叠加性     | **线性** / 非线性      |
| 系统参数是否随时间变化     | **时不变（移不变）** / 时变 |
| 输出是否仅由当前及过去输入决定 | 因果 / 非因果          |
| 有界激励是否产生有界响应    | 稳定 / 不稳定          |

本讲重点讲解**线性/非线性**和**时不变/时变**的判断方法。

---

## 三、线性系统与非线性系统

### 定义

系统满足**线性叠加原理**（叠加性 + 齐次性/比例性）：

$$ T[a_1 x_1(n) + a_2 x_2(n)] = a_1 T[x_1(n)] + a_2 T[x_2(n)] = a_1 y_1(n) + a_2 y_2(n) $$

| 性质 | 含义 |
|------|------|
| **齐次性（比例性）** | 输入扩大 $a$ 倍，输出也扩大 $a$ 倍 |
| **叠加性（可加性）** | 多个输入之和的输出等于各输入输出之和 |

### 判断步骤（三步法）

```
第一步：计算 a₁y₁(n) + a₂y₂(n)
       将 y(n) 分别替换为 y₁(n)、y₂(n)，x(n) 分别替换为 x₁(n)、x₂(n)
       得到系统对独立输入的响应，再叠加

第二步：计算 T[a₁x₁(n) + a₂x₂(n)]
       将原式中所有 x(n) 替换为 a₁x₁(n) + a₂x₂(n)
       得到系统对叠加输入的直接响应

第三步：对比两个结果是否相等
       相等 → 线性系统
       不等 → 非线性系统
```

---

### 例题 1：判断 $y(n) = x(n) + b$ 是否为线性

> **第一步：计算 $a_1 y_1(n) + a_2 y_2(n)$**
>
> 由 $a_1 y_1(n) = a_1 x_1(n) + b$
>
> $a_2 y_2(n) = a_2 x_2(n) + b$
>
> $a_1 y_1(n) + a_2 y_2(n) = a_1 x_1(n) + a_2 x_2(n) + 2b$
>
> **第二步：计算 $T[a_1 x_1(n) + a_2 x_2(n)]$**
>
> $y(n) = [a_1 x_1(n) + a_2 x_2(n)] + b = a_1 x_1(n) + a_2 x_2(n) + b$
>
> **第三步：对比**
>
> $a_1 y_1(n) + a_2 y_2(n) = a_1 x_1(n) + a_2 x_2(n) + 2b$
>
> $T[a_1 x_1(n) + a_2 x_2(n)] = a_1 x_1(n) + a_2 x_2(n) + b$
>
> 两者相差一个 $b$ → **非线性系统** ✗

---

### 例题 2：判断 $y(n) = n \cdot x(n)$ 是否为线性

> **第一步：计算 $y_1(n) + y_2(n)$**
>
> $y_1(n) = n \cdot x_1(n)$
>
> $y_2(n) = n \cdot x_2(n)$
>
> $y_1(n) + y_2(n) = n \cdot x_1(n) + n \cdot x_2(n)$
>
> **第二步：计算 $T[x_1(n) + x_2(n)]$**
>
> $y(n) = n \cdot [x_1(n) + x_2(n)] = n \cdot x_1(n) + n \cdot x_2(n)$
>
> **第三步：对比**
>
> 两者相等 → **线性系统** ✓

> **注意：** 系数 $n$ 是系统参数，在运算中不需要改动。

## 四、时不变系统与时变系统

### 定义

系统对输入信号的运算关系在整个运算过程中不随时间变化而变化。系统参数（幅度、自变量）不随时间改变。

| 类型 | 特征 |
|------|------|
| **时不变（移不变）** | 输入移位 $n_0$，输出也相应移位 $n_0$：$T[x(n-n_0)] = y(n-n_0)$ |
| **时变** | 系统参数随时间/自变量变化 |

### 判断步骤（三步法）

```
第一步：计算 y(n-n₀)
       将原式中所有 n 替换为 n-n₀

第二步：计算 T[x(n-n₀)]
       将原式中所有 x(n) 替换为 x(n-n₀)

第三步：对比
       y(n-n₀) = T[x(n-n₀)] → 时不变
       y(n-n₀) ≠ T[x(n-n₀)] → 时变
```

---

### 例题 3：判断 $y(n) = x(n) + b$ 是否为时不变

> **第一步：$y(n-n_0) = x(n-n_0) + b$**
>
> **第二步：$T[x(n-n_0)] = x(n-n_0) + b$**
>
> **第三步：对比**
>
> 两者相等 → **时不变系统** ✓

---

### 例题 4：判断 $y(n) = n \cdot x(n)$ 是否为时不变

> **第一步：$y(n-n_0) = (n-n_0) \cdot x(n-n_0)$**
>
> **第二步：$T[x(n-n_0)] = n \cdot x(n-n_0)$**
>
> **第三步：对比**
>
> $y(n-n_0) = (n-n_0) \cdot x(n-n_0)$
>
> $T[x(n-n_0)] = n \cdot x(n-n_0)$
>
> 两者不等 → **时变系统** ✗

> 从定义速判：幅度参数 $n$ 不是常数，而是自变量的函数，所以系统是时变的。

---

## 五、快速判断方法

### 线性系统速判

抓住线性的两个特征：**输入输出的齐次性**和**叠加性**。

| 系统 | 分析 | 结论 |
|------|------|------|
| $y(n) = x(n) + b$ | $y$ 一次，$x$ 一次，但常数 $b$ 为零次 → 不满足齐次性 | **非线性** |
| $y(n) = n \cdot x(n)$ | $y$ 一次，$x$ 一次 → 齐次 | **线性** |

### 时不变系统速判

关注两个参数：
1. **自变量尺度**：$y(n)$ 和 $x(n)$ 中的 $n$ 尺度应相同
2. **幅度参数**：幅度应为常数，不随时间变化

---

### 例题 5：判断 $y(n) = x^2(n)$

> **线性判断：** $y$ 是一次的（输出本身一次方），$x$ 是二次的（输入平方）
> → 不满足齐次性 → **非线性系统**
>
> **时不变判断：** $y$ 和 $x$ 的自变量都是 $n$（尺度相同），$x$ 的幅度是常数
> → **时不变系统**
>
> **结论：非线性时不变系统** ✓

---

### 例题 6：判断 $y(n) = x(n^2)$

> **线性判断：** $y$ 是一次，$x$ 也是一次 → 齐次 → **线性系统**
>
> **时不变判断：** 自变量 $y$ 用 $n$，$x$ 用 $n^2$ → 自变量尺度不同
> → **时变系统**
>
> **结论：线性时变系统** ✓

---

## 六、线性系统的直觉理解（补充）

以上三步法是严格的数学判据。在工程中还有更直观的理解方式：

### 1. 静态线性（Static Linearity）

将输入"冻结"为直流值，若输入输出关系是**过原点的直线**，则系统具有静态线性。静态线性 + 无记忆（输出仅取决于当前输入）→ 系统一定是线性的。例如欧姆定律 $I=V/R$。

### 2. 正弦保真性（Sinusoidal Fidelity）

**这是频域分析之所以有效的根基**：线性系统输入正弦波 → 输出必定是**同频率**的正弦波（仅幅度和相位可变化）。正弦波是**唯一**具有此性质的波形。正因为有此性质，傅里叶变换（将信号分解为正弦波之和）才如此强大。

### 3. 乘法歧义

乘以**常数**是线性（放大器），乘以**另一信号**是非线性（调制器）。$y(n)=n\cdot x(n)$ 中 $n$ 是系统参数不是信号，所以是线性的。

### 4. 可交换性

两个线性系统级联时，交换顺序不影响结果。"先放大再滤波"与"先滤波再放大"效果相同（理想情况下）。

## 关键公式

| 系统类型 | 数学条件 |
|---------|---------|
| 线性系统 | $T[a_1 x_1(n) + a_2 x_2(n)] = a_1 T[x_1(n)] + a_2 T[x_2(n)]$ |
| 时不变系统 | $T[x(n-n_0)] = y(n-n_0)$ |
| LTI 系统 | 同时满足线性和时不变性 |

## 易错点

1. **常数项破坏线性**：$y(n) = x(n) + b$ 中的常数 $b$ 会被误以为不影响线性，但实际上它破坏了齐次性。
2. **自变量前的系数**：$y(n) = n \cdot x(n)$ 中的系数 $n$ 是系统参数，判断线性时不需要改动它；但判断时变时，它作为幅度参数会暴露时变性。
3. **三步法要严谨**：第一步是对 $n$ 整体移位（所有 $n$ 变 $n-n_0$），第二步是替换输入 $x(n)$ 为 $x(n-n_0)$，不可混淆。
4. **简化判断时的"次数"概念**：看的是 $y$ 表达式中输入 $x$ 的次数，而不是 $n$ 的次数。
