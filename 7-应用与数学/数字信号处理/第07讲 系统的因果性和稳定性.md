# 第07讲 系统的因果性和稳定性


## 一、因果系统

### 定义

**因果**：有因才有果。系统的输出不发生在输入之前。

对于离散时间系统，在时间轴上比较输入和输出的时序序号：

- 输出序号 $\ge$ 输入序号 → 因果
- 输出序号 < 输入序号（超前） → 非因果

**示例**：
- $y(n) = a x(n) + b$ → 因果（同时刻）
- $y(n) = a x(n-1) + b$ → 因果（滞后）
- $y(n) = a x(n+1) + b$ → 非因果（超前）

> 当 $n=0$ 时，$y(0) = a x(1) + b$，输出序号为 0，输入序号为 1，输出发生在输入之前，故为非因果。

### LTI系统因果性的充要条件

对于线性时不变系统（LTI），因果性的充要条件是：

$$
h(n) = 0, \quad n < 0
$$

即单位脉冲响应在 $n<0$ 时全部为零。这等价于系统在输入作用之前初始储能为零（initial rest）。

### 判断因果性的典型例题

> **例1**：$y(n) = x(n) + x(n+1)$
> 
> 含有超前项 $x(n+1)$，输出超前于输入，**非因果系统**。

> **例2**：$y(n) = x(n-n_0)$
> 
> - 当 $n_0 > 0$ 时，滞后，**因果**
> - 当 $n_0 = 0$ 时，同时，**因果**
> - 当 $n_0 < 0$ 时，超前，**非因果**

> **例3**：$y(n) = x(n^2)$（复杂函数形式）
> 
> 代入 $n=1$ → $y(1) = x(1)$，同时，看似因果。
> 代入 $n=2$ → $y(2) = x(4)$，输出超前于输入，**非因果**。
> 
> **灵活代入法**：将不同的 $n$ 值代入，检查是否出现输出超前于输入的情况。

## 二、稳定系统

### 定义

**稳定性（BIBO）**：对于有界输入，系统产生的输出也是有界的。

$$
\text{若 } |x(n)| \le M_x < \infty \quad \Rightarrow \quad |y(n)| \le M_y < \infty
$$

### LTI系统稳定性的充要条件

单位脉冲响应 **绝对可和**：

$$
\sum_{n=-\infty}^{\infty} |h(n)| < \infty
$$

这里"绝对"指取绝对值，"可和"指求和结果为有限值而非无穷大。

### 判断稳定性的步骤

1. 先判断系统是否为线性时不变（LTI）
2. 若是 LTI → 用单位脉冲响应的充要条件判断
3. 若不是 LTI → 直接用有界输入有界输出（BIBO）的定义判断

> **例4**：$y(n) = e^{x(n)}$
> 
> - **线性判断**：不符合齐次性和叠加性，**非线性系统**
> - **稳定性**：用一般定义判断。若 $x(n)$ 有界，则 $e^{x(n)}$ 也有界，**稳定**。

> **例5**：$h(n) = u(n)$（已知 LTI，直接给 $h(n)$）
> 
> - **因果性**：$u(n)$ 在 $n<0$ 时为零，**因果**
> - **稳定性**：$\displaystyle\sum_{n=-\infty}^{\infty} |u(n)| = \sum_{n=0}^{\infty} 1 = \infty$，无穷多个 1 相加 → 和无穷大 → **不稳定**

> **例6**：$h(n) = a^n u(n)$（已知 LTI）
> 
> - **因果性**：含 $u(n)$ 因子，$n<0$ 时 $h(n)=0$，**因果**
> - **稳定性**：$\displaystyle\sum_{n=0}^{\infty} |a|^n$
>   - 等比数列求和：$\displaystyle\lim_{N\to\infty} \frac{1-|a|^N}{1-|a|}$
>   - 当 $|a|<1$ 时，$|a|^N \to 0$，和为 $\frac{1}{1-|a|}$（有限值）→ **稳定**
>   - 当 $|a|>1$ 时，$|a|^N \to \infty$，和为无穷大 → **不稳定**
>   - 当 $|a|=1$ 时，退化为 $u(n)$ 的情况 → **不稳定**

## 关键公式

1. **LTI因果性充要条件**：$h(n) = 0,\ n<0$
2. **LTI稳定性充要条件**：$\displaystyle\sum_{n=-\infty}^{\infty} |h(n)| < \infty$
3. **等比数列前 $N$ 项和**：$S_N = \frac{1-q^N}{1-q}$
4. **等比数列无穷项和（$|q|<1$）**：$S_\infty = \frac{1}{1-q}$

## 易错点

1. **因果性与时间轴序号的关系**：序号 0 发生在序号 1 之前。$y(0)$ 依赖 $x(1)$ 即为超前（非因果），不要搞反。
2. **$n_0$ 符号陷阱**：$y(n) = x(n-n_0)$ 中，$n_0>0$ 才是因果（滞后），$n_0<0$ 是非因果（超前），不要凭直觉以为减号就是滞后。
3. **复杂函数形式需代入验证**：如 $y(n) = x(n^2)$ 表面看 $n$ 与 $n^2$ 都是正数，但代入 $n=2$ 即发现 $y(2)$ 依赖 $x(4)$，超前于当前时刻。
4. **判断顺序**：先判断是否 LTI，再选择使用充要条件还是一般定义，不要混用。
5. **$u(n)$ 的稳定性**：$h(n) = u(n)$ 虽然因果，但无穷多个 1 相加为无穷大，不稳定。不要因序列简单就误判为稳定。
6. **等比数列收敛条件**：$|a|<1$ 时 $a^n \to 0$，和有限；$|a|>1$ 时发散；$|a|=1$ 时需要单独分析（退化为常数序列，和发散）。这是判断 $h(n) = a^n u(n)$ 稳定性的关键。
