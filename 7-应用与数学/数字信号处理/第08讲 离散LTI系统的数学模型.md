# 第08讲 离散LTI系统的数学模型

> 来源：[[DSP 数字信号处理（超浓缩版）]] 第8讲

## 离散系统的基本单元

| 单元 | 符号 | 功能 |
|------|------|------|
| 加法器 | $\Sigma$ | 序列相加 |
| 乘法器（加权器）| $\times a$ | 序列乘以常数 |
| 延时器（Delay）| $z^{-1}$ | 序列右移一位 |

延时器的作用：$y_n$ 经过延迟器输出 $y_{n-1}$。序列内容不变，整体右移一位。

> 如 $y_n = \{1,2,3,4,5\}$（原点在第一个），则 $y_{n-1} = \{\_,1,2,3,4,5\}$（右移一位，第一位补零）

## 一阶时域离散系统

典型结构：输入 $x_n$ 与输出反馈项在加法器叠加。

加法器输出 $y_n$ 的表达式：
$$
y_n = x_n - a\, y_{n-1}
$$

习惯上把输出放在等号左边，输入放在右边：
$$
y_n + a\, y_{n-1} = x_n
$$

式中仅有一阶延迟 $(n-1)$，称为**一阶线性常系数差分方程**。

## 差分方程的一般形式

n 阶差分方程：

$$
\sum_{i=0}^{N} a_i\, y_{n-i} = \sum_{j=0}^{M} b_j\, x_{n-j}
$$

其中 $y_n$ 是未知待求的输出序列，$x_n$ 是已知输入序列，$a_i$ 和 $b_i$ 为常数系数。

> **核心结论**：常系数线性差分方程描述的系统是线性时不变系统（LTI）。

## 解差分方程的三种方法

| 方法 | 特点 | 使用场景 |
|------|------|----------|
| 经典法 | 纯数学求解 | 数学基础好时使用 |
| 递推法 | 逐项计算，逻辑简单但繁琐 | 手算少量项、计算机迭代 |
| **z 变换法** | 转为代数运算，最强大 | 后期重点学习 |

## 递推法详解

核心思想：将 $y_n$ 放在方程左边，其余项移到右边，从初始条件开始逐项递推。

### 例1：斐波那契兔子序列

**问题**：第1个月有1对兔子，第2个月有2对，求第4个月的兔子对数。

**列方程**：
- $y_n$ = 第 $n$ 个月的兔子对数
- 第 $n$ 个月 = 上上个月兔子 + 上个月兔子

$$
y_n = y_{n-2} + y_{n-1},\quad n \ge 3
$$

这是一个**齐次差分方程**（只有输出项，没有输入项）。

**递推求解**：
- 初始条件：$y_1 = 1$（第1个月有1对），$y_2 = 2$（第2个月有2对）
- $y_3 = y_2 + y_1 = 2 + 1 = 3$
- $y_4 = y_3 + y_2 = 3 + 2 = 5$

> 初始条件是由系统初始状态直接给出的，不是从差分方程推出来的。

### 例2：给定差分方程求 $y_3$

已知差分方程及初始条件 $y_{-1}=1$，以及序列 $x_n$ 的各样值，用递推法求 $y_3$。

**步骤**：
1. 将方程整理为 $y_n =$ 形式
2. 代入 $n=0$ 求 $y_0$：需使用 $y_{-1}$、$x_0$、$x_{-1}$
3. 代入 $n=1$ 求 $y_1$：需使用上一步求出的 $y_0$
4. 依次递推至 $y_3$

> 注意集合形式序列的读法：带下划线的样值对应 $n=0$，其左边是 $n=-1$，右边是 $n=1$。

### 例3：由差分方程求单位脉冲响应 $h_n$

已知差分方程 $y_n = \frac{1}{2} y_{n-1} + x_n$，求 $h_n$。

**方法**：利用单位脉冲响应的定义，令输入 $x_n = \delta_n$，输出即为 $h_n$。

$$
h_n = \frac{1}{2} h_{n-1} + \delta_n
$$

**递推求解**：
- $h_0 = \frac{1}{2} h_{-1} + \delta_0$，系统因果 $\Rightarrow h_{-1}=0$，$\delta_0=1 \Rightarrow h_0 = 1$
- $h_1 = \frac{1}{2} h_0 + \delta_1 = \frac{1}{2} \times 1 + 0 = \frac{1}{2}$
- $h_2 = \frac{1}{2} h_1 + \delta_2 = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$
- 依此类推，归纳出通项公式

$$
h_n = \left(\frac{1}{2}\right)^n u_n
$$

> 递推若干项后观察规律，可归纳出通项公式。加上 $u_n$ 表示系统的因果性。

## 关键公式

1. **一阶差分方程**：$y_n + a y_{n-1} = x_n$
2. **n 阶差分方程一般形式**：$\displaystyle\sum_{i=0}^{N} a_i y_{n-i} = \sum_{j=0}^{M} b_j x_{n-j}$
3. **递推法核心**：$y_n = \text{已知项的组合} \Rightarrow$ 逐次代入计算
4. **单位脉冲响应与差分方程的关系**：$x_n = \delta_n \Rightarrow y_n = h_n$

## 易错点

1. **延时器的方向**：$y_{n-1}$ 是右移（延迟），序号减 1 对应时间上的滞后，不是超前。
2. **初始条件与递推起点**：递推法需要从给定的初始条件开始，$y_{n-1}$ 等初始值必须已知或由因果性假设为零，不能遗漏。
3. **集合形式序列的索引**：下划线标记 $n=0$ 的位置，左右分别为 $n=-1$ 和 $n=1$，读题时要仔细定位。
4. **齐次差分方程的含义**：方程右边没有输入 $x_n$ 项，只有输出 $y_n$ 的移位项，不要误以为方程写错了。
5. **因果性在递推中的作用**：因果系统的 $h_n$ 在 $n<0$ 时为零，这为递推提供了关键的初始条件（$h_{-1}=0$），不要忘记使用。
6. **通项公式后的 $u_n$**：从递推归纳出的通项公式默认只适用于 $n\ge 0$，需要显式乘以 $u_n$ 表示因果性，否则表达式不完整。
