# 第09讲 模拟信号数字化——采样的数学过程

> [!abstract] 本讲定位
> 本讲属于课程第一章的收尾，回答"序列从何而来"这一根本问题。前承序列的基本概念（第02-08讲），后启离散时间系统的频域分析。采样定理是整个数字信号处理的理论基石，后续所有变换（DTFT、z 变换、DFT）都以采样得到的离散序列为分析对象。

## 一、从模拟到数字：三步转换

通信系统中，典型的模拟信号如语音信号，其自变量为连续时间 $t$。要进入数字系统传输或处理，必须将连续时间函数转换为离散的。

模拟信号转为数字信号需要三个步骤：**采样、量化、编码**。其中量化与编码属于通信原理的范畴。数字信号处理课程聚焦于第一步——连续时间信号如何通过采样转换为序列。

**核心问题**：在采样过程中，信号会不会发生变化？发生什么变化？如何设计采样参数，才能在接收端无失真地还原信号？

## 二、理想采样的数学模型

### 2.1 乘法器模型

采样的传统模型是一个乘法电路。乘法器的两个输入端分别为：

- 原始模拟信号 $x_a(t)$
- 采样信号 $p_\delta(t)$（周期冲激串）

输出为两者相乘的结果：$\hat{x}_a(t) = x_a(t) \cdot p_\delta(t)$。

> [!note] 工程实现
> 现代电子技术中可用 AD 转换器（模数转换器）将采样、量化、编码一次完成。数字信号处理课程侧重算法原理，以下讨论传统模型中的数学过程。

### 2.2 理想冲激串

**定义**：理想采样使用周期单位冲激串（impulse train）作为采样信号：

$$p_\delta(t) = \sum_{n=-\infty}^{\infty} \delta(t - nT)$$

其中 $T$ 为采样间隔（采样周期），单位：秒。对应的采样频率 $f_s = \dfrac{1}{T}$（Hz），采样角频率 $\Omega_s = \dfrac{2\pi}{T}$（rad/s）。

### 2.3 采样信号的表达式

将 $p_\delta(t)$ 代入乘法器模型：

$$\hat{x}_a(t) = x_a(t) \cdot p_\delta(t) = x_a(t) \sum_{n=-\infty}^{\infty} \delta(t - nT)$$

由冲激函数的**筛选特性**（$\delta(t - nT)$ 仅在 $t = nT$ 处非零），$x_a(t)$ 在每个冲激点被"取出"样值：

$$\hat{x}_a(t) = \sum_{n=-\infty}^{\infty} x_a(nT) \, \delta(t - nT)$$

这就是**理想采样信号**的一般表达式。

> [!important] 核心公式：理想采样信号
> $$\hat{x}_a(t) = \sum_{n=-\infty}^{\infty} x_a(nT) \, \delta(t - nT)$$
>
> 其中 $x_a(nT)$ 是 $x_a(t)$ 在 $t = nT$ 时刻的样值，$\delta(t - nT)$ 标记采样时刻。

## 三、从采样信号到离散序列

### 3.1 关键观察

$\hat{x}_a(t)$ 中虽然只保留了离散时刻的样值，但其自变量仍是连续时间 $t$，$\delta(t - nT)$ 也是连续时间函数。因此 $\hat{x}_a(t)$ **仍然是连续时间信号**，并非离散序列。

在离散时间系统中，我们只关心样值本身。将求和符号和 $\delta(t - nT)$ 去掉，留下的就是反映 $x_a(t)$ 在采样时刻取值的样值序列：

$$x(n) \triangleq x_a(nT) = x_a(t)\big|_{t=nT}$$

由 $x(n)$ 构成的就是**时域离散序列**。

> [!important] 核心公式：序列与模拟信号的关系
> $$x(n) = x_a(nT)$$
>
> 其中 $n$ 为整数序号，$T$ 为采样间隔。

### 3.2 实用技巧

做题时若只需求采样后的序列，无需写出冲激串和求和。直接将 $x_a(t)$ 中的 $t$ 替换为 $nT$ 即可。

### 3.3 示例：正弦信号的采样

设模拟信号 $x_a(t) = \cos(2\pi f t + \phi)$，以间隔 $T$ 采样：

$$x(n) = x_a(nT) = \cos(2\pi f T n + \phi)$$

将常数因子合并，定义**数字频率**：

$$\omega_0 \triangleq 2\pi f T = 2\pi \frac{f}{f_s}$$

则序列写为：

$$x(n) = \cos(\omega_0 n + \phi)$$

**物理意义**：数字频率 $\omega_0$ 是模拟频率 $f$ 与采样频率 $f_s$ 的比值乘以 $2\pi$，反映了每个采样间隔内的相位增量。模拟信号的初始相位 $\phi$ 在采样后保持不变。

## 四、采样后序列的周期性

采样后的序列是否具有周期性，取决于采样频率与信号频率的关系。

设信号频率为 $f_m$，采样周期为 $T_s$（$T_s = 1/f_s$），则：

$$x(n) = \cos\left(2\pi \frac{f_m}{f_s} n\right)$$

令 $\omega_0 = 2\pi \dfrac{f_m}{f_s}$，序列 $x(n) = \cos(\omega_0 n)$ 是周期序列当且仅当 $\dfrac{\omega_0}{2\pi} = \dfrac{f_m}{f_s}$ 为有理数。分以下情况：

**情况一**：$f_s = 2f_m$（恰好满足奈奎斯特速率）

$$x(n) = \cos(\pi n), \quad \text{周期 } N = 2$$

每个模拟周期内恰好有两个样值。

**情况二**：$f_s = 4f_m$

$$x(n) = \cos\left(\frac{\pi}{2} n\right), \quad \text{周期 } N = 4$$

每个模拟周期内有四个样值。

**情况三**：比值 $\dfrac{f_m}{f_s}$ 为无理数

此时 $\dfrac{2\pi}{\omega_0}$ 为无理数，序列无周期。

> [!warning] 易错点
> 并不是 $f_s > 2f_m$ 就能保证序列有周期。序列是否周期，取决于 $\omega_0 / 2\pi = f_m/f_s$ 是否是有理数。

> [!important] 工程设计原则
> 在满足采样定理（$f_s > 2f_m$）的基础上，采样频率还应取为信号频率的**整数倍**，使采样后序列具有周期性，便于后续分析与处理。

## 五、采样定理与频谱分析

### 5.1 采样信号的频谱

设原始模拟信号 $x_a(t)$ 的频谱为 $X_a(j\Omega)$（傅里叶变换），最高频率分量为 $\Omega_m$（即 $X_a(j\Omega) = 0$ 当 $|\Omega| > \Omega_m$）。

理想采样信号 $\hat{x}_a(t)$ 的频谱为原频谱以 $\Omega_s$ 为周期的**周期延拓**：

$$\hat{X}_a(j\Omega) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_a\big(j(\Omega - k\Omega_s)\big)$$

其中 $\Omega_s = \dfrac{2\pi}{T}$ 为采样角频率。

> [!note] 与信号与系统的联系
> 该结论可由时域相乘对应频域卷积推出。冲激串 $p_\delta(t)$ 的傅里叶变换为 $\frac{2\pi}{T} \sum_{k=-\infty}^{\infty} \delta(\Omega - k\Omega_s)$，与 $X_a(j\Omega)$ 卷积即得上式。详细推导见信号与系统课程中"冲激采样"一节。

### 5.2 奈奎斯特采样定理

**定理（奈奎斯特采样定理）**：若 $x_a(t)$ 是带限信号，最高频率为 $f_m$（角频率 $\Omega_m = 2\pi f_m$），则以采样频率 $f_s$ 对其采样。当

$$\Omega_s > 2\Omega_m \quad \text{即} \quad f_s > 2f_m$$

时，采样信号的频谱中，各周期延拓副本互不重叠。此时可用理想低通滤波器从 $\hat{x}_a(t)$ 中唯一地恢复 $x_a(t)$。

满足采样定理的采样频率 $2f_m$ 称为**奈奎斯特采样速率**（Nyquist rate）。

**物理意义**：采样频率必须大于信号最高频率的两倍，才能保证频谱副本之间留有"安全间隙"。否则频谱将发生混叠（aliasing），无法通过滤波恢复原信号。

> [!important] 采样定理（核心定理）
> $$f_s > 2f_m \quad \text{或} \quad \Omega_s > 2\Omega_m$$
>
> 满足该条件时，可从采样信号中唯一恢复原信号。该结论是模数转换的理论基础。

### 5.3 频谱混叠的后果

若不满足采样定理（$f_s \leq 2f_m$），采样信号频谱中各延拓副本将相互重叠。此时使用低通滤波器无法将原信号频谱完整提取，恢复的信号将失真——丢失高频分量的波形特征，无法还原原信号。

> [!info] 工程背景：人耳听觉范围
> 人的正常听力范围约为 20 Hz 至 20 kHz。音频数字系统中，采样频率必须大于 40 kHz 才能避免可听频段内的混叠。CD 音质采用的 44.1 kHz 采样率即基于此原则。

## 六、信号的恢复

### 6.1 频域视角

当满足采样定理时，用一个理想低通滤波器从 $\hat{x}_a(j\Omega)$ 中取出 $k=0$ 的基带频谱（$|\Omega| \leq \Omega_s/2$），即可恢复 $X_a(j\Omega)$，从而恢复 $x_a(t)$。

低通滤波器的另一个作用：**滤除高频分量**。采样信号的频谱中除了基带分量外，还存在周期延拓产生的高频副本。若这些高频分量不被滤除，将在恢复信号中引入干扰。

### 6.2 时域视角

时域上也可直观理解：若采样间隔 $T$ 较小（满足 $f_s > 2f_m$），采样点足够密集，经低通滤波后输出信号与原始信号基本一致。若采样间隔过大（$f_s$ 过小），恢复信号将丢失最高频率分量对应的波形特征，无法还原。

### 6.3 保持器的作用

序列由离散样值组成，样值之间没有定义。接收端需用**保持器**将每个样值的取值在时间上延长，使相邻采样点之间也有定义，从而恢复为连续性较好的连续时间信号。这一步骤在实际 DAC（数模转换器）中由零阶保持器或更高阶保持电路实现。

## 本讲小结

### 知识地图

本讲是第一章的收尾，建立了模拟信号到离散序列的桥梁。采样定理是整个数字信号处理的先决条件——若采样不满足奈奎斯特条件，后续所有离散时间分析（DTFT、z 变换、DFT、滤波器设计）都将因频谱混叠而失效。本讲知识点直接为后续课程中所有以 $x(n)$ 为起点的分析奠定物理基础。

| 概念 | 说明 | 与相关课程的联系 |
|------|------|------------------|
| 理想冲激采样 | 用周期冲激串在时域对模拟信号做理想采样 | 《信号与系统》冲激采样、冲激响应 |
| 采样定理 | $f_s > 2f_m$ 时可唯一恢复原信号 | 《通信原理》奈奎斯特准则、无码间干扰传输 |
| 频谱周期延拓 | 采样使原频谱以 $\Omega_s$ 为周期重复 | 《信号与系统》傅里叶变换的卷积性质 |
| 量化与编码 | 将样值幅度离散化并编码为二进制 | 《通信原理》信源编码 |

### 易错点

- 混淆 $\hat{x}_a(t)$ 与 $x(n)$：前者是连续时间信号（含冲激函数），后者才是离散序列
- 混淆模拟角频率 $\Omega$（rad/s）与数字角频率 $\omega$（rad）：$\omega = \Omega T$
- 误以为满足采样定理后序列必然周期：周期性取决于 $f_m/f_s$ 是否为有理数
- 忽略采样信号频谱中的 $1/T$ 因子
- 将线频率 $f$（Hz）与角频率 $\Omega$（rad/s）混用：$\Omega = 2\pi f$
