# 第11讲 傅里叶变换的性质


## 预备知识：复数基础

| 概念 | 表示法 |
|------|--------|
| 代数形式 | $Z = x + yj$（实部 $x$，虚部 $y$） |
| 指数形式 | $Z = r e^{j\theta}$ |
| 模 | $r = \sqrt{x^2 + y^2}$ |
| 辐角 | $\theta = \arctan(y/x)$ |

> 在工程中虚数单位用 $j$ 表示（数学中用 $i$），信号与系统中沿用此习惯。

---

## 共轭复数

设 $Z = x + yj$，则其**共轭**为 $Z^* = x - yj$。

| 类型 | 共轭关系 |
|------|----------|
| 一般复数 | 实部相同，虚部相反 |
| 指数形式 | 模相等，相位相反 |
| 实数 | 共轭等于自身（因为无虚部） |
| 纯虚数 | 共轭与自身符号相反 |

> 实信号的共轭是自身，因此实信号的傅里叶变换具有特殊的对称性。

---

## 序列傅里叶变换的对称性

### 几个基本变换对

| 时域序列 | 频域结果 |
|----------|----------|
| $x(-n)$ | $X(e^{-j\omega})$ |
| $x^*(n)$ | $X^*(e^{-j\omega})$ |
| $x^*(-n)$ | $X^*(e^{j\omega})$ |

**规律**：时域符号取反 $\rightarrow$ 频域自变量取反；时域取共轭 $\rightarrow$ 频域取共轭。

---

### 共轭对称与共轭反对称分解

定义序列的共轭对称部分和共轭反对称部分：

$$
x_e(n) = \frac{1}{2}[x(n) + x^*(-n)]
$$

$$
x_o(n) = \frac{1}{2}[x(n) - x^*(-n)]
$$

则有 $x(n) = x_e(n) + x_o(n)$。

---

### 对称性与实部/虚部的关系

| 分解方式 | 对应关系 |
|----------|----------|
| $x(n) = \text{Re}[x(n)] + j\text{Im}[x(n)]$ | $\text{Re}[x(n)] \rightarrow$ 频域共轭对称部分 |
| | $\text{Im}[x(n)] \rightarrow$ 频域共轭反对称部分 |
| $x(n) = x_e(n) + x_o(n)$ | $x_e(n) \rightarrow \text{Re}[X(e^{j\omega})]$（实部） |
| | $x_o(n) \rightarrow j\text{Im}[X(e^{j\omega})]$（虚部） |

---

### 实序列的特殊情况

当 $x(n)$ 为实序列时（$x^*(n) = x(n)$），公式简化为：

$$
x_e(n) = \frac{1}{2}[x(n) + x(-n)] \quad \text{（偶分量）}
$$

$$
x_o(n) = \frac{1}{2}[x(n) - x(-n)] \quad \text{（奇分量）}
$$

此时频域函数具有以下奇偶性：

| 性质 | 结论 |
|------|------|
| 实部 | $\omega$ 的偶函数 |
| 虚部（含 $j$） | $\omega$ 的奇函数 |
| 模 | $\omega$ 的偶函数 |
| 辐角 | $\omega$ 的奇函数 |

---

## 例题

### 例：求 $R_4(n)$ 的 $x_e(n)$ 和 $x_o(n)$

**已知**：$R_4(n)$ 为实序列（矩形序列），范围 $n = 0,1,2,3$。

**解**：

1. 画出 $R_4(n)$ 的波形；
2. 画出 $R_4(-n)$（反折后的波形）；
3. 按公式 $x_e(n) = \frac{1}{2}[x(n) + x(-n)]$ 和 $x_o(n) = \frac{1}{2}[x(n) - x(-n)]$ 进行加减；

> 最终结果：
> - $x_e(n)$：偶对称波形
> - $x_o(n)$：奇对称波形
> - 注意不要忘记乘以 $\frac{1}{2}$

通过图形可以直观地看出偶对称和奇对称的特点。

---

## 关键公式

| 变换 | 公式 |
|------|------|
| 序列反折 | $x(-n) \leftrightarrow X(e^{-j\omega})$ |
| 序列共轭 | $x^*(n) \leftrightarrow X^*(e^{-j\omega})$ |
| 共轭反折 | $x^*(-n) \leftrightarrow X^*(e^{j\omega})$ |
| 共轭对称部分 | $x_e(n) = \frac{1}{2}[x(n) + x^*(-n)]$ |
| 共轭反对称部分 | $x_o(n) = \frac{1}{2}[x(n) - x^*(-n)]$ |
| 实序列偶分量 | $x_e(n) = \frac{1}{2}[x(n) + x(-n)]$ |
| 实序列奇分量 | $x_o(n) = \frac{1}{2}[x(n) - x(-n)]$ |

---

## 易错点

1. **共轭符号写法**：教材使用 $X^*$ 表示共轭（与数学教材的 $\overline{X}$ 不同），需熟悉这种记法。
2. **实部与虚部的对应关系**：时域分解为实部+虚部时，对应的是频域的共轭对称/反对称部分，而非简单的偶/奇函数 -- 只有实序列时才退化为偶/奇分量。
3. **$x_e(n)$ 和 $x_o(n)$ 的定义**：对于复序列，$x_e(n)$ 不是"偶分量"而是"共轭对称部分"，$x_o(n)$ 是"共轭反对称部分"。
4. **画图时要记得乘 1/2**：计算 $x_e(n)$ 和 $x_o(n)$ 时容易遗漏系数。
