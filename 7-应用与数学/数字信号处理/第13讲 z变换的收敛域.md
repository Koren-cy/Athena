# 第13讲 z变换的收敛域

> [!abstract] 本讲定位
> 本讲属于z变换（复频域分析）模块，前承z变换的定义与正变换计算，系统建立序列时域支撑类型与收敛域形状之间的对应规则。收敛域是z变换区别于DTFT的本质特征——DTFT仅在单位圆上定义并要求序列绝对可和，z变换通过引入$r=|z|$的自由度使更广泛的序列拥有频域表示。本讲的极点-收敛域对应关系是后续系统稳定性判据和因果性判断的理论基础。

## 一、序列按时间支撑的分类

**定义**：序列的**时间支撑**是指序列非零值所覆盖的自变量 $n$ 的取值范围。根据支撑范围的不同，序列可分为以下类型。

### 双边序列

若序列的自变量 $n$ 从 $-\infty$ 延伸到 $+\infty$，以 $n=0$ 为中心两侧均有非零样值，则称为**双边序列**。任意一般序列 $x(n)$ 默认为双边序列。

### 右序列

若存在某个 $n_1$（通常 $n_1 < 0$），使得序列在 $n < n_1$ 时全为零，仅当 $n \geq n_1$ 时有非零值，则称为**右序列**。右序列的自变量取值向右发展，反映了序列向右的增长趋势。

### 左序列

若存在某个 $n_1$（通常 $n_1 > 0$），使得序列在 $n > n_1$ 时全为零，仅当 $n \leq n_1$ 时有非零值，则称为**左序列**。左序列的自变量取值向左发展。

### 右边序列与左边序列

在右序列和左序列的基础上，将 $n_1$ 固定于原点，得到更常用的分类。

**定义（右边序列 / 因果序列）**：若序列 $x(n)$ 满足 $n < 0$ 时 $x(n) = 0$，非零值仅出现在 $n \geq 0$，则称为**右边序列**，也称为**因果序列**。

因果序列遵循真实时间系统的发展规律——系统输出不会先于输入出现。形式上，任意序列乘以 $u(n)$ 即截取其右边部分：

$$x(n) \cdot u(n) \quad \Rightarrow \quad n \geq 0 \text{ 部分保留，} n < 0 \text{ 部分置零}$$

**定义（左边序列 / 非因果序列）**：若序列 $x(n)$ 满足 $n \geq 0$ 时 $x(n) = 0$，非零值仅出现在 $n < 0$，则称为**左边序列**。左边序列是非因果的。

形式上，任意序列乘以 $u(-n-1)$ 即截取其左边部分：

$$x(n) \cdot u(-n-1) \quad \Rightarrow \quad n < 0 \text{ 部分保留，} n \geq 0 \text{ 部分置零}$$

### 有限长序列

若序列的非零值仅出现在有限区间 $n_1 \leq n \leq n_2$ 内，则称为**有限长序列**。有限长序列在 DFT 分析中具有特殊地位——其 z 变换为有限项求和，基本不受收敛性问题困扰。

> [!note] 分类说明
> 各教材对序列分类的命名可能略有差异，核心在于考察自变量 $n$ 的取值范围。本讲的分类服务于后续收敛域的判定，无需纠结名称的细微差别。

## 二、用极点确定收敛域

### 从等比级数条件到极点方法

回顾收敛域的基本求解思路：计算 z 变换 $X(z) = \sum x(n) z^{-n}$，将其整理为等比级数，由公比绝对值小于 1 的条件导出 $z$ 的取值范围。这一过程涉及初等函数的求和条件讨论，缺乏系统性。

更为系统的方法是直接利用 $X(z)$ 表达式的极点来确定收敛域。

**定义（极点）**：设 $X(z)$ 为 $z$ 的有理分式。令分母多项式等于零，使 $X(z)$ 趋于无穷大的 $z$ 值称为 $X(z)$ 的**极点**，记作 $z_p$。

**推导**：以 $u(n)$ 的 z 变换为例。

由 z 变换定义：
$$X(z) = \sum_{n=0}^{\infty} z^{-n} = \frac{1}{1 - z^{-1}}$$

令分母 $1 - z^{-1} = 0$，解得极点 $z_p = 1$。以该极点为半径在 $z$ 平面上画圆，得到一个单位圆。$u(n)$ 的收敛域 $|z| > 1$ 正好是该单位圆的**外部**区域。

> [!important] 极点-收敛域对应规则
> 序列在时域的支撑方向与 z 平面收敛域相对于极点圆的位置存在确定对应关系：
> - 时域支撑向右 → 收敛域在极点圆的**外部**，即 $|z| > |z_p|$
> - 时域支撑向左 → 收敛域在极点圆的**内部**，即 $|z| < |z_p|$
>
> 这一规则将收敛域的判定从等比级数条件分析提升为对 $X(z)$ 极点的代数求解，是后续系统分析的基石。

### 有限长序列的收敛域

有限长序列的 z 变换为有限项求和，只要求每一项 $|z^{-n}|$ 为有限值。因此有限长序列的收敛域为整个 $z$ 平面，可能除去 $z=0$ 或 $z=\infty$ 两个特殊点：

$$0 < |z| < \infty$$

具体排除规则：
- 若序列包含 $n < 0$ 的项，则 $z = \infty$ 处不收敛
- 若序列包含 $n > 0$ 的项，则 $z = 0$ 处不收敛

## 三、典型例题

> [!example] 求 $x(n) = \left(\dfrac{1}{2}\right)^n u(n)$ 的 z 变换及收敛域
> 已知 $x(n) = \left(\frac{1}{2}\right)^n u(n)$。求 $X(z)$ 及其收敛域。
>
> **解：**
>
> 由 z 变换定义：
> $$X(z) = \sum_{n=-\infty}^{\infty} x(n) z^{-n}$$
>
> 代入 $x(n)$，由 $u(n)$ 将求和下限改为 $0$：
> $$X(z) = \sum_{n=0}^{\infty} \left(\frac{1}{2}\right)^n z^{-n}$$
>
> 将 $\frac{1}{2}$ 与 $z^{-1}$ 合并，凑出标准等比级数形式：
> $$X(z) = \sum_{n=0}^{\infty} \left(\frac{1}{2} \cdot z^{-1}\right)^n$$
>
> 公比 $r = \frac{1}{2} z^{-1}$，由无穷等比级数求和公式 $\sum_{n=0}^{\infty} r^n = \frac{1}{1-r}$（要求 $|r| < 1$）：
> $$X(z) = \frac{1}{1 - \frac{1}{2} z^{-1}}$$
>
> **确定收敛域（极点法）：**
>
> 令分母 $1 - \frac{1}{2} z^{-1} = 0$，解得极点：
> $$z_p = \frac{1}{2}$$
>
> 序列 $x(n) = \left(\frac{1}{2}\right)^n u(n)$ 为右边序列（$n \geq 0$ 才有非零值），由极点-收敛域对应规则，收敛域为极点圆的外部：
> $$\text{ROC}: |z| > \frac{1}{2}$$

> [!tip] 观察
> 极点 $z_p = \frac{1}{2}$ 恰好等于 $X(z)$ 表达式中 $z^{-1}$ 项的系数。实际上，对于形如 $a^n u(n)$ 的序列，$X(z) = \frac{1}{1 - a z^{-1}}$，极点恒为 $z = a$。这一规律可用于快速验证计算结果。

## 四、双边序列的收敛域

### 分解策略

双边序列的 z 变换求和范围为 $n = -\infty$ 到 $\infty$，不能直接套用单边等比级数求和。策略是将双边序列拆分为左半部分和右半部分，分别作为左边序列和右边序列处理，然后取两部分收敛域的**交集**。

**推导**：

将求和范围在 $n = 0$ 处拆分：

$$X(z) = \sum_{n=-\infty}^{\infty} x(n) z^{-n} = \underbrace{\sum_{n=-\infty}^{-1} x(n) z^{-n}}_{\text{左边序列部分 } X_1(z)} + \underbrace{\sum_{n=0}^{\infty} x(n) z^{-n}}_{\text{右边序列部分 } X_2(z)}$$

$X_1(z)$ 对应左边序列，其收敛域为 $|z| < |r_+|$，其中 $r_+$ 是 $X_1(z)$ 各极点中模值最大者。

$X_2(z)$ 对应右边序列，其收敛域为 $|z| > |r_-|$，其中 $r_-$ 是 $X_2(z)$ 各极点中模值最小者。

### 收敛域的交集条件

双边序列 $X(z)$ 的收敛域必须同时满足两部分各自的收敛条件，即不等式组：

$$\begin{cases} |z| < |r_+| \\ |z| > |r_-| \end{cases}$$

> [!important] 双边序列收敛域存在条件与形式
> 不等式组有解当且仅当 $|r_-| < |r_+|$。此时收敛域为**环形区域**：
> $$|r_-| < |z| < |r_+|$$
>
> 若 $|r_-| \geq |r_+|$，则两部分收敛域无交集，双边序列的 z 变换不存在。

### 几何解释

在 $z$ 平面上：
- 内圆 $|z| = |r_-|$ 由右边序列部分的极点确定（收敛域在此圆外）
- 外圆 $|z| = |r_+|$ 由左边序列部分的极点确定（收敛域在此圆内）
- 收敛域是两圆之间的**环状区域**

> [!warning] 易错点
> - 双边序列的收敛域是**环形**，不是整个平面，也不是简单的圆外或圆内
> - 不要混淆内外圆的来源：外圆对应**左边**序列部分的极点，内圆对应**右边**序列部分的极点
> - 若 $|r_-| \geq |r_+|$，序列的 z 变换**不存在**——这是双边序列特有的情况

## 本讲小结

### 知识地图

本讲是z变换理论的核心环节，系统建立了序列时域支撑类型与收敛域形状之间的对应规则。序列按时间支撑分为有限长、右边（因果）、左边（非因果）、双边四类，每种类型对应不同的收敛域几何形态。极点位置的代数求解取代了等比级数条件分析，使收敛域判定系统化、标准化。这一对应关系将直接用于后续z变换性质的推导和极零点分析中，同时也是判断离散系统因果性与稳定性的关键工具。

### 核心公式表

| 条目 | 表达式 | 适用条件 |
|------|--------|----------|
| 有限长序列 ROC | $0 < \|z\| < \infty$ | $n_1 \leq n \leq n_2$ 有限支撑 |
| 右边序列 ROC | $\|z\| > \max\|z_p\|$ | $n < 0$ 时 $x(n) = 0$ |
| 左边序列 ROC | $\|z\| < \min\|z_p\|$ | $n \geq 0$ 时 $x(n) = 0$ |
| 双边序列 ROC | $\|r_-\| < \|z\| < \|r_+\|$ | $\|r_-\| < \|r_+\|$ |
| $a^n u(n)$ 的 z 变换 | $\dfrac{1}{1 - a z^{-1}}$，ROC: $\|z\| > \|a\|$ | $\|a z^{-1}\| < 1$ |
| 极点定义 | 分母 $=0$ 使 $X(z) \to \infty$ 的 $z$ 值 | $X(z)$ 为有理分式 |

### 易错点

- [ ] 混淆左边序列与右边序列的收敛域方向——时域向右则 $|z| > |z_p|$，时域向左则 $|z| < |z_p|$
- [ ] 双边序列求ROC时忘记取两部分ROC的**交集**，误将并集当作收敛域
- [ ] 忽略双边序列收敛域存在的充要条件 $|r_-| < |r_+|$（内半径严格小于外半径）
- [ ] 极点法仅适用于有理形式的 $X(z)$，对非有理形式需回到等比级数条件逐项分析
- [ ] 将有限长序列的ROC误记为零点和无穷点全部排除——只有 $n>0$ 或 $n<0$ 的项存在时才需要分别排除 $z=0$ 或 $z=\infty$
