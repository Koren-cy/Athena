## z变换解差分方程的基本思路

线性时不变系统的数学模型是常系数差分方程。z变换法先通过z变换将差分方程转换为代数方程，化简处理后再做z反变换得到时域序列。

**一般步骤**：
1. 将差分方程两边按各自的公式做z变换
2. 整理多项式，将 $Y(z)$ 单独放在方程一边
3. 对 $Y(z)$ 做z反变换，得到输出 $y[n]$

## 单边z变换与初始值处理

电路系统从 $n \ge 0$ 才开始工作，因此采用**单边z变换**。

### 输出信号 -- 需代入初始状态

系统有存储功能（电容储能等），初始值会产生零输入响应，所以z变换需代入初始值的"尾巴"：

$$Z\{y_{n-1}\} = z^{-1}Y(z) + y_{-1}$$

$$Z\{y_{n-2}\} = z^{-2}Y(z) + z^{-1}y_{-1} + y_{-2}$$

### 输入信号 -- 无需初始状态

输入信号是因果的（$n=0$ 才进入系统），没有地方存初始值：

$$Z\{x_{n-1}\} = z^{-1}X(z)$$

$$Z\{x_{n-2}\} = z^{-2}X(z)$$

## 系统函数

系统函数定义为输出z变换与输入z变换之比：

$$H(z) = \frac{Y(z)}{X(z)}$$

$H(z)$ 的z反变换就是系统的单位脉冲响应 $h[n]$。求系统函数可以直接对差分方程两边z变换（不带初始值），提取 $Y(z)$ 和 $X(z)$ 得到比值。

## 例题

### 例1：一阶系统求输出解析式

> 已知差分方程 $y_n - 0.5y_{n-1} = x_n$，输入 $x_n = 0.7^n u_n$，初始状态 $y_{-1} = 1.5$，求输出 $y_n$。
>
> **解**：
>
> **步骤1：两边z变换**
>
> $$Y(z) - 0.5[z^{-1}Y(z) + y_{-1}] = X(z)$$
>
> 代入 $y_{-1}=1.5$，$X(z) = \dfrac{z}{z-0.7}$：
>
> $$Y(z)(1 - 0.5z^{-1}) - 0.75 = \frac{z}{z-0.7}$$
>
> **步骤2：整理多项式**
>
> 将 $Y(z)$ 移到一边，分子分母同乘 $z$ 化为正指数形式：
>
> $$Y(z) = \frac{z^2}{(z-0.5)(z-0.7)} + \frac{0.75z}{z-0.5}$$
>
> **步骤3：留数法z反变换**
>
> 极点 $z_1 = 0.7$，$z_2 = 0.5$
>
> 极点0.7的留数：$\dfrac{7}{2} \times 0.7^n$
>
> 极点0.5的留数：$-\dfrac{7}{4} \times 0.5^n$
>
> 最终结果：
>
> $$y_n = \left[\frac{7}{2}(0.7)^n - \frac{7}{4}(0.5)^n\right] u_n$$

### 例2：求单位脉冲响应

> 已知差分方程，求单位脉冲响应 $h[n]$。
>
> **方法一**（直接法）：将方程右边 $x_n$ 替换为 $\delta_n$，两边z变换（无需初始值），整理得 $H(z)$，反变换得 $h[n]$。
>
> **方法二**（系统函数法）：直接对差分方程两边z变换，合并同类项后提取 $H(z) = Y(z)/X(z)$，再反变换得 $h[n]$。当差分方程系数为 $a$ 时，$h[n] = a^n u[n]$。

### 例3：二阶系统

> 已知二阶差分方程，求：
>
> **(1) 单位样值响应 $h[n]$**
>
> 方程两边z变换（不代初始值），整理得：
>
> $$H(z) = \frac{z(z+1)}{(z-0.4)(z+0.6)}$$
>
> 极点 $z_1 = 0.4$，$z_2 = -0.6$
>
> 留数法求反变换：
>
> $$h_n = [1.4 \times (0.4)^n - 0.4 \times (-0.6)^n] u_n$$
>
> **(2) 零状态响应（输入 $x_n = u_n$）**
>
> 由卷积定理（时域卷积 $\rightarrow$ z域相乘）：
>
> $$Y_{zs}(z) = X(z) \cdot H(z)$$
>
> $X(z) = \dfrac{z}{z-1}$，三个极点：0.4、-0.6、1
>
> 留数法求得：
>
> $$y_n = \left[-\frac{14}{15}(0.4)^n - \frac{3}{20}(-0.6)^n + \frac{25}{12}\right] u_n$$

## 关键公式

1. **输出右移的单边z变换**：
   $$Z\{y_{n-1}\} = z^{-1}Y(z) + y_{-1}$$
   $$Z\{y_{n-2}\} = z^{-2}Y(z) + z^{-1}y_{-1} + y_{-2}$$

2. **输入右移的单边z变换**（因果信号）：
   $$Z\{x_{n-1}\} = z^{-1}X(z)$$

3. **系统函数**：
   $$H(z) = \frac{Y(z)}{X(z)}$$

4. **卷积定理**：
   $$y[n] = x[n] * h[n] \iff Y(z) = X(z)H(z)$$

5. **常用z变换对**：
   $$a^n u_n \iff \frac{z}{z-a}$$

## 易错点

1. **初始值处理混淆**：输出信号的z变换必须带初始"尾巴"（$y_{-1}, y_{-2}$等），但输入信号（因果）的z变换不需要
2. **方法选择**：求较大n处的值或解析表达式时用z变换法；只求前几个 $y_0, y_1, y_2$ 时可用递推法
3. **幂次统一**：z变换结果若有负幂次，应化为正指数形式（分子分母同乘 $z$ 的适当幂次），方便求极点
4. **留数法公式**：留数主体是 $X(z)z^{n-1}$ 而非 $X(z)$ 本身，$n=0$ 时可能引入额外极点（$z=0$ 处的极点）需单独处理
