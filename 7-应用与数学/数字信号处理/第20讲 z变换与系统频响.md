# 第20讲 z变换与系统频响


## 一、系统频率响应函数与系统函数的关系

### 频率响应函数 $H(e^{j\omega})$

- 是系统单位脉冲响应 $h[n]$ 的**离散时间傅里叶变换（DTFT）**
- 反映系统对不同频率 $\omega$ 的响应特性

### 系统函数 $H(z)$

- 是系统单位脉冲响应 $h[n]$ 的**z变换**
- $H(z) = \dfrac{Y(z)}{X(z)}$

### 两者关系

$$H(e^{j\omega}) = H(z)\big|_{z = e^{j\omega}}$$

通过简单的变量代换即可相互转换，完美避开了傅里叶变换的复杂积分计算。

---

## 二、幅频特性与相频特性

$H(e^{j\omega})$ 是复数，可以表示为几何形式：

$$H(e^{j\omega}) = |H(e^{j\omega})| \cdot e^{j\varphi(\omega)}$$

- **幅频特性** $|H(e^{j\omega})|$：反映幅度随频率变化的规律
- **相频特性** $\varphi(\omega)$：反映相位随频率变化的规律

> **例**：已知 $H(z) = \dfrac{1}{9}z^{-3}$，求幅频和相频特性。
>
> 代入 $z = e^{j\omega}$：
> $$H(e^{j\omega}) = \frac{1}{9} e^{-j3\omega}$$
>
> 幅频：$|H(e^{j\omega})| = \dfrac{1}{9}$（常数，与频率无关）
>
> 相频：$\varphi(\omega) = -3\omega$

---

## 三、系统对单频信号的响应

### 输入为虚指数序列

当输入 $x[n] = e^{j\omega_0 n}$ 时：
$$y[n] = e^{j\omega_0 n} \cdot H(e^{j\omega_0})$$

即：输出是输入乘以系统在该频点的频响值。

写成几何形式：
$$y[n] = |H(e^{j\omega_0})| \cdot e^{j[\omega_0 n + \varphi(\omega_0)]}$$

- **幅度**：输入幅度乘以系统在该频点的幅频响应值
- **相位**：输入相位加上系统在该频点的相频响应值

### 输入为正弦/余弦信号

当输入 $x[n] = A\cos(\omega_0 n + \theta)$ 时：
$$y[n] = A \cdot |H(e^{j\omega_0})| \cdot \cos[\omega_0 n + \theta + \varphi(\omega_0)]$$

保持相同的频率，仅幅度和相位发生变化。这是频响分析在工程应用中的核心结论。

## 四、例题

### 例1：利用z变换求频响

> 已知离散系统的单位脉冲响应 $h[n] = R_N[n]$（矩形序列），求系统的频率响应。
>
> **解**：
>
> 将矩形序列表示为：$R_N[n] = u_n - u_{n-N}$
>
> 利用 $u_n$ 及其移位的z变换和线性性质，得到 $H(z)$，令 $z = e^{j\omega}$，再利用欧拉公式化简，即可得到频响函数。

### 例2：已知频响应输入求输出

> 已知系统频响特性 $H(e^{j\omega})$ 为几何形式，输入 $x[n] = \sin(3\pi n)$，求输出。
>
> **解**：
>
> 找出单频信号的频点：$\omega_0 = 3\pi$
>
> 读取系统在该频点的模值和相移：
>
> 若 $|H(e^{j\omega})| = 0.2$，$\varphi(\omega) = -2\omega$，则：
>
> 在 $\omega_0 = 3\pi$ 处：$\varphi(3\pi) = -6\pi$
>
> 输出：
> $$y[n] = 0.2 \cdot \sin(3\pi n - 6\pi) = 0.2 \cdot \sin(3\pi n)$$
> （相位 $-6\pi$ 是 $2\pi$ 的整数倍，不影响实际波形）

---

## 关键公式

1. **频响与系统函数的关系**：
   $$H(e^{j\omega}) = H(z)\big|_{z = e^{j\omega}}$$

2. **频响的几何形式**：
   $$H(e^{j\omega}) = |H(e^{j\omega})| e^{j\varphi(\omega)}$$

3. **虚指数输入响应**：
   $$x[n] = e^{j\omega_0 n} \;\Longrightarrow\; y[n] = H(e^{j\omega_0}) \cdot e^{j\omega_0 n}$$

4. **余弦输入响应**：
   $$x[n] = A\cos(\omega_0 n + \theta) \;\Longrightarrow\; y[n] = A |H(e^{j\omega_0})| \cos[\omega_0 n + \theta + \varphi(\omega_0)]$$

5. **正弦输入响应**：
   $$x[n] = A\sin(\omega_0 n + \theta) \;\Longrightarrow\; y[n] = A |H(e^{j\omega_0})| \sin[\omega_0 n + \theta + \varphi(\omega_0)]$$

## 易错点

1. **$H(e^{j\omega})$ 和 $H(z)$ 的关系**：$z = e^{j\omega}$ 代入只在系统稳定的前提下成立（单位圆在收敛域内）
2. **幅频和相频是频率的函数**：不同频率点 $\omega_0$ 对应的 $|H(e^{j\omega_0})|$ 和 $\varphi(\omega_0)$ 一般不同，不能混用
3. **正弦信号的特殊性**：上述"幅度相乘、相位相加"的规律仅适用于单频正弦/余弦/虚指数信号，对一般信号不成立
4. **工程应用**：频响分析的结果可以直接在示波器中观察到波形变化，理解物理意义比数学推导更重要
