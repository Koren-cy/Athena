# 第22讲 离散傅里叶变换的定义

> [!abstract] 本讲定位
> 本讲开启第三章「离散傅里叶变换（DFT）」，前承第二章序列傅里叶变换（DTFT），给出 DFT 的正式定义、核心符号 $W_N$ 的几何含义以及基本计算示例。DFT 是数字信号处理中唯一可在计算机上直接实现的频域分析工具，后续将引出快速傅里叶变换（FFT）并应用于卷积快速计算与滤波器设计。

## 一、DFT 的技术背景

信号处理的核心是频谱分析，傅里叶变换、拉普拉斯变换和 z 变换将微积分与级数运算转化为多项式，便于手工计算。随着计算机技术进步，利用计算机代替手工计算成为可能且必要。计算机的工作逻辑与手工计算有本质不同，需要新的理论支撑计算机算法，离散傅里叶变换（DFT）和快速傅里叶变换（FFT）应运而生。

连续傅里叶变换主要提供理论框架，DFT 则面向实际应用。例如第四代移动通信标准（LTE）中的正交频分复用（OFDM）技术就建立于 DFT 之上。计算机处理的核心约束是：连续系统自变量与函数值均为连续且取值范围无穷，而计算机要求计算范围有限、函数值离散。

序列傅里叶变换（DTFT）的频谱 $X(e^{j\omega})$ 仍然是 $\omega$ 的连续函数。一个自然的想法是：仿照时域抽样的思路，在频域对 $X(e^{j\omega})$ 进行等间隔频率抽样，用样值的包络代表频域函数的包络。这一思路在实现时面临关键问题——信号与系统的特性均为时域描述，频域采样必须通过时域的某些运算来转换。

## 二、从傅里叶级数到 DFT

回顾四类傅里叶变换的对偶规律：

| 变换类型 | 时域特征 | 频域特征 |
|----------|----------|----------|
| 傅里叶级数（FS） | 连续、周期 | 离散、非周期（谱线间隔 $\frac{2\pi}{T_0}$） |
| 傅里叶变换（FT） | 连续、非周期（$T_0 \to \infty$） | 连续、非周期（频谱密度） |
| 序列傅里叶变换（DTFT） | 离散、非周期 | 连续、周期（周期 $2\pi$） |
| 离散傅里叶变换（DFT） | 离散、周期 | 离散、周期 |

规律可以概括为：**一个域离散，另一个域周期；一个域周期，另一个域离散**。DFT 恰好位于两个域均为离散且周期的位置——这是唯一适合数字计算机处理的情形。

DTFT 的频谱 $X(e^{j\omega})$ 是连续的、周期为 $2\pi$ 的函数。要将这个连续周期频谱离散化，根据上述对偶规律反推，时域序列 $x(n)$ 必须周期化，才能像傅里叶级数那样实现频谱的离散化。

> [!note] 从 DTFT 到 DFT 的过渡
> DFT 可以理解为在单位圆上对 DTFT 频谱 $X(e^{j\omega})$ 做 $N$ 点等间隔采样：
> $$X(k) = X(e^{j\omega})\big|_{\omega = \frac{2\pi}{N}k}, \quad k = 0, 1, \ldots, N-1$$
> 这一视角将 DFT 与 DTFT 直接联系起来：DFT 的 $N$ 个样点就是 DTFT 频谱在 $[0, 2\pi)$ 上的 $N$ 等分点处的采样值。后续讨论频域采样定理时将严谨证明这一关系。

## 三、DFT 的正式定义

**定义（DFT 变换对）**：设 $x(n)$ 为长度为 $N$ 的有限长序列，即 $x(n)$ 仅在 $n = 0, 1, \ldots, N-1$ 上有定义（或非零），则

> [!important] DFT 正变换
> $$X(k) = \sum_{n=0}^{N-1} x(n) W_N^{nk}, \quad k = 0, 1, \ldots, N-1$$

> [!important] DFT 逆变换（IDFT）
> $$x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}, \quad n = 0, 1, \ldots, N-1$$

其中 $W_N = e^{-j\frac{2\pi}{N}}$ 称为**单位周期复指数序列因子**。

**参数说明**：

- $X(k)$：频域序列，$k$ 为频域离散序号。$X(k)$ 本质上对应频谱在频率 $\omega_k = \frac{2\pi}{N}k$ 处的采样值。
- $x(n)$：时域序列，$n$ 为时域样值序号，在求和式中 $n$ 是求和哑变量。
- $N$：DFT 变换区间长度。对同一序列取不同的 $N$ 值，所得 DFT 结果不同，因此 DFT 计算必须指明变换区间长度，称为「$N$ 点 DFT」。
- $k$ 和 $n$ 均为从 $0$ 开始的正整数。

$N$ 是 DFT 中最重要的参数，在公式中两次出现：一次作为 $W_N$ 的下标，决定频率采样间隔 $\frac{2\pi}{N}$；一次作为求和上限 $N-1$，决定参与变换的序列长度。

> [!warning] 序列长度与变换区间长度
> 若序列实际长度 $M < N$，应在序列末尾补 $N-M$ 个零后参与求和。若 $M > N$，则只能取前 $N$ 点参与变换（截断），这在后续讨论频谱泄漏时会有严格分析。

## 四、单位周期复指数序列 $W_N$

**定义**：$W_N$ 是一类以 $e$ 为底、指数为 $-j\frac{2\pi}{N}$ 的复指数序列因子：

$$W_N = e^{-j\frac{2\pi}{N}}$$

$W_N^{nk}$ 展开为：

$$W_N^{nk} = e^{-j\frac{2\pi}{N} nk}$$

**性质**：$W_N$ 是本章第一个核心符号，其原型为负指数信号。将 $N$ 理解为变换区间长度——同时也是一组频率采样点数——则 $W_N$ 在复平面单位圆上对应 $N$ 等分点：

- $N=4$ 时，$W_4$ 在单位圆上取四个角度：$0$, $-\frac{\pi}{2}$, $-\pi$, $-\frac{3\pi}{2}$，对应复数值 $1$, $-j$, $-1$, $j$。
- $N=8$ 时，$W_8$ 取八个角度：$0$, $-\frac{\pi}{4}$, $-\frac{\pi}{2}$, $-\frac{3\pi}{4}$, $-\pi$, $-\frac{5\pi}{4}$, $-\frac{3\pi}{2}$, $-\frac{7\pi}{4}$。
- $N=16$ 时取十六个角度，依此类推。

> [!tip] $W_N$ 的记忆
> 将 $W_N$ 理解为「复平面单位圆上的 $N$ 等分旋转因子」。$W_N^{nk}$ 中 $nk$ 每增加 $N$ 时旋转一整周回到原位：$W_N^N = e^{-j2\pi} = 1$。这一周期性是 DFT 所有性质的基础。

$W_N$ 的双重角色：既是频域采样间隔的载体（$\frac{2\pi}{N}$），又与变换区间长度一致——$N$ 既等于频率采样点数，也等于时域参与变换的序列长度。

## 五、DFT 计算示例

### 例 1：$\delta(n)$ 的四点 DFT

求单位脉冲序列 $\delta(n)$ 的 $4$ 点 DFT。

**已知**：$x(n) = \delta(n)$，$N = 4$。

**解**：

由 DFT 定义：

$$X(k) = \sum_{n=0}^{3} \delta(n) W_4^{nk}$$

将求和按 $n=0,1,2,3$ 展开：

$$X(k) = \delta(0) W_4^{0 \cdot k} + \delta(1) W_4^{1 \cdot k} + \delta(2) W_4^{2 \cdot k} + \delta(3) W_4^{3 \cdot k}$$

$\delta(n)$ 仅在 $n=0$ 处为 $1$，其余位置为 $0$：

$$X(k) = 1 \cdot W_4^{0} + 0 + 0 + 0 = 1$$

故 $X(k) = 1$（$k = 0, 1, 2, 3$）。$\delta(n)$ 的四点 DFT 是全 1 的常数序列。该结果表明单位脉冲在频域的所有频率分量上是平坦的，与 DTFT 中 $\delta(n)$ 的频谱 $X(e^{j\omega}) = 1$ 相一致。

### 例 2：$R_4(n)$ 的四点 DFT 与八点 DFT

> [!example] $R_4(n)$ 的四点 DFT
> 已知矩形序列 $R_4(n) = \{1, 1, 1, 1\}$（$n = 0, 1, 2, 3$），$N = 4$。求其 $4$ 点 DFT。
>
> **解：**
>
> 由 DFT 定义，$N = 4$，$W_4 = e^{-j\frac{\pi}{2}}$：
> $$X(k) = \sum_{n=0}^{3} R_4(n) W_4^{nk}, \quad k = 0, 1, 2, 3$$
>
> 由于 $R_4(n)$ 四个样值均为 $1$：
> $$X(k) = W_4^{0 \cdot k} + W_4^{1 \cdot k} + W_4^{2 \cdot k} + W_4^{3 \cdot k}$$
>
> 展开指数的四项：
> $$X(k) = 1 + e^{-j\frac{\pi}{2}k} + e^{-j\pi k} + e^{-j\frac{3\pi}{2}k}$$
>
> 逐项计算：
> - $k = 0$：$X(0) = 1 + 1 + 1 + 1 = 4$
> - $k = 1$：$X(1) = 1 + e^{-j\frac{\pi}{2}} + e^{-j\pi} + e^{-j\frac{3\pi}{2}}$
>
> 由欧拉公式：$e^{-j\pi} = -1$，$e^{-j\frac{\pi}{2}} = -j$，$e^{-j\frac{3\pi}{2}} = j$，代入得 $X(1) = 0$。
>
> 同理 $X(2) = 0$，$X(3) = 0$。
>
> 故 $R_4(n)$ 的四点 DFT 为 $\{4, 0, 0, 0\}$。
>
> 将该结果与 $R_4(n)$ 的 DTFT 幅度谱对比：在归一化频率 $\omega/\pi$ 的 $[0, 1]$ 区间上标注四个采样点 $(0, 0.5, 1, 1.5)\pi$ 处，仅 $k=0$ 处有值 $4$，其余为零，完全无法反映频谱的包络形状。

> [!example] $R_4(n)$ 的八点 DFT
> 已知 $R_4(n) = \{1, 1, 1, 1\}$，$N = 8$。求其 $8$ 点 DFT。
>
> **解：**
>
> $R_4(n)$ 仅有 $4$ 个非零样值，变换区间 $N=8$ 要求 $8$ 个时域样值。按补零规则，在 $n=4,5,6,7$ 处补四个零：
> $$x(n) = \{1, 1, 1, 1, 0, 0, 0, 0\}$$
>
> 由 DFT 定义，$N = 8$，$W_8 = e^{-j\frac{\pi}{4}}$：
> $$X(k) = \sum_{n=0}^{7} x(n) W_8^{nk}, \quad k = 0, 1, \ldots, 7$$
>
> 由于 $n \geq 4$ 各项为 $0$，求和至多四项非零：
> $$X(k) = 1 + e^{-j\frac{\pi}{4}k} + e^{-j\frac{\pi}{2}k} + e^{-j\frac{3\pi}{4}k}$$
>
> 此为首项 $1$、公比 $q = e^{-j\frac{\pi}{4}k}$、项数 $4$ 的等比数列。由等比数列前 $m$ 项和公式 $S = \frac{1 - q^m}{1 - q}$（$m=4$）：
> $$X(k) = \frac{1 - e^{-j\pi k}}{1 - e^{-j\frac{\pi}{4}k}}, \quad k \neq 0$$
>
> $k = 0$ 时各项均为 $1$，$X(0) = 4$。
>
> 利用 $e^{-j\pi k} = (-1)^k$ 化简分子：
> - $k$ 为偶数（$k=2, 4, 6$）时：分子 $1 - 1 = 0$，而分母不为零，故 $X(k) = 0$。
> - $k$ 为奇数时：分子 $1 - (-1) = 2$，代入 $k=1, 3, 5, 7$ 分别计算。
>
> 最终得八个频域样值。与四点 DFT 仅得 $\{4, 0, 0, 0\}$ 对比，八点 DFT 的八个样值在单位圆上更密集地采样，得到的频谱形状明显更接近实际的 DTFT 频谱包络。
>
> **结论**：变换区间长度 $N$ 越大，频率采样点越密集，DFT 结果越逼近真实频谱。计算机计算 DFT 时通常取 $N$ 为 $2$ 的幂次（$8, 16, 32, \ldots$），既保证足够的频率分辨率，又为 FFT 算法创造条件。

> [!info] DFT 与频谱分辨率
> DFT 本质上是对 DTFT 频谱 $X(e^{j\omega})$ 在 $[0, 2\pi)$ 上的等间隔采样。采样点数 $N$ 决定频谱的「显示分辨率」：$N$ 越大，相邻采样点频率间隔 $\Delta\omega = \frac{2\pi}{N}$ 越小，频谱细节越丰富。这一性质在频谱分析、信号检测等工程应用中至关重要。

## 本讲小结

### 知识地图

本讲是 DFT 章节的入口。从傅里叶级数→傅里叶变换→DTFT 的演进规律出发，导出了时域和频域均为离散的 DFT 变换对。核心符号 $W_N = e^{-j\frac{2\pi}{N}}$ 贯穿 DFT 全部性质。后续各讲将讨论 DFT 的性质、应用及加速算法 FFT。

DFT 在课程知识体系中的位置：

| 前驱知识 | 与 DFT 的关系 |
|----------|---------------|
| DTFT $X(e^{j\omega})$ | DFT 是 DTFT 在单位圆上的 $N$ 点等间隔采样 |
| z 变换 $X(z)$ | DFT 是 z 变换在单位圆上 $N$ 等分点处的取值 |
| 傅里叶级数 | 对偶关系的终态——两个域均离散 |

DFT 是后续所有章节的基础工具，频谱分析、卷积快速算法、滤波器频域设计均以 DFT 为计算核心。

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| DFT 正变换 | $X(k) = \sum_{n=0}^{N-1} x(n) W_N^{nk}$ | $x(n)$ 为 $N$ 点有限长序列，$k = 0, 1, \ldots, N-1$ |
| DFT 逆变换 | $x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}$ | $X(k)$ 为 $N$ 点频域序列，$n = 0, 1, \ldots, N-1$ |
| 单位周期复指数因子 | $W_N = e^{-j\frac{2\pi}{N}}$ | $N \in \mathbb{Z}^+$，$W_N^{N} = 1$ |
| 等比求和化简 | $X(k) = \frac{1 - e^{-j\pi k}}{1 - e^{-j\frac{\pi}{4}k}}$ | $R_4(n)$ 八点 DFT 推导，$k \neq 0$ |

### 易错点

> [!warning] 常见错误
> - **混淆求和项数与变换区间长度**。例 2 八点 DFT 中，实际参与求和的非零项为 $4$ 项，等比数列的项数 $m = 4$，而分母 $1 - q$ 中的 $q$ 仍用 $W_8$（非 $W_4$），切勿将变换区间 $N=8$ 代入分子指数 $q^N$。
> - **遗忘补零规则**。当序列长度 $M < N$ 时，必须在末尾补充 $N - M$ 个零，而非循环重复或截断。
> - **混淆 $n$ 与 $k$ 的角色**。$n$ 是时域求和哑变量，$k$ 是频域输出序号。$X(k)$ 中 $k$ 确定后，对所有 $n$ 求和得到一个值。
> - **忽略 $k=0$ 的特殊情况**。等比数列求和公式 $\frac{1-q^m}{1-q}$ 在 $q=1$（即 $k$ 使得 $e^{-j\frac{2\pi}{N}k}=1$，典型地 $k=0$）时分母为零，需单独代入求和式得到 $X(0) = \sum_{n=0}^{N-1} x(n)$。
