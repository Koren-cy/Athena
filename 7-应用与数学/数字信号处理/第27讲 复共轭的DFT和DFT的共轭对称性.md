# 第27讲 复共轭的DFT和DFT的共轭对称性

> [!abstract] 本讲定位
> 本讲属于 DFT 性质模块，前承线性性质、循环移位性质和循环卷积定理。本讲引入复共轭序列的 DFT 与 DFT 的共轭对称性——这两个性质是减少 DFT 计算量的核心工具，其利用对称性缩减运算的思想将直接用于后续 FFT 算法的推导。

## 一、DFT定义回顾

在讨论新性质之前，先明确 DFT 正变换与反变换的定义及其关键区别。

> [!important] DFT 变换对
> **正变换（DFT）**：已知时域序列 $x(n)$（$n=0,1,\ldots,N-1$），求其频谱采样值 $X(k)$：
> $$X(k) = \sum_{n=0}^{N-1} x(n) W_N^{nk}, \quad k = 0,1,\ldots,N-1$$
>
> **反变换（IDFT）**：已知频谱采样值 $X(k)$，反求时域序列 $x(n)$：
> $$x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}, \quad n = 0,1,\ldots,N-1$$
>
> 其中 $W_N = e^{-j\frac{2\pi}{N}}$ 为旋转因子。

正变换与反变换有三点本质区别：

1. **归一化因子**：反变换在求和后乘以 $1/N$。原因在于 $X(k)$ 是 $x(n)$ 的 $N$ 项累加的结果，反求时必须除以 $N$ 以保持数值尺度一致。
2. **求和变量**：正变换的求和变量为 $n$，反变换的求和变量为 $k$。两者在各自公式中分别为自变量和因变量，角色互换。
3. **旋转因子指数符号**：正变换使用 $W_N^{+nk}$，反变换使用 $W_N^{-nk}$，符号相反。

> [!warning] 易错点
> IDFT 公式中的 $1/N$ 因子极易遗漏。正变换中 $X(k)$ 是 $N$ 项累加的结果，反变换若不除以 $N$，计算结果将放大 $N$ 倍。

## 二、IDFT计算示例

以下通过一个简单例题演示 IDFT 的计算过程。

> [!example] 已知频谱求时域序列
> 已知序列 $x(n)$ 的长度 $N=4$，其四点 DFT 为 $X(k) = \{4,\; 0,\; 0,\; 0\}$。求 $x(n)$。
>
> **解：**
>
> 由 IDFT 定义，代入 $N=4$：
> $$x(n) = \frac{1}{4} \sum_{k=0}^{3} X(k) W_4^{-nk}, \quad n = 0,1,2,3$$
>
> 展开求和：
> $$x(n) = \frac{1}{4} \left[ X(0) W_4^{0} + X(1) W_4^{-n} + X(2) W_4^{-2n} + X(3) W_4^{-3n} \right]$$
>
> 题目中 $X(0)=4$，其余三项 $X(1)=X(2)=X(3)=0$。代入：
> $$x(n) = \frac{1}{4} \cdot 4 \cdot W_4^{0} = 1 \cdot 1 = 1$$
>
> 其中 $W_4^{0} = e^{-j\frac{2\pi}{4} \cdot 0} = 1$。
>
> $n$ 取遍 $0,1,2,3$，故 $x(n) = \{1,\; 1,\; 1,\; 1\}$。
>
> 题目明确 $x(n)$ 的长度为 $4$，因此结果取四项即可。DFT 对序列长度和变换区间长度的定义是严格的——若长度不明确，序列项数无法确定。

此例中 $X(0)=4$ 恰好等于序列所有元素之和 $1+1+1+1=4$，与 DFT 定义中 $k=0$ 时的表达式 $X(0) = \sum_{n=0}^{N-1} x(n)$ 一致。当 $X(k)$ 仅有一个非零值时，IDFT 退化为常数序列。

> [!tip] 计算心态
> DFT 的计算量较大，应主动总结计算技巧以减少不必要的运算，而非被动接受逐一求和的方式。后续性质正是此类技巧的系统化。

## 三、复共轭序列的DFT

**性质（复共轭的DFT）**：若 $x(n)$ 的 $N$ 点 DFT 为 $X(k)$，则 $x^*(n)$ 的 $N$ 点 DFT 为 $X^*(N-k)$，即：

$$\text{DFT}[x^*(n)] = X^*(N-k), \quad k = 0,1,\ldots,N-1$$

其中补充规定 $X(N) = X(0)$，以处理 $k=0$ 时 $N-k=N$ 越界的情况。

**推导思路**：由 DFT 定义：
$$\text{DFT}[x^*(n)] = \sum_{n=0}^{N-1} x^*(n) W_N^{nk} = \left[ \sum_{n=0}^{N-1} x(n) W_N^{-nk} \right]^*$$

括号内恰为 $X(-k)$ 的形式。由 DFT 的隐含周期性，$X(-k) = X(N-k)$，取共轭后即得 $X^*(N-k)$。

**工程意义**：已知 $X(k)$ 时，求 $x^*(n)$ 的 DFT 无需重新计算 $N$ 点求和，仅需对 $X(k)$ 做索引反转和取共轭两步操作。

> [!tip] 记忆技巧
> 时域取共轭 $\longrightarrow$ 频域反转再取共轭。即用 $N-k$ 替换 $k$ 后对整个表达式取共轭。

### 计算示例

> [!example] 利用复共轭性质求 DFT
> 已知 $x(n)$ 的四点 DFT 为 $X(k) = \{1,\; \frac{1}{2}+j,\; -2,\; 1+j\}$。求 $x^*(n)$ 的四点 DFT。
>
> **解：**
>
> 设 $X_e(k) = \text{DFT}[x^*(n)]$。由复共轭的 DFT 性质，$X_e(k) = X^*(N-k)$，$N=4$。
>
> 逐项计算：
>
> $k=0$：$X_e(0) = X^*(4-0) = X^*(4)$。由补充规定 $X(4)=X(0)$，故 $X_e(0) = X^*(0) = 1^* = 1$。
>
> $k=1$：$X_e(1) = X^*(4-1) = X^*(3) = (1+j)^* = 1-j$。
>
> $k=2$：$X_e(2) = X^*(4-2) = X^*(2) = (-2)^* = -2$。
>
> $k=3$：$X_e(3) = X^*(4-3) = X^*(1) = (\frac{1}{2}+j)^* = \frac{1}{2}-j$。
>
> 故 $X_e(k) = \{1,\; 1-j,\; -2,\; \frac{1}{2}-j\}$。
>
> 全程未使用求和运算与旋转因子计算，仅由性质直接得出。

## 四、DFT的共轭对称性

复共轭的 DFT 是适用于任意序列的一般性质。当序列为实数时，该性质退化出极为实用的共轭对称性，可将 DFT 计算量减少近一半。

### 4.1 实序列的共轭对称性

**性质（实序列 DFT 的共轭对称性）**：设 $x(n)$ 是长度为 $N$ 的实序列，其 $N$ 点 DFT 为 $X(k)$，则 $X(k)$ 满足共轭对称关系：

$$X(k) = X^*(N-k), \quad k = 0,1,\ldots,N-1$$

其中补充规定 $X(N) = X(0)$。

**推导**：实序列满足 $x(n) = x^*(n)$。对等式两边同时做 $N$ 点 DFT，左边得 $X(k)$，右边由复共轭的 DFT 性质得 $X^*(N-k)$。因此 $X(k) = X^*(N-k)$。

**物理意义**：实序列频谱的幅度具有偶对称性，相位具有奇对称性：

$$|X(k)| = |X(N-k)|, \quad \arg X(k) = -\arg X(N-k)$$

> [!important] 核心结论
> 对于 $N$ 点实序列，只需用 DFT 定义计算约 $N/2$ 个频谱点的值，其余点由共轭对称关系直接写出。在数值计算中，这可节省约一半的复指数运算量——乘法运算在数字处理器中需要的机器周期约为加法的四倍，指数运算更为复杂，因此这一节省直接转化为程序运行时间的缩减。

### 4.2 实偶序列与实奇序列

当实序列进一步满足对称性时，DFT 继续简化。

**性质（实偶序列）**：若实序列 $x(n)$ 满足偶对称 $x(n) = x(N-n)$，则其 DFT $X(k)$ 为实偶对称序列：

$$X(k) = X(N-k)$$

此时 $X(k)$ 是纯实数，连共轭操作也不需要，直接对称取值。

**性质（实奇序列）**：若实序列 $x(n)$ 满足奇对称 $x(n) = -x(N-n)$，则其 DFT $X(k)$ 为纯虚奇对称序列：

$$X(k) = -X(N-k)$$

> [!note] 与连续时间傅里叶变换的对比
> 实偶信号的频谱为实偶函数、实奇信号的频谱为纯虚奇函数——这一规律在连续时间傅里叶变换（CTFT）中同样成立。DFT 将这一规律从连续域推广到了离散有限长序列。

### 4.3 利用共轭对称性求解频谱

> [!example] 由偶数点频谱求奇数点频谱
> 已知 $N=7$ 的实序列 $x(n)$，其 DFT $X(k)$ 的偶数索引值已全部算出，其中 $X(6) = 5.2 + 3.7j$，$X(4) = 2.4 + 4.2j$。求奇数索引值 $X(1)$ 和 $X(3)$。
>
> **解：**
>
> 由实序列的共轭对称性 $X(k) = X^*(N-k)$，代入 $N=7$：
>
> $$X(1) = X^*(7-1) = X^*(6) = (5.2 + 3.7j)^* = 5.2 - 3.7j$$
>
> $$X(3) = X^*(7-3) = X^*(4) = (2.4 + 4.2j)^* = 2.4 - 4.2j$$
>
> 同理，$X(5) = X^*(7-5) = X^*(2)$，$X(7) = X^*(0)$（$X(7)$ 由周期性等价于 $X(0)$，自动为实数）。
>
> 四个奇数索引点的值全部由对称关系得出，无需任何复指数求和计算。

> [!info] 工程应用
> 乘法运算在数字处理器（DSP）中需要的机器周期约为加法的四倍，指数运算则更为复杂。利用共轭对称性将频谱计算量减半，可直接缩短程序运行时间。这一"利用对称性减少计算量"的思想在 FFT 算法中被发挥到极致——FFT 正是通过逐层利用 DFT 的对称性和周期性，将计算复杂度从 $O(N^2)$ 降至 $O(N \log N)$。

## 本讲小结

### 知识地图

本讲在 DFT 三个基本性质的基础上，引入复共轭的 DFT 与 DFT 的共轭对称性。前者是普适性质，适用于任意序列；后者是其特例，专用于实序列且实用价值更大。

这两条性质共同指向一个核心思想：**利用频谱内部的对称关系避免重复计算**。这一思想将在 FFT 中被系统化为快速算法。

| 性质 | 条件 | 结论 | 计算收益 |
|------|------|------|----------|
| 复共轭的 DFT | 任意序列 $x(n)$ | $\text{DFT}[x^*(n)] = X^*(N-k)$ | 避免重新计算 $N$ 点求和 |
| 实序列共轭对称 | $x(n)$ 为实序列 | $X(k) = X^*(N-k)$ | 只需计算约一半的频谱点 |
| 实偶序列 | $x(n)$ 实偶 | $X(k) = X(N-k)$，纯实数 | 连共轭也不必取，直接对称 |
| 实奇序列 | $x(n)$ 实奇 | $X(k) = -X(N-k)$，纯虚数 | 同上 |

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| DFT 正变换 | $X(k) = \sum_{n=0}^{N-1} x(n) W_N^{nk}$ | 有限长序列 $x(n)$ |
| IDFT 反变换 | $x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}$ | 已知频谱 $X(k)$ |
| 复共轭的 DFT | $\text{DFT}[x^*(n)] = X^*(N-k)$ | $k=0,\ldots,N-1$，$X(N)=X(0)$ |
| 实序列共轭对称 | $X(k) = X^*(N-k)$ | $x(n)$ 为实序列 |
| 实偶序列 DFT | $X(k) = X(N-k)$ | $x(n)$ 实偶 |
| 实奇序列 DFT | $X(k) = -X(N-k)$ | $x(n)$ 实奇 |

### 易错点

> [!warning] 常见错误
> - IDFT 公式遗漏 $1/N$ 因子，导致结果放大 $N$ 倍。
> - 复共轭的 DFT 性质中，将 $X^*(N-k)$ 误写为 $X(N-k)$ 或 $X^*(k)$——必须同时反转索引 **和** 取共轭，缺一不可。
> - 计算 $k=0$ 时 $X^*(N)$ 索引越界，忘记使用补充规定 $X(N) = X(0)$。
> - 混淆正反变换中旋转因子的指数符号：正变换 $W_N^{+nk}$，反变换 $W_N^{-nk}$。
> - 将共轭对称性 $X(k) = X^*(N-k)$ 用于非实序列——该式仅在 $x(n)$ 为实数时成立。
