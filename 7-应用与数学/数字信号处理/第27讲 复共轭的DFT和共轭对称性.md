## IDFT（离散傅里叶反变换）回顾

$$\displaystyle x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}$$

### 正变换与反变换的三大区别

| 区别点 | DFT 正变换 | IDFT 反变换 |
|--------|-----------|------------|
| 系数 | 无 | $\frac{1}{N}$ |
| 求和变量 | $n$（时域） | $k$（频域） |
| 旋转因子指数 | $W_N^{nk}$（正指数） | $W_N^{-nk}$（负指数） |

> **理解**：正变换是 $N$ 项求和，反变换若不加 $\frac{1}{N}$ 会越来越大，因此除以 $N$ 归一化。

### 例题

> **例**：已知序列 $x(n)$ 长度 $N=4$，四点 DFT 为 $X(k)=[4,0,0,0]$，求 $x(n)$。
> 
> **解**：
> 
> $x(n) = \frac{1}{4} \sum_{k=0}^{3} X(k) W_4^{-nk}$
> 
> 只有 $X(0)=4$ 非零，其他 $X(1)=X(2)=X(3)=0$。
> 
> $x(n) = \frac{1}{4} \times 4 \times W_4^{-n\cdot 0} = \frac{1}{4} \times 4 \times 1 = 1$
> 
> 由于 $N=4$，故 $x(n)=[1,1,1,1]$，长度为 4 的常数序列。

## 复共轭的 DFT

### 性质表述

若 $x(n)$ 的 $N$ 点 DFT 为 $X(k)$，则 $x^*(n)$ 的 $N$ 点 DFT 为：

$$\text{DFT}[x^*(n)] = X^*(N - k), \quad k = 0,1,\cdots,N-1$$

补充说明：$X(N) = X(0)$，即 $X^*(N) = X^*(0)$，保证了 $k=0$ 时公式的一致性。

### 例题

> **例**：已知 $x(n)$ 的四点 DFT 为 $X(k)=[1, 2+j, -2, 1+j]$，求 $x^*(n)$ 的四点 DFT $X_1(k)$。
> 
> **解**：利用 $\text{DFT}[x^*(n)] = X^*(N-k)$，$N=4$
> 
> - $X_1(0) = X^*(4) = X^*(0) = 1^* = 1$
> - $X_1(1) = X^*(3) = (1+j)^* = 1-j$
> - $X_1(2) = X^*(2) = (-2)^* = -2$
> - $X_1(3) = X^*(1) = (2+j)^* = 2-j$
> 
> 无需用到求和和复指数计算，直接利用性质得到结果。

## DFT 的共轭对称性（实序列）

实际中大多数序列是实序列，此性质非常有价值。

### 定理

若 $x(n)$ 是长度为 $N$ 的**实序列**，则其 DFT $X(k)$ 满足：

$$X(k) = X^*(N - k)$$

即 $X(k)$ 共轭对称。利用此关系可减少近一半的计算量。

### 三种特殊情况

| 时域 $x(n)$ 特性 | 频域 $X(k)$ 特性 |
|------------------|------------------|
| 实序列 | 共轭对称：$X(k) = X^*(N-k)$ |
| 实偶对称序列 | 实偶对称：$X(k) = X(N-k)$（无需求共轭） |
| 实奇对称序列 | 纯虚奇对称：$X(k) = -X(N-k)$ |

### 例题

> **例**：已知 $N=7$ 的实序列 $x(n)$，其 $X(k)$ 的偶数点值已知为：
> $X(0)=4.0$，$X(2)=3.8+1.2j$，$X(4)=2.4+4.2j$，$X(6)=5.2-3.7j$
> 
> 求 $X(1), X(3), X(5)$（奇数点值）。
> 
> **解**：利用实序列 DFT 的共轭对称性 $X(k) = X^*(N-k)$，$N=7$
> 
> - $X(1) = X^*(6) = (5.2-3.7j)^* = 5.2+3.7j$
> - $X(3) = X^*(4) = (2.4+4.2j)^* = 2.4-4.2j$
> - $X(5) = X^*(2) = (3.8+1.2j)^* = 3.8-1.2j$
> 
> **意义**：只需求出部分 $X(k)$ 值，其余利用对称性推导，可减少近一半的复指数运算。

## 关键公式

1. IDFT：$\displaystyle x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-nk}$
2. 复共轭的 DFT：$\text{DFT}[x^*(n)] = X^*(N-k)$
3. 实序列 DFT 共轭对称性：$X(k) = X^*(N-k)$
4. 实偶序列：$X(k) = X(N-k)$
5. 实奇序列：$X(k) = -X(N-k)$

## 易错点

1. **IDFT 除以 $N$**：容易忘记 IDFT 公式前面的 $\frac{1}{N}$，正变换没有这个系数。
2. **复共轭性质下标 $N-k$**：$k=0$ 时 $N-k=N$，对应 $X(0) = X(N)$，利用周期性 $X(N)=X(0)$ 处理。
3. **共轭对称性的适用范围**：只适用于**实序列**。若 $x(n)$ 是复序列，则无此性质。
4. **$N$ 为奇偶的区别**：$N$ 为奇数时对称点一一对应；$N$ 为偶数时，$X(N/2)$ 是自身的对称点（实数）。
5. **实偶对称的条件**：$x(n)$ 不仅要实，还必须关于 $n=0$ 偶对称，$X(k)$ 才为实数偶对称。
