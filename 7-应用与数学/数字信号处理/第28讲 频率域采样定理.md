# 第28讲 频率域采样定理

> [!abstract] 本讲定位
> 本讲属于 DFT 理论模块，承接 DFT 作为频域等间隔采样的观点，系统阐述频率域采样定理——从频域采样 $X(k)$ 无失真恢复原序列 $x(n)$ 的条件。频率域采样定理与时域采样定理形成对称对偶，是理解 DFT 隐含周期性、频率分辨率等后续概念的理论基础。

## 一、时域采样与频域采样的对比

时域采样定理将连续时间信号 $x_a(t)$ 以采样间隔 $T$ 离散化为序列 $x(n)$，再通过理想低通滤波器从采样值恢复原始连续信号。这一过程由 ADC 硬件和模拟滤波电路实现，属于物理世界可直接操作的信号处理。

**频率域采样**则完全不同。序列 $x(n)$ 的频谱是连续的周期函数 $X(e^{j\omega})$。若对该连续频谱在 $[0, 2\pi)$ 上等间隔采样 $N$ 点，得到

$$X(k) = X(e^{j\omega})\big|_{\omega = \frac{2\pi k}{N}}, \quad k = 0, 1, \dots, N-1$$

这 $N$ 个采样值恰好构成 $x(n)$ 的 $N$ 点 DFT。核心问题是：能否从 $X(k)$ 通过 IDFT 无失真恢复原序列 $x(n)$？

> [!note] 时域与频域采样的本质区别
> 时域采样由 ADC 硬件完成，恢复靠低通滤波电路。频率域采样是纯粹的数值运算——对 DTFT 频谱等间隔取值，不存在对应的「频域低通滤波电路」。因此频率域采样定理的条件和结论形式与时域采样定理有本质不同，不可混淆使用。

## 二、频率域采样定理

### 2.1 问题的数学表述

**定义（频率域采样）**：设有限长序列 $x(n)$ 的长度为 $M$，即 $x(n) \neq 0$ 仅在 $0 \le n \le M-1$。对其 DTFT $X(e^{j\omega})$ 在 $[0, 2\pi)$ 上等间隔采样 $N$ 点：

$$X(k) = X(e^{j\omega})\big|_{\omega = \frac{2\pi k}{N}} = \sum_{n=0}^{M-1} x(n) e^{-j\frac{2\pi}{N}kn}, \quad k = 0, 1, \dots, N-1$$

对 $X(k)$ 做 $N$ 点 IDFT 得到序列 $x_N(n)$：

$$x_N(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) e^{j\frac{2\pi}{N}kn}, \quad n = 0, 1, \dots, N-1$$

下标 $N$ 强调 $x_N(n)$ 的长度与 DFT 变换区间长度相同，为 $N$ 点。

### 2.2 定理陈述与证明

> [!important] 频率域采样定理
> 若序列 $x(n)$ 的长度为 $M$，$X(k)$ 是 $x(n)$ 的 DTFT 在 $[0, 2\pi)$ 上的 $N$ 点等间隔采样，$x_N(n) = \text{IDFT}[X(k)]$，则
> $$x_N(n) = x(n), \quad 0 \le n \le N-1$$
> 的**充要条件**是 $N \ge M$。

**证明**：

将 $X(k)$ 的表达式代入 IDFT 公式：

$$x_N(n) = \frac{1}{N} \sum_{k=0}^{N-1} \left[ \sum_{m=0}^{M-1} x(m) e^{-j\frac{2\pi}{N}km} \right] e^{j\frac{2\pi}{N}kn}$$

交换求和次序：

$$x_N(n) = \sum_{m=0}^{M-1} x(m) \left[ \frac{1}{N} \sum_{k=0}^{N-1} e^{j\frac{2\pi}{N}k(n-m)} \right]$$

由复指数正交性：

$$\frac{1}{N} \sum_{k=0}^{N-1} e^{j\frac{2\pi}{N}k(n-m)} = \begin{cases} 1, & n - m = rN,\; r \in \mathbb{Z} \\[6pt] 0, & \text{其他} \end{cases}$$

因此

$$x_N(n) = \sum_{r=-\infty}^{\infty} x(n + rN), \quad 0 \le n \le N-1$$

该式表明 $x_N(n)$ 等于原序列 $x(n)$ 以周期 $N$ 周期延拓后取主值区间 $[0, N-1]$。

- 若 $N \ge M$：$x(n+rN)$ 在 $r \ne 0$ 时恒为零（因为 $n+rN$ 超出 $[0, M-1]$），故 $x_N(n) = x(n)$。原序列可完整恢复。
- 若 $N < M$：不同周期的延拓分量在主值区间内求和，发生**时域混叠**。原序列无法恢复。

> [!info] 工程含义
> 频率域采样定理规定了 DFT 分析有限长序列的最小变换点数。要对长度为 $M$ 的序列做频谱分析，DFT 点数 $N$ 必须不小于 $M$，否则 $X(k)$ 反变换回去的不是原序列，而是混叠后的序列。这在实际工程中直接决定了 FFT 分析窗长的下限选取。

## 三、周期延拓与时域混叠

### 3.1 周期延拓的几何解释

DFT 的变换区间长度 $N$ 就是隐含的周期延拓长度。对长度为 $M$ 的序列做 $N$ 点 DFT，等价于：

1. 将序列以周期 $N$ 延拓为周期序列 $\tilde{x}(n) = x((n))_N$
2. 取主值区间 $0 \le n \le N-1$ 的 $N$ 个值作为 $x_N(n)$

> [!tip] 记忆技巧
> DFT 的点数 $N$ 如同一个「框」去框序列。如果序列比框长（$M > N$），多出的尾巴会「折返」叠加到框的起始位置，造成混叠。框至少要和序列一样大（$N \ge M$）才能完整容纳原序列。

### 3.2 混叠的叠加规则

当 $N < M$ 时，时域混叠按以下规则叠加：

$$x_N(n) = x(n) + x(n + N) + x(n + 2N) + \cdots, \quad 0 \le n \le N-1$$

即以周期 $N$ 为步长，将主值区间之外的序列值循环叠加回主值区间对应位置。由于 $x(n)$ 长度有限，实际只需叠加有限几项。

> [!warning] 易混淆概念
> 频率域采样不足导致的是**时域混叠**（原序列的时域波形发生混叠），而非频域混叠。这与时域采样不足导致频域混叠在数学上为对偶关系，但物理含义不同。时域混叠使 IDFT 结果 $\ne$ 原序列，直接影响频谱分析、DFT 实现线性卷积等应用的准确性。

## 四、典型例题

> [!example] 频率域采样不足导致的时域混叠
> 已知 $x(n) = \{1, 2, 3, 4, 5, 4, 3, 2, 1\}$，$n = 0, 1, \dots, 8$（长度 $M = 9$）。$X(k)$ 是 $x(n)$ 的 DTFT 在 $[0, 2\pi)$ 上的 $8$ 点等间隔采样，求 $X(k)$ 的 $8$ 点 IDFT 序列 $x_8(n)$。
>
> **解：**
>
> 由题意，$N = 8$，$M = 9$。因为 $N < M$，不满足频率域采样定理条件，将发生时域混叠。
>
> 由周期延拓关系：
> $$x_N(n) = \sum_{r=-\infty}^{\infty} x(n + rN), \quad 0 \le n \le N-1$$
>
> 代入 $N = 8$。由于 $x(n)$ 仅在 $0 \le n \le 8$ 非零，求和仅需考虑 $r = -1, 0$ 两项（$r = -1$ 贡献 $x(n+8)$）：
>
> $$
> \begin{aligned}
> x_8(0) &= x(0) + x(8) = 1 + 1 = 2 \\
> x_8(1) &= x(1) = 2 \\
> x_8(2) &= x(2) = 3 \\
> x_8(3) &= x(3) = 4 \\
> x_8(4) &= x(4) = 5 \\
> x_8(5) &= x(5) = 4 \\
> x_8(6) &= x(6) = 3 \\
> x_8(7) &= x(7) = 2
> \end{aligned}
> $$
>
> 故 $x_8(n) = \{2, 2, 3, 4, 5, 4, 3, 2\}$，$n = 0, 1, \dots, 7$。
>
> **验证**：若认为「变换一次再反变换恢复原样」会得到 $x(n)|_{n=0}^{7} = \{1, 2, 3, 4, 5, 4, 3, 2\}$，与实际结果对比，$x_8(0) = 2 \ne 1 = x(0)$，说明 $N < M$ 时 IDFT 结果确实不等于原序列。

> [!tip] 解题方法论
> 频率域采样定理类题目的解题步骤：
> 1. 比较 $N$ 与 $M$：若不满足 $N \ge M$，必然发生混叠。
> 2. 列出主值区间各点 $n = 0, 1, \dots, N-1$。
> 3. 对每个 $n$，按 $x_N(n) = \sum_{r} x(n+rN)$ 叠加非零项。实际只需找到落入 $[0, M-1]$ 的 $n+rN$ 对应的 $x$ 值相加。
> 4. 若为填空题，可直观操作：将序列按长度 $N$ 分段，各段对应位置相加。

## 本讲小结

### 知识地图

频率域采样定理是 DFT 理论的核心定理，建立了「DTFT 频域等间隔采样」与「序列时域周期延拓」之间的等价关系。本定理前承时域采样定理，后启 DFT 的频率分辨率分析——$N \ge M$ 是频谱分析无混叠的前提。理解该定理是后续学习用 DFT 进行频谱分析、DFT 实现线性卷积等内容的基础。

| 对比维度 | 时域采样定理 | 频率域采样定理 |
|----------|-------------|---------------|
| 采样对象 | 连续时间信号 $x_a(t)$ | 序列的连续频谱 $X(e^{j\omega})$ |
| 采样方式 | 等间隔 $T$ 对时域采样 | 等间隔 $2\pi/N$ 对频域采样 |
| 恢复方式 | 理想低通滤波器 | IDFT |
| 无失真条件 | $f_s \ge 2f_{\max}$（采样频率 $\ge$ 两倍最高频率） | $N \ge M$（DFT 点数 $\ge$ 序列长度） |
| 不满足时导致的失真 | 频域混叠 | 时域混叠 |
| 工程实现 | ADC 硬件 + 模拟滤波器 | 数值计算（DFT/FFT 软件或 DSP 芯片） |

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| 频域采样 | $X(k) = X(e^{j\omega})\big\|_{\omega = 2\pi k/N}$ | $k = 0, 1, \dots, N-1$ |
| IDFT 恢复序列 | $x_N(n) = \frac{1}{N}\sum_{k=0}^{N-1} X(k) e^{j2\pi kn/N}$ | $n = 0, 1, \dots, N-1$ |
| 周期延拓关系 | $x_N(n) = \sum_{r=-\infty}^{\infty} x(n + rN)$ | $0 \le n \le N-1$ |
| 无混叠条件 | $x_N(n) = x(n)$ 对 $0 \le n \le N-1$ | $N \ge M$（$M$ 为原序列长度） |

### 易错点

- **混淆两个采样定理的条件**：时域采样定理的条件是 $f_s \ge 2f_{\max}$（对连续信号），频率域采样定理的条件是 $N \ge M$（对有限长序列）。两者不可互换使用。
- **误以为 DFT 点数可以任意选取**：当 $N < M$ 时 $x_N(n) \ne x(n)$，IDFT 结果是混叠后的序列，不能代表原序列。
- **混淆 $x(n)$ 与 $x_N(n)$ 的含义**：$x_N(n)$ 是 $N$ 点 IDFT 的结果，长度恒为 $N$；$x(n)$ 是原序列，长度为 $M$。两者仅在 $N \ge M$ 时在 $0 \le n \le N-1$ 内相等。
- **周期延拓方向搞反**：时域混叠是将原序列以周期 $N$ 延拓后叠加，不是将频谱延拓后叠加。
- **忘记有限长序列的取值范围**：$x(n) = 0$ 当 $n < 0$ 或 $n \ge M$，因此周期延拓求和实际只需考虑有限几项，无需逐项计算无穷级数。
