# 第30讲 频域抽取的基-2 FFT算法原理及运算流图

> [!abstract] 本讲定位
> 本讲属于 DFT 快速算法模块，前承第29讲时域抽取（DIT）的基-2 FFT 算法，介绍另一种对称的分解思路——按**频域抽取**（Decimation-In-Frequency, DIF）的基-2 FFT。两种算法计算量相同、互为对偶，是 FFT 工程实现的两大基础方案。理解两者的蝶形结构与数据排列差异，是后续 FFT 硬件实现和编程的基础。

## 一、从时域抽取到频域抽取

第29讲中，DIT-FFT 将序列 $x(n)$ 在时域按奇偶序号一分为二，逐步分解为短 DFT。另一种同样直接的分解思路是将序列分成**前后两半**：前 $N/2$ 点和后 $N/2$ 点，分别计算其短 DFT，再合成 $N$ 点 DFT。这种分法在时域上不做奇偶抽取，而是通过频域输出的奇偶分离来递推，因此称为**频域抽取**的基-2 FFT，也称 **Sande-Tukey 算法**。

> [!info] 背景知识
> DIF-FFT 由 Sande 与 Tukey 在同一时期提出，与 Cooley-Tukey 的 DIT-FFT 形成对偶关系。两种算法的计算量均为 $O(N\log_2 N)$，复数乘法总数均为 $\frac{N}{2}\log_2 N$，区别仅在于蝶形结构和数据排列顺序。

**物理直觉**：将长序列对半截断，前后两段各自做短 DFT。通过考察旋转因子的符号变化（$(-1)^k$），发现偶数频率点恰好是两段短 DFT 之和，奇数频率点则需额外乘以旋转因子再相减。这一规律可逐级递推，将 $N$ 点 DFT 化为 $\log_2 N$ 级蝶形运算。

## 二、核心推导

### 2.1 序列拆分

设 $x(n)$ 是长度为 $N$ 的有限长序列，$N = 2^M$（$M$ 为正整数）。将其对半分成两个长度为 $N/2$ 的子序列：

$$x_1(n) = x(n), \quad n = 0, 1, \ldots, \frac{N}{2} - 1$$

$$x_2(n) = x\left(n + \frac{N}{2}\right), \quad n = 0, 1, \ldots, \frac{N}{2} - 1$$

分别记它们的 $N/2$ 点 DFT 为：

$$X_1(k) = \sum_{n=0}^{N/2-1} x_1(n) W_{N/2}^{nk} = \sum_{n=0}^{N/2-1} x(n) W_{N/2}^{nk}$$

$$X_2(k) = \sum_{n=0}^{N/2-1} x_2(n) W_{N/2}^{nk} = \sum_{n=0}^{N/2-1} x\left(n + \frac{N}{2}\right) W_{N/2}^{nk}$$

其中 $W_{N/2} = e^{-j\frac{4\pi}{N}}$，$k = 0, 1, \ldots, \frac{N}{2} - 1$。

### 2.2 N 点 DFT 的拆分

**推导**：

由 $N$ 点 DFT 定义：

$$X(k) = \sum_{n=0}^{N-1} x(n) W_N^{nk}$$

将求和按前后两段拆开：

$$X(k) = \sum_{n=0}^{N/2-1} x(n) W_N^{nk} + \sum_{n=N/2}^{N-1} x(n) W_N^{nk} \tag{1}$$

对第二段做变量代换：令 $n' = n - N/2$，则 $n = n' + N/2$，求和上下限变为 $n' = 0$ 到 $N/2 - 1$。为书写方便仍将 $n'$ 记为 $n$：

$$\sum_{n=N/2}^{N-1} x(n) W_N^{nk} = \sum_{n=0}^{N/2-1} x\left(n + \frac{N}{2}\right) W_N^{(n + N/2)k}$$

旋转因子拆开：

$$W_N^{(n + N/2)k} = W_N^{nk} \cdot W_N^{(N/2)k}$$

由旋转因子的可约性：

$$W_N^{(N/2)k} = \left(e^{-j\frac{2\pi}{N}}\right)^{(N/2)k} = e^{-j\pi k} = (-1)^k$$

代入 (1) 式，得拆分后的统一表达式：

$$X(k) = \sum_{n=0}^{N/2-1} x(n) W_N^{nk} + (-1)^k \sum_{n=0}^{N/2-1} x\left(n + \frac{N}{2}\right) W_N^{nk} \tag{2}$$

式 (2) 是 DIF-FFT 推导的核心起点。因子 $(-1)^k$ 随 $k$ 的奇偶取不同符号，自然导向对 $k$ 分奇偶讨论。

### 2.3 偶数和奇数频率点

**偶数频率点**：令 $k = 2m$，$m = 0, 1, \ldots, N/2 - 1$。

$(-1)^{2m} = 1$，且由旋转因子的可约性：$W_N^{n \cdot 2m} = W_{N/2}^{nm}$。代入 (2) 式：

$$X(2m) = \sum_{n=0}^{N/2-1} x(n) W_{N/2}^{nm} + \sum_{n=0}^{N/2-1} x\left(n + \frac{N}{2}\right) W_{N/2}^{nm}$$

对比 $X_1(m)$ 和 $X_2(m)$ 的定义，立即得到：

$$X(2m) = X_1(m) + X_2(m), \quad m = 0, 1, \ldots, \frac{N}{2} - 1 \tag{3}$$

> [!important] 核心结论
> $N$ 点 DFT 的偶数频率点 $X(2m)$ 等于前、后两半子序列 $N/2$ 点 DFT 直接相加。这一关系极其简洁，无需额外旋转因子。

**奇数频率点**：令 $k = 2m + 1$，$m = 0, 1, \ldots, N/2 - 1$。

$(-1)^{2m+1} = -1$。将旋转因子拆项：

$$W_N^{n(2m+1)} = W_N^{n \cdot 2m} \cdot W_N^n = W_{N/2}^{nm} \cdot W_N^n$$

代入 (2) 式：

$$X(2m+1) = \sum_{n=0}^{N/2-1} x(n) W_{N/2}^{nm} W_N^n - \sum_{n=0}^{N/2-1} x\left(n + \frac{N}{2}\right) W_{N/2}^{nm} W_N^n$$

提取公因子 $W_{N/2}^{nm}$ 并将 $W_N^n$ 与被求序列结合：

$$X(2m+1) = \sum_{n=0}^{N/2-1} \left[x(n) W_N^n\right] W_{N/2}^{nm} - \sum_{n=0}^{N/2-1} \left[x\left(n + \frac{N}{2}\right) W_N^n\right] W_{N/2}^{nm} \tag{4}$$

这两个求和分别是 $x(n)W_N^n$ 和 $x(n+N/2)W_N^n$ 的 $N/2$ 点 DFT。由 DFT 的频域循环移位性质：时域乘以旋转因子 $W_N^n$ 对应频域的循环位移。因此 $x(n)W_N^n$ 的 $N/2$ 点 DFT 等于 $X_1(m)$ 循环左移并取主值区间。记循环移位算子为 $(\cdot)_{N/2}$，则奇数频率点的表达式为：

$$X(2m+1) = X_1\big((m+1)\big)_{N/2} - X_2\big((m+1)\big)_{N/2}, \quad m = 0, 1, \ldots, \frac{N}{2} - 1 \tag{5}$$

式 (3) 和 (5) 共同表明：$N$ 点 DFT 的输出可按频率序号的奇偶**抽取**为两个 $N/2$ 点子频谱，分别由前后半时域序列的组合得到。"频域抽取"因此得名。

> [!tip] 记忆技巧
> - **DIT**：时域做奇偶抽取，频域自然序输出
> - **DIF**：时域自然序输入（只做前后分组），频域做奇偶抽取输出

## 三、蝶形运算符

### 3.1 DIF 蝶形的导出

从偶数与奇数输出的计算过程中提取重复的计算结构。定义两个中间序列：

$$g_1(n) = x(n) + x\left(n + \frac{N}{2}\right), \quad n = 0, 1, \ldots, \frac{N}{2} - 1$$

$$g_2(n) = \left[x(n) - x\left(n + \frac{N}{2}\right)\right] W_N^n, \quad n = 0, 1, \ldots, \frac{N}{2} - 1$$

则偶数与奇数频率点分别由 $g_1(n)$ 和 $g_2(n)$ 的 $N/2$ 点 DFT 给出：

$$X(2m) = \sum_{n=0}^{N/2-1} g_1(n) W_{N/2}^{nm} = \operatorname{DFT}_{N/2}\big[g_1(n)\big] \tag{6}$$

$$X(2m+1) = \sum_{n=0}^{N/2-1} g_2(n) W_{N/2}^{nm} = \operatorname{DFT}_{N/2}\big[g_2(n)\big] \tag{7}$$

上述计算结构对应如下的**基本蝶形运算单元**：

```
        ┌───────────────────────────┐
x(n) ───┤                           ├─── g₁(n) = x(n) + x(n+N/2)
        │       DIF Butterfly       │
x(n+N/2)┤                           ├─── g₂(n) = [x(n) − x(n+N/2)] · W_Nⁿ
        └───────────────────────────┘
                                   │
                                 W_Nⁿ（旋转因子在下方输出端，减法之后）
```

**DIF 蝶形的三个特征**：
- 加减法在旋转因子乘法**之前**完成
- 旋转因子 $W_N^n$ 乘在**减法分支的后端**（输出端）
- 下支路标注 $-1$ 表示减法操作

### 3.2 与 DIT 蝶形的对比

| 特征 | DIT 蝶形 | DIF 蝶形 |
|------|----------|----------|
| 旋转因子位置 | 输入端（下方输入先乘 $W_N^k$） | 输出端（下方输出后乘 $W_N^n$） |
| 加减法顺序 | 后置（先乘后加减） | 前置（先加减后乘） |
| 旋转因子索引变量 | 频率序号 $k$ | 时间序号 $n$ |
| 输入信号 | $X_1(k)$ 和 $X_2(k)$（上一级频域输出） | $x(n)$ 和 $x(n+N/2)$（时域采样值） |

> [!warning] 易错点
> DIF 蝶形的旋转因子标在**输出端**下方（减法之后），初学者容易按 DIT 的习惯标在输入端。画流图时应特别注意：**DIT 旋转因子在左边，DIF 旋转因子在右边**。

> [!note] 标准流图的画法补充
> 在蝶形交叉点处补上直线，下方支路标注 $-1$（表示相减），上方对应 $+1$（相加）。旋转因子冠在下方输出支路。这些标注是区分 DIF 与 DIT 标准流图的关键。

## 四、运算流图

### 4.1 四点 DIF FFT

对 $N=4$，$\log_2 4 = 2$ 级运算。输入 $x(0), x(1), x(2), x(3)$ 按自然顺序排列。

**第一级**（蝶形跨度 $N/2=2$）：

- 蝶形 1：输入 $\big(x(0), x(2)\big)$，旋转因子 $W_4^0$
  - 上输出：$g_1(0) = x(0) + x(2)$
  - 下输出：$g_2(0) = [x(0) - x(2)] W_4^0$
- 蝶形 2：输入 $\big(x(1), x(3)\big)$，旋转因子 $W_4^1$
  - 上输出：$g_1(1) = x(1) + x(3)$
  - 下输出：$g_2(1) = [x(1) - x(3)] W_4^1$

**第二级**：两个 2 点 DFT，蝶形跨度为 1，旋转因子仅为 $W_2^0 = 1$。

- 对上支路 $\big(g_1(0), g_1(1)\big)$ 做 2 点 DFT：
  $$X(0) = g_1(0) + g_1(1), \quad X(2) = g_1(0) - g_1(1)$$
- 对下支路 $\big(g_2(0), g_2(1)\big)$ 做 2 点 DFT：
  $$X(1) = g_2(0) + g_2(1), \quad X(3) = g_2(0) - g_2(1)$$

**输出顺序**：$X(0), X(2), X(1), X(3)$（偶数频率点在前，奇数在后）。

### 4.2 八点 DIF FFT

对 $N=8$，$\log_2 8 = 3$ 级运算。输入 $x(0), x(1), \ldots, x(7)$ 自然顺序排列。

**第一级**（蝶形跨度 $N/2=4$）：4 个蝶形

| 蝶形 | 输入对 | 旋转因子 |
|------|--------|----------|
| 1 | $\big(x(0), x(4)\big)$ | $W_8^0$ |
| 2 | $\big(x(1), x(5)\big)$ | $W_8^1$ |
| 3 | $\big(x(2), x(6)\big)$ | $W_8^2$ |
| 4 | $\big(x(3), x(7)\big)$ | $W_8^3$ |

第一级输出 $g_1(0..3)$ 和 $g_2(0..3)$，分别送入两个 4 点 DFT。

**第二级**：两个 4 点 DFT 各自分解，蝶形跨度为 2。

**第三级**：四个 2 点 DFT，蝶形跨度为 1，仅 $W_2^0 = 1$。

**输出顺序**（频域序号 bit-reversed）：

$$X(0), X(4), X(2), X(6), X(1), X(5), X(3), X(7)$$

这一顺序的规律：将自然序号 $0, 1, \ldots, 7$ 写成三位二进制，比特逆序（bit-reversal）后即得输出位置。例如序号 $1$（二进制 `001`）逆序为 `100`（十进制 $4$），对应输出位置 $4$。

> [!important] 核心结论
> DIF-FFT 的数据排列特征：**输入自然序，输出倒位序**。与 DIT-FFT（输入倒位序、输出自然序）恰好对称。级数为 $\log_2 N$，每级 $N/2$ 个蝶形，总复数乘法 $\frac{N}{2}\log_2 N$ 次，总复数加法 $N\log_2 N$ 次。

### 4.3 旋转因子的规律

DIF-FFT 各级旋转因子的分布规律与 DIT-FFT 一致：

- 第 $p$ 级（$p = 1, 2, \ldots, \log_2 N$）有 $2^{p-1}$ 组，每组内蝶形使用相同的旋转因子集合
- 旋转因子按 $W_{2^p}^{r}$ 排列，$r = 0, 1, \ldots, 2^{p-1} - 1$
- 每个蝶形下方输出端标注对应的旋转因子

## 五、DIF 与 DIT 的综合对比

| 对比维度 | DIT-FFT（Cooley-Tukey） | DIF-FFT（Sande-Tukey） |
|----------|--------------------------|--------------------------|
| 分解域 | 时域奇偶抽取 | 频域奇偶抽取（时域前后分组） |
| 输入顺序 | 倒位序 | 自然序 |
| 输出顺序 | 自然序 | 倒位序 |
| 旋转因子在蝶形中的位置 | 输入侧（下方输入乘 $W_N^k$） | 输出侧（下方输出乘 $W_N^n$） |
| 加减法与乘法的顺序 | 先乘后相加减 | 先相加减后乘 |
| 级数 | $\log_2 N$ | $\log_2 N$ |
| 每级蝶形数 | $N/2$ | $N/2$ |
| 复数乘法总数 | $\frac{N}{2}\log_2 N$ | $\frac{N}{2}\log_2 N$ |
| 复数加法总数 | $N\log_2 N$ | $N\log_2 N$ |

> [!tip] 选用策略
> - 若数据采集时为自然序而频域分析需要自然序输出，可在 DIF 后加一次倒位序重排，或在 DIT 前加倒位序重排。两者计算量等同。
> - 硬件实现中，DIF 的蝶形（先加减后乘）在定点运算中有时具有更好的数值精度。

> [!note] 与后续章节的联系
> 两种基-2 FFT 算法的蝶形结构和数据流图是第32讲基-4 FFT 和第33讲分裂基 FFT 的基础。理解蝶形的对称性和旋转因子递推规律后，更高阶的分解本质上是将蝶形做进一步的分组和因子复用。

## 六、应用示例

> [!example] 周期延拓序列的 DFT
> 已知长度为 $8$ 的序列 $x(n)$，其 $8$ 点 DFT $X(k)$ 已全部算出。令 $y(n)$ 为 $x(n)$ 以周期 $8$ 延拓后截取前 $16$ 点：
> $$y(n) = x(n \bmod 8), \quad n = 0, 1, \ldots, 15$$
> 求 $y(n)$ 的 $16$ 点 DFT $Y(k)$。
>
> **解：** $N=16$，$N/2=8$。将 $y(n)$ 对半分为 $y_1(n)$ 和 $y_2(n)$：
> $$y_1(n) = y(n) = x(n), \quad n = 0, \ldots, 7$$
> $$y_2(n) = y(n+8) = x\big((n+8) \bmod 8\big) = x(n), \quad n = 0, \ldots, 7$$
>
> 故 $y_1(n) = y_2(n)$。构造 DIF 蝶形的中间变量：
> $$g_1(n) = y_1(n) + y_2(n) = 2x(n)$$
> $$g_2(n) = \big[y_1(n) - y_2(n)\big] W_{16}^n = 0 \cdot W_{16}^n = 0$$
>
> **偶数频率点**（$k = 2m$）：
> $$Y(2m) = \operatorname{DFT}_8\big[g_1(n)\big] = \operatorname{DFT}_8\big[2x(n)\big] = 2X(m), \quad m = 0, \ldots, 7$$
>
> **奇数频率点**（$k = 2m+1$）：
> $$Y(2m+1) = \operatorname{DFT}_8\big[g_2(n)\big] = \operatorname{DFT}_8[0] = 0, \quad m = 0, \ldots, 7$$
>
> 因此：
> $$Y(k) = \begin{cases} 2X(k/2), & k = 0, 2, 4, \ldots, 14 \\[4pt] 0, & k = 1, 3, 5, \ldots, 15 \end{cases}$$

> [!info] 工程解释
> 时域周期延拓（重复）等价于频域**插零**（上采样）再乘以常数。本例中 $y(n)$ 是 $x(n)$ 重复两次，对应的 $16$ 点 DFT 在 $8$ 点 DFT $X(k)$ 的相邻谱线之间插入零点（奇数位置），偶数位置幅值加倍。这是 DFT 时域延拓-频域插值对偶性质的一个实例。

## 本讲小结

### 知识地图

本讲是 DFT 快速算法模块的第二讲。第29讲从时域奇偶抽取出发建立了 DIT-FFT，本讲从时域前后分组出发建立了对称的 DIF-FFT。两种算法通过不同的分解路径通向相同的计算复杂度：$\frac{N}{2}\log_2 N$ 次复数乘法和 $N\log_2 N$ 次复数加法。理解二者的对偶关系——蝶形结构互为转置、输入输出顺序互换——是后续学习基-4 FFT、分裂基 FFT 以及 FFT 硬件流水线实现的理论基础。

| 对比要点 | DIT-FFT | DIF-FFT |
|----------|---------|---------|
| 分解策略 | 时域按奇偶序号一分为二<br>$x(2r)$ 和 $x(2r+1)$ 各做 $N/2$ 点 DFT | 时域按前后位置对半分<br>$x(n)$ 和 $x(n+N/2)$ 组合后做 $N/2$ 点 DFT |
| 蝶形核心运算 | 先乘旋转因子，后加减<br>旋转因子在输入端下方 | 先加减，后乘旋转因子<br>旋转因子在输出端下方 |
| 数据排列 | 输入倒位序，输出自然序 | 输入自然序，输出倒位序 |

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| DFT 前后拆分 | $X(k)=\sum\limits_{n=0}^{N/2-1}x(n)W_N^{nk}+(-1)^k\sum\limits_{n=0}^{N/2-1}x(n+\frac{N}{2})W_N^{nk}$ | $N=2^M$ |
| DIF 偶数频率点 | $X(2m)=X_1(m)+X_2(m)$ | $m=0,\ldots,\frac{N}{2}-1$ |
| DIF 奇数频率点 | $X(2m+1)=X_1((m+1))_{N/2}-X_2((m+1))_{N/2}$ | $m=0,\ldots,\frac{N}{2}-1$ |
| DIF 蝶形上支路 | $g_1(n)=x(n)+x(n+N/2)$ | $n=0,\ldots,\frac{N}{2}-1$ |
| DIF 蝶形下支路 | $g_2(n)=[x(n)-x(n+N/2)]\,W_N^n$ | $n=0,\ldots,\frac{N}{2}-1$ |
| 关键恒等式 | $W_N^{(N/2)k}=e^{-j\pi k}=(-1)^k$ | $N$ 为偶数 |

### 易错点

- [!warning] DIF 蝶形的旋转因子标在**输出端下方**（减法分支之后），而 DIT 蝶形的旋转因子标在**输入端下方**。画流图时先判断算法类型，再确定旋转因子位置。
- [!warning] DIF-FFT 在输入自然序的情况下，输出为**倒位序**。若分析需要自然序的频谱，必须在 FFT 之后加一次倒位序重排，不可忽略。
- [!warning] 恒等式 $W_N^{(N/2)k} = (-1)^k$ 是 DIF 推导的关键一步，它来自 $e^{-j\pi} = -1$。该等式仅当 $N$ 为偶数时成立，基-2 FFT 要求 $N=2^M$ 自动满足。
- [!warning] DIF 蝶形下支路的运算是 $[x(n)-x(n+N/2)] \cdot W_N^n$，不是 $x(n)W_N^n - x(n+N/2)W_N^n$。旋因子只乘一次，在减法之后。
