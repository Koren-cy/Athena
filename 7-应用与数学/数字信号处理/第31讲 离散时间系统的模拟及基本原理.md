# 第31讲 离散时间系统的模拟及基本原理

> [!abstract] 本讲定位
> 本讲进入第五章「离散系统的网络结构」，是系统函数 $H(z)$ 与实际硬件/软件实现之间的桥梁。前承 z 变换与系统函数理论（第22讲附近），后续将展开 IIR、FIR 滤波器的具体结构实现。核心任务：掌握系统框图 $\leftrightarrow$ 差分方程 $\leftrightarrow$ 系统函数三者之间的转换。

## 一、系统框图中的基本运算单元

离散系统可以用系统框图来描述，框图中每种运算对应一个实体符号。

### 1.1 延迟器

**定义**：使序列延迟一个采样周期的运算单元，用方框标注 $\mathrm{D}$（Delay）。

输入序列 $x(n)$ 经过一个延迟单元，输出为：

$$y(n) = x(n-1)$$

z 变换后，延迟器对应 $z^{-1}$（单位延迟因子）。

### 1.2 常数乘法器（加权器）

**定义**：将输入序列乘以常数 $a$ 的运算单元，用三角形符号表示。

$$y(n) = a \cdot x(n)$$

z 变换后，加权系数 $a$ 保持不变。

### 1.3 加法器

**定义**：对多路输入做代数求和的运算单元，用圆圈内含加号表示。输入端按箭头方向标注：箭头指向圆圈的为输入，箭头从圆圈向外的为输出。每个输入端口标注正负号指示加减。

对于两输入加法器：

$$y(n) = x_1(n) + x_2(n)$$

> [!tip] 加法器符号判断
> 箭头端标注「$$+$$」表示该支路信号直接相加；标注「$$-$$」表示该支路信号相减。列方程时严格按标注符号写入等号右侧。

## 二、系统框图的标准结构

### 2.1 主线路与支路

**定义**：系统框图中从输入 $x(n)$ 到输出 $y(n)$ 的主信号路径称为**主线路**，箭头方向即为信号传输的正方向。主线路之外的信号传输线路称为**支路**。

> [!tip] 支路分类
> - **正向支路**：与主线路方向相同的支路。其信号从前方节点取出，经加权后注入后方的加法器。
> - **反馈支路**：与主线路方向相反的支路。其信号从后方节点取出，经加权后反馈到前方的加法器。

### 2.2 节点与中间变量

**定义**：框图中信号交汇的位置称为**节点**。每个节点处可定义一个中间变量，用于列写加法器的输入输出关系。

对主线路上的节点依次编号。设第一个加法器输出端节点为 $f(n)$，则经过一级延迟后为 $f(n-1)$，经过两级延迟后为 $f(n-2)$，依此类推。系统中包含的延迟器个数决定系统的阶数——含有两个延迟器即为**二阶系统**。

> [!important] 核心关系
> $x(n)$ 和 $y(n)$ 是系统的输入和输出（求解目标），$f(n)$ 等只是辅助列式的中间变量，最终需消去。

### 2.3 抽头的概念

**定义**：主线路上的每个节点称为一个**抽头**。处理系统框图时，只需按顺序标注各抽头的值：$1$、$z^{-1}$、$z^{-2}$、……（对应时域的 $\delta(n)$、$\delta(n-1)$、$\delta(n-2)$、……）。

从 z 域视角看，第一个抽头值为 $1$，其 z 反变换正是单位样值序列 $\delta(n)$；系统的单位样值响应 $h(n)$ 的 z 变换正是系统函数 $H(z)$。因此抽头值的标注本质上对应了系统函数分子分母多项式中各 $z^{-k}$ 项的系数来源。

## 三、从系统框图求差分方程与系统函数（例一）

### 3.1 时域列式法

系统框图为标准二阶结构：主线路含两个延迟器，左端输入 $x(n)$，右端输出 $y(n)$，输入端和输出端各有一个加法器。

设第一个加法器输出为 $f(n)$，则三个节点依次为 $f(n)$、$f(n-1)$、$f(n-2)$。

**第一个加法器**（输入端加法器）：输出为 $f(n)$，输入端包括 $x(n)$ 以及来自 $f(n-1)$ 和 $f(n-2)$ 的两条反馈支路。

由加法器输入输出关系：

$$f(n) = x(n) + a_1 f(n-1) - a_0 f(n-2)$$

**第二个加法器**（输出端加法器）：输出为 $y(n)$，输入端包括主线路上 $f(n-2)$ 的支路，以及来自 $f(n-1)$ 和 $f(n)$ 的两条正向支路。

$$y(n) = b_0 f(n-2) - b_1 f(n-1) + b_2 f(n)$$

理论上消去中间变量 $f(n)$ 及其各级差分即可得到 $y(n)$ 关于 $x(n)$ 的差分方程，但时域消元比较繁琐。

### 3.2 z 域列式法

对各变量做 z 变换：$x(n) \to X(z)$，$y(n) \to Y(z)$，$f(n) \to F(z)$。延迟器对应 $z^{-1}$，加权系数不变。各节点依次为 $F(z)$、$z^{-1}F(z)$、$z^{-2}F(z)$。

**第一个加法器**（z 域）：

$$F(z) = X(z) + a_1 z^{-1} F(z) - a_0 z^{-2} F(z) \tag{1}$$

**第二个加法器**（z 域）：

$$Y(z) = b_0 z^{-2} F(z) - b_1 z^{-1} F(z) + b_2 F(z) \tag{2}$$

### 3.3 代数化简求系统函数

由式 (1)，合并含 $F(z)$ 的项并移项：

$$F(z) \left(1 - a_1 z^{-1} + a_0 z^{-2}\right) = X(z)$$

得：

$$F(z) = \frac{X(z)}{1 - a_1 z^{-1} + a_0 z^{-2}} \tag{3}$$

将式 (3) 代入式 (2)：

$$Y(z) = \left(b_0 z^{-2} - b_1 z^{-1} + b_2\right) \cdot \frac{X(z)}{1 - a_1 z^{-1} + a_0 z^{-2}} \tag{4}$$

由此：

$$H(z) = \frac{Y(z)}{X(z)} = \frac{b_2 - b_1 z^{-1} + b_0 z^{-2}}{1 - a_1 z^{-1} + a_0 z^{-2}}$$

### 3.4 由系统函数求差分方程

将式 (4) 整理为：

$$Y(z) \left(1 - a_1 z^{-1} + a_0 z^{-2}\right) = X(z) \left(b_2 - b_1 z^{-1} + b_0 z^{-2}\right)$$

两边取 z 反变换，由 $z^{-k}$ 对应 $n \to n-k$ 的时移性质，得差分方程：

$$y(n) - a_1 y(n-1) + a_0 y(n-2) = b_2 x(n) - b_1 x(n-1) + b_0 x(n-2)$$

> [!important] 系统框图、系统函数、差分方程三者的等价关系
> 给定其中任何一种描述，均可导出另外两种。系统框图是硬件/软件实现的蓝图，系统函数是频域分析的工具，差分方程是可编程的递推公式。

## 四、系统函数与框图的直接对应规律

经过前节推导可以发现：中间变量 $F(z)$ 在化简中被消去，但其系数原封不动地保留在了 $H(z)$ 分子分母的相应位置。因此可以**跳过设中间变量和列加法器方程**两步，直接从框图上写出 $H(z)$。

### 4.1 标注抽头值

从第一个加法器输出端开始，沿主线路依次标注各节点值：$1$、$z^{-1}$、$z^{-2}$、……（若有更多延迟器则依次类推）。

### 4.2 写出系统函数

$$H(z) = \frac{\text{分子多项式}}{\text{分母多项式}}$$

| 部分 | 对应框图元素 | 系数符号规则 |
|------|-------------|-------------|
| **分子** | 所有正向支路（含主线路） | 系数符号与支路实际标注符号**相同**。未标注的默认为正 |
| **分母**第一项 | 输入信号 $X(z)$，系数为 $1$ | — |
| **分母**其他项 | 所有反馈支路 | 系数符号与支路实际标注符号**相反** |

> [!warning] 反馈支路符号取反
> 分母多项式中的反馈支路系数与框图上标注的符号相反，这是因为在移项整理 $F(z)$ 表达式时，等式两边交换了符号。这是最易出错的一步。

### 4.3 示例

对于例一的框图，直接按规律写出：

**分子**（正向支路）：
- 抽头 $1$：加权 $b_2$，符号「$+$」$\;\to\; +b_2$
- 抽头 $z^{-1}$：加权 $b_1$，符号「$-$」$\;\to\; -b_1 z^{-1}$
- 主线路抽头 $z^{-2}$：默认加权 $1$，默认正号 $\;\to\; +b_0 z^{-2}$

得分子：$b_2 - b_1 z^{-1} + b_0 z^{-2}$

**分母**（反馈支路，符号取反）：
- 第一项 $X(z)$：$1$
- 抽头 $z^{-1}$ → 加权 $a_1$，标注「$+$」→ 取反为 $-a_1 z^{-1}$
- 抽头 $z^{-2}$ → 加权 $a_0$，标注「$-$」→ 取反为 $+a_0 z^{-2}$

得分母：$1 - a_1 z^{-1} + a_0 z^{-2}$

结果与前述严格推导完全一致。

## 五、直接写出法示例（例二）

给出一个标准结构系统框图，要求直接写出 $H(z)$ 和差分方程。

> [!example] 由框图直接求系统函数和差分方程
> 已知标准二阶系统框图，正向支路有：从抽头 $1$ 经加权 $0.5$ 到输出加法器（标注「$$+$$」）；主线路从 $z^{-2}$ 到输出加法器（默认加权 $1$，默认「$$+$$」）。反馈支路有：从 $z^{-1}$ 经加权 $1$ 到输入加法器（标注「$$-$$」）；从 $z^{-2}$ 经加权 $0.02$ 到输入加法器（标注「$$-$$」）。求 $H(z)$ 和差分方程。
>
> **解：** 直接在框图上标注抽头值 $1$、$z^{-1}$、$z^{-2}$，按对应规律写出。
>
> **分子**（正向支路）：
> - 抽头 $1$，加权 $0.5$，符号「$$+$$」$\;\to\; 0.5$
> - 抽头 $z^{-2}$，主线路，默认加权 $1$，默认「$$+$$」$\;\to\; +z^{-2}$
>
> 分子：$0.5 + z^{-2}$
>
> **分母**（反馈支路，符号取反）：
> - 输入 $X(z)$：$1$
> - 抽头 $z^{-1}$，加权 $1$，标注「$$-$$」$\;\to\;$ 取反为 $+z^{-1}$
> - 抽头 $z^{-2}$，加权 $0.02$，标注「$$-$$」$\;\to\;$ 取反为 $+0.02 z^{-2}$
>
> 分母：$1 + z^{-1} + 0.02 z^{-2}$
>
> 故：
> $$H(z) = \frac{0.5 + z^{-2}}{1 + z^{-1} + 0.02 z^{-2}}$$
>
> 整理为 $Y(z)(1 + z^{-1} + 0.02 z^{-2}) = X(z)(0.5 + z^{-2})$，两边 z 反变换得差分方程：
> $$y(n) + y(n-1) + 0.02 y(n-2) = 0.5 x(n) + x(n-2)$$

> [!note] 缺失抽头的处理
> $z^{-1}$ 抽头在本例中没有正向支路，分子中对应项缺失（系数为 $0$）。这在实际结构中完全正常——并非每个抽头都必须有支路。

## 本讲小结

### 知识地图

本讲是离散系统从「频域分析」（系统函数 $H(z)$）向「物理实现」（网络结构）过渡的关键环节。三种系统表示方式——系统框图（结构视角）、差分方程（时域递推视角）、系统函数（频域代数视角）——彼此等价。掌握由框图直接读出 $H(z)$ 的方法，为后续学习 IIR 直接型、级联型、并联型以及 FIR 的各种实现结构（横向结构、频率采样结构等）打下基础。

| 对比维度 | 时域表示 | z 域表示 |
|---------|---------|---------|
| 延迟器 | $y(n) = x(n-1)$ | $Y(z) = z^{-1}X(z)$ |
| 加权器 | $y(n) = a x(n)$ | $Y(z) = a X(z)$ |
| 加法器 | $y(n) = x_1(n) + x_2(n)$ | $Y(z) = X_1(z) + X_2(z)$ |
| 系统描述 | 差分方程 | 系统函数 $H(z)$ |

### 核心公式表

| 名称 | 表达式 | 说明 |
|------|--------|------|
| 分子多项式（正向支路） | $\displaystyle\sum_{i=0}^{M} b_i z^{-i}$ | 系数符号与框图标号相同 |
| 分母多项式（反馈支路） | $\displaystyle 1 - \sum_{i=1}^{N} a_i z^{-i}$ | 系数符号与框图标号相反 |
| 系统函数 | $H(z) = \dfrac{Y(z)}{X(z)}$ | 系统框图的核心频域表达 |
| z 反变换对应关系 | $z^{-k} \leftrightarrow \delta(n-k)$ | 用于从 $H(z)$ 返回差分方程 |

### 易错点

> [!warning] 常见错误
> - **反馈支路符号忘记取反**：框图标注「$$-$$」的反馈支路，进入分母多项式时变为「$$+$$」；标注「$$+$$」的变为「$$-$$」。这是最容易出错的地方。
> - **分子和分母的规则搞反**：分子（正向支路）符号不变，分母（反馈支路）符号取反——两者的处理规则不同。
> - **忘记在分母第一项写 $1$**：$H(z)$ 的分母常数项始终来自 $X(z)$，系数恒为 $1$。
> - **主线路延迟器数量判断失误**：数延迟器个数时注意每个 $\mathrm{D}$ 代表一个 $z^{-1}$，而不是 $z^{-2}$。
> - **加法器输入端口的正负号看错**：必须严格按箭头端标注的符号写入方程。
