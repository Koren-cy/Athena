# 第32讲 系统框图及其结构形式


## 一、系统框图与系统函数的关系

系统函数的分子分母分别对应系统结构中的不同支路，支路的传输函数组合成系统函数。这种直接对应时域差分方程各级组成关系的结构，称为**直接型系统框图**。

直接型系统框图有两种排列方式：
- **横向排列**：延迟器横向排列
- **纵向排列**：延迟器纵向排列形成直接型系统结构

## 二、级联型与并联型结构

对于一个系统函数 $H(z)$，可以通过多项式运算得到不同形式的模拟方案。

### 级联型（Cascade Form）

将系统函数分解为多个因式相乘的形式：

$$H(z) = H_1(z) \cdot H_2(z) \cdot ... \cdot H_k(z)$$

每个因式对应一个独立的子系统，子系统串联得到级联型结构。

### 并联型（Parallel Form）

通过部分分式展开，将系统函数分解为多个多项式相加：

$$H(z) = H_1(z) + H_2(z) + ... + H_k(z)$$

各子系统并联，输入信号同时进入每个子系统，输出相加。

## 三、例题

### 例一：级联型与并联型模拟

> 已知离散系统的差分方程，分别用级联型和并联型模拟该系统。

**解题步骤：**

1. **求系统函数**：对差分方程两边进行零状态 Z 变换，整理得到 $H(z) = \frac{Y(z)}{X(z)}$

2. **因式分解**：将分子分母进行多项式因式分解
   - 例如：分子提取公因子后为 $2(1 + z^{-2})$
   - 分母分解为 $(1 + 0.5z^{-1})(1 + 0.25z^{-2})$

3. **级联型实现**：
   - 将各个因式任意两两组合
   - 例如 $H(z) = \frac{2}{1-0.5z^{-1}} \cdot \frac{1+z^{-2}}{1+0.25z^{-2}}$
   - 第一项为一阶系统（一个延迟器），第二项为二阶系统
   - 分别画出各子系统的结构图后串联

4. **并联型实现**：
   - 进行部分分式展开
   - 例如展开为 $H(z) = \frac{A}{1+0.5z^{-1}} + \frac{B+Cz^{-1}}{1+0.25z^{-2}}$
   - 第一项为一阶系统，第二项为二阶系统
   - 各子系统并联，输出相加

### 级联型系统的画法要点

- 一阶系统主线路两端各有一个加法器，中间一个延迟器
- 反馈支路的加权值与分母多项式对应项系数符号**相反**
- 分子系数对应前向支路加权值
- 二阶系统需画两节延迟器，标注 $z^{-1}$ 和 $z^{-2}$ 抽头

### 并联型系统的画法要点

- 各子系统独立画出
- 输入信号同时进入所有子系统
- 各子系统输出相加得到总输出

## 四、非标准结构的分析方法

### 例二：非标准系统框图求系统函数

> 给出一个非标准结构图，要写出系统函数，进而求解系统差分方程。

**解题步骤：**

1. **找输入输出关系**：识别真正的加法器（忽略只有一个输入端的无效加法器）

2. **设中间变量**：令各加法器输出为 $X_1(z), X_2(z), ...$

3. **标注延迟器**：在延迟器输入输出端标注 $z^{-1}, z^{-2}$，确定系统阶数

4. **列加法器方程**：
   - 对每个加法器，列出输入输出方程
   - 如 $X_2(z) = \frac{5}{6}z^{-1}X_1(z) - \frac{1}{6}z^{-2}X_1(z)$
   - $X_1(z) = X(z) + X_2(z)$

5. **写出输出方程**：$Y(z)$ 从相关节点出发，沿支路推导

6. **消去中间变量**：联立方程消去 $X_1(z), X_2(z)$ 等，得到 $H(z) = \frac{Y(z)}{X(z)}$

7. **反变换得差分方程**：整理为 $Y(z)$ 和 $X(z)$ 的关系式，进行 Z 反变换

## 关键公式

1. 系统函数与差分方程的关系：$H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$

2. 级联型：$H(z) = H_1(z) \cdot H_2(z) \cdot ... \cdot H_k(z)$

3. 并联型：$H(z) = H_1(z) + H_2(z) + ... + H_k(z)$

4. 反馈支路符号规则：分母多项式系数 $a_k$ 对应反馈支路加权 $-a_k$

5. 支路传输函数：串联支路合并为乘积，并联支路合并为求和

## 易错点

1. **反馈支路符号反转**：分母多项式中 $a_k$ 为正时，信号流图中反馈支路加权为 $-a_k$，切勿忘记符号反转

2. **无效加法器**：只有一个输入端的加法器实际上是直通，不是真正的加法，需在分析时剔除

3. **级联顺序不影响系统函数**：不同因式组合方式可得到不同级联结构，系统函数不变

4. **部分分式展开**：并联型需要正确进行部分分式展开，注意假分式时先做长除法

5. **零状态假设**：求系统函数时默认按零状态求解，不代入初始条件
