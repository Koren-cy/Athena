# 第34讲 巴特沃斯模拟低通滤波器设计

## 频响特性与滤波器分类

系统的频率响应 $H(j\Omega)$（连续）或 $H(e^{j\omega})$（离散）是一个复数：
- **幅频响应特性**：模 $|H(j\Omega)|$，表示不同频率信号的增益
- **相频响应特性**：相位 $\angle H(j\Omega)$

**模拟频率与数字频率的区别**：
- 大 $\Omega$ 表示模拟角频率（rad/s）
- 小 $\omega$ 表示数字角频率（rad）
- 关系：$\omega = \Omega T_s = \frac{2\pi f}{f_s}$

### 经典滤波器类型

| 类型 | 特点 |
|------|------|
| **低通** | 低频信号通过，高频信号衰减 |
| **高通** | 高频信号通过，低频信号衰减 |
| **带通** | 某一频段信号通过，其余衰减 |
| **带阻** | 某一频段信号衰减，其余通过 |

## 模拟滤波器设计模板

传统模拟滤波器设计主要有以下几种模板：

| 滤波器类型 | 通带特性 | 过渡带 | 特点 |
|-----------|---------|--------|------|
| **巴特沃斯** | 最平坦（无波纹） | 较宽 | 最常用，基本款 |
| **切比雪夫** | 有波纹 | 较窄 | 过渡带更陡 |
| **椭圆** | 有波纹 | 最窄 | 相同阶数下过渡带最窄 |
| **贝塞尔** | — | — | 线性相位特性好 |

## 巴特沃斯低通滤波器设计

### 关键参数

- $\Omega_p$：**通带截止频率** — 信号可无失真通过的最高频率
- $\Omega_s$：**阻带截止频率** — 信号被大幅衰减的起始频率
- $\Omega_c$：**3dB 截止频率** — 功率下降到最大值一半（幅度下降到 $\frac{\sqrt{2}}{2}$）时的频率
- $\alpha_p$：**通带衰减**（dB）
- $\alpha_s$：**阻带衰减**（dB）

巴特沃斯滤波器将频率范围分为三段：**通带**、**过渡带**、**阻带**。

### 巴特沃斯滤波器的特点

- 系统函数是**全极点型**（只有极点，没有零点）
- 极点均匀分布在以 $\Omega_c$ 为半径的**巴特沃斯圆**上，间隔为 $\pi/n$
- 极点关于实轴对称
- 只有**左半平面**的 $n$ 个极点构成因果稳定系统
- 阶数 $n$ 越大，过渡带下降越快，越接近理想滤波器
- 各阶曲线都通过固定的 **3dB 点**（不随 $n$ 变化）

### 设计步骤

**步骤一：确定阶数 $n$**
- 计算参数 $k_{sp} = \sqrt{\frac{10^{\alpha_s/10} - 1}{10^{\alpha_p/10} - 1}}$
- 计算归一化频率比 $\lambda_{sp} = \frac{\Omega_s}{\Omega_p}$
- $n = \frac{\log k_{sp}}{\log \lambda_{sp}}$，结果**向上取整**

**步骤二：查表得归一化传输函数 $G_a(p)$**

查巴特沃斯归一化低通滤波器参数表：
- 极点位置表：给出各极点值，以因式形式写出 $G_a(p)$
- 分母多项式系数表：按降幂排列的分母多项式系数

**步骤三：计算 3dB 截止频率 $\Omega_c$**
- 以通带截止频率 $\Omega_p$ 为参考：$\Omega_c = \Omega_p \cdot (10^{\alpha_p/10} - 1)^{-1/(2n)}$
- $\Omega_c$ 一般在 $\Omega_p$ 和 $\Omega_s$ 之间

**步骤四：频率转换**
- 令 $p = \frac{s}{\Omega_c}$，代入 $G_a(p)$ 得到 $H_a(s) = G_a(p)\big|_{p = s/\Omega_c}$

### 例题

> **例一：** 给定通带截止频率、阻带截止频率、通带衰减、阻带衰减，设计巴特沃斯低通滤波器。

**解题过程：**
1. 将线频率 $f$ 转换为角频率 $\Omega = 2\pi f$
2. 计算 $k_{sp}$ 和 $\lambda_{sp}$，代入公式得 $n = 4.25$，向上取整得到 $n = 5$
3. 查表得 $n=5$ 对应的归一化传输函数 $G_a(p)$ 的分母多项式系数
4. 计算 $\Omega_c$（以通带指标为参考）
5. 令 $p = \frac{s}{\Omega_c}$ 代入 $G_a(p)$，得到 $H_a(s)$

> **例二：** 直接给出 $G_a(p)$ 结构和 3dB 截止频率，考察最后一步的频率转换。

**解题过程：**
- 已知 $\Omega_c$，直接将 $p = \frac{s}{2}$ 代入 $G_a(p)$
- 化简得到 $H_a(s)$

## 关键公式

1. 频率转换：$\Omega = 2\pi f$

2. 阶数公式：$n = \frac{\log k_{sp}}{\log \lambda_{sp}}$，$k_{sp} = \sqrt{\frac{10^{\alpha_s/10} - 1}{10^{\alpha_p/10} - 1}}$，$\lambda_{sp} = \frac{\Omega_s}{\Omega_p}$

3. 3dB 截止频率：$\Omega_c = \Omega_p \cdot (10^{\alpha_p/10} - 1)^{-1/(2n)}$

4. 频率转换代入：$H_a(s) = G_a(p)\big|_{p = s/\Omega_c}$

5. 3dB 点幅度：$|H(j\Omega_c)| = \frac{\sqrt{2}}{2}$，对应功率下降一半

## 易错点

1. **阶数向上取整**：计算得到的 $n$ 必须向上取整（如 4.25 取 5），取整不足会导致阻带指标不满足

2. **频率单位转换**：线频率 $f$（Hz）需转换为角频率 $\Omega$（rad/s），公式 $\Omega = 2\pi f$；但在计算频率比时 $2\pi$ 可约去

3. **查表方法**：极点位置表得到的是因式形式，多项式系数表得到的是分母多项式系数，注意区分

4. **$\Omega_c$ 的范围**：$\Omega_c$ 应在 $\Omega_p$ 和 $\Omega_s$ 之间，如果计算异常需检查公式是否用对

5. **阻带指标验算**：当 $\Omega_s$ 与 $\Omega_p$ 接近时，需要验算阻带指标是否有富余
