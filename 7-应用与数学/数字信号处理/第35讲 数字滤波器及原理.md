# 第35讲 数字滤波器及原理

> [!abstract] 本讲定位
> 本讲属于滤波器设计模块的基础理论部分，前承模拟滤波器知识与采样定理，核心任务是建立模拟域与数字域频率参数之间的定量桥梁，并掌握数字滤波器频响特性的分析方法。本讲结论将直接用于后续 IIR 滤波器的双线性变换法设计以及 FIR 滤波器频响分析。

## 一、数字滤波器概述

数字信号处理是用数值计算方法对信号进行处理的技术，实现这种数值计算的系统称为**数字滤波器**。

数字滤波器按功能可分为两类：

- **经典滤波器**：滤除噪声干扰、提取特定频段有用信号。如低通、高通、带通、带阻滤波器，其设计思路与传统模拟滤波器一脉相承。
- **现代滤波器**：实现波形形成、调制解调、混叠滤波、信道均衡等更灵活的信号处理功能，不限于简单的频率选择。

数字滤波器的分析与设计是数字信号处理中最核心、最贴近工程实践的部分。

## 二、模拟域的频率参数

在信号处理中，连续时间信号与离散时间序列各有一套频率参数体系，极易混淆。本节先梳理模拟域的频率概念。

**定义**（模拟角频率 $\Omega$）：对于典型单频信号 $\cos(\Omega t)$，参数 $\Omega$ 称为**模拟角频率**，单位为弧度每秒（rad/s）。其几何含义是复平面上旋转射线绕原点转动的角速度。

**定义**（线频率 $f$）：线频率 $f$ 是单位时间内完成完整周期变化的次数，单位为赫兹（Hz），物理含义为 $\text{s}^{-1}$。线频率是连续时间域特有的参数，工程中常用的"多少赫兹""多少兆赫兹"指的就是线频率。

**定义**（周期 $T$）：连续时间信号的周期 $T$ 指函数值重复出现的最短时间间隔，单位为秒（s）。

三个参数之间的关系如下：

$$T = \frac{1}{f}, \quad \Omega = 2\pi f, \quad T = \frac{2\pi}{\Omega}$$

> [!important] 模拟域频率三参数关系
> 线频率 $f$、角频率 $\Omega$、周期 $T$ 三者互通：知道任意一个即可导出另外两个。这三个参数均带有实际物理单位，对应真实的物理时间尺度。

**物理含义**：角频率 $\Omega$ 描述旋转快慢，线频率 $f$ 描述重复次数，周期 $T$ 描述重复间隔。$\Omega = 2\pi f$ 的本质是：旋转一周（$2\pi$ 弧度）对应于一次完整的周期变化。

## 三、采样与数字频率的建立

通过采样，连续时间信号被转换为时间离散的序列。这一过程引入了采样频率，也建立了数字频率与模拟频率之间的桥梁。

采样信号本质上仍在连续时间域中，因此采样周期 $T_s$、采样频率 $f_s$、采样角频率 $\Omega_s$ 服从与第二节相同的关系：

$$T_s = \frac{1}{f_s}, \quad \Omega_s = 2\pi f_s, \quad T_s = \frac{2\pi}{\Omega_s}$$

**推导**（数字角频率 $\omega$ 的建立）：

设被采样的模拟信号为 $\cos(2\pi f t)$。采样后，连续时间自变量 $t$ 替换为 $n T_s$：

$$\cos(2\pi f t) \Big|_{t = nT_s} = \cos(2\pi f \cdot n T_s) = \cos\left(2\pi f T_s \cdot n\right)$$

与离散余弦序列的标准形式 $\cos(\omega n)$ 对比，可得数字角频率 $\omega$ 的表达式：

$$\boxed{\omega = 2\pi f T_s}$$

将 $T_s = 1/f_s$ 代入，得到工程中最常用的形式：

$$\boxed{\omega = 2\pi \frac{f}{f_s}}$$

若被采样信号用模拟角频率 $\Omega$ 表示（$\Omega = 2\pi f$），则：

$$\boxed{\omega = \Omega T_s}$$

这三式完全等价，可根据已知条件灵活选用。

> [!important] 数字频率的归一化本质
> 从 $\omega = 2\pi f/f_s$ 可以看出，$\omega$ 是信号频率 $f$ 与采样频率 $f_s$ 的**比值**再乘以 $2\pi$。$f$ 与 $f_s$ 单位均为 Hz，二者相除后单位抵消，因此 $\omega$ 的单位是弧度，是**无量纲的归一化频率**。

**工程含义**：给定一个数字频率 $\omega$，仅凭 $\omega$ 本身无法对应到某个具体的 Hz 值或频段。必须将 $\omega$ 乘以采样频率 $f_s$（即还原 $\omega \cdot f_s / (2\pi) = f$）才能对应现实中的通信频率。

## 四、数字频率的周期性与归一化特征

**采样定理约束**：根据奈奎斯特采样定理，$f_s \geq 2f_{\text{max}}$，即被采样信号的最高频率不超过采样频率的一半。代入 $\omega = 2\pi f/f_s$：

$$f_{\text{max}} \leq \frac{f_s}{2} \quad\Rightarrow\quad \omega_{\text{max}} = 2\pi \frac{f_{\text{max}}}{f_s} \leq 2\pi \cdot \frac{f_s/2}{f_s} = \pi$$

因此在数字域中，$\omega$ 的取值范围被限制在 $[-\pi, \pi]$ 或 $[0, 2\pi]$ 区间内。

**频谱的周期延拓**：连续信号的频谱经采样脉冲作用后，在角频率轴上以 $\Omega_s$ 为间隔不断重复。数字域的频率响应也因此是以 $2\pi$ 为周期的周期函数，因为 $\omega_s = \Omega_s T_s = 2\pi f_s \cdot (1/f_s) = 2\pi$。

> [!important] 数字域频率特征总结
> - 数字频率 $\omega$ 是归一化频率，无量纲，单位 rad。
> - 数字频率响应以 $2\pi$ 为周期。
> - $\pi$ 对应模拟域的最高无混叠频率 $f_s/2$（即被采样带限信号的最高频率）。
> - $0$ 和 $2\pi$ 在单位圆上对应同一点，均代表低频。

> [!tip] 记忆技巧
> 在数字频率轴上，**低频靠近 0 和 $2\pi$（两端），高频靠近 $\pi$（中间）**。这与模拟域"频率沿轴递增"的直觉不同，是初学者最易混淆之处。

**数字信号的周期**：对于离散序列，周期 $N$ 指每隔固定整数个样值，序列按相同规律重复变化。$N$ 无量纲，仅表示采样点数。例如在单位圆上等分 8 点，则数字周期为 8。

## 五、模拟滤波器与数字滤波器的频响特性

> [!warning] 核心差异
> 模拟滤波器与数字滤波器频响曲线形态不同的根本原因是**对"高频"的定义不同**。模拟域高频在 $\Omega \to \infty$，数字域高频在 $\omega = \pi$ 附近。

**理想模拟低通滤波器**：通带为 $[0, \Omega_c]$（$\Omega_c$ 为截止角频率），$\Omega > \Omega_c$ 时幅度为零，信号不能通过。

**理想数字低通滤波器**：通带靠近 $\omega = 0$ 和 $\omega = 2\pi$（单位圆上 $z = 1$ 附近）。根据第四节结论，$0$ 和 $2\pi$ 均对应低频，因此数字低通滤波器的通带集中在频率轴的两端。

**理想模拟高通滤波器**：通带为 $(\Omega_c, \infty)$，$\Omega < \Omega_c$ 处信号被抑制。

**理想数字高通滤波器**：通带靠近 $\omega = \pi$（即单位圆上 $z = -1$ 附近），因为 $\pi$ 对应于模拟域的最高频率 $f_s/2$。

各类滤波器的频响特征可统一归纳如下：

| 滤波器类型 | 模拟域通带位置 | 数字域通带位置 |
|-----------|-------------|-------------|
| 低通 | $[0, \Omega_c]$ | $\omega = 0$ 及 $\omega = 2\pi$ 附近 |
| 高通 | $(\Omega_c, \infty)$ | $\omega = \pi$ 附近 |
| 带通 | $[\Omega_1, \Omega_2]$ | $\omega = \pi/2$ 两侧某区间 |
| 带阻 | $[0, \Omega_1] \cup [\Omega_2, \infty)$ | 除中间某段外的两侧 |

> [!info] 工程应用
> 经典滤波器的幅频响应在通带内为常数（或近似常数），阻带内为零（或近似为零），以此实现不同频段信号的分离。数字滤波器画频响曲线时通常只画 $[0, 2\pi]$ 一个周期。

## 六、由系统函数判断滤波器类型

系统的幅频响应曲线由系统函数 $H(z)$ 决定。本节介绍两种从 $H(z)$ 出发判断滤波器类型的方法。

### 几何法绘制幅频响应

**原理**：已知系统函数 $H(z)$ 的零极点分布，可借助几何直观估算幅频响应 $|H(e^{j\omega})|$。

将 $z = e^{j\omega}$ 代入系统函数的因式分解形式：

$$|H(e^{j\omega})| = \frac{\prod_{k=1}^{M} |e^{j\omega} - z_k|}{\prod_{k=1}^{N} |e^{j\omega} - p_k|}$$

其中 $z_k$ 为系统零点，$p_k$ 为系统极点，$|e^{j\omega} - z_k|$ 表示单位圆上的动点 $e^{j\omega}$ 到零点 $z_k$ 的距离，$|e^{j\omega} - p_k|$ 表示动点到极点 $p_k$ 的距离。

**几何含义**：$|H(e^{j\omega})|$ 等于"所有零点到 $e^{j\omega}$ 的距离之积"除以"所有极点到 $e^{j\omega}$ 的距离之积"。

**操作步骤**：

1. 求出 $H(z)$ 的全部零点和极点，标注在 z 平面上。
2. 令动点 $e^{j\omega}$ 从 $\omega = 0$ 出发，沿单位圆逆时针旋转一周至 $\omega = 2\pi$。
3. 在若干特殊频点处，量取各零极点到动点的距离，代入公式计算 $|H(e^{j\omega})|$。
4. 用描点法连接各计算值，得到 $[0, 2\pi]$ 范围内的幅频响应曲线。

**演示**：设系统函数为 $H(z) = \dfrac{z - 0.5}{z + 0.5}$。零点为 $z_1 = 0.5$，极点为 $p_1 = -0.5$。

在四个特殊频点处计算幅频响应值：

- $\omega = 0$（$z = 1$）：$|H(e^{j0})| = \dfrac{|1 - 0.5|}{|1 + 0.5|} = \dfrac{0.5}{1.5} = \dfrac{1}{3}$
- $\omega = \dfrac{\pi}{2}$（$z = j$）：$|H(e^{j\pi/2})| = \dfrac{|j - 0.5|}{|j + 0.5|} = \dfrac{\sqrt{0.25 + 1}}{\sqrt{0.25 + 1}} = 1$
- $\omega = \pi$（$z = -1$）：$|H(e^{j\pi})| = \dfrac{|-1 - 0.5|}{|-1 + 0.5|} = \dfrac{1.5}{0.5} = 3$
- $\omega = \dfrac{3\pi}{2}$（$z = -j$）：$|H(e^{j3\pi/2})| = \dfrac{|-j - 0.5|}{|-j + 0.5|} = 1$

描点连线可知，幅频响应在 $\omega = \pi$ 附近取值最大，向两侧递减，$\omega = 0$ 处取值最小。因此该系统是**高通滤波器**。

> [!note] 几何直觉
> 零点靠近单位圆上某点时，该频点处幅频响应被压低；极点靠近单位圆上某点时，该频点处幅频响应被抬高。高通滤波器的零点分布在低频方向（正实轴），极点分布在高频方向（负实轴），正是利用这一几何原理。

### 特殊频点代入法

对于填空或选择题，无需完整描点。直接计算 $|H(e^{j\omega})|$ 在 $\omega = 0$、$\pi/2$、$\pi$ 处的值，即可快速判定滤波器类型。

令 $H(z)$ 中 $z = e^{j\omega}$，得频率响应 $H(e^{j\omega})$，分别代入三个关键频点：

| $\omega = 0$ 处 | $\omega = \pi/2$ 处 | $\omega = \pi$ 处 | 滤波器类型 |
|:---:|:---:|:---:|:---:|
| 大（常数 $> 1$ 或 $\gg 0$） | — | 小（$\approx 0$ 或显著更小） | **低通** |
| 小（$\approx 0$ 或显著更小） | — | 大（$> 1$ 或显著更大） | **高通** |
| 小 | 大 | 小 | **带通** |
| 大 | 小 | 大 | **带阻** |

**原理**：该方法实质是几何法的简化——仅在三个能表征"低频/中频/高频"位置的特征频点处采样，无需逐点计算即可把握频响曲线的整体趋势。

> [!tip] 解题技巧
> 考试中遇到判断滤波器类型的填空题时，只需令 $z = 1$（$\omega = 0$）和 $z = -1$（$\omega = \pi$），计算两个幅频值并比较大小：$|H(1)| > |H(-1)|$ 则为低通，$|H(1)| < |H(-1)|$ 则为高通。若怀疑是带通或带阻，再补算 $z = j$（$\omega = \pi/2$）。

## 本讲小结

### 知识地图

本讲是数字滤波器设计的**频率基础课**。前驱知识为模拟系统频率参数（$\Omega$、$f$、$T$）和奈奎斯特采样定理。本讲的核心贡献是建立了数字角频率 $\omega$ 与模拟频率的定量关系 $\omega = \Omega T_s = 2\pi f/f_s$，并阐明了数字频率的归一化本质和周期性（周期 $2\pi$，$\pi$ 对应 $f_s/2$）。在此基础之上，介绍了数字滤波器频响特性的分析方法（几何法和特殊频点代入法），为后续 IIR 滤波器设计中的频率预畸变和双线性变换提供了理论准备。

模拟域与数字域的频率参数对比：

| 对比维度 | 模拟域 | 数字域 |
|------|------|------|
| 角频率符号 | $\Omega$（大写） | $\omega$（小写） |
| 单位 | rad/s | rad（无量纲） |
| 频率范围 | $[0, \infty)$ | $[0, 2\pi]$（周期性重复） |
| 高频位置 | $\Omega \to \infty$ | $\omega = \pi$ 附近 |
| 低频位置 | $\Omega = 0$ | $\omega = 0$ 及 $\omega = 2\pi$ |
| 周期参数 | $T$（秒） | $N$（采样点数，无量纲） |
| 线频率 | $f$（Hz） | 无对应量（需乘以 $f_s$ 恢复） |

滤波器类型与频响特征对比：

| 滤波器类型 | 模拟域频响特征 | 数字域频响特征（$[0, 2\pi]$ 范围） |
|------|------|------|
| 低通 | $\vert H(j\Omega)\vert$ 在 $\Omega=0$ 附近最大，$\Omega \to \infty$ 趋于零 | $\vert H(e^{j\omega})\vert$ 在 $\omega=0$ 和 $\omega=2\pi$ 附近最大，$\omega=\pi$ 处最小 |
| 高通 | $\vert H(j\Omega)\vert$ 在 $\Omega \to \infty$ 处为常数，$\Omega=0$ 附近趋于零 | $\vert H(e^{j\omega})\vert$ 在 $\omega=\pi$ 附近最大，$\omega=0$ 处最小 |
| 带通 | 中间某频段为通带，两侧为阻带 | $\omega=0$ 和 $\omega=\pi$ 处均小，中间某段高 |
| 带阻 | 中间某频段为阻带，两侧为通带 | $\omega=0$ 和 $\omega=\pi$ 处均大，中间某段低 |

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| 模拟角频率与线频率 | $\Omega = 2\pi f$ | 连续时间域 |
| 周期与线频率 | $T = 1/f$ | 连续时间域 |
| 周期与角频率 | $T = 2\pi/\Omega$ | 连续时间域 |
| 采样周期与采样频率 | $T_s = 1/f_s$ | 采样过程 |
| 数字角频率（形式一） | $\omega = \Omega T_s$ | 已知模拟角频率 $\Omega$ 和采样间隔 $T_s$ |
| 数字角频率（形式二） | $\omega = 2\pi f T_s$ | 已知信号线频率 $f$ 和采样间隔 $T_s$ |
| 数字角频率（形式三） | $\omega = 2\pi f/f_s$ | 已知信号频率 $f$ 和采样频率 $f_s$（最常用） |
| 数字采样频率 | $\omega_s = \Omega_s T_s = 2\pi$ | 恒成立 |
| 几何法幅频响应 | $\vert H(e^{j\omega})\vert = \dfrac{\prod \vert e^{j\omega} - z_k\vert}{\prod \vert e^{j\omega} - p_k\vert}$ | $H(z)$ 零极点已知 |

### 易错点

- **混淆 $\Omega$ 与 $\omega$**：$\Omega$ 单位为 rad/s，有物理量纲；$\omega$ 单位为 rad，是归一化无量纲量。两者通过 $\omega = \Omega T_s$ 联系，不可混用。
- **认为 $\omega$ 直接对应某个具体的 Hz 值**：$\omega$ 是归一化频率，必须乘以 $f_s / (2\pi)$ 才能还原为实际频率 $f$。
- **在数字域中用模拟域的直觉判断高低频**：数字域低频在两端（$0$ 和 $2\pi$），高频在中间（$\pi$ 附近），与模拟域"频率沿轴单调递增"的直觉相反。
- **忽略 $\pi$ 的物理含义**：$\pi$ 对应 $f_s/2$，是被采样带限信号的最高无混叠频率，不是任意频率。
- **用特殊频点代入法时只比较 $\omega=0$ 和 $\omega=\pi$**：可能漏判带通或带阻滤波器，必要时应补算 $\omega = \pi/2$。
- **几何法中混淆分子分母**：分子是零点距离之积，分母是极点距离之积。零点压低频响，极点抬高频响。
