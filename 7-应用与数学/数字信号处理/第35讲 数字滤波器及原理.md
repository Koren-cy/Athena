# 第35讲 数字滤波器及原理

> 来源：[[DSP 数字信号处理（超浓缩版）]] 第35讲

## 模拟信号与数字信号的基本参数

### 频率相关参数定义

| 参数 | 符号 | 单位 | 说明 |
|-----|------|------|------|
| 模拟角频率 | $\Omega$ | rad/s | 连续信号旋转角速度 |
| 线频率 | $f$ | Hz | 每秒周期变化次数 |
| 数字角频率 | $\omega$ | rad | 归一化频率，无量纲 |
| 模拟周期 | $T$ | s | 连续信号重复的时间间隔 |
| 数字周期 | $N$ | 无单位 | 序列每隔 $N$ 个样值重复 |

### 核心关系

模拟信号频率关系：
$$\Omega = 2\pi f,\quad T = \frac{1}{f},\quad T = \frac{2\pi}{\Omega}$$

数字频率与模拟频率的关系（通过采样）：
$$\omega = \Omega T_s = \frac{2\pi f}{f_s}$$

其中 $T_s$ 为采样间隔，$f_s = 1/T_s$ 为采样频率。

### 数字频率的重要特性

- 数字频率 $\omega$ 是**归一化频率**（$f/f_s$ 为比值，单位抵消）
- 根据采样定理 $f_s \geq 2f$，数字频率 $\omega \leq \pi$
- 数字频率以 $2\pi$ 为周期
- $\pi$ 对应时域中被采样带限信号的**最高频率**

## 模拟滤波器与数字滤波器的映射关系

### 频谱的周期延拓

连续信号频谱在采样脉冲作用下产生周期延拓，以 $\Omega_s = 2\pi/T_s$ 为间隔不断重复。在数字域中，这对应单位圆上以 $2\pi$ 为周期旋转。

### 频率响应的对应

- **模拟低通滤波器**：通带在低频端（$\Omega < \Omega_c$）
- **数字低通滤波器**：通带在 $\omega = 0$ 和 $\omega = 2\pi$ 附近（低频端）

- **模拟高通滤波器**：通带在高频端（$\Omega > \Omega_c$）
- **数字高通滤波器**：通带在 $\omega = \pi$ 附近（高频端）

### 不同滤波器的数字域特性

| 滤波器类型 | 模拟域通带位置 | 数字域通带位置 |
|-----------|--------------|--------------|
| 低通 | $\Omega < \Omega_c$ | $\omega = 0$ 和 $\omega = 2\pi$ 附近 |
| 高通 | $\Omega > \Omega_c$ | $\omega = \pi$ 附近 |
| 带通 | $\Omega_{pL} < \Omega < \Omega_{pU}$ | 中间频段 |
| 带阻 | 与带通相反 | 与带通相反 |

## 几何法判断滤波器类型

### 零极点几何法

根据系统函数的零极点分布，在单位圆上设置动点从 $0$ 到 $2\pi$ 转动：

$$|H(e^{j\omega})| = \frac{\prod \text{零点到动点距离}}{\prod \text{极点到动点距离}}$$

### 特殊频点代入法快速判断

令 $H(z)$ 中的 $z = e^{j\omega}$，代入 $\omega = 0$ 和 $\omega = \pi$ 计算：

| 条件 | 滤波器类型 |
|-----|-----------|
| $\omega = 0$ 时 $|H(e^{j\omega})|$ 大（>1），$\omega = \pi$ 时小 | **低通** |
| $\omega = 0$ 时 $|H(e^{j\omega})|$ 小（≈0），$\omega = \pi$ 时大 | **高通** |
| $\omega = \pi/2$ 时 $|H(e^{j\omega})|$ 大 | **带通** |

### 例题：由系统函数判断滤波器类型

> 系统函数 $H(z) = \frac{z + 0.5}{z - 0.5}$，零点为 -0.5，极点为 0.5

**求解过程：**
1. 令 $z = e^{j\omega}$
2. 在 $\omega = 0$ 处：$|H(e^{j0})| = |(1+0.5)/(1-0.5)| = 3$（较小）
3. 在 $\omega = \pi$ 处：$|H(e^{j\pi})| = |(-1+0.5)/(-1-0.5)| = 1/3$（大）
4. 代入 $\omega = \pi/2$、$3\pi/2$ 等特殊频点计算描点
5. 画出幅频响应曲线，在 $\pi$ 附近响应值高 → **高通滤波器**

## 关键公式

1. 模拟频率关系：$\Omega = 2\pi f$，$T = 1/f$，$T = 2\pi/\Omega$

2. 数字频率与模拟频率：$\omega = \Omega T_s = \frac{2\pi f}{f_s}$

3. 采样频率与采样周期：$f_s = 1/T_s$，$\Omega_s = 2\pi f_s$

4. 系统频响：$H(e^{j\omega}) = H(z)\big|_{z=e^{j\omega}}$

5. 几何法幅频响应：$\displaystyle |H(e^{j\omega})| = \frac{\prod_{i=1}^{M} |e^{j\omega} - z_i|}{\prod_{i=1}^{N} |e^{j\omega} - p_i|}$

## 易错点

1. **模拟频率与数字频率符号混淆**：大 $\Omega$ 是模拟角频率（rad/s），小 $\omega$ 是数字角频率（rad），两者不可混用

2. **数字频率的归一化特性**：$\omega = 2\pi f/f_s$ 中 $f/f_s$ 是比值，单位抵消，因此数字频率无量纲

3. **数字域高频位置**：数字域中高频在 $\pi$ 附近而非大数值处，这是与模拟域最根本的区别

4. **采样定理约束**：数字频率 $\omega$ 最大为 $\pi$（对应模拟最高频率 $f_s/2$），不会达到 $2\pi$

5. **代入法判断滤波器类型**：$\omega=0$ 对应直流分量，$\omega=\pi$ 对应最高频率分量，代入计算时注意区分结果大小关系
