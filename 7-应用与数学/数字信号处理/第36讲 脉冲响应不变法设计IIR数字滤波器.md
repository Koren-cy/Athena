# 第36讲 脉冲响应不变法设计IIR数字滤波器

> [!abstract] 本讲定位
> 本讲属于IIR数字滤波器设计模块，前承[[第35讲 模拟滤波器设计]]中的巴特沃斯低通滤波器设计方法，介绍间接法设计IIR数字滤波器的第一种核心方法——脉冲响应不变法。本讲的s平面到z平面映射关系是理解所有间接设计法的关键，后续[[第37讲 双线性变换法设计IIR数字滤波器]]将在此基础上引入克服频率混叠的改进方案。

## 一、数字滤波器的分类

### 1.1 IIR与FIR的基本区分

数字滤波器按单位脉冲响应长度可分为两类。

**定义**：若离散系统的单位脉冲响应 $h(n)$ 的长度无限，则称该系统为无限长单位脉冲响应（IIR, Infinite Impulse Response）滤波器。若 $h(n)$ 在有限个采样点后恒为零，则称为有限长单位脉冲响应（FIR, Finite Impulse Response）滤波器。

IIR滤波器的系统函数具有有理分式形式：

$$H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$$

分母中 $z$ 的最低幂次为 $-N$，称为 $N$ 阶 IIR 滤波器。滤波器的阶数由分母的阶数决定。IIR滤波器的单位脉冲响应 $h(n)$ 是对应的连续系统单位冲激响应 $h_a(t)$ 采样得到的，因此 $H(z)$ 与 $H_a(s)$ 之间具有内在联系。

FIR滤波器的系统函数为多项式形式：

$$H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$$

这是一个 $N-1$ 阶的有限长脉冲响应滤波器，在 $z$ 平面上有 $N-1$ 个零点，系统始终稳定。

> [!important] 核心结论
> FIR滤波器最突出的优点是稳定和线性相位，能够在保证幅度特性满足技术要求的同时，严格实现线性相位特性，在数字通信领域具有重要作用。现代数字滤波器大多数属于FIR类型。

### 1.2 设计方法的分类

| | 直接法 | 间接法 |
|---|---|---|
| **思路** | 利用数值计算算法直接在离散域设计滤波器 | 先设计模拟滤波器，再转换为数字滤波器 |
| **IIR** | — | 脉冲响应不变法、双线性变换法 |
| **FIR** | 窗函数法、频率采样法、切比雪夫等波纹逼近法 | 不可用 |

> [!warning] 易错点
> FIR滤波器不能采用间接法实现。间接法仅适用于IIR滤波器的设计。

## 二、间接法设计IIR滤波器的总体框架

**定义**：间接法是指借助成熟的模拟滤波器设计技术，先设计出模拟滤波器的传输函数 $H_a(s)$，再通过某种映射关系将其转换为离散系统的系统函数 $H(z)$。

设计步骤：
1. 根据给定的数字滤波器技术指标（通带频率、阻带频率、通带衰减、阻带衰减），确定模拟滤波器的对应指标
2. 选用合适的模拟滤波器原型（巴特沃斯型、切比雪夫型等），设计出 $H_a(s)$
3. 通过 $s$ 域到 $z$ 域的映射关系，将 $H_a(s)$ 转换为 $H(z)$

模拟滤波器设计技术已非常成熟，有多种典型的优良滤波器模板可直接使用，使间接法极为便捷。步骤3是间接法的核心环节——如何将 $H_a(s)$ 转换为 $H(z)$，本质上就是拉普拉斯变换与 $z$ 变换的关系问题。

## 三、脉冲响应不变法的基本原理

### 3.1 设计目标

$H_a(s)$ 与 $H(z)$ 的相似性体现在两个层面：

- **结构相似**：两者都是系统函数，可通过变量代换转换为频率响应函数
- **频响一致**：转换后滤波器的频率响应类型应保持不变——原为低通则转换后仍为低通，原为高通则转换后仍为高通

两者的差异则是转换需要解决的核心问题：

| | 模拟系统 $H_a(s)$ | 离散系统 $H(z)$ |
|---|---|---|
| 域 | 连续时间 | 离散时间 |
| 变换 | 拉普拉斯变换 | $z$ 变换 |
| 自变量 | $s = \sigma + j\Omega$ | $z$ |
| 对应平面 | $s$ 平面 | $z$ 平面 |

### 3.2 s平面到z平面的映射关系

$s$ 平面与 $z$ 平面之间的映射是理解脉冲响应不变法的关键。

在 $s$ 平面中，复变量 $s = \sigma + j\Omega$，水平轴为实部 $\sigma$，垂直轴为虚部 $j\Omega$，模拟角频率 $\Omega$ 沿虚轴方向线性递增。

在 $z$ 平面中，$z = e^{sT} = e^{\sigma T} e^{j\Omega T}$，数字频率 $\omega = \Omega T$ 绕原点旋转，旋转一周对应 $2\pi$。

$s$ 平面到 $z$ 平面的映射关系由 $z$ 变换与拉普拉斯变换的关系给出：

$$z = e^{sT}$$

其中 $T$ 为采样间隔。

> [!important] 核心结论：s平面到z平面的映射特性
>
> 1. **周期性映射**：数字频率 $\omega$ 以 $2\pi$ 为周期。$s$ 平面上沿虚轴每个宽度为 $2\pi/T$ 的水平条带，都映射到 $z$ 平面的整个单位圆。例如 $-\pi/T$ 到 $\pi/T$ 映射到一个单位圆，$\pi/T$ 到 $3\pi/T$ 映射到同一个单位圆。
>
> 2. **稳定性保持**：$s$ 左半平面（$\sigma < 0$）映射到 $z$ 平面单位圆内部（$|z| < 1$）。因此，稳定的模拟系统（极点在 $s$ 左半平面）转换后仍为稳定的离散系统（极点在单位圆内）。
>
> 3. **极点数量不变**：$s$ 域左半平面一个 $2\pi/T$ 范围内的极点，映射到 $z$ 平面一个单位圆内的对应数量极点。

正是这种映射关系保证了：模拟低通滤波器转换后仍是数字低通滤波器，滤波器类型的对应关系得以保持。

### 3.3 从模拟极点到数字极点的转换

设模拟系统的系统函数 $H_a(s)$ 有一个极点 $s = -0.9$：

$$H_a(s) = \frac{1}{s + 0.9}$$

由 $z = e^{sT}$，该极点映射为 $z$ 域的极点 $z_1 = e^{-0.9T}$。若取 $T = 1$，则 $z_1 \approx 0.406$。

$z$ 域单极点系统的标准形式为：

$$H(z) = \frac{1}{1 - a z^{-1}}$$

其中极点即为 $z^{-1}$ 项的系数 $a$。因此可直接写出离散系统函数。

## 四、脉冲响应不变法的实用公式

### 4.1 公式形式

设模拟滤波器 $H_a(s)$ 经部分分式展开为：

$$H_a(s) = \sum_{i=1}^{N} \frac{A_i}{s - s_i}$$

其中 $s_i$ 为 $H_a(s)$ 的极点，$A_i$ 为部分分式展开的各项系数。

则脉冲响应不变法将 $H_a(s)$ 转换为：

$$H(z) = \sum_{i=1}^{N} \frac{T A_i}{1 - e^{s_i T} z^{-1}}$$

> [!important] 实用公式中各符号的含义
>
> - $s_i$：模拟系统 $H_a(s)$ 的极点，位于 $s$ 平面
> - $T$：采样间隔。若无特殊说明，可取 $T = 1$
> - $A_i$：部分分式展开时每一项的系数
> - $e^{s_i T}$：映射到 $z$ 域后的极点

### 4.2 公式的物理含义

单独观察公式中的一项：

$$\frac{T A_i}{1 - e^{s_i T} z^{-1}}$$

其对应的时域序列为 $T A_i (e^{s_i T})^n u(n) = T A_i e^{s_i T n} u(n)$。

而在模拟域中，$\dfrac{A_i}{s - s_i}$ 对应的单位冲激响应为 $A_i e^{s_i t} u(t)$。

对比可知：离散序列 $h(n)$ 恰好是连续冲激响应 $h_a(t)$ 在 $t = nT$ 处的采样值。即

$$h(n) = T \cdot h_a(t)\big|_{t = nT}$$

这就是该方法被称为"脉冲响应不变法"的原因——系统的脉冲响应在转换中保持形式不变，只是从连续域变换到了离散域。

> [!note] 与教材的联系
> 分子中的 $T$ 因子用于抵消采样信号频谱中出现的 $1/T$ 项。当采样频率较高（$T$ 较小）时，若不加 $T$ 因子补偿，频响幅值会过大。相关推导参见教材第2.4节「时域离散信号的傅里叶变换与模拟信号傅里叶变换之间的关系」。

## 五、典型例题

> [!example] 用脉冲响应不变法将模拟滤波器转换为数字滤波器
> 已知 $H_a(s) = \dfrac{1}{2s^2 + 3s + 1}$，用脉冲响应不变法求 $H(z)$，取 $T = 1$。
>
> **解：**
>
> **第一步**：部分分式分解。
>
> 分母因式分解：$2s^2 + 3s + 1 = 2(s + 0.5)(s + 1)$
>
> $H_a(s) = \frac{1}{2(s+0.5)(s+1)}$
>
> 设 $\dfrac{1}{2(s+0.5)(s+1)} = \dfrac{A_1}{s+0.5} + \dfrac{A_2}{s+1}$，由部分分式法：
>
> $A_1 = \left.\frac{1}{2(s+1)}\right|_{s=-0.5} = \frac{1}{2 \times 0.5} = 1, \quad A_2 = \left.\frac{1}{2(s+0.5)}\right|_{s=-1} = \frac{1}{2 \times (-0.5)} = -1$
>
> 故 $H_a(s) = \dfrac{1}{s+0.5} - \dfrac{1}{s+1}$，即极点 $s_1 = -0.5$，$s_2 = -1$，系数 $A_1 = 1$，$A_2 = -1$。
>
> **第二步**：转换为数字极点（$T = 1$）。
>
> $z_1 = e^{s_1 T} = e^{-0.5} \approx 0.6065$
>
> $z_2 = e^{s_2 T} = e^{-1} \approx 0.3679$
>
> **第三步**：代入实用公式。
>
> $$H(z) = \frac{T A_1}{1 - z_1 z^{-1}} + \frac{T A_2}{1 - z_2 z^{-1}} = \frac{1}{1 - 0.6065 z^{-1}} - \frac{1}{1 - 0.3679 z^{-1}}$$
>
> **第四步**：通分化简。
>
> $$H(z) = \frac{(1 - 0.3679 z^{-1}) - (1 - 0.6065 z^{-1})}{(1 - 0.6065 z^{-1})(1 - 0.3679 z^{-1})} = \frac{0.2386 z^{-1}}{1 - 0.9744 z^{-1} + 0.2231 z^{-2}}$$
>
> 分子分母同乘 $z^2$ 得标准形式：
>
> $$H(z) = \frac{0.2386 z}{z^2 - 0.9744 z + 0.2231}$$

## 六、巴特沃斯低通滤波器的脉冲响应不变法设计流程

当设计要求通带和阻带具有单调下降特性时，可选用巴特沃斯低通滤波器作为设计原型。完整设计流程如下：

1. **指标转换**：将数字频率指标转换为模拟频率指标，$\Omega_p = \omega_p / T$，$\Omega_s = \omega_s / T$
2. **求阶数**：按巴特沃斯滤波器设计公式计算阶数 $N$，向上取整
3. **查表得极点**：查巴特沃斯归一化低通滤波器极点位置表，获得 $N$ 个极点 $p_k$
4. **部分分式展开**：将 $N$ 个一阶因式的乘积展开为 $N$ 项之和，确定各项系数 $A_k$
5. **求截止频率**：计算 $3\text{dB}$ 截止频率 $\Omega_c$，令 $p = s/\Omega_c$ 得到 $H_a(s)$
6. **极点映射**：用 $z_i = e^{s_i T}$ 将每个模拟极点转换为数字极点
7. **写出 $H(z)$**：代入实用公式逐项写出，通分得到标准形式

> [!tip] 工程实践
> 手工计算高阶（如六阶）巴特沃斯滤波器的复极点参数极其繁琐——极点一般为复数，小数位数多。实际工程中交给 MATLAB 计算，关键函数调用即可直接输出 $H(z)$ 分子分母多项式的系数矩阵。但理解手工推导过程是掌握该方法原理的基础。

> [!warning] 易错点
> 查极点位置表时注意：表中所列为极点 $p_k$，对应因式为 $p - p_k$ 而非 $s - p_k$。代入 $p = s/\Omega_c$ 后才能得到以 $s$ 为自变量的系统函数 $H_a(s)$。

## 本讲小结

### 知识地图

本讲属于IIR数字滤波器间接设计法的第一部分。前驱知识包括模拟巴特沃斯低通滤波器设计（第35讲）以及 $s$ 域与 $z$ 域的基本映射关系（$z$ 变换与拉普拉斯变换的联系）。本讲核心——脉冲响应不变法——利用 $z = e^{sT}$ 将模拟极点直接映射为数字极点，保持了脉冲响应形式不变，因而也保持了滤波器类型和稳定性。该方法的固有缺陷（频率混叠）将在本讲末尾以思考题引出，并在第37讲双线性变换法中得到解决。

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| s-z 映射 | $z = e^{sT}$ | 脉冲响应不变法的理论基础 |
| 脉冲响应不变法 | $H(z) = \sum_{i=1}^{N} \dfrac{T A_i}{1 - e^{s_i T} z^{-1}}$ | $H_a(s)$ 已分解为部分分式，$s_i$ 为极点，$A_i$ 为系数 |
| 模拟极点转数字极点 | $z_i = e^{s_i T}$ | $T$ 为采样间隔 |
| 一阶项时域对应 | $\dfrac{1}{1 - a z^{-1}} \leftrightarrow a^n u(n)$ | $\vert a \vert < 1$（稳定） |

### 易错点

- [!warning] FIR滤波器不能使用间接法设计，间接法仅适用于IIR滤波器
- [!warning] $s$ 平面到 $z$ 平面的映射 $z = e^{sT}$ 是多对一映射：$s$ 域虚轴上每隔 $2\pi/T$ 的条带都映射到同一个单位圆，这是脉冲响应不变法产生频率混叠的根本原因
- [!warning] 高阶滤波器查表得到的是归一化极点 $p_k$，需要用 $p = s/\Omega_c$ 代换后才能得到 $H_a(s)$ 的实际极点 $s_i$
- [!warning] 实用公式分子中的 $T$ 不可遗漏，它用于抵消采样引入的 $1/T$ 因子
- [!warning] 部分分式展开时注意系数——例如 $2s+1 = 2(s+0.5)$，写成标准形式 $(s+0.5)$ 后系数需要相应调整
