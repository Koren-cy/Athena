# 第36讲 脉冲响应不变法设计IIR滤波器


## 一、IIR 与 FIR 滤波器的基本区别

### IIR 滤波器（无限长单位脉冲响应）
- 系统函数分子分母都是 $z$ 的多项式：$\displaystyle H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$
- 分母比分子多了一个常数项 1
- 阶数由分母的阶数 $N$ 决定，称为 $N$ 阶 IIR 滤波器
- 单位脉冲响应对连续系统单位冲激响应的采样

### FIR 滤波器（有限长单位脉冲响应）
- 系统函数为求和形式：$\displaystyle H(z) = \sum_{k=0}^{N-1} b_k z^{-k}$
- $N-1$ 阶（有 $N-1$ 个零点）
- 系统**无条件稳定**
- 线性相位特性是突出优点

## 二、IIR 滤波器的设计方法

### 直接法
利用数值计算算法原理，直接设计滤波器结构。

### 间接法（利用模拟滤波器模板）
1. 先设计模拟滤波器传输函数 $H_a(s)$
2. 将 $H_a(s)$ 转换为离散系统函数 $H(z)$
3. 两种常用转换方法：
   - **脉冲响应不变法**
   - **双线性变换法**

## 三、脉冲响应不变法的核心原理

### s 平面到 z 平面的映射关系

s 平面与 z 平面的映射关系：
$$z = e^{sT_s}$$

其中 $T_s$ 为采样间隔。

映射特点：
- s 平面虚轴 $j\Omega$ 映射到 z 平面单位圆
- s 平面左半平面映射到 z 平面单位圆内（保证稳定性）
- s 平面每一条宽 $2\pi/T_s$ 的水平带映射到整个 z 平面
- 频率响应保持不变：模拟低通 → 数字低通，模拟高通 → 数字高通

### 极点转换公式

若 $H_a(s)$ 有极点 $s_i$，则对应 $H(z)$ 的极点为：
$$z_i = e^{s_iT_s}$$

### 实用转换公式

将 $H_a(s)$ 部分分式展开后：
$$H_a(s) = \sum_{i=1}^{N} \frac{A_i}{s - s_i}$$

转换到数字域：
$$H(z) = \sum_{i=1}^{N} \frac{T_s A_i}{1 - e^{s_i T_s} z^{-1}}$$

其中：
- $s_i$ 是 $H_a(s)$ 的极点
- $A_i$ 是部分分式展开的系数
- $T_s$ 是采样间隔（无特殊说明可取 $T_s = 1$）
- 分子乘以 $T_s$ 是为了抵消系统频响中的 $1/T_s$ 项

## 五、例题

### 例一：设计数字低通滤波器（完整流程）

> 给定数字低通滤波器的通带频率、阻带频率、通带衰减、阻带衰减指标，用脉冲响应不变法设计。

**解题步骤：**

1. **数字频率转模拟频率**：
   $$\Omega = \frac{\omega}{T_s}$$

2. **设计模拟巴特沃斯低通滤波器**：
   - 按 $H_a(s)$ 设计方法求阶数 $n$（向上取整得 $n=6$）
   - 查巴特沃斯归一化低通滤波器极点位置表
   - 6 个极点对应 6 个因式相乘
   - 部分分式分解为 6 项相加，系数为 $A_1, A_2, ...$

3. **求 3dB 截止频率 $\Omega_c$**：
   - 按标准公式计算

4. **频率转换得 $H_a(s)$**：
   - 令 $p = \frac{s}{\Omega_c}$ 代入 $G_a(p)$

5. **极点转换**：
   - 求出 $H_a(s)$ 的极点 $s_i$（如 $s_1 = -0.2588\Omega_c - j0.9695\Omega_c$）
   - 用 $z = e^{sT_s}$ 转换为数字极点 $z_i$

6. **写出 $H(z)$ 并联形式**：
   $$H(z) = \sum_{i=1}^{6} \frac{T_s A_i}{1 - z_i z^{-1}}$$

7. **通分化简**得到 $H(z)$ 标准形式

### 例二：简单系统的脉冲响应不变法转换

> 已知 $H_a(s) = \frac{1}{2s^2 + 3s + 1}$，用脉冲响应不变法转换为数字滤波器。

**解题步骤：**

1. **部分分式分解**：
   $$H_a(s) = \frac{1}{(2s+1)(s+1)} = \frac{A}{s+1} + \frac{B}{s+\frac{1}{2}}$$
   
   解得 $A = 1$，$B = -1$

2. **求极点**：
   $s_1 = -1$，$s_2 = -\frac{1}{2}$（均为实数）

3. **转换为数字极点**：
   $z_1 = e^{-T_s}$，$z_2 = e^{-0.5T_s}$

4. **写出 $H(z)$ 并联形式**：
   $$H(z) = \frac{T_s}{1 - e^{-T_s}z^{-1}} - \frac{T_s}{1 - e^{-0.5T_s}z^{-1}}$$

5. **通分化简**得到 $H(z)$ 标准形式

## 四、脉冲响应不变法的局限性

- **会产生混叠现象**，因为 s 平面到 z 平面是多值映射
- 不适用于**高通**和**带阻**滤波器的设计（高频部分会严重混叠）
- 适用于**低通**和**带通**滤波器（高频分量少的场景）

## 关键公式

1. s 平面到 z 平面的映射：$z = e^{sT_s}$

2. 极点转换：$z_i = e^{s_i T_s}$

3. 脉冲响应不变法转换公式：$\displaystyle H(z) = \sum_{i=1}^{N} \frac{T_s A_i}{1 - e^{s_i T_s} z^{-1}}$

4. 数字频率转模拟频率：$\Omega = \frac{\omega}{T_s}$

5. 一阶节基本结构：$\displaystyle \frac{1}{1 - a z^{-1}}$ 对应原函数 $a^n u[n]$

## 易错点

1. **部分分式分解**：必须先将 $H_a(s)$ 分解为真分式相加的形式，再逐项转换，假分式需要先长除法

2. **分子漏乘 $T_s$**：实用公式中分子需乘以采样间隔 $T_s$，以抵消频响中的 $1/T_s$，不可遗漏

3. **复数极点处理**：复数极点的转换仍然使用 $z = e^{sT_s}$，结果仍为复数，需成对处理

4. **混叠效应**：脉冲响应不变法会产生频率混叠，注意仅适用于低通和有限带宽的带通滤波器

5. **$T_s$ 的取值**：无特殊说明可取 $T_s = 1$，但对实际系统需按采样频率计算

6. **查表的极点排列**：查巴特沃斯极点位置表确定极点时，注意极点是 $p - p_k$ 因式形式，需正确相乘
