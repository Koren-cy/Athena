# 第40讲 IIR滤波器的基本网络结构

> [!abstract] 本讲定位
> 本讲属于数字滤波器实现模块，前承 IIR 滤波器设计方法，解决如何将设计得到的系统函数 $H(z)$ 转化为可实现的滤波网络。介绍的四种基本结构（直接一型、直接二型、级联型、并联型）是后续硬件或软件实现滤波器的基础。本讲末尾从 IIR 的无限脉冲响应特性自然引出 FIR 滤波器的概念，为下一讲做铺垫。

## 一、从系统函数到网络结构

IIR 数字滤波器设计完成后，得到的是系统函数 $H(z)$ 的有理分式。下一步需要将 $H(z)$ 转化为具体的数字滤波网络——即用加法器、乘法器和单位延迟器构成的物理可实现结构。

设 $N$ 阶 IIR 滤波器的系统函数为：

$$H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}} = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2} + \cdots + b_M z^{-M}}{1 + a_1 z^{-1} + a_2 z^{-2} + \cdots + a_N z^{-N}}$$

分子为 $M+1$ 项，分母首项归一化为 $1$ 后共 $N+1$ 项。对于实际 IIR 滤波器，阶数通常较高，需要采用结构清晰、延迟器用量少的实现方案。

## 二、直接一型结构

**定义**：直接一型结构是按系统函数 $H(z)$ 的分子多项式（前向支路）和分母多项式（反馈支路）分别实现，再通过加法器合并的结构。两种支路各有一套独立的延迟器链。

### 构建步骤

规定信号流向从左到右。

**第一步：绘制分子对应的前向支路。**

画出主支路，在输出端设加法器。从加法器前的节点引出 $M$ 节延迟器，依次向下排列，每节标注 $z^{-1}$。各延迟器抽头处的支路方向与主线路相同（向右），经加法器汇入主支路输出端。支路权值依次为 $b_0, b_1, \ldots, b_M$。其中 $b_0$ 对应未经延迟的直通支路，直接在主线上标注。

**第二步：绘制分母对应的反馈支路。**

在输入端添加加法器，延长主线路。引出 $N$ 节延迟器向下排列。各延迟器输出端的支路方向与主线路相反（向左向上），经加法器叠加后返回主线路。

> [!important] 反馈支路权值符号规则
> 反馈支路的权值取分母多项式系数的相反数，即标注 $-a_1, -a_2, \ldots, -a_N$。这是因为差分方程中反馈项移至等号另一侧时符号反转。

**第三步：标注输入和输出。**

支路两端分别标注 $x(n)$ 和 $y(n)$，即得完整的直接一型结构。

### 信号流图表示

更简洁的表示方式采用信号流图：用节点代替加法器，用箭头表示信号传递方向。箭头上标注 $z^{-1}$ 表示单位延迟，箭头旁标注数字表示乘法权值。按上述构建步骤分别在信号流图中绘出前向支路和反馈支路，标注对应权值，即得直接一型的信号流图。

### 结构特点

- 前向支路需 $M$ 个延迟器，反馈支路需 $N$ 个延迟器
- 总延迟器数：$M + N$
- 优点：结构直观，系数与系统函数各项一一对应
- 缺点：延迟器数量较多，资源利用不经济

## 三、直接二型结构（典范型）

### 核心思路

直接一型中前向支路和反馈支路各有独立的延迟器链，处理的是同一信号的延迟序列，可以合并共用。

**构建方法**：将直接一型中反馈支路和前向支路的位置互换——反馈支路放在左侧，前向支路放在右侧。此时两组延迟器处于公共支路上，省去一套延迟器链。

### 结构特点

- 延迟器数：$\max(M, N)$
- 是所有实现结构中延迟器数量最少的

> [!important] 典范型
> 直接二型所需延迟器最少，因此也称为**典范型结构**。在硬件资源受限时为首选实现方案。

### 画法要点

以反馈支路在左、前向支路在右的顺序绘制。公共延迟器链上标注 $z^{-1}$。反馈支路的权值仍为 $-a_k$，前向支路的权值仍为 $b_k$。

> [!warning] 易错点
> 由直接一型换为直接二型时，仅交换反馈与前向的位置并合并延迟器链。系数的值和符号均不变——不要改动任何系数。

## 四、级联型结构

**定义**：将系统函数 $H(z)$ 分解为多个低阶子系统的乘积，各子系统串联连接的结构称为级联型。

$$H(z) = H_1(z) \cdot H_2(z) \cdot \ldots \cdot H_K(z)$$

### 实现要点

- 每个子系统 $H_k(z)$ 一般不超过二阶，内部用直接二型实现
- 画法：先判断各子系统的阶数以确定延迟器数量，分别绘出反馈和前向支路，再串联连接各子系统
- 各二阶节的系数只影响本级输出，便于独立调整

### 优点

零极点可灵活配对，量化噪声性能可通过调整子系统顺序来优化。

## 五、并联型结构

**定义**：将系统函数 $H(z)$ 通过部分分式展开为多个低阶子系统之和，各子系统并联连接（输入相同，输出相加）的结构称为并联型。

$$H(z) = C + H_1(z) + H_2(z) + \cdots + H_K(z)$$

其中 $C$ 为直流项常数。

### 实现要点

**情况一：分子阶数小于分母阶数（真分式）。**

直接进行部分分式展开，按分母因式列项。

**情况二：分子阶数等于或大于分母阶数（假分式）。**

先用长除法分离出一个常数项 $C$ 和一个真分式 $H_0(z)$：
$$H(z) = C + H_0(z)$$
再对 $H_0(z)$ 做部分分式展开。

### 部分分式系数求解

当分母阶数较高、极点不容易直接求解时，可采用待定系数法：按分母因式列项，每项系数设为待定值 $A, B, \ldots$；通分后利用同类项系数相等的原理列方程，求解待定系数。

### 并联画法

- 直流项 $C$：直接画一条无延迟支路，标注权值 $C$
- 各子系统：分别用直接二型实现，所有子系统输入相连，输出汇入同一加法器

### 二阶节的概念

> [!important] 二阶节
> 级联型和并联型中，子系统一般最多由二阶组成，称为**二阶节**。二阶节是大型数字滤波系统的基本构建单元。

每个二阶节的权值只影响该子系统的输出，不影响其他子系统。当滤波器参数需要调整时，各子系统的作用相互独立，比直接型滤波器更便于控制和优化。

> [!tip] 记忆技巧
> 级联型 = 乘积 → 串联连接；并联型 = 求和 → 并联连接。两类结构的共同设计模式：基本单元均用二阶节，二阶节内部均用直接二型。

## 六、典型例题

> [!example] 直接一型和直接二型结构实现
> 已知 IIR 滤波器的系统函数
> $$H(z) = \frac{1 + 2z^{-1} - 0.5z^{-2}}{1 + 3z^{-1} + 3z^{-2} + z^{-3}}$$
> 分别画出直接一型和直接二型网络结构。
>
> **解：**
>
> 分子为二阶（$M = 2$），系数：$b_0 = 1, \; b_1 = 2, \; b_2 = -0.5$。分母为三阶（$N = 3$），系数：$a_1 = 3, \; a_2 = 3, \; a_3 = 1$。
>
> **直接一型画法：**
>
> 1. 画出从左到右的主支路，输出端设加法器。
> 2. 前向部分：从加法器前节点引出两节向下排列的延迟器，标注 $z^{-1}$。$b_0 = 1$ 直通支路在主线上。从第一个延迟器输出端向右向上引出支路，权值 $2$。从第二个延迟器输出端引出支路，权值 $-0.5$。三路汇入加法器。
> 3. 反馈部分：延长主线路，引出三节向下排列的延迟器。从各延迟器输出端向左向上引出反馈支路，权值取分母系数相反数：$-3, -3, -1$。汇入输入端的加法器。
> 4. 两端标注 $x(n)$ 和 $y(n)$。
>
> **直接二型画法：**
>
> 将直接一型中的前向和反馈支路位置互换——反馈在左、前向在右。省去前向部分的两节延迟器，仅保留公共的三节延迟器链。左侧反馈权值 $-3, -3, -1$，右侧前向权值 $1, 2, -0.5$。

> [!example] 级联型与并联型实现
> 已知系统函数以多个因式的乘积形式给出，令
> $$H(z) = H_1(z) \cdot H_2(z)$$
> 其中 $H_1(z)$ 为一阶系统，$H_2(z)$ 为二阶系统。分别画出级联型和并联型网络结构。
>
> **解：**
>
> **级联型：**
>
> 两个子系统均用直接二型实现：
> - $H_1(z)$（一阶）：分子分母均含 $z^{-1}$ 项，需一个延迟器。反馈权值从延迟器输出端向左向上引出（符号与分母系数相反），前向权值从延迟器输出端向右向上引出。主线上另有直通权值 $b_0$。
> - $H_2(z)$（二阶）：需两个延迟器。按直接二型分别绘出反馈支路和前向支路。两子系统串联连接。
>
> **并联型：**
>
> 将 $H(z)$ 分解为多个子系统之和。本题分子分母同阶（假分式），先用长除法得直流项 $C = 12.346$。剩余真分式按分母因式进行部分分式展开，用待定系数法求解各系数。
>
> 画法：
> 1. 直流项 $12.346$：直接画一条无延迟支路，标注权值。
> 2. 一阶子系统：仅含反馈支路，若分子无 $z^{-1}$ 项则在输入端标注直通权值。
> 3. 二阶子系统：含两条反馈支路和一条前向支路。
> 4. 三个子系统的输入端并联，输出端汇入同一加法器。

> [!example] 由网络结构反求系统函数与单位脉冲响应
> 已知一个直接二型系统的信号流图：反馈支路权值分别为 $3/4$ 和 $-1/8$（符号已取反），前向支路权值分别为 $1$ 和 $1/3$。初始条件 $h(-1) = 1$，$h(-2) = 2$。
>
> 求：（1）系统函数 $H(z)$ 和差分方程；（2）用递推法求单位脉冲响应 $h(n)$ 的前三项值；（3）判断系统属于 IIR 还是 FIR 滤波器，说明理由。
>
> **解：**
>
> **（1）系统函数与差分方程**
>
> 在直接二型信号流图中，反馈支路标注的权值是分母多项式系数的相反数：
> $$-a_1 = \frac{3}{4},\quad -a_2 = -\frac{1}{8}$$
> 得 $a_1 = -\dfrac{3}{4}$，$a_2 = \dfrac{1}{8}$。
>
> 前向支路权值直接为分子系数：$b_0 = 1$，$b_1 = \dfrac{1}{3}$。
>
> 故系统函数：
> $$H(z) = \frac{1 + \frac{1}{3}z^{-1}}{1 - \frac{3}{4}z^{-1} + \frac{1}{8}z^{-2}}$$
>
> 由 $H(z) = Y(z)/X(z)$，交叉相乘：
> $$Y(z)\left(1 - \frac{3}{4}z^{-1} + \frac{1}{8}z^{-2}\right) = X(z)\left(1 + \frac{1}{3}z^{-1}\right)$$
>
> 取逆 $z$ 变换，得差分方程：
> $$y(n) - \frac{3}{4}y(n-1) + \frac{1}{8}y(n-2) = x(n) + \frac{1}{3}x(n-1)$$
>
> 整理为标准形式：
> $$y(n) = x(n) + \frac{1}{3}x(n-1) + \frac{3}{4}y(n-1) - \frac{1}{8}y(n-2)$$
>
> **（2）递推法求前三项单位脉冲响应**
>
> 令输入 $x(n) = \delta(n)$，则输出 $y(n) = h(n)$，代入差分方程：
> $$h(n) = \delta(n) + \frac{1}{3}\delta(n-1) + \frac{3}{4}h(n-1) - \frac{1}{8}h(n-2)$$
>
> 关键前提：$\delta(n)$ 仅在 $n = 0$ 时取值为 $1$，其余 $n$ 均为 $0$，即 $\delta(0) = 1$，$\delta(-1) = \delta(1) = \delta(2) = 0$。代入递推：
>
> $$\begin{aligned}
> h(0) &= \delta(0) + \frac{1}{3}\delta(-1) + \frac{3}{4}h(-1) - \frac{1}{8}h(-2) \\[4pt]
>      &= 1 + 0 + \frac{3}{4} \times 1 - \frac{1}{8} \times 2 = 1 + \frac{3}{4} - \frac{1}{4} = \frac{3}{2} \\[10pt]
> h(1) &= \delta(1) + \frac{1}{3}\delta(0) + \frac{3}{4}h(0) - \frac{1}{8}h(-1) \\[4pt]
>      &= 0 + \frac{1}{3} + \frac{3}{4} \times \frac{3}{2} - \frac{1}{8} \times 1 = \frac{1}{3} + \frac{9}{8} - \frac{1}{8} = \frac{4}{3} \\[10pt]
> h(2) &= \delta(2) + \frac{1}{3}\delta(1) + \frac{3}{4}h(1) - \frac{1}{8}h(0) \\[4pt]
>      &= 0 + 0 + \frac{3}{4} \times \frac{4}{3} - \frac{1}{8} \times \frac{3}{2} = 1 - \frac{3}{16} = \frac{13}{16}
> \end{aligned}$$
>
> 故 $h(0) = \dfrac{3}{2}$，$h(1) = \dfrac{4}{3}$，$h(2) = \dfrac{13}{16}$。
>
> **（3）系统类型判断**
>
> 观察递推公式，当 $n \geq 2$ 时 $\delta(n)$ 和 $\delta(n-1)$ 的贡献均为零，但 $h(n)$ 的值始终由前两个时刻的 $h(n-1)$ 和 $h(n-2)$ 经反馈支路决定。只要反馈支路存在，过去的输出将持续被反馈到输入端，不断产生新的输出。因此 $h(n)$ 是一个无限长序列。
>
> 该系统属于 **IIR（Infinite Impulse Response，无限脉冲响应）滤波器**。
>
> > [!important] IIR 与 FIR 的本质区别
> > **IIR 滤波器**：存在反馈支路（分母多项式非平凡），过去的输出持续影响未来的输出，单位脉冲响应无限长。
> >
> > **FIR 滤波器**：无反馈支路（分母多项式 $D(z) = 1$，所有 $a_k = 0$），输出仅由当前和过去的输入决定。一旦输入激励消失，响应在有限步之内终止。单位脉冲响应有限长。

## 本讲小结

### 知识地图

本讲是 IIR 滤波器从「设计」到「物理实现」的桥梁。四种基本网络结构各有适用场景：
- **直接一型**：最直观，系数与系统函数一一对应，但延迟器最多
- **直接二型**（典范型）：延迟器最少，硬件实现的首选
- **级联型**：子系统串联，零极点配对灵活，量化噪声性能可优化
- **并联型**：子系统并联，各自独立，参数调整互不干扰

本讲末尾通过对比有反馈系统的无限响应与无反馈系统的有限响应，自然引出 FIR 滤波器的概念，直接衔接下一讲 FIR 滤波器设计。

| 结构 | 延迟器数 | 子系统形式 | 核心优点 | 典型适用 |
|------|----------|-----------|----------|----------|
| 直接一型 | $M + N$ | 无需分解 | 结构直观，系数直接对应 | 低阶滤波器快速原型 |
| 直接二型 | $\max(M, N)$ | 无需分解 | 延迟器最少（典范型） | 硬件资源受限场景 |
| 级联型 | 各二阶节之和 | 一阶/二阶节串联 | 零极点配对灵活，可优化噪声 | 高精度低噪声应用 |
| 并联型 | 各二阶节之和 | 一阶/二阶节并联 | 子系统独立，调整方便 | 参数需频繁调整的系统 |

### 核心公式表

| 公式名 | 表达式 | 说明 |
|--------|--------|------|
| IIR 系统函数一般形式 | $H(z) = \dfrac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$ | 分母首项归一化为 $1$ |
| 反馈支路权值规则 | 权值 $= -a_k$ | 与分母多项式系数的符号相反 |
| 直接一型延迟器数 | $M + N$ | 前向 $M$ 个 + 反馈 $N$ 个，各有一套 |
| 直接二型延迟器数 | $\max(M, N)$ | 共用延迟器链 |
| 系统函数 ↔ 差分方程 | $y(n) = \sum_{k=0}^{M} b_k x(n-k) - \sum_{k=1}^{N} a_k y(n-k)$ | 由 $H(z) = Y(z)/X(z)$ 交叉相乘取逆变换 |
| IIR 脉冲响应长度 | 无限长 | 反馈使输出持续再生 |
| FIR 脉冲响应长度 | 有限长 | 无反馈，响应在有限步内终止 |

### 易错点

> [!warning] 常见错误
> - 反馈支路权值忘加负号：反馈系数应为 $-a_k$，不是 $a_k$
> - 直接一型换直接二型时改动系数符号：仅交换位置并合并延迟器，系数不变
> - 并联型处理假分式时漏做长除法：分子分母同阶或分子阶数更高时，应先除出直流项，再对剩余真分式做部分分式展开
> - 递推法求 $h(n)$ 时搞错 $\delta(n)$ 的非零值范围：$\delta(0) = 1$，其余所有 $n$ 处 $\delta(n) = 0$
> - 误以网络结构形式判断 IIR/FIR：核心判据是差分方程中是否有反馈项（$a_k$ 是否非零），而非网络拓扑
