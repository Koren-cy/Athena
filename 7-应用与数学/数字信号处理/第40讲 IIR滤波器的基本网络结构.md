# 第40讲 IIR滤波器的基本网络结构


## 一、IIR 滤波器的系统函数

$N$ 阶 IIR 滤波器的系统函数标准形式：

$$H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$$

其中：
- $b_0, b_1, ..., b_M$ 为前向支路系数（分子）
- $a_1, a_2, ..., a_N$ 为反馈支路系数（分母）

## 二、直接一型结构

直接一型结构直接对应差分方程和系统函数的多项式形式。

### 画法要点

1. **画主线路**：从左到右，标注 $x(n)$ 和 $y(n)$
2. **正向支路（分子部分）**：
   - 在输出端设加法器
   - 选择节点引出延迟器，依次向下排列
   - 从各延迟器抽头引出支路进入加法器
   - 支路全值：$b_0, b_1, ..., b_M$
3. **反馈支路（分母部分）**：
   - 在输入端设加法器
   - 延长主线路，引出抽头连接延迟器
   - 各延迟器输出端引出支路返回输入端加法器
   - 支路全值：$-a_1, -a_2, ..., -a_N$（符号与分母系数相反）

### 信号流图表示

直接一型的信号流图：
- 节点代替加法器
- 箭头上标注 $z^{-1}$ 表示延迟器
- 箭头标注常数表示加权值

### 直接一型的问题

- 正向支路需要 $M$ 个延迟器
- 反馈支路需要 $N$ 个延迟器
- 延迟器总数较多，不够经济

## 三、直接二型结构（典范型）

直接二型通过调整正反馈支路的位置，使延迟器放在**公共支路**上，大大节约延迟器数量。

### 转换方法

将直接一型中的正向支路和反馈支路位置互换：
- 反馈部分放在左边
- 正向部分放在右边
- 延迟器处于公共支路上

**特点**：所需延迟器最少（$\max(M, N)$ 个），称为**典范型结构**。

## 四、级联型结构

将系统函数分解为多个因式相乘：

$$H(z) = H_1(z) \cdot H_2(z) \cdot ... \cdot H_k(z)$$

每个子系统通常采用**直接二型**（最简洁），一般子系统不超过**二阶**（称为**二阶节**）。

### 级联型的优点

- 各子系统的全值只影响该子系统输出
- 参数调整相互独立，容易控制
- 比直接型更方便灵活

## 五、并联型结构

将系统函数分解为多个子系统相加：

$$H(z) = H_1(z) + H_2(z) + ... + H_k(z) + \text{常数项（直流项）}$$

### 分解方法

1. **假分式处理**：若分子与分母同阶，先用长除法得到常数项（直流分量）
2. **部分分式展开**：将余下的真分式按分母因式展开
3. **待定系数法**：设未知系数后通分，由同类项系数相等求解

### 并联型的画法

- 各子系统独立画出
- 直流项直接标为一条加权直线
- 输入输出分别用线路连接

## 六、例题

### 例一：直接一型和直接二型结构实现

> 已知 IIR 滤波器的系统函数，用直接一型和直接二型结构实现。

**直接一型画法：**

1. 分子为二阶（$M=2$），画主线路，延迟器支路向下有两阶
2. 抽头值依次为 $1, z^{-1}, z^{-2}$
3. 前向支路全值：$b_0, b_1, b_2$（如 $-5, 2, -0.5$）
4. 延长主线路，反馈部分为三阶（$N=3$）
5. 反馈支路从各抽头引出，全值为分母系数的相反数

**直接二型画法：**

1. 将直接一型中的正向和反馈位置互换
2. 省去前向部分的延迟器
3. 保留公共延迟器

### 例二：级联型结构实现

> 系统函数由多个因式组成，实现级联型结构。

1. 确定子系统：$H_1(z)$ 为一阶系统（1个延迟器），$H_2(z)$ 为二阶系统（2个延迟器）
2. 每个子系统采用直接二型（最简洁）
3. 判断延迟器数量：一阶系统用1个，二阶系统用2个
4. 分别标注反馈支路和前向支路全值

### 例三：并联型结构实现

1. 长除法得常数项（直流项）12.346
2. 部分分式展开得三个子系统
3. 直流项：直接画直线，标注全值 12.346
4. 一阶系统：只有反馈支路，分子无 $z^{-1}$ 项
5. 二阶系统：反馈有两条支路，正向有一条
6. 三个子系统并联，输入输出连接

### 例四：由直接二型结构图求系统函数和差分方程

> 给定一个直接二型系统结构图，第一问求系统函数和差分方程，第二问求单位脉冲响应的前三项。

**第一问：求系统函数**

1. 看图写 $H(z)$：
   - 分母看反馈支路，全值分别为 $3/4$ 和 $-1/8$
   - 记得符号相反（分母多项式为 $1 - \frac{3}{4}z^{-1} + \frac{1}{8}z^{-2}$）
   - 分子看前向支路：$1 + \frac{1}{3}z^{-1}$

2. $H(z) = Y(z)/X(z)$，交叉相乘后反变换得差分方程

**第二问：求单位脉冲响应的前三项**

1. 令输入 $x(n) = \delta(n)$，则输出 $y(n) = h(n)$
2. 差分方程转换为系统单位脉冲响应差分方程
3. **递推法**（只求少量样值时适用）：
   - 代入 $n = 0, 1, 2$
   - 注意 $\delta(n)$ 仅在 $n=0$ 时为 1，其余为 0
   - 利用已知初始条件 $h(-1)=1, h(-2)=2$
   - 逐步递推：$h(0) = 3/2$，$h(1) = 4/3$，$h(2) = 7/8$

**第三问：分析 IIR 特性**

- $h(2)$ 后的值由前两个时刻的值决定
- 输出不断反馈产生新输出，响应无限延伸
- 这就是 IIR（无限脉冲响应）的本质

## 七、IIR 与 FIR 的区别

- **IIR**：有反馈回路，脉冲响应无限
- **FIR**：无反馈回路，脉冲响应有限（输入停止后输出也停止）

## 关键公式

1. IIR 系统函数：$\displaystyle H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$

2. 直接一型：正向支路 $b_k$，反馈支路 $-a_k$

3. 直接二型（典范型）：所需延迟器最少 $\max(M, N)$

4. 级联型：$H(z) = H_1(z) \cdot H_2(z) \cdot ...$

5. 并联型：$H(z) = C + \sum_k H_k(z)$（$C$ 为直流项）

6. 递推法求单位脉冲响应：令 $x(n)=\delta(n)$，代入差分方程逐项计算 $h(n)$

## 易错点

1. **反馈支路符号取反**：分母多项式系数 $a_k$ 对应信号流图中的全值 $-a_k$，这是最常犯的错误

2. **阶数的确定**：$N$ 阶 IIR 滤波器分母最高幂次为 $z^{-N}$，延迟器数量等于阶数

3. **假分式处理（长除法）**：当分子阶数等于分母阶数时，不能直接部分分式展开，必须先长除法提取常数项

4. **待定系数法**：并联型分解时用待定系数法，通分后比较分子各次幂系数，容易在代数运算中出错

5. **级联型子系统的独立性**：前级子系统不影响后级，每个子系统的全值独立调整

6. **递推法中的 $\delta(n)$ 特性**：$\delta(0)=1$，其余均为 0，代入递推时注意不要遗漏
