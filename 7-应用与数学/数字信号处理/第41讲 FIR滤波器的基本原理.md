# 第41讲 FIR滤波器的基本原理

> 来源：[[DSP 数字信号处理（超浓缩版）]] 第41讲

## FIR 滤波器的数学模型

### 差分方程

FIR 滤波器的差分方程不含输出反馈项：

$$y(n) = \sum_{k=0}^{N-1} b_k \cdot x(n - k)$$

对比 IIR 滤波器，没有由反馈支路组成的 $y(n-k)$ 项。

### 单位脉冲响应

令输入 $x(n) = \delta(n)$，则输出 $y(n)$ 即为单位脉冲响应 $h(n)$：

$$h(n) = \sum_{k=0}^{N-1} b_k \cdot \delta(n - k)$$

即 FIR 滤波器的单位脉冲响应是一系列单位脉冲序列及其系数的叠加。

### 系统函数

对 $h(n)$ 进行 Z 变换，利用时移特性：

$$H(z) = \sum_{k=0}^{N-1} b_k z^{-k}$$

系统函数只有分子多项式，分母为 1。

## FIR 滤波器的零极点

### 零点

令分子多项式等于 0：
$$\sum_{k=0}^{N-1} b_k z^{-k} = 0$$

展开后得到 $N-1$ 阶多项式方程，有 $N-1$ 个零点。

### 极点

由于分母为 1（$1 - 0$），令分母为零得：
$$z^{-k} = 0 \implies z = 0$$

即系统有 $z=0$ 处的 $N-1$ 重极点。

## FIR 滤波器的稳定性

**FIR 滤波器无条件稳定**，理由如下：
- 系统函数收敛域取向外（因单位脉冲响应是右边序列、因果的）
- 所有极点都在原点（$z=0$），一定在单位圆内
- 收敛域包含单位圆

**稳定和线性相位是 FIR 滤波器最突出的优点。**

## 例题

### 例一：由差分方程系数求系统函数和频响

> 已知差分方程系数 $b_k$ 有三项：1, 2, 1（$k=0,1,2$），求系统函数和频响。

**解题步骤：**

1. **写出单位脉冲响应**：
   $$h(n) = \delta(n) + 2\delta(n-1) + \delta(n-2)$$

2. **求系统函数**（对 $h(n)$ 进行 Z 变换）：
   $$H(z) = 1 + 2z^{-1} + z^{-2}$$

3. **求频响**（令 $z = e^{j\omega}$）：
   $$H(e^{j\omega}) = 1 + 2e^{-j\omega} + e^{-2j\omega}$$

4. **结论**：系统函数和频响的各项系数与差分方程的系数相同，这是一种简单的对应关系，反之亦然。

### 例二：由单位脉冲响应分析滤波器特性

> 已知 FIR 系统的单位脉冲响应 $h(n) = \delta(n) - \delta(n-1)$，求差分方程、系统函数、频响，并分析特性。

**解题步骤：**

1. **求系统函数**（Z 变换）：
   $$H(z) = 1 - z^{-1}$$

2. **求差分方程**：
   - 由 $H(z) = Y(z)/X(z)$ 得 $Y(z) = (1 - z^{-1})X(z)$
   - 反变换：$y(n) = x(n) - x(n-1)$

3. **求频响**（令 $z = e^{j\omega}$）：
   $$H(e^{j\omega}) = 1 - e^{-j\omega}$$

4. **求幅频响应**：
   - 利用欧拉公式展开：$e^{-j\omega} = \cos\omega - j\sin\omega$
   - $H(e^{j\omega}) = (1 - \cos\omega) + j\sin\omega$
   - 模：$|H(e^{j\omega})| = \sqrt{(1-\cos\omega)^2 + \sin^2\omega}$
   - 利用半角公式化简：$|H(e^{j\omega})| = \left|2\sin\frac{\omega}{2}\right|$

5. **求相频响应**：
   - 幅角：$\phi(\omega) = \arctan\frac{\sin\omega}{1-\cos\omega}$
   - 利用半角公式化简：$\frac{\sin\omega}{1-\cos\omega} = \frac{2\sin(\omega/2)\cos(\omega/2)}{2\sin^2(\omega/2)} = \cot\frac{\omega}{2}$
   - 进一步得：$\phi(\omega) = -\frac{\omega}{2} + \frac{\pi}{2}$

6. **特性分析**：
   - 当 $\omega = 0$ 时，$|H(e^{j0})| = 0$ → **直流分量被完全滤除** → 称为**隔直滤波器**
   - 当 $\omega = \pi$ 时，$|H(e^{j\pi})|$ 最大 → **高通特性**
   - 整个曲线单调上升，通带内不平坦（不算理想高通）
   - 相频特性在 $0$ 到 $\pi$ 范围内是一条直线 → **线性相位滤波器**

## FIR 滤波器的关键特点

- 差分方程系数 = 单位脉冲响应样值 = 系统函数系数 = 频响系数
- 阶数 $N-1$ 取决于延迟器数量（$z^{-k}$ 的最高次幂）
- 改变阶数和系数组合可获得不同的滤波效果
- 设计灵活，创新空间大，但设计套路少

## 关键公式

1. FIR 差分方程：$\displaystyle y(n) = \sum_{k=0}^{N-1} b_k x(n-k)$

2. FIR 系统函数：$\displaystyle H(z) = \sum_{k=0}^{N-1} b_k z^{-k}$

3. FIR 单位脉冲响应：$\displaystyle h(n) = \sum_{k=0}^{N-1} b_k \delta(n-k)$

4. FIR 频响：$\displaystyle H(e^{j\omega}) = \sum_{k=0}^{N-1} b_k e^{-j\omega k}$

5. 幅频响应：$|H(e^{j\omega})| = \sqrt{[\text{Re}(H)]^2 + [\text{Im}(H)]^2}$

6. 相频响应：$\phi(\omega) = \arctan\frac{\text{Im}(H)}{\text{Re}(H)}$

## 易错点

1. **极点位置**：FIR 滤波器的极点在 $z=0$（原点），不是没有极点。分母为 1 只是表示没有反馈项，但系统函数仍存在多重极点

2. **阶数判断**：$N$ 项求和的 FIR 滤波器是 $N-1$ 阶（如 $H(z) = 1 + 2z^{-1} + z^{-2}$ 是 2 阶），阶数由 $z^{-k}$ 的最高次幂决定

3. **系数对应关系**：差分方程、单位脉冲响应、系统函数、频响的系数完全一致，可以从任意形式直接读出系数

4. **隔直滤波器的理解**：$\omega=0$ 时 $|H(e^{j0})|=0$ 的滤波器能完全滤除直流分量

5. **线性相位的意义**：相频特性为直线时，信号通过滤波器后各频率分量的时延相同，不会产生相位失真

6. **理想与非理想**：FIR 滤波器的幅频响应通常是缓变曲线而非陡峭的矩形特性，需要高阶数或窗函数法才能逼近理想滤波器
