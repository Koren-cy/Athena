# 第42讲 FIR滤波器的频响特性与分类

> [!abstract] 本讲定位
> 本讲属于FIR滤波器基础模块，前承FIR差分方程的定义，在本讲中推导FIR的单位脉冲响应与频率响应的一般形式，给出FIR滤波器的时域分类标准（第一类、第二类线性相位），后续将直接应用于窗函数法、频率采样法等FIR滤波器设计方法。

## 一、FIR滤波器的单位脉冲响应

FIR滤波器的差分方程标准形式为：

$$y(n) = \sum_{k=0}^{N-1} b_k x(n - k)$$

其中 $b_k$ 为滤波器系数，$N$ 为求和项数。

**定义**：FIR滤波器的**单位脉冲响应** $h(n)$ 是系统在输入为单位脉冲 $\delta(n)$ 时的零状态响应。将 $x(n) = \delta(n)$ 代入差分方程：

$$h(n) = \sum_{k=0}^{N-1} b_k \delta(n - k)$$

将求和式逐项展开：

$$h(n) = b_0 \delta(n) + b_1 \delta(n-1) + b_2 \delta(n-2) + \cdots + b_{N-1} \delta(n - (N-1))$$

由单位脉冲序列的性质：$\delta(n-k)$ 仅在 $n=k$ 时取值为 $1$，其余 $n$ 处均为 $0$。因此，对于具体的 $n = 0, 1, \ldots, N-1$：

$$h(0) = b_0, \quad h(1) = b_1, \quad h(2) = b_2, \quad \cdots, \quad h(N-1) = b_{N-1}$$

> [!important] 核心结论
> FIR滤波器的单位脉冲响应 $h(n)$ 与差分方程系数 $b_k$ 存在一一对应关系：
> $$h(n) = b_n, \quad n = 0, 1, \ldots, N-1$$
> 即 $h(n)$ 的每个样值直接等于滤波器对应阶次的系数。这一结论是推导FIR频响特性和分析 $h(n)$ 对称性的基础。

**物理意义**：FIR滤波器的系数序列就是它的单位脉冲响应。这一特性使FIR的设计可以直接在时域中操作 $h(n)$ 的样值——想要什么样的滤波效果，就设计什么样的 $h(n)$ 序列。

## 二、FIR滤波器的系统函数与频率响应

### 2.1 系统函数

由系统函数的定义 $H(z) = \sum_{n=-\infty}^{\infty} h(n) z^{-n}$，FIR的 $h(n)$ 是有限长序列，非零范围仅为 $n = 0$ 到 $N-1$，代入得：

$$H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$$

$H(z)$ 是 $z^{-1}$ 的 $N-1$ 次多项式，不含极点（除 $z=0$ 外），因此FIR滤波器始终稳定。

### 2.2 频率响应

由DTFT与z变换的关系，令 $z = e^{j\omega}$ 代入系统函数，得FIR滤波器的频率响应：

$$H(e^{j\omega}) = \sum_{n=0}^{N-1} h(n) e^{-j\omega n}$$

> [!tip] 记忆技巧
> FIR的系统函数和频率响应形式与z变换、DTFT的定义式几乎一致，区别仅在于求和范围为有限项 $n=0$ 到 $N-1$。记住这一点即可快速写出任意FIR滤波器的 $H(z)$ 和 $H(e^{j\omega})$。

### 2.3 滤波器阶数

**定义**：FIR滤波器的**阶数**等于结构中延迟器的个数，在系统函数中体现为 $z^{-1}$ 的最高次方。

对于 $N$ 项求和的FIR滤波器，$H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$，$z^{-1}$ 的最高次方为 $N-1$，故阶数为 $N-1$。

> [!warning] 易错点
> 不同教材对"阶数"的定义存在细微差异——有的称 $N$ 为阶数，有的称 $N-1$ 为阶数。判断滤波器阶数时，统一以 $z^{-1}$ 的最高指数为准，不可死记公式。例如 $H(z) = h(0) + h(1)z^{-1} + \cdots + h(6)z^{-6}$ 中最高指数为 $6$，故为六阶滤波器，尽管求和项数为 $7$。

**物理意义**：阶数等于滤波器中存储单元的数量，反映滤波器结构的复杂度。阶数越高，频率响应的可塑性越强，但所需的乘法器和延迟器也越多，实现成本随之增加。

## 三、FIR滤波器的时域分类

按时域中单位脉冲响应 $h(n)$ 的对称性，FIR滤波器分为两类线性相位滤波器。

### 3.1 第一类线性相位滤波器

**定义**：若FIR滤波器的单位脉冲响应 $h(n)$ 同时满足以下两个条件，则称为**第一类线性相位FIR滤波器**：

1. $h(n)$ 为实序列；
2. $h(n) = h(N-1-n)$，即序列前后对称的样值大小相等——偶对称。

**几何直觉**：将 $h(n)$ 的 $N$ 个样值排列为序列，以中心点为轴，左右两边的样值镜像相等。例如 $h = \{1, 2, 3, 2, 1\}$ 以 $n=2$ 为对称中心，$h(0)=h(4)=1$，$h(1)=h(3)=2$。

### 3.2 第二类线性相位滤波器

**定义**：若FIR滤波器的单位脉冲响应 $h(n)$ 满足：

1. $h(n)$ 为实序列；
2. $h(n) = -h(N-1-n)$，即序列前后对称位置的样值绝对值相等、符号相反——奇对称。

则称为**第二类线性相位FIR滤波器**。

**几何直觉**：$h(n)$ 以中心点为轴呈反对称。例如 $h = \{1, 2, 0, -2, -1\}$，$h(0)=-h(4)=1$，$h(1)=-h(3)=2$，中心点 $h(2)=0$ 是奇对称在 $N$ 为奇数时的必然推论——中心对称位置的样值必须等于自身的相反数。

### 3.3 两类比较

| 类型 | 对称性 | 时域条件 | 中心样值（$N$ 为奇数时） |
|------|--------|----------|--------------------------|
| 第一类 | 偶对称 | $h(n) = h(N-1-n)$ | 可为任意值 |
| 第二类 | 奇对称 | $h(n) = -h(N-1-n)$ | 必须为零 |

> [!note] 与其他课程的联系
> 线性相位条件是FIR滤波器设计的核心约束。窗函数法天然产生第一类线性相位，保证了滤波器不引入相位失真。这一特性使FIR滤波器在要求严格线性相位的场合（如数据传输、图像处理、高保真音频）优于IIR滤波器。

### 3.4 直流增益与系数和的关系

令 $\omega = 0$ 代入频率响应，此时 $e^{-j\omega n} = e^{0} = 1$：

$$H(e^{j0}) = \sum_{n=0}^{N-1} h(n) \cdot 1 = \sum_{n=0}^{N-1} h(n)$$

> [!important] 核心结论
> FIR滤波器在 $\omega = 0$（直流）处的频率响应等于所有 $h(n)$ 系数的代数和。若系数和为零，则该滤波器完全抑制直流分量。

## 四、典型例题

> [!example] 由差分方程判断滤波器类型
> 已知系统的差分方程为 $y(n) = \dfrac{1}{5}\sum\limits_{i=0}^{4} x(n-i)$。判断该FIR滤波器属于哪一类线性相位滤波器。
>
> **解：**
>
> 由差分方程直接读出系数，根据 $h(n) = b_n$，单位脉冲响应为：
>
> $$h(n) = \left\{\frac{1}{5}, \frac{1}{5}, \frac{1}{5}, \frac{1}{5}, \frac{1}{5}\right\}, \quad n = 0, 1, 2, 3, 4$$
>
> 共 $N = 5$ 项。检查对称性——比较 $h(n)$ 与 $h(4-n)$：
>
> $$h(0) = h(4) = \frac{1}{5}, \quad h(1) = h(3) = \frac{1}{5}, \quad h(2) = \frac{1}{5}$$
>
> 序列关于 $n=2$ 偶对称，满足 $h(n) = h(N-1-n)$，且 $h(n)$ 为实序列。
>
> 故该滤波器为**第一类线性相位FIR滤波器**。共 $5$ 项，阶数为 $4$。

> [!example] 由单位脉冲响应判断滤波器类型、阶数与直流增益
> 已知FIR滤波器的单位脉冲响应为 $h(n) = \{1, -1, 1, 0, -1, 1, -1\}$（$n = 0, 1, \ldots, 6$）。判断：
> 1. 滤波器的类型；
> 2. 滤波器的阶数；
> 3. 该滤波器是否可以滤除直流信号。
>
> **解：**
>
> **（1）判断类型**：$N = 7$，比较 $h(n)$ 与 $h(6-n)$：
>
> $$h(0)=1,\; h(6)=-1 \;\Rightarrow\; h(0) = -h(6)$$
> $$h(1)=-1,\; h(5)=1 \;\Rightarrow\; h(1) = -h(5)$$
> $$h(2)=1,\; h(4)=-1 \;\Rightarrow\; h(2) = -h(4)$$
> $$h(3)=0,\; h(3)=0 \;\Rightarrow\; h(3) = -h(3) = 0$$
>
> 各对样值满足 $h(n) = -h(6-n)$，且 $h(n)$ 为实序列。中心样值 $h(3)=0$ 符合奇对称要求。
>
> 故该滤波器为**第二类线性相位FIR滤波器**。
>
> **（2）判断阶数**：写出系统函数：
>
> $$H(z) = \sum_{n=0}^{6} h(n) z^{-n} = 1 - z^{-1} + z^{-2} + 0 - z^{-4} + z^{-5} - z^{-6}$$
>
> $z^{-1}$ 的最高指数为 $6$，故为**六阶FIR滤波器**。
>
> **（3）直流增益**：$\omega = 0$ 时 $e^{-j\omega n} = 1$，频率响应退化为系数和：
>
> $$H(e^{j0}) = \sum_{n=0}^{6} h(n) = 1 + (-1) + 1 + 0 + (-1) + 1 + (-1) = 0$$
>
> $H(e^{j0}) = 0$ 表明系统对直流分量的增益为零。
>
> 故该滤波器**可以完全滤除直流信号**。

> [!example] 由单位脉冲响应表达式反推滤波器参数
> 已知FIR滤波器的单位脉冲响应为 $h(n) = \cos\left(\dfrac{\pi n}{15}\right) \cdot R_N(n)$，其中 $R_N(n)$ 为长度为 $N$ 的矩形窗序列。若要使其为第一类线性相位滤波器，求 $N$ 的取值及对应的滤波器阶数。
>
> **解：**
>
> 第一类线性相位要求 $h(N-1-n) = h(n)$。将 $N-1-n$ 代入表达式：
>
> $$h(N-1-n) = \cos\left(\frac{\pi (N-1-n)}{15}\right) \cdot R_N(N-1-n)$$
>
> 当 $0 \le N-1-n \le N-1$（即 $n$ 在有效范围 $[0, N-1]$ 内）时，矩形窗 $R_N(N-1-n) = 1 = R_N(n)$，窗函数部分不影响对称性。关键在余弦项：
>
> $$h(N-1-n) = \cos\left(\frac{\pi (N-1)}{15} - \frac{\pi n}{15}\right)$$
>
> 要使此式等于 $h(n) = \cos\left(\frac{\pi n}{15}\right)$，利用余弦函数的周期性，要求 $\frac{\pi (N-1)}{15}$ 为 $2\pi$ 的整数倍：
>
> $$\frac{\pi (N-1)}{15} = 2\pi m, \quad m \in \mathbb{Z}$$
>
> 取最小的正整数解 $m = 1$：
>
> $$\frac{\pi (N-1)}{15} = 2\pi \quad \Rightarrow \quad N - 1 = 30 \quad \Rightarrow \quad N = 31$$
>
> 此时 $h(30-n) = h(n)$，满足第一类线性相位条件。$h(n)$ 共有 $N = 31$ 项，$z^{-1}$ 的最高指数为 $30$。
>
> 故 $N = 31$，该滤波器为**三十阶第一类线性相位FIR滤波器**。

> [!tip] FIR类型的快速判断方法
> 考试中FIR滤波器类型判断通常为填空题，熟练后可快速作答：
> - 偶对称（左右镜像相等）→ 第一类线性相位
> - 奇对称（左右大小相等、符号相反，奇数项时中心必为零）→ 第二类线性相位
> - 含复杂表达式时，将 $N-1-n$ 代入 $h(\cdot)$，化简后比对 $h(n)$ 即可。

## 本讲小结

### 知识地图

本讲从FIR差分方程出发，建立了单位脉冲响应 $h(n)$ 与滤波器系数 $b_k$ 的对应关系，进而导出FIR的系统函数 $H(z)$ 和频率响应 $H(e^{j\omega})$。在此基础上给出了FIR滤波器的核心时域分类——第一类（偶对称）与第二类（奇对称）线性相位滤波器，并通过三个例题展示了分类判断、阶数确定和直流增益分析的方法。本讲内容为后续FIR滤波器的窗函数设计法提供了分类判断的工具基础。

| 对比维度 | 第一类线性相位 | 第二类线性相位 |
|----------|---------------|---------------|
| 对称性 | 偶对称 | 奇对称 |
| 时域条件 | $h(n) = h(N-1-n)$，$h(n)$ 为实序列 | $h(n) = -h(N-1-n)$，$h(n)$ 为实序列 |
| 中心样值（$N$ 奇数） | 可为任意值 | 必须为零 |
| 几何特征 | 左右样值镜像相等 | 左右样值绝对值相等、符号相反 |

### 核心公式表

| 公式名 | 表达式 | 适用条件 |
|--------|--------|----------|
| FIR单位脉冲响应 | $h(n) = \sum_{k=0}^{N-1} b_k \delta(n-k)$ | 有限长FIR系统 |
| 系数对应关系 | $h(n) = b_n$ | $n = 0,1,\ldots,N-1$ |
| FIR系统函数 | $H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$ | $h(n)$ 为 $N$ 点有限长序列 |
| FIR频率响应 | $H(e^{j\omega}) = \sum_{n=0}^{N-1} h(n) e^{-j\omega n}$ | $h(n)$ 为 $N$ 点有限长序列 |
| 直流增益 | $H(e^{j0}) = \sum_{n=0}^{N-1} h(n)$ | $\omega = 0$ 时 $e^{-j0} = 1$ |
| 第一类条件 | $h(n) = h(N-1-n)$ | $h(n)$ 实序列，偶对称 |
| 第二类条件 | $h(n) = -h(N-1-n)$ | $h(n)$ 实序列，奇对称 |

### 易错点

> [!warning] 常见错误
> - 混淆 $N$（求和项数）与阶数（$N-1$）：不同教材定义不一，统一以 $H(z)$ 中 $z^{-1}$ 的最高指数判断阶数
> - 第二类线性相位在 $N$ 为奇数时，中心样值 $h((N-1)/2)$ 必须为零——这是 $h(n) = -h(N-1-n)$ 在 $n = N-1-n$ 时的直接推论，不可遗漏
> - 判断滤波器类型时遗漏"$h(n)$ 为实序列"这一前提条件——线性相位的定义要求 $h(n)$ 为实序列
> - 计算直流增益时错误地使用频率响应公式逐项乘以 $e^{-j\omega n}$ 再求和——$\omega = 0$ 时所有指数项均为 $1$，频响直接等于所有系数的代数和
