# 第42讲 FIR滤波器的频响特性与分类

## FIR 滤波器的一般定义

### 系统函数

将 FIR 滤波器的单位脉冲响应展开为一般形式：

$$H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$$

其中 $h(n)$ 即为滤波器的系数 $b_n$，$N$ 为求和的项数。

### 频率响应

令 $z = e^{j\omega}$，得到频率响应：

$$H(e^{j\omega}) = \sum_{n=0}^{N-1} h(n) e^{-j\omega n}$$

这与离散时间傅立叶变换（DTFT）的形式一致。

### 阶数的判断

FIR 滤波器的**阶数**等于滤波器结构中延迟器的个数：
- 看 $z^{-k}$ 的最高指数
- 如 $z^{-(N-1)}$ 最高，则为 $N-1$ 阶
- 注意：$N$ 是求和项数，不是阶数

**不要死背公式，以 $z$ 的指数为准。**

## FIR 滤波器的时域分类

FIR 滤波器按时域特性分为两类，判断依据是单位脉冲响应 $h(n)$ 的对称性。

### 第一类：偶对称线性相位

**条件**：
1. $h(n)$ 为**实序列**
2. $h(n) = h(N-1-n)$ — 序列前后对称，样值大小相同，**偶对称**

### 第二类：奇对称线性相位

**条件**：
1. $h(n)$ 为**实序列**
2. $h(n) = -h(N-1-n)$ — 序列前后对称样值的绝对值相同，一正一负，**奇对称**

## 例题

### 例一：判断滤波器类型

> 已知差分方程 $y(n) = \frac{1}{5} \sum_{i=0}^{4} x(n - i)$，判断属于哪类线性相位滤波器。

**解题步骤：**

1. 将差分方程转换为单位脉冲响应的差分方程，令 $x(n) = \delta(n)$：
   $$h(n) = \frac{1}{5} \sum_{i=0}^{4} \delta(n - i)$$

2. 展开求和式，得到系数（$n=0,1,2,3,4$）：
   $$h(0) = h(1) = h(2) = h(3) = h(4) = \frac{1}{5}$$

3. 所有系数均为 $\frac{1}{5}$，关于 $n=2$ 对称：
   $$h(n) = h(4-n)$$

4. 满足**偶对称**条件 → **第一类线性相位滤波器**

### 例二：判断滤波器特性

> 系统单位脉冲响应样值序列为 $\{1, 3, 3, 1\}$（以 $n=3$ 为中心），判断滤波器类型、长度、能否滤除直流。

**解题步骤：**

1. **判断类型**：
   - $h(0)=1, h(1)=3, h(2)=3, h(3)=1$（假设以 $n=3$ 为中心，则共 7 项，其余项为 0）
   
   另一种理解：若序列为 $\{1, 0, 3, 0, -3, 0, -1\}$ 且以 $n=3$ 为中心反对称：
   - $h(0)=1, h(1)=0, h(2)=3, h(3)=0, h(4)=-3, h(5)=0, h(6)=-1$
   - $h(n) = -h(6-n)$ 成立 → **奇对称**
   - 满足**第二类线性相位滤波器**条件

2. **求阶数**：
   - 共 7 项，$z^{-6}$ 为最高次方 → **6 阶滤波器**

3. **判断能否滤除直流**：
   - 令 $\omega = 0$，$H(e^{j0}) = \sum h(n)$（因 $e^{-j\omega n} = 1$）
   - 所有系数之和为 0 → **可以滤除直流信号**

### 例三：复杂序列的类型判断

> 系统单位脉冲响应为 $h(n) = \cos\left(\frac{\pi n}{15}\right) \cdot R_N(n)$，判断滤波器类型。

**解题步骤：**

1. 判断方法：计算 $h(N-1-n)$ 是否等于 $\pm h(n)$

2. 代入 $N-1-n$：
   $$h(N-1-n) = \cos\left(\frac{\pi (N-1-n)}{15}\right) \cdot R_N(N-1-n)$$

3. 利用余弦函数的偶函数性质和周期性：
   要使 $\cos\left(\frac{\pi (N-1-n)}{15}\right) = \cos\left(\frac{\pi n}{15}\right)$
   需 $\frac{\pi (N-1)}{15} = 2\pi$（即相差 $2\pi$ 的整数倍）
   
   解得 $N-1 = 30$，$N = 31$

4. 当 $N=31$ 时，$h(N-1-n) = h(n)$ → **偶对称**

5. 结论：**第一类线性相位滤波器**，30 阶 FIR 滤波器

## 知识点小结

FIR 滤波器的类型判断在考试中通常以填空题出现，要求快速识别：
- **看对称性**：偶对称 → 第一类，奇对称 → 第二类
- **看最高幂次**：确定阶数
- **求和定直流**：$\sum h(n) = 0$ 则可滤除直流

## 关键公式

1. FIR 系统函数一般形式：$\displaystyle H(z) = \sum_{n=0}^{N-1} h(n) z^{-n}$

2. FIR 频响一般形式：$\displaystyle H(e^{j\omega}) = \sum_{n=0}^{N-1} h(n) e^{-j\omega n}$

3. 第一类线性相位条件：$h(n) = h(N-1-n)$（实序列，偶对称）

4. 第二类线性相位条件：$h(n) = -h(N-1-n)$（实序列，奇对称）

5. 直流分量响应：$\displaystyle H(e^{j0}) = \sum_{n=0}^{N-1} h(n)$

## 易错点

1. **阶数 vs 项数**：$N$ 项求和是 $N-1$ 阶滤波器，阶数等于延迟器个数（$z$ 的最高指数），而不是求和项数

2. **对称中心的确定**：偶对称/奇对称的对称中心是 $(N-1)/2$，不是 $N/2$，这一点在判断时容易出错

3. **判断第二类时注意符号**：奇对称要求 $h(n) = -h(N-1-n)$，绝对值相同但正负号相反

4. **直流滤除的判断**：$\sum h(n) = 0$ 时 $\omega=0$ 处幅频为 0，可滤除直流。这是第二类滤波器的特性和考点

5. **复杂 $h(n)$ 的处理**：当 $h(n)$ 含三角函数时，利用函数的周期性和奇偶性来化简判断
