# 组合电路中的竞争—冒险

> [!abstract] 本讲定位
> 介绍组合逻辑电路中因信号传输延迟导致的竞争冒险现象，包括其成因、检测方法和消除手段。本讲是组合逻辑电路章节的收尾内容，承接前述中规模器件的讨论，引出竞争冒险这一在实际设计中不可忽视的问题。

## 组合电路设计中的复用思想

设计一个对两个三位无符号数进行加减运算的电路，控制端 F 决定运算类型（F=0 为加，F=1 为减）。存在多种设计方案，体现不同的设计思路。

**方案一：分别实现，数据选择器输出。** 加法电路和减法电路各自独立实现，用并行数据选择器根据 F 选取结果。该方法正确但不够简洁，两套电路无法复用。

**方案二：利用补码统一为加法。** 被加数/被减数 A 直接送入全加器；B 根据 F 预处理——F=0 时 B 原码送入，F=1 时 B 取反加一（求补码）。全加器最低位进位 CI 接 F（而非接地），F=1 时实现加一操作。

B 的取反方式可以选择：
- 反相器加数据选择器，每 bit 用二选一选择原码或反码
- 异或门，一端接 F，F=1 时取反，F=0 时直通

减法得到的是补码结果，输出端需再做一次取反加一转换为原码，同样由 F 控制。

> [!note] 设计思想
> 组合电路设计没有唯一的标准答案，但有相对更好的方案。好的设计体现在资源的复用和电路结构的简洁性上。鼓励独立完成设计作业，亲自体会从构思到实现的过程。

## 数值比较器

### 一位数值比较器

一位二进制数的比较结果有三种：

- $Y_{A>B} = A \overline{B}$
- $Y_{A<B} = \overline{A} B$
- $Y_{A=B} = \overline{A \oplus B} = A \odot B$（同或）

### 多位数值比较器

多位比较从高位开始，高位结果优先。若高位相等则比较次高位，依次类推。芯片内部通常采用并行结构以均衡各输出的传输延迟时间，避免单一关键路径制约整体速度。

## 竞争冒险现象

### 问题的提出

在前述电路分析中，常使用这样的推理：与门有一端为 0 则输出恒为 0，或门有一端为 1 则输出恒为 1。但该结论成立的前提是输入信号跳变过程中不产生中间干扰。

事实上，门电路存在传输延迟时间 $t_{PD}$。当输入从真值表的一行跳变到另一行时，即使两行输出相同，中间也可能因时序差异出现干扰脉冲。

> [!note] CMOS/TTL 器件的容差特性
> CMOS 和 TTL 工艺的器件具备一定的容差能力：当某一输入信号能够确定输出值时，另一输入信号的变化不会干扰输出。因此上述推理在大多数情况下成立。

### 竞争与冒险的定义

**竞争**：两个输入同时向相反方向的逻辑电平变化时，称为存在竞争。

**冒险**：竞争导致输出端出现不希望有的尖峰脉冲（毛刺），称为冒险尖峰。

例如，与门输入从 10 变为 01 时，输出理论上应保持为 0，但若两个信号到达时间存在差异，输出可能出现正向毛刺。或门亦同理。

### 2-4 线译码器中的竞争冒险

> [!note] 2-4 线译码器的竞争冒险
> 2-4 线译码器的输入 A、B 译出四个最小项。当输入从 10 变到 01（或反之）时，变化过程中可能出现中间状态 00 或 11，导致瞬时选通错误的输出端。A 的原变量和反变量之间存在一个反相器，引入了一个传输延迟时间差。这个延迟差使得过渡期间即使输入最终稳定，中间瞬间也可能激活非预期的输出端。若译码器输出接在总线控制端，可能造成数据误传输；若接在显示端（如 LED），人眼无法察觉短暂的闪变，影响不大。

## 竞争冒险的检测方法

### 代数法

若输出函数在一定的条件下可以整理为以下形式，则一定存在竞争冒险：

- $Y = A + \overline{A}$（或型，产生正向毛刺）
- $Y = A \cdot \overline{A}$（与型，产生负向毛刺）

原理：其他输入变量取值固定后，A 和 $\overline{A}$ 之间存在反相器的传输延迟，两者会在一个短暂的时间窗口内同时为 1（或同时为 0）。

### 观测法

实际调试中用示波器捕捉输出端的尖峰脉冲。电路静态分析正确但动态工作异常时，往往存在竞争冒险。仿真方法更为便捷，物理电路排查则比较繁琐。

### 卡诺图法

如果卡诺图中两个卡诺圈**相切**（相邻但不重叠），则必然存在固定的竞争冒险。相切处的相邻最小项仅一个变量不同，该变量同时以原变量和反变量形式出现在电路中，延迟差必然导致毛刺。

## 竞争冒险的消除方法

冒险尖峰的宽度通常仅为一个传输延迟时间，属于高频噪声，因此有多种消除方式。

### 方法一：接入滤波电容

在输出端接入小电容，与输出端导通电阻构成 RC 一阶低通滤波电路，将窄尖峰滤除。由于冒险尖峰很窄，很小的电容即可有效消峰。

### 方法二：引入选通脉冲

冒险发生在输入信号变化期间。引入选通控制端，在输入变化并稳定之后再选通输出，让电路内部的瞬态过程先自行消化完毕。

变化期间输出置于高阻态（三态），选通脉冲到来后才输出稳态信号。该方法在大系统中使用广泛。

### 方法三：修改逻辑设计
以逻辑函数 $Y = \overline{C}A + CB$（二选一数据选择器，C 为选择端）为例。当 $A = B = 1$ 时，无论 C 如何变化，Y 应始终为 1。将函数填入卡诺图后发现，$\overline{C}A$ 和 $CB$ 两个卡诺圈相切。最简实现必然导致 C 变化时输出出现固定毛刺。这是一个确定性的冒险（每次重复该输入条件都会出现），而非偶然发生的概率性冒险。

消除方法：在卡诺图中将相切的部分用冗余项覆盖，增加乘积项 $AB$：

$Y = \overline{C}A + CB + AB$

当 $A = B = 1$ 时，$AB = 1$ 保持输出恒为 1，屏蔽了 C 变化带来的影响。这虽然不再是"最简"实现，但消除了固定的竞争冒险。这正是"最简不一定是最好"的典型例证。

> [!warning] 最简 ≠ 最好
> 逻辑化简追求最简，但最简实现可能引入固定的竞争冒险。在需要高可靠性的场合，适当增加冗余项以换取输出的稳定性是必要的权衡。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 竞争 | 两个输入同时向相反方向跳变 |
| 冒险 | 竞争导致的输出尖峰脉冲 |
| 代数检测法 | $Y = A + \overline{A}$ 或 $Y = A \cdot \overline{A}$ |
| 卡诺图检测法 | 卡诺圈相切处存在固定竞争冒险 |
| 滤波电容消除 | RC 低通滤波，适用于输出端 |
| 选通脉冲消除 | 变化期间封锁输出，稳定后选通 |
| 修改逻辑消除 | 增加冗余项覆盖相切处 |

### 核心公式
- 竞争冒险判定：$Y = A + \overline{A}$（或型）/ $Y = A \cdot \overline{A}$（与型）
- 冗余消除：$Y = \overline{C}A + CB \quad \rightarrow \quad Y = \overline{C}A + CB + AB$
