# 基本 SR 锁存器

> [!abstract] 本讲定位
> 从组合逻辑电路过渡到时序逻辑电路，介绍触发器的基本概念、电路结构和工作原理。以基本 SR 锁存器为例，分析利用门电路的正反馈构建双稳态存储单元的原理，建立现态/次态时间概念，为后续引入时钟控制的触发器奠定基础。

## 从组合电路到时序电路

组合逻辑电路的输出仅取决于当前输入，无法记忆历史状态。这一根本性局限使其无法处理涉及状态变化的任务。

以单键翻转灯控电路为例：一个按钮开关控制一盏灯，每按一次按钮，灯的状态翻转——亮变灭，灭变亮。该电路用组合逻辑无法实现，原因有二。

其一，输出不仅取决于按钮当前是否被按下，还取决于灯原来是什么状态，即出现了对**状态**的依赖。这是组合逻辑设计中首次遇到需要关心"过去"的情况。

其二，输入并非稳定的电平值，而是一个**事件**——按下后弹起，信号经历 $0 \to 1 \to 0$ 的变化。真值表只能描述稳定输入下的稳定输出，无法表达一个输入事件对输出的影响。因此，该电路需要具备记忆功能的存储元件。

### 时序电路模型

时序电路由两部分组成，通过 **load 控制信号**协同工作：

- **组合逻辑电路**：负责计算输出和电路的下一个状态
- **存储器件（memory device）**：记录电路过去的状态

组合电路计算完毕后，load 信号将有效结果存入存储器件，存入的数据随即参与下一次运算。load 信号按节拍（一拍一拍）周期性地到来，每拍的极限长度受组合电路传输延迟时间 $t_{PD}$ 限制——一旦算完就存入，随即开始下一次运算，形成稳定的工作节拍。

引入 load 信号的根本原因在于：数字系统中并非每个时刻线上的信号都是有效信号。组合电路在输入变化后需要经历一段传输延迟才能输出稳定结果，若不加控制地持续存入，会将中间的不稳定数据存入存储器，导致错误。

$$
\text{时序电路} = \text{组合电路} + \text{存储器件}
$$

## 触发器概述

触发器（flip-flop, FF）用于记忆**一位二进制信号**。其基本要求为：

- 有两个能够自行保持的状态，分别表示 0 和 1
- 能够根据外部需要写入 0 或 1

### 两个分类维度

一个完整的触发器描述必须同时包含两个维度：

| 分类方式 | 内容 | 例子 |
|---------|------|------|
| 按触发方式（动作特点） | 输出翻转的时机和特点 | 电平触发、边沿触发、主从触发（脉冲触发） |
| 按逻辑功能 | 输入输出之间的逻辑关系 | RS、JK、D、T 触发器 |

> [!important] 两个维度缺一不可
> 仅说"D 触发器"不准确，因为没有说明动作特点；仅说"电平触发"也不准确，因为没有说明功能。二者结合——如"电平触发的 D 触发器"——才是对触发器的完整描述。

## 基本 SR 锁存器

### 存储原理：正反馈形成双稳态

两个反相器首尾相连构成最原始的存储结构。分析时，在环路中画一条分割线，电路即被拆分为上、下两个两端口网络。

下方两端口网络包含两个串联的反相器：两次取反相当于一次同相传输，其电压传输特性（VTC）呈 S 形曲线——在中间段增益很高，两端趋于平坦。上方两端口网络是一根直连线（$V_{out} = V_{in}$），其 VTC 为一条 45° 斜线。

将两条 VTC 曲线叠加，得到三个交点：两端交点为稳定工作点，分别对应 Q = 0 和 Q = 1；中间交点为**亚稳态**，该点处任何微小扰动都会经正反馈环路的逐级放大，最终将电路驱使至两端稳定状态之一。

> [!warning] 正反馈 ≠ 不稳定
> 正反馈直接挂钩"不稳定"是一种常见的错误概括。负反馈同样可能引起振荡，正反馈也可以构成双稳态电路。反馈的稳定性取决于具体电路的极点分布，不可一概而论。在本电路中，正反馈在中间点为不稳定（推离亚稳态）、在两端为稳定（维持已建立的状态），正是正反馈使电路获得了**两个自行保持的稳定状态**。

该电路没有输入，上电后处于哪个状态（0 或 1）由随机因素决定。它满足触发器的第一条要求——有两个自行保持的状态，但不满足第二条——无法按需写入。因此需要引入输入端。

### 或非门 SR 锁存器

反相器没有额外的输入端可用于施加写入信号。将两个反相器替换为两个或非门，引出两个控制端 $S_D$ 和 $R_D$。

#### 电路结构

两个或非门交叉耦合：第一个或非门的输出接第二个或非门的输入，第二个或非门的输出接第一个或非门的输入。定义 Q 为存储值，$\overline{Q}$ 为其互补输出。

- $S_D$（Set Direct）：置一端，**高电平有效**
- $R_D$（Reset Direct）：置零端，**高电平有效**

字母 D 代表 direct（直接），意为输入端直接操作存储单元进行置位或复位，不经任何中间控制环节。

#### 工作原理

当 $S_D$ 和 $R_D$ 均为 0 时，两个或非门各自退化为反相器——$S_D$ 一侧的或非门等效为以 $\overline{Q}$ 为输入的反相器，$R_D$ 一侧同理。整个电路退化为首尾相连的反相器结构，依靠正反馈自行保持已写入的值。

写入操作利用或非门的特性：只要或非门的一个输入端为 1，输出就被强制为 0，另一个输入端被屏蔽。具体而言：

- $S_D = 1$：上侧或非门输出为 0（即 $\overline{Q} = 0$），该 0 送入下侧或非门，与 $R_D = 0$ 共同作用下侧输出为 1（即 Q = 1），完成**置一**
- $R_D = 1$：下侧或非门输出为 0（即 Q = 0），该 0 送入上侧或非门，与 $S_D = 0$ 共同作用上侧输出为 1（即 $\overline{Q} = 1$），完成**置零**

写入完成后，将 $S_D$ 和 $R_D$ 均拉回 0，电路便退化为首尾相连的反相器结构，利用正反馈自行保持存入的值。

#### 状态转换表

分析触发器时，同一物理节点 Q 同时出现在输入端（作为现态 $Q^n$）和输出端（作为次态 $Q^{n+1}$）。状态转换表是引入时间维度的真值表，将现态和输入并列，共同决定次态：

| $S_D$ | $R_D$ | $Q^n$ | $Q^{n+1}$ | 功能 |
|:----:|:----:|:----:|:---------:|:----:|
| 0 | 0 | 0 | 0 | 保持 |
| 0 | 0 | 1 | 1 | 保持 |
| 0 | 1 | 0 | 0 | 置零 |
| 0 | 1 | 1 | 0 | 置零 |
| 1 | 0 | 0 | 1 | 置一 |
| 1 | 0 | 1 | 1 | 置一 |
| 1 | 1 | 0 | 0（不定） | 不允许 |
| 1 | 1 | 1 | 0（不定） | 不允许 |

> [!warning] 不定出现在输入同时撤除的时刻
> $S_D = R_D = 1$ 时，两个或非门的输出均被强制为 0（Q 和 $\overline{Q}$ 同时为 0），这是一个确定的电路状态。**不定出现在 $S_D$ 和 $R_D$ 同时从 1 撤除为 0 的瞬间**：两个 0 送入或非门后，两个门各自向 1 翻转，形成竞争。哪个门的传输延迟更短、先翻转到 1，就会封锁另一个门，将对方锁定在 0。最终谁胜出完全取决于工艺偏差和噪声，结果不可预测。因此 $S_D = R_D = 1$ 是不允许的输入组合。

### 与非门 SR 锁存器

#### 电路结构与标识

将或非门替换为与非门，输入端变为低电平有效，记为 $\overline{S_D}$ 和 $\overline{R_D}$（读作"S_D 反"和"R_D 反"）。在电路符号中，低电平有效的输入端加有反相圈（小圆圈），与标识中的上划线形成一致的视觉效果，使读图更加直观：

- $\overline{S_D} = 0$：置一。（反相圈 + 上划线共同提示：低电平起作用，这与或非门版本 $S_D = 1$ 的效果统一——都是"使 S 端起作用"）
- $\overline{R_D} = 0$：置零
- $\overline{S_D} = \overline{R_D} = 1$：保持（两个与非门各自退化为反相器）
- $\overline{S_D} = \overline{R_D} = 0$：Q 和 $\overline{Q}$ 同为 1（不允许——同时撤除时出现不定）

采用低电平有效的与非门结构还有一个实际优势：TTL 工艺中，与非门的驱动能力和速度通常优于或非门，因此实际的锁存器芯片多采用与非门实现。

#### 状态转换表

| $\overline{S_D}$ | $\overline{R_D}$ | $Q^n$ | $Q^{n+1}$ | 功能 |
|:-----:|:-----:|:----:|:---------:|:----:|
| 0 | 0 | 0 | 不定 | 不允许 |
| 0 | 0 | 1 | 不定 | 不允许 |
| 0 | 1 | 0 | 1 | 置一 |
| 0 | 1 | 1 | 1 | 置一 |
| 1 | 0 | 0 | 0 | 置零 |
| 1 | 0 | 1 | 0 | 置零 |
| 1 | 1 | 0 | 0 | 保持 |
| 1 | 1 | 1 | 1 | 保持 |

或非门实现（高电平有效）和与非门实现（低电平有效）是基本 SR 锁存器的两种常见形式，逻辑功能完全等价，仅有效电平不同。

## 动作特点

### 现态与次态

引入时间概念描述触发器的状态变化。同一个物理节点 Q，在分析中因所处时刻不同而有不同的含义：

- $Q^n$：现态，记为 $Q$。当前时刻存储的状态
- $Q^{n+1}$：次态，记为 $Q^*$。下一个时刻将要变成的状态

次态 $Q^{n+1}$ 是现态 $Q^n$ 和当前输入信号的函数——这是触发器与组合电路在分析上的根本区别。

### 电平敏感特性

基本 SR 锁存器的动作特点是**电平触发**：输入端电平的变化会直接、即时地反映在输出 Q 和 $\overline{Q}$ 上。电路没有时钟信号来控制写入时机，任何时刻的输入变化都会影响存储内容。

> [!warning] 电平敏感的根本缺陷
> 若将基本 SR 锁存器直接与组合电路相连，组合电路在信号稳定过程中发生的任何扰动都会直接被存入锁存器。该电路缺少一个 load 控制信号来指定写入时机——这一缺陷正是后续引入时钟控制、进而发展出边沿触发和主从触发等更复杂触发方式的根本动因。

### 波形图描述

或非门 SR 锁存器的输入输出波形关系：

- $S_D$ 出现一个正脉冲 → Q 在脉冲前沿立即变为 1，脉冲结束后 Q 保持 1
- $R_D$ 出现一个正脉冲 → Q 在脉冲前沿立即变为 0，脉冲结束后 Q 保持 0
- $S_D$ 和 $R_D$ 同时从高电平撤除 → Q 出现一段不确定区域（竞争导致的过渡过程）

与非门 SR 锁存器的波形类似，但有效电平取反：

- $\overline{S_D}$ 出现一个负脉冲 → Q 在脉冲前沿立即变为 1，脉冲结束后 Q 保持 1
- $\overline{R_D}$ 出现一个负脉冲 → Q 在脉冲前沿立即变为 0，脉冲结束后 Q 保持 0
- $\overline{S_D}$ 和 $\overline{R_D}$ 同时从低电平撤除 → Q 出现一段不确定区域

无论使用哪种实现，在不定期间 Q 和 $\overline{Q}$ 始终保持互补关系——两个输出虽然不确定具体值，但一定相反。

## 本讲小结

### 时序电路与触发器

| 概念 | 要点 |
|------|------|
| 时序电路模型 | 时序电路 = 组合电路 + 存储器件，二者通过 load 信号协同工作 |
| 组合电路的局限 | 输出仅取决于当前输入（memoryless），无法处理依赖历史状态的任务 |
| 引入 load 信号的原因 | 数字系统中并非每时每刻信号都有效，load 信号指定何时将组合电路的有效结果存入存储器 |
| 触发器定义 | 记忆一位二进制信号的基本单元，具有两个能自行保持的状态且可按需写入 |
| 完整描述 | 触发方式（动作特点）+ 逻辑功能，两个维度缺一不可 |

### SR 锁存器两种实现

| | 或非门实现 | 与非门实现 |
|------|------|------|
| 置一端 | $S_D = 1$（高电平有效） | $\overline{S_D} = 0$（低电平有效） |
| 置零端 | $R_D = 1$（高电平有效） | $\overline{R_D} = 0$（低电平有效） |
| 保持 | $S_D = R_D = 0$ | $\overline{S_D} = \overline{R_D} = 1$ |
| 禁止输入 | $S_D = R_D = 1$ | $\overline{S_D} = \overline{R_D} = 0$ |

> [!warning] 不定出现在输入同时撤除的瞬间
> 两个输入端同时有效期间，Q 和 $\overline{Q}$ 同为 0（或非门）或同为 1（与非门），这是确定的。**不定**出现在两个输入端同时撤除的时刻——两个门发生竞争，结果不可预测。Q 和 $\overline{Q}$ 在不定期间始终保持互补。
