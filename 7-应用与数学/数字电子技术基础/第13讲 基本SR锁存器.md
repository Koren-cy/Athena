# 触发器的电路结构和动作特点

> [!abstract] 本讲定位
> 从组合逻辑电路过渡到时序逻辑电路，介绍触发器的基本概念、电路结构和工作原理。以基本 SR 锁存器为例，分析利用门电路构建存储单元的原理、状态转换和动作特点。

## 从组合电路到时序电路

组合逻辑电路存在一个根本性的局限：输出仅取决于当前输入，无法记忆历史状态。

看一个具体例子。

**例：单键翻转灯控电路**——设计一个电路：一个按钮开关（按下弹起式）控制一盏灯。按一下，灯的状态翻转——原来是亮的就灭，原来是灭的就亮。输入只有一个开关变量，输出只有一个灯变量。

**解：** 该电路无法用组合逻辑电路实现，原因有二：

第一，输出不仅取决于当前输入（是否按了开关），还取决于电路过去的状态（灯原来是亮还是灭），即出现了对**状态**的依赖。

第二，输入不是稳定的电平值，而是一个**事件**（按下后弹起）。真值表描述的是稳定值，无法处理此类动态变化。

因此，该电路需要具备记忆功能的存储元件。

### 时序电路模型

时序电路由两部分组成：

- **组合逻辑电路**：负责计算输出和电路的下一个状态
- **存储器件（memory device）**：记录电路过去的状态

两者通过 **load 控制信号** 同步。组合电路计算完毕后，load 信号将有效结果存入存储器件。存储周期受组合电路的传输延迟时间限制——一旦算完就存入，随即开始下一次运算，形成一拍一拍的节拍。

$$
\text{时序电路} = \text{组合电路} + \text{存储器件}
$$

## 触发器概述

触发器（flip-flop, FF）用于记忆**一位二进制信号**。

### 基本要求

- 有两个能够自行保持的状态（0 和 1）
- 能够根据需要写入 0 或 1

### 分类方式

一个完整的触发器描述包含两个维度：

| 分类方式 | 内容 | 例子 |
|---------|------|------|
| 按触发方式（动作特点） | 输出翻转的特点 | 电平触发、边沿触发、主从触发 |
| 按逻辑功能 | 输入输出之间的逻辑关系 | RS、JK、D、T 触发器 |

> [!important] 两个维度缺一不可
> 仅说"D 触发器"不准确，因为缺少动作特点描述；仅说"电平触发"也不准确，因为没有说明功能。二者结合才是对触发器的完整描述。

## 基本 SR 锁存器

### 存储原理：正反馈形成双稳态

两个反相器首尾相连（输出接输入），构成最原始的存储结构。

> [!info] 反馈与稳定性
> 不能简单地将正反馈等同于不稳定、负反馈等同于稳定。正反馈也可能使电路趋于稳定状态，具体取决于电路结构。

将两个反相器的电压传输特性叠加分析，得到三个交点：
- 两端的交点为**稳定状态**（对应 Q=0 和 Q=1）
- 中间的交点为**亚稳态**——在正反馈作用下，任何微小扰动都会驱使电路向两端之一偏移

该电路**没有输入**，上电后状态随机（0 或 1），只能保持已有状态，无法按需写入。因此需要引入输入端。

### 或非门 SR 锁存器

将反相器替换为或非门，引出两个输入端 $S_D$ 和 $R_D$。

#### 电路结构

两个或非门交叉耦合：第一个或非门的输出接第二个或非门的输入，第二个或非门的输出接第一个或非门的输入。定义 Q 为存储的值，$\overline{Q}$ 为其反相输出。

- $S_D$（Set Direct）：置一端，**高电平有效**
- $R_D$（Reset Direct）：置零端，**高电平有效**
- 字母 D 代表 direct，意为直接置位/复位

#### 工作原理

- $S_D = 1$：将 Q 置为 1
- $R_D = 1$：将 Q 置为 0
- $S_D = R_D = 0$：保持当前状态（电路退化为首尾相连的反相器结构）

写入完成后，将 $S_D$ 和 $R_D$ 都置为 0，电路利用正反馈自行保持存储的值。

#### 状态转换表

状态转换表中，同一物理节点 Q 同时出现在输入（作为现态 $Q^n$）和输出（作为次态 $Q^{n+1}$）：

| $S_D$ | $R_D$ | $Q^n$ | $Q^{n+1}$ | 功能 |
|:----:|:----:|:----:|:---------:|:----:|
| 0 | 0 | 0 | 0 | 保持 |
| 0 | 0 | 1 | 1 | 保持 |
| 0 | 1 | 0 | 0 | 置零 |
| 0 | 1 | 1 | 0 | 置零 |
| 1 | 0 | 0 | 1 | 置一 |
| 1 | 0 | 1 | 1 | 置一 |
| 1 | 1 | 0 | 不定 | 不允许 |
| 1 | 1 | 1 | 不定 | 不允许 |

> [!warning] 不定状态的理解
> $S_D = R_D = 1$ 时，Q 和 $\overline{Q}$ 同为零，这是确定的状态。**不定出现在二者同时从 1 撤除为 0 的时刻**——两个或非门竞争，谁先翻转将决定最终状态，结果不可预测。因此 $S_D = R_D = 1$ 是不允许的输入组合。

### 与非门 SR 锁存器

将或非门改为与非门，输入端变为 $S_D'$ 和 $R_D'$（**低电平有效**）：

#### 电路结构

两个与非门交叉耦合，输入端的标识 $S_D'$ 和 $R_D'$ 方便读图——带反相圈的输入表示低电平有效。

- $S_D' = 0$：置一
- $R_D' = 0$：置零
- $S_D' = R_D' = 1$：保持
- $S_D' = R_D' = 0$：Q 和 $\overline{Q}$ 同为一（不允许同时撤除）

#### 状态转换表

| $S_D'$ | $R_D'$ | $Q^{n+1}$ | 功能 |
|:-----:|:-----:|:---------:|:----:|
| 0 | 0 | 不定 | 不允许 |
| 0 | 1 | 1 | 置一 |
| 1 | 0 | 0 | 置零 |
| 1 | 1 | $Q^n$ | 保持 |

或非门实现（高有效）和与非门实现（低有效）是基本 SR 锁存器的两种常见形式，逻辑上等价，只是有效电平不同。

## 动作特点

### 现态与次态

引入时间概念描述触发器的状态变化：

- $Q^n$（现态，记作 $Q$）：当前时刻存储的状态
- $Q^{n+1}$（次态，记作 $Q^*$）：下一个时刻的状态

分析触发器时，次态 $Q^{n+1}$ 不仅取决于当前输入，还取决于现态 $Q^n$。

### 电平敏感特性

基本 SR 锁存器的动作特点是**电平触发**：输入电平的变化会**直接**反映在输出 Q 和 $\overline{Q}$ 上，没有额外的控制信号来指定存入时机。

> [!warning] 电平敏感带来的问题
> 若将基本 SR 锁存器直接与组合电路相连，组合电路的任何扰动都会直接影响存储内容。该电路缺少一个 load 控制信号来指定何时将数据存入，因此需要引入时钟控制来改进——这正是后续各种触发方式改进的方向。

### 波形图描述

在波形图上，或非门 SR 锁存器的输入输出关系表现为：
- $S_D$ 置 1 脉冲 → Q 立即变为 1
- $R_D$ 置 1 脉冲 → Q 立即变为 0
- $S_D$ 和 $R_D$ 同时撤除时 → Q 出现不确定段（但 Q 与 $\overline{Q}$ 始终相反）

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 时序电路模型 | 组合电路 + 存储器件 + load 同步信号 |
| 触发器定义 | 记忆一位二进制信号，能自行保持且可写入 |
| 触发器分类 | 触发方式（动作特点）+ 逻辑功能，二者结合 |
| 存储原理 | 门电路首尾相连，正反馈形成双稳态 |
| 基本 SR 锁存器 | 或非门实现（$S_D$/$R_D$ 高有效） |
| 与非门 SR 锁存器 | $S_D'$/$R_D'$ 低电平有效 |
| 不定状态 | 输入同时有效并同时撤除时出现竞争 |
| 动作特点 | 电平敏感，输入直接控制输出 |

### 核心结论

- 触发器必须同时从**触发方式**和**逻辑功能**两个维度来描述
- 基本 SR 锁存器是所有触发器的根本——后续各种触发器均在此基础上改进而来
- 反馈是实现存储的关键，但有反馈的电路不能混入组合逻辑电路中，应封装为独立的存储单元
