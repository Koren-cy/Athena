# 电路结构与逻辑功能的关系

> [!abstract] 本讲定位
> 本讲深入探讨电平触发、脉冲触发（主从结构）和边沿触发三种电路结构如何影响触发器的逻辑功能。分析主从结构 SR 触发器仍存在的约束条件问题，以及通过引入 JK 触发器解除约束的原理和方法。重点说明主从 JK 触发器"主触发器打开期间只能翻转一次"的动作特点，并引出边沿触发器的概念。

## 主从结构（脉冲触发结构）

任何一个电平触发的触发器都可以构成主从结构（即脉冲触发结构）。主从结构将触发器分为两级：主触发器（Master）和从触发器（Slave）。

### 工作原理

- 主触发器与从触发器的时钟相位相反——两者之间插入一个反相器实现
- **Clock = 1 期间**：主触发器打开，接收输入信号；从触发器保持，Q 和 $\overline{Q}$ 不变
- **Clock 下降沿**：主触发器保持当前状态，从触发器取主触发器的状态输出
- Q 和 $\overline{Q}$ 只在下降沿发生变化

若将反相器从主触发器一侧移到从触发器一侧，则主触发器在 Clock = 0 期间打开，触发沿变为**上升沿**。

### 图形符号解读

主从结构触发器的符号中有 `>` 形标记，表示其为脉冲触发结构。符号解读要点：

- 符号的**前半段**画出的是主触发器的触发情况——与外部输入和时钟直接交互
- 从触发器不在符号中直接画出——其时钟相位与主触发器相反，由反相器推导得出
- **无圈**：主触发器在高电平打开 → Q 在 **下降沿** 变化
- **有圈**：主触发器在低电平打开 → Q 在 **上升沿** 变化

> [!warning] 符号易错点
> 主从结构的符号中，加圈表示上升沿触发，不加圈表示下降沿触发。这与边沿触发器符号中"加圈表示下降沿"的惯例恰好相反，极易出错。原因在于主从符号中的圈画在时钟输入端，表示时钟先经反相器再到主触发器——有圈意味着反相后主触发器在低电平打开，从触发器在上升沿取数。而边沿触发器符号中的圈直接标注触发边沿的极性，两者不可混淆。

## 主从 SR 触发器

主从结构的 SR 触发器，其 Q 和 $\overline{Q}$ 与 S、R 之间的逻辑关系与电平触发 SR 触发器完全一致：

| S | R | 功能 |
|---|---|---|
| 0 | 0 | 保持 |
| 0 | 1 | 置 0 |
| 1 | 0 | 置 1 |
| 1 | 1 | 约束条件（不允许） |

约束条件依然存在：当 S = R = 1 时，Clock = 1 期间主触发器的两个输出端均为 1。下降沿到来时从触发器面对两个 1，无法确定取哪个值，次态不定。**主从结构并未解除 SR 触发器的约束条件。**

### 功能表的正确用法

> [!warning] 主从 SR 功能表不可直接查用
> 主从 SR 触发器的功能表虽然与电平触发 SR 相同，但 **不能直接在下降沿时刻用 S 和 R 的值查表确定输出**。因为 Q 和 $\overline{Q}$ 并非直接受外部 S、R 控制，而是受主触发器的中间结果 $Q_m$ 控制。
>
> 功能表仅在以下情况可直接使用：**主触发器打开期间（Clock = 1），S 和 R 的组合没有发生变化**。
>
> 若主触发器打开期间输入组合发生了变化，则必须分析主触发器在 Clock = 1 期间的完整翻转过程，确定下降沿到来前 $Q_m$ 的最终值。下降沿到达时，从触发器取 $Q_m$ 的值输出，而非取外部 S、R 的值查表。

### 分析步骤

1. **Clock = 1 期间**：主触发器退化为一个电平触发的 SR 触发器，按 S、R 每次变化的组合确定 $Q_m$ 的翻转。从触发器在此期间保持，输出不变。
2. **Clock 下降沿到达时**：主触发器保持 $Q_m$ 的最终值；从触发器打开，按 $Q_m$ 翻转。Q 取得新值。

> [!tip] 分析技巧：画 $Q_m$ 中间波形
> 若对分析没有把握，可在波形图下方额外画出 $Q_m$（主触发器中间结果）的波形。Clock = 1 期间 $Q_m$ 按电平触发规律随 S、R 变化，下降沿时 Q 直接取 $Q_m$ 的值。这一方法能将易错的两级分析拆为两步独立操作。

### D 触发器为何能屏蔽中间变化

D 触发器通过将 S 和 R 接在一起并加反相器来解除约束，但这一改动使它**丧失了保持功能**——在 Clock = 1 期间，D 触发器没有保持状态，始终跟随输入 D 变化。正因如此，D 触发器不累积中间过程的数据：它不关心前面过程中数据如何变化，只关心边沿到达时刻的 D 是什么。这一特性使 D 触发器天然屏蔽了主触发器打开期间的输入变化。这也是设计者通常倾向于选用 D 触发器的原因——分析简单，抗干扰能力强。

## 主从 JK 触发器

SR 触发器具备置零、置一和保持三种功能，但受 S = R = 1 的约束条件限制。为了在**保留全部三个功能**的前提下解除约束，在主从 SR 触发器的基础上引入两条大反馈线，构成 JK 触发器。

### 电路结构

- 将 Q 反馈到 R 输入端，与外部 K 信号相与
- 将 $\overline{Q}$ 反馈到 S 输入端，与外部 J 信号相与
- J 端对应原 SR 触发器的 S 端（置一），K 端对应 R 端（置零）

这两条反馈线的唯一作用是 **解除约束条件**，使 J = K = 1 成为合法输入。

### 约束解除原理

利用 Q 和 $\overline{Q}$ 互为反相的特性——两者中必有一个为 0。当 J = K = 1（外部同时来两个有效信号）时，值为 0 的那一端通过反馈线将对应的输入端封锁，自动将 (1, 1) 转化为 (1, 0) 或 (0, 1)：

**若当前状态 Q = 1（$\overline{Q}$ = 0）：**
- Q = 1 反馈到 R 端，与 K = 1 相与 → R 端保持 1，置零信号有效
- $\overline{Q}$ = 0 反馈到 S 端，与 J = 1 相与 → S 端变为 0，置一信号被屏蔽
- 实际等效为 S = 0, R = 1 → **置零**

**若当前状态 Q = 0（$\overline{Q}$ = 1）：**
- Q = 0 反馈到 R 端，与 K = 1 相与 → R 端变为 0，置零信号被屏蔽
- $\overline{Q}$ = 1 反馈到 S 端，与 J = 1 相与 → S 端保持 1，置一信号有效
- 实际等效为 S = 1, R = 0 → **置一**

反馈线对正常的置一、置零、保持操作无影响：
- **保持（J = K = 0）**：无论反馈线回来什么值，与 0 相与后均为 0，主触发器两端均为 0，保持原值。
- **置零（J = 0, K = 1）**：若当前 Q = 1，Q 反馈不阻止置零；若当前 Q = 0，置零到 0 与保持 0 效果相同。
- **置一（J = 1, K = 0）**：对称分析，功能不受影响。

> [!important] 核心结论
> 两条反馈线在允许 J = K = 1 的同时，完整保持了置一、置零、保持三个基本功能。当 J = K = 1 时，触发器 **取反**（翻转），即 $Q^{n+1} = \overline{Q}^n$。JK 触发器是功能最全的触发器。

### 功能表

| J | K | 功能 | 等效 SR |
|---|---|---|---|
| 0 | 0 | 保持 | S = 0, R = 0 |
| 0 | 1 | 置 0 | S = 0, R = 1 |
| 1 | 0 | 置 1 | S = 1, R = 0 |
| 1 | 1 | 取反（翻转） | 由当前 Q 决定 |

### 动作特点：主触发器只能翻转一次

> [!warning] 关键特点
> 主从结构的 JK 触发器，**主触发器在 Clock = 1 期间只能翻转一次**。

这一特点源于反馈线的封锁机制，可分层理解：

1. **初始状态**：Clock = 1 刚打开时，主触发器的 $Q_m$ 与从触发器输出 Q 相同，Q 和 $\overline{Q}$ 互为反相。两者中必有一个为 0。
2. **输入封锁**：值为 0 的那一端通过反馈线将对应输入端封锁——若 Q = 1（$\overline{Q}$ = 0），则置一端被 $\overline{Q}$ = 0 封锁；若 Q = 0，则置零端被 Q = 0 封锁。
3. **单向翻转**：主触发器一旦翻转（如由 0 变 1），Q 和 $\overline{Q}$ 互换，封锁随之转移到另一输入端。已翻转过去的方向被锁死，无法再翻回来。
4. **结论**：主触发器在本次 Clock = 1 期间最多翻转一次。下一次 Clock = 1 重新打开时，从触发器已更新，反馈值随之刷新，重新开始新一轮判断。

> [!note] 设计实践
> 在实际电路设计中，应尽可能保证主触发器打开期间 JK 输入组合不发生变化，以规避"一次翻转"带来的分析复杂度。考试和作业中之所以刻意让输入变化，是为了考察对这一结构特性的理解。

### 分析步骤

分析主从 JK 触发器时，不仅需要像主从 SR 那样追踪 Clock = 1 期间的完整过程，还要叠加"一次翻转"规则：

1. **Clock = 1 期间**：追踪 JK 组合的全部变化过程。每次变化按 JK 功能表确定主触发器的动作（置一、置零、取反或保持），同时遵守"只能翻转一次"的约束——若 $Q_m$ 已经翻转过一次，后续即使 JK 组合要求反向翻转，$Q_m$ 也不再响应，维持当前值不变。
2. **Clock 下降沿到达时**：主触发器保持 $Q_m$ 的最终值，从触发器取此值输出。**注意**：此时不能用下降沿时刻的 J、K 值直接查表确定输出——输出由 $Q_m$ 决定，而非由该时刻的外部输入决定。

> [!example] 主从 JK 触发器波形分析
> 已知主从结构 JK 触发器，初始状态 Q = 0。Clock、J 和 K 的波形如下：第一个 Clock 高电平期间 J = 1、K = 0；第二个 Clock 高电平期间 J、K 由 00 变为 01；第三个 Clock 高电平期间 J、K 出现 11 后又变为 01。求 Q 的输出波形。
>
> **解：**
>
> **第一个 Clock 周期**：Clock 高电平期间 J = 1, K = 0，查表为置 1。主触发器 $Q_m$ 由 0 翻转为 1 并保持。下降沿到达时，从触发器按 $Q_m = 1$ 翻转，Q 变为 1。
>
> **第二个 Clock 周期**：高电平开始时 J = 0, K = 0（保持），$Q_m$ 维持上一周期末的 1。随后 J、K 变为 0 和 1（置 0），$Q_m$ 由 1 翻转为 0。下降沿到达时，若机械地用此刻的 J = 0, K = 1 查表得"置 0"，结果与 $Q_m$ = 0 一致——但这纯属巧合，正确的判断依据始终是 $Q_m$ 的最终值。Q 变为 0。
>
> **第三个 Clock 周期**：高电平期间 J、K 先出现 11（取反），$Q_m$ 从 0 翻转为 1。之后 J、K 变为 01（要求置 0），但 **"只能翻转一次"** 规则生效：$Q_m$ 已从 0 翻到 1，不能再从 1 翻回 0。$Q_m$ 保持 1 直至下降沿。下降沿到达时 Q 变为 1。
>
> 结论：Q 在每个 Clock 周期只变化一次（下降沿更新），但实际取值由整个 Clock 高电平期间主触发器经历的完整过程决定，而非仅由下降沿时刻的 J、K 值决定。主从触发器的分析核心在于**追踪 $Q_m$ 的变化历史**。

## 边沿触发器

### 设计动机

主从 JK 触发器虽然在输出端实现了"一个周期只变化一次"，但主触发器在 Clock = 1 期间仍然对输入敏感。若高电平期间出现干扰信号，主触发器可能被误触发——即使因"一次翻转"规则未造成二次翻转，初始翻转已使 $Q_m$ 变化，最终仍会影响输出。

边沿触发器的设计目标是将触发器的写入时间缩短到边沿时刻，使 Q 的变化**仅取决于边沿到达瞬间的数据**，从而大幅提高抗干扰能力。

### 主从结构 D 触发器的边沿特性

主从结构的 D 触发器虽然采用脉冲触发结构，但**实际具备边沿触发的特性**。原因在于 D 触发器丧失了保持功能——在 Clock = 1 期间始终跟随 D 输入变化，不会像 SR 或 JK 触发器那样累积中间过程的状态。前边的变化不会"记下来"，最终 Q 的输出只取决于边沿到达时刻的 D 值。对 Clock = 1 期间 D 的中间变化天然不敏感。

### 图形符号区分

| 类型 | 符号特征 | 触发沿约定 |
|---|---|---|
| 主从结构（脉冲触发） | 标有 `>` 形标记，无三角 | 无圈 = 下降沿，有圈 = 上升沿 |
| 边沿触发 | 标有三角 `▷` | 无圈 = 上升沿，有圈 = 下降沿 |

> [!warning] 两种符号不可同时出现
> 主从结构的 `>` 标记和边沿触发的三角 `▷` **不能同时出现在同一个符号中**。旧版教材存在两者同时印刷的错误。若符号中同时出现两种标记，以三角形（边沿触发）为准。

## 电路结构与逻辑功能的关系

触发器的分类可以从两个独立维度进行：

1. **按电路结构（决定动作特点）**：电平触发 → 脉冲触发（主从结构）→ 边沿触发
2. **按逻辑功能（决定输入输出关系）**：RS 触发器 → D 触发器 → JK 触发器

同一电路结构可以实现不同的逻辑功能——主从结构可构成 RS、D、JK 触发器。同一逻辑功能也可以采用不同的电路结构实现——JK 功能既可用主从结构也可用边沿结构。两个维度相互组合，才构成一个完整的触发器描述。触发器的封装符号上会同时标注 **功能端**（S/R、D、J/K）和 **动作特点标记**（电平/脉冲/边沿），使用时应从两个维度完整识别。

> [!note] 电路改进的权衡
> 任何电路性能的改进都伴随着新的问题，不存在只有好处没有坏处的改进。主从结构解决了"一个周期变化一次"的问题，但引入了分析复杂度（需要追踪 Clock = 1 期间的全部过程）且抗干扰能力未提升；边沿触发器大幅提高了抗干扰能力，但符号体系对解读提出了新要求（两种结构的符号惯例恰好相反）。

## 本讲小结

### 核心公式

主从 JK 触发器的特性方程：

$$Q^{n+1} = J \cdot \overline{Q}^n + \overline{K} \cdot Q^n$$

等价的分段表示：

$$Q^{n+1} = \begin{cases} Q^n & (J=0,\; K=0) \\[4pt] 0 & (J=0,\; K=1) \\[4pt] 1 & (J=1,\; K=0) \\[4pt] \overline{Q}^n & (J=1,\; K=1) \end{cases}$$

### 核心对比

| 对比维度 | 主从 SR 触发器 | 主从 JK 触发器 | 边沿 D 触发器 |
|---|---|---|---|
| 约束条件 | S = R = 1 不允许<br>次态不定 | 无约束<br>J = K = 1 合法（取反） | 无约束 |
| 分析要点 | 追踪 Clock = 1 期间<br>$Q_m$ 的全部翻转过程 | 追踪全部翻转过程<br>叠加"一次翻转"规则 | 仅关心边沿时刻的 D 值 |
| 功能表能否直接查用 | 仅输入不变时可用 | 仅输入不变时可用 | 可直接使用 |
| 抗干扰能力 | 较弱<br>（Clock = 1 期间敏感） | 较弱<br>（Clock = 1 期间敏感） | 较强<br>（仅边沿时刻敏感） |

### 知识点速查

| 知识点 | 要点 |
|---|---|
| 主从结构原理 | 两级触发器通过反相器使时钟相位相反；主触发器在 Clock = 1 接收信号，从触发器在下降沿取 $Q_m$ 的值输出 |
| 主从 SR 分析要点 | 功能表不可直接查用；须追踪 Clock = 1 期间 $Q_m$ 的全部变化过程，下降沿时 Q 取 $Q_m$ 的最终值（建议在波形图下方画出 $Q_m$ 辅助分析） |
| 主从 SR 约束条件 | 主从结构未解除约束，S = R = 1 时主触发器两输出端均为 1，下降沿时从触发器无法确定取值，次态不定 |
| JK 反馈线的作用 | 利用 Q 和 $\overline{Q}$ 互为反相，将 J = K = 1 自动转化为 (1, 0) 或 (0, 1)；在解除约束的同时完整保留了置一、置零、保持三个功能 |
| 一次翻转规则 | 主触发器在 Clock = 1 期间最多翻转一次；翻转后反馈信号封锁反向输入端，无法再次翻转。源于反馈线的固有封锁机制 |
| 边沿触发器优势 | 仅关心边沿时刻的输入数据，抗干扰能力强；主从结构 D 触发器因无保持功能而天然具备此特性 |
| 符号识别 | 主从结构用 `>` 标记（有圈 = 上升沿），边沿触发用三角 `▷`（有圈 = 下降沿）；两种标记不可同时出现，若同时出现以三角为准 |
