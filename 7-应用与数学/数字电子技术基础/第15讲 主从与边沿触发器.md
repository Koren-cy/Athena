# 电路结构与逻辑功能的关系

> [!abstract] 本讲定位
> 本讲深入探讨电平触发、脉冲触发（主从结构）和边沿触发三种电路结构如何影响触发器的逻辑功能。分析主从结构 SR 触发器仍存在的约束条件问题，以及通过引入 JK 触发器解除约束的原理和方法。重点说明主从 JK 触发器"主触发器打开期间只能翻转一次"的动作特点，并引出边沿触发器的概念。

## 主从结构（脉冲触发结构）

任何一个电平触发的触发器都可以构成主从结构（即脉冲触发结构）。主从结构将触发器分为两级：主触发器（Master）和从触发器（Slave）。

### 工作原理

- 主触发器与从触发器的时钟相位相反
- **Clock = 1 期间**：主触发器打开，接收输入信号；从触发器保持
- **Clock 下降沿**：主触发器保持，从触发器按主触发器的状态翻转
- Q 和 Q' 只在下降沿发生变化

如果将反相器位置调换（将反相器从主触发器移到从触发器一侧），可使触发发生在上升沿。

### 图形符号解读

主从结构触发器的符号中有特殊标记（`>` 形符号），表示其为脉冲触发结构。符号解读要点：

- 符号的前半段代表 **主触发器** 的触发情况
- 从触发器不在符号中直接画出，但其时钟相位与主触发器相反
- 若时钟端 **有圈**，表示 **上升沿** 触发；**无圈** 表示 **下降沿** 触发

> [!warning] 符号易错点
> 主从结构的符号中，加圈表示上升沿，不加圈表示下降沿。这与通常"加圈表示低电平有效"的习惯相反，极容易出错。

## 主从 SR 触发器

主从结构的 SR 触发器，其 Q 和 Q' 与 S、R 之间的逻辑关系与电平触发 SR 触发器完全一致：

| S | R | 功能 |
|---|---|---|
| 0 | 0 | 保持 |
| 0 | 1 | 置 0 |
| 1 | 0 | 置 1 |
| 1 | 1 | 约束条件（不允许） |

约束条件依然存在：当 S = R = 1 时，Clock = 1 期间主触发器输出两个 1，下降沿到来时从触发器无法确定取哪个值，输出不确定。

### 功能表的正确用法

> [!warning] 主从 SR 功能表不可直接查用
> 主从 SR 触发器的功能表虽然与电平触发 SR 相同，但 **不能直接在下降沿用 S 和 R 的值查表确定输出**。因为 Q 和 Q' 并非直接受 S 和 R 控制，而是受主触发器的中间结果控制。
>
> 功能表仅在以下情况可直接使用：**主触发器打开期间（Clock=1），S 和 R 的组合没有发生变化**。
>
> 若主触发器打开期间输入组合发生变化，则必须分析主触发器在 Clock=1 期间的完整变化过程，确定下降沿到来前主触发器的最后状态。

### 分析步骤

1. **Clock = 1 期间**：主触发器按电平触发 SR 的规律翻转，从触发器保持
2. **Clock 下降沿**：主触发器保持，从触发器按主触发器的状态翻转

### D 触发器为何能屏蔽中间变化

D 触发器没有保持功能，在打开期间始终跟随输入变化。它不关心前面过程中数据如何变化，只关心边沿到达时刻的数据是什么，因此天然屏蔽了主触发器打开期间的输入变化。这也是为什么设计者通常倾向于选用 D 触发器。

## 主从 JK 触发器

SR 触发器具备置零、置一和保持三种功能，但受约束条件限制。为了解除约束，在主从 SR 触发器的基础上引入两条大反馈线，构成 JK 触发器。

### 电路结构

- 将 Q 反馈到 R 输入端，与外部 K 信号相与
- 将 Q' 反馈到 S 输入端，与外部 J 信号相与

这两条反馈线的唯一作用就是 **解除约束条件**。

### 约束解除原理

利用 Q 和 Q' 互为反相的特性，当 J = K = 1（即外部同时来两个 1）时，反馈线自动将一组输入变为 1 和 0：

若当前状态 Q = 1：
- Q = 1 返回 R 端，置零信号不受影响
- Q' = 0 返回 S 端，将置一信号屏蔽
- 实际得到 J = 0, K = 1 → 置零

若当前状态 Q = 0：
- Q = 0 返回 R 端，将置零信号屏蔽
- Q' = 1 返回 S 端，置一信号不受影响
- 实际得到 J = 1, K = 0 → 置一

> [!important] 核心结论
> 两条反馈线在允许 J = K = 1 的同时，完整保持了置一、置零、保持三个基本功能。当 J = K = 1 时，触发器 **取反**（翻转），即 $Q^{n+1} = \overline{Q^{n}}$。

### 功能表

| J | K | 功能 |
|---|---|---|
| 0 | 0 | 保持 |
| 0 | 1 | 置 0 |
| 1 | 0 | 置 1 |
| 1 | 1 | 取反（翻转） |

### 动作特点：主触发器只能翻转一次

> [!warning] 关键特点
> 主从结构的 JK 触发器，**主触发器在打开期间只能翻转一次**。

这一特点源于反馈线的存在。主触发器一旦翻转，Q 和 Q' 的状态随之变化，反馈回输入端的信号就会封锁其中一条通路，使其无法再向反方向翻转。例如：若主触发器原为 0，翻转为 1 后，Q = 1 返回封锁了置一端，无法再置回 0（直到下一个时钟周期）。

### 分析注意事项

与主从 SR 触发器类似，JK 触发器的功能表也不能直接查用。分析时必须：

1. 观察 Clock = 1 期间 JK 组合的 **全部变化过程**
2. 确定主触发器的最终状态（考虑"只能翻转一次"的约束）
3. Clock 下降沿到达时，从触发器按主触发器的最终状态翻转

> [!example] 例：主从 JK 触发器波形分析
> 给定一个主从结构 JK 触发器，初始状态 Q = 0。Clock、J 和 K 的波形时序如下：第一个 Clock 高电平期间 J = 1、K = 0；第二个 Clock 高电平期间 J、K 由 00 变为 01；第三个 Clock 高电平期间 J、K 出现 11 后又变为 01。
>
> **解：** 分析按以下步骤进行：
>
> 1. **第一个 Clock 周期**：J = 1, K = 0，查表为置 1。主触发器由 0 翻转为 1，此值在 Clock 高电平期间保持。下降沿到达时，从触发器按主触发器的 1 翻转，Q 变为 1。
>
> 2. **第二个 Clock 周期**：高电平开始时 J = 0, K = 0，主触发器保持前一周期值 1。随后 J、K 变为 0 和 1（置 0），主触发器由 1 翻转为 0。下降沿到达时查得 J = 0, K = 0（保持），但此值不代表主触发器的最终状态，不能直接使用。主触发器的最终状态是 0，故下降沿时 Q 变为 0。
>
> 3. **第三个 Clock 周期**：高电平期间 J、K 出现 11（取反），主触发器从 0 翻转为 1。之后 J、K 变为 01（应置 0），但 **"只能翻转一次"** 的规则生效：主触发器已翻转一次，不能再翻回 0。下降沿到达时，主触发器最终状态为 1，Q 变为 1。
>
> 结论：虽然 Q 在每个 Clock 周期只变化一次（下降沿更新），但实际取值由整个 Clock 高电平期间主触发器经历的最终状态决定，而非仅由下降沿时刻的 J、K 值决定。

## 边沿触发器

### 设计动机

主从 JK 触发器虽然在输出端实现了"一个周期只变化一次"，但主触发器在 Clock 高电平期间仍然对输入敏感。若高电平期间出现干扰信号，主触发器可能被误触发，最终影响输出。

边沿触发器旨在将触发器的写入时间缩短到边沿时刻，提高抗干扰能力。理想情况是：Q 的变化只取决于边沿到达瞬间的数据。

### D 触发器的边沿特性

D 触发器 **天然具备边沿触发的特性**。原因在于 D 触发器没有保持功能，在打开期间始终跟随输入变化，不会累积中间过程的数据。最终输出只取决于边沿到达时刻的 D 值。

### 图形符号区分

| 类型 | 符号特征 | 触发时刻 |
|---|---|---|
| 主从结构（脉冲触发） | 标有 `>` 形标记 | 下降沿或上升沿 |
| 边沿触发 | 标有三角形 `>`（无圈 = 上升沿，有圈 = 下降沿） | 边沿时刻 |

> [!note] 符号区分要点
> - 主从结构和边沿触发的符号 **不能同时出现**
> - 若符号中既有脉冲触发标记又有三角形，以三角形（边沿）为准

## 电路结构与功能的关系总结

触发器的分类可以从两个维度进行：

1. **按电路结构**：电平触发 → 脉冲触发（主从结构）→ 边沿触发
2. **按逻辑功能**：RS 触发器 → D 触发器 → JK 触发器

同一结构可以实现不同的功能（如主从结构可构成 RS、D、JK 触发器），同一功能也可以采用不同的结构实现。二者相互组合，才构成一个完整的触发器描述。

> [!quote] 电路设计中的权衡
> 任何电路性能的改进都伴随着新的问题，没有单纯只有好处没有坏处的改进。主从结构解决了"一个周期变化一次"的问题，但引入了分析复杂度和抗干扰能力的下降；边沿触发器提高了抗干扰能力，但对符号解读提出了新要求。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 主从结构原理 | 主从两级，时钟相位相反；主触发器在高电平接收，从触发器在下降沿翻转 |
| 主从 SR 功能表用法 | 不可直接查用，需分析主触发器打开期间的完整过程 |
| SR 约束条件 | 主从结构未解除约束，S = R = 1 时输出仍不确定 |
| JK 触发器反馈线 | 通过 Q 和 Q' 反馈解除约束，允许 J = K = 1 时取反 |
| 主从 JK"一次翻转" | 主触发器打开期间只能翻转一次，由反馈线信号封锁导致 |
| 边沿触发器 | 仅关心边沿时刻的数据，抗干扰能力强 |
| D 触发器的边沿特性 | 因无保持功能，输出仅取决于边沿时刻的 D 值 |

### 核心公式 / 结论

- 主从 JK 触发器的功能：$Q^{n+1} = \begin{cases} Q^n & (J=0, K=0) \\ 0 & (J=0, K=1) \\ 1 & (J=1, K=0) \\ \overline{Q^n} & (J=1, K=1) \end{cases}$
- 主从 JK"一次翻转"：主触发器在 Clock = 1 期间翻转后即被反馈信号封锁，无法再次翻转
- 分析主从触发器时，必须关注 **Clock 高电平期间的完整过程**，而非仅下降沿时刻
