# 边沿触发器的电路结构与工作原理

> [!abstract] 本讲定位
> 本讲回顾第四章触发器电路结构的演变历程（基本锁存器 → 电平触发 → 主从结构 → 边沿触发），在此基础上深入分析 CMOS 传输门边沿 D 触发器的电路结构、两阶段工作过程和触发边沿判定方法，并介绍边沿触发器的符号规范与传输门高阻态的使用注意事项。

## 触发器结构的演变主线

从基本锁存器到边沿触发器，电路结构的每一次改进都围绕同一个核心目标：**能够存储数据（能存能写），并不断缩短写入数据的时间，使存储的数据在单位时间内只变化一次**。

### 从基本锁存器到电平触发锁存器

基本 RS 锁存器可通过 R、S 端直接写入数据。电平触发锁存器在此基础上引入时钟（clock）控制信号——数据必须经过时钟信号的允许才能写入触发器。时钟信号决定**何时**放数据，但**不参与功能逻辑**。

> [!important] 时钟信号的角色
> 时钟信号虽然列在输入信号中，但它只控制数据写入的时机，不参与触发器输入与输出之间的逻辑关系。在功能表中，clock 只管何时放数据，不管数据与输出之间的逻辑关系。

### RS 触发器的约束条件

在 RS 触发器中，S 和 R 不能同时为 1。当 S = R = 1 时，写 1 和写 0 的指令矛盾，两个输出端 Q 和 $\overline{Q}$ 同时被置为 1，电路进入**不定态**。当 clock 撤去（从 1 变 0）时，S 和 R 的组合被关在门外，Q 和 $\overline{Q}$ 的最终状态无法确定——不能由当前的输入组合决定，也不能由电路的历史状态决定。

> [!warning] 不定态的波形画法
> 考试中画波形图遇到不定态时，拉一条确定的高电平线或低电平线是**错误的**。正确做法：用斜线填充、上下两条线（0 和 1 同时画出）、标注「不定」或打问号——总之要表达出「不确定」的含义。

### 解除约束的两种方式

为解除 RS 触发器中 S = R = 1 的约束条件，有两种改进路径。

#### D 触发器：将 S 和 R 合二为一

将 S 和 R 两个输入端合并为一个 D 端。触发后 $Q = D$，不再有同时输入矛盾的状况。

> [!note] D 触发器的取舍
> D 触发器牺牲了 RS 触发器的直接保持功能。在 RS 触发器中，可通过特定的输入组合让输出保持原值；而在 D 触发器中，触发后 Q 始终等于 D。若希望保持原值，只能将原值重新在 D 端输入一遍。

#### JK 触发器：引入大反馈线

在主从 RS 结构的基础上，将 Q 反馈到原 R 输入端、$\overline{Q}$ 反馈到原 S 输入端，引入两条大反馈线。原来的 S、R 信号变为 J、K 信号，约束条件由此解除——J 和 K 可以同时为 1。

反馈线解除约束的原理：利用 Q 与 $\overline{Q}$ 恒为反相的特性（必有一端为 0），当 J = K = 1 时，值为 0 的那一端通过反馈线将对应输入端封锁，自动将 $(1, 1)$ 转化为 $(1, 0)$ 或 $(0, 1)$。

当 $J = K = 1$ 时，触发器的次态与现态相反：
$$Q_{n+1} = \overline{Q_n}$$

> [!warning] 主从 JK 触发器的「一次翻转」问题
> 约束条件解除的同时带来新问题：主从 JK 触发器中，主触发器在 clock 高电平期间**只能翻转一次**。翻转后 Q 与 $\overline{Q}$ 互换，反馈信号的封锁位置随之转移——已经翻转过去的方向被锁死，即使后续 JK 组合要求反向翻转，主触发器也不再响应。这一特性使电路分析更加复杂：功能表虽然给出了对应关系，但不能完全放心地直接查表使用，必须追踪 clock = 1 期间主触发器的完整翻转过程。

## 边沿触发器

### 设计目标

主从 JK 触发器的输出 Q 虽然在每个时钟周期只变化一次，但主触发器在 clock = 1 期间仍然对输入敏感——若高电平期间出现干扰信号，主触发器可能被误触发。即使因「一次翻转」规则未造成二次翻转，初始翻转已改变了中间状态，最终仍会影响输出。

边沿触发器的提出是为了**提高可靠性**：
- 触发器的次态**仅取决于 clock 边沿（上升沿或下降沿）时刻的输入信号**
- 在边沿时刻读取数据端的值后直接写入 Q
- 若能实现这一理想特性，就可以完全放心地直接使用功能表进行分析

> [!important] 边沿触发器的核心优势
> 仅关心边沿时刻的输入数据，对 clock 有效电平期间的输入变化天然不敏感，抗干扰能力大幅提升。功能表可直接查用，无需追踪中间过程。

### 主从结构 D 触发器天然具备边沿特性

主从结构的脉冲触发 D 触发器本质上就是一种边沿 D 触发器。

原因在于电平触发的 D 触发器不具备 RS 电平触发器的保持功能——在 clock 有效电平期间，Q 始终跟随 D 变化，不会像 SR 或 JK 触发器那样累积中间过程的状态变化。因此，在 clock 有效电平**最后时刻**读到的 D 值才是对输出起作用的有效值。前面虽可能有变化，但最终结果仅由最后时刻决定，对中间变化天然不敏感。这是设计者通常倾向于选用 D 触发器的关键原因——分析简单，抗干扰能力强。

除主从 D 触发器外，还有多种实现边沿触发的电路结构：CMOS 传输门边沿触发器、维持阻塞结构、利用门电路传输延迟时间的边沿触发器等。

## CMOS 传输门边沿 D 触发器

> [!note] 结构本质
> 从电路拓扑的角度看，CMOS 传输门边沿 D 触发器本质上仍可归类为主从结构——两组传输门交替通断，分别对应前级取数和后级保持的功能。老师特别强调：「如果要让我来说的话，我认为这个结构**仍然是主从结构**。」

### 存储核心：正反馈环

两个反相器首尾相连形成**正反馈环**，这是触发器的存储核心。

正反馈的存在使电路必定处于两个稳态之一（高电平或低电平），而不会停留在中间的亚稳态。若输出电压恰好处于不高不低的中间电平，正反馈会迅速将电路推向某一侧稳态——正反馈的方向决定了它总是**推着电路离开中间状态**，向最近的稳态加速趋近。

> [!note] 存储原理的演进
> 最初讲两个反相器首尾相连形成存储环时面临一个问题：虽然能存数据，但不知道存的是 0 还是 1，也无法写入指定值。当时的解决方案是将反相器替换为或非门或与非门，开出输入端口来写入数据。另一种思路是：**写入数据时断开环，数据放入后再将环闭合**。CMOS 传输门边沿触发器采用的就是后一种思路——在反馈环上串联可切断的开关。

### 数据写入方式

在正反馈环上加入 CMOS 传输门（CMOS 模拟开关）作为数据通路的控制开关。传输门由一对互补的 NMOS 和 PMOS 管并联构成，当控制端 C = 1、$\overline{C}$ = 0 时开关**闭合**，两端导通；不满足此条件时开关**断开**，呈现高阻态。数据写入的基本流程：断开环路 → 放入数据 → 闭合环路。

### 电路结构与两阶段控制

电路中设有两组传输门（以红色和绿色区分），控制端相位相反：

| clock 电平 | 红色传输门 | 绿色传输门 | 电路状态 |
|:----------:|:----------:|:----------:|----------|
| clock = 1 | 闭合 | 断开 | 存储环闭合保持数据，与外部输入断开，不从外部取数 |
| clock = 0 | 断开 | 闭合 | 存储环断开，从外部取数，数据经绿色传输门传入第一级反相器 |

### 触发边沿分析

将工作过程分为两个阶段理解：

**阶段一（clock = 0）**：红色断开——存储环打开，正反馈中断；绿色闭合——外部数据 D 经绿色传输门进入第一级反相器。此阶段相当于主触发器打开（从外部取数），从触发器（后级）保持原有输出不变。

**阶段二（clock = 1）**：红色闭合——存储环重新闭合，刚取入的数据被锁存在环内，正反馈将其推向稳定状态；绿色断开——外部通路切断，D 端的变化不再影响存储环。此阶段存储环保持数据并输出，不从外部取数。

输出 Q 在 **clock 从 0 跳变到 1 的瞬间**（上升沿）更新为新值。在 clock = 0 期间，D 的值可能变化多次，但起作用的始终是 clock 上升沿到来前最后一刻的 D 值——该值在阶段二中被存储环锁存并输出。因此这是一个**上升沿（正边沿）触发的 D 触发器**。

> [!tip] 判定触发沿的方法
> 将 clock = 0 对应主触发器打开（从外部取数），clock = 1 对应从触发器打开（输出更新）。从 0 跳变到 1 的瞬间输出变化，故为上升沿触发，逻辑符号中 clock 端画一条线（不加圈）。若相位关系反过来（clock = 1 取数、clock = 0 输出），则为下降沿触发，符号中 clock 端需加圈。

### 符号规范

边沿触发器的逻辑符号中，clock 端用三角 `▷` 标记表示边沿触发。主从结构（脉冲触发）使用 `>` 形标记。两种结构对「加圈」的定义恰好相反：

| | 主从结构（脉冲触发） | 边沿触发 |
|---|---|---|
| 标记 | `>` 形标记（无三角） | 三角 `▷` |
| 无圈含义 | 下降沿触发 | 上升沿触发 |
| 有圈含义 | 上升沿触发 | 下降沿触发 |

符号差异的根源：主从结构中的圈画在时钟输入端，表示时钟先经反相器再到主触发器（有圈 = 反相后主触发器在低电平打开 → 从触发器在上升沿取数）；边沿触发器中的圈直接标注触发沿的极性。

> [!warning] 两种标记不可同时出现
> 主从结构的 `>` 标记和边沿触发的三角 `▷` **不能同时出现在同一个触发器符号中**。若符号中同时出现两种标记，以三角形（边沿触发）为准——同时出现是旧版教材曾出现的错误，新教材已修正。

### 传输门高阻态的使用注意事项

CMOS 传输门断开时呈现**高阻态**。高阻态不能随意接入后续逻辑电路，其行为取决于后级门电路的类型：

- **接入 CMOS 逻辑门输入端**：CMOS 门输入阻抗极高（栅极绝缘），高阻态导致输入端悬空。悬空输入端的电平由漏电流和环境噪声决定，产生不确定的逻辑电平，导致逻辑门输出不可预测。**这是不允许的。**
- **接入 TTL 门电路输入端**：TTL 输入级的电路结构使得悬空输入端被内部上拉至高电平。因此高阻态会被 TTL 门**视为高电平**输入。

> [!danger] 高阻态接 TTL 或门的典型错误
> 若将传输门的高阻态输出直接接入一个 TTL 或门的某一输入端，该输入端被 TTL 内部上拉为高电平。对于或门，一个输入端固定为高电平意味着输出恒为 1，或门的逻辑功能完全丧失——其他输入端的信号不再对输出产生任何影响。设计电路时，若传输门后接逻辑门，必须加入适当的上拉或下拉电阻以确定默认电平。

## 本讲小结

### 核心对比

| 对比维度 | 电平触发 | 主从结构（脉冲触发） | 边沿触发 |
|---|---|---|---|
| 写入时间窗口 | clock 有效电平全时段 | clock 有效电平全时段（主触发器）<br>跳变沿（从触发器输出 Q） | clock 跳变沿时刻 |
| 抗干扰能力 | 最弱（全时段敏感） | 较弱（主触发器对干扰敏感） | 最强（仅边沿时刻敏感） |
| 功能表可否直接查用 | 仅输入不变时可用 | 仅输入不变时可用 | 可直接使用 |

### 知识点速查

| 知识点 | 要点 |
|---|---|
| 触发器演变主线 | 基本锁存器 → 电平触发 → 主从结构 → 边沿触发；核心目标是缩短写入时间，使每周期只变化一次 |
| D 触发器的双面性 | 牺牲了直接保持功能的**同时**，也因 Q 始终跟随 D 而天然屏蔽了 clock 有效电平期间的中间变化——这是 D 触发器分析简单的根本原因 |
| JK 触发器的一次翻转 | 主触发器在 clock = 1 期间最多翻转一次；翻转后反馈封锁位置转移，反向通路锁死 |
| CMOS 传输门 D 触发器 | 正反馈环为存储核心；两组传输门控制端相位相反——clock = 0 取数，clock = 1 锁存并输出；**上升沿触发** |
| 符号识别规则 | 边沿触发用三角 `▷`（无圈 = 上升沿，有圈 = 下降沿）；主从结构用 `>`（无圈 = 下降沿，有圈 = 上升沿）；**两种标记不可同时出现** |
| 传输门高阻态处理 | CMOS 门输入接高阻态 → **不允许**（电平不确定）；TTL 门输入接高阻态 → 被视为高电平（可能使逻辑功能丧失） |
| 不定态的画法 | 不能用确定的高/低电平线表示；用斜线填充、上下双线、问号或标注「不定」均可 |

### 核心公式/结论

- D 触发器：$Q_{n+1} = D$（触发后输出始终跟随输入）
- JK 触发器（$J=K=1$）：$Q_{n+1} = \overline{Q_n}$（翻转模式）
- 边沿触发器的核心特征：次态仅由 clock 边沿时刻的输入决定，功能表可直接查用
