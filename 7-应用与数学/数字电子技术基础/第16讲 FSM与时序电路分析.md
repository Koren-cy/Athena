# FSM, 时序电路的分析方法

> [!abstract] 本讲定位
> 本讲在回顾第四章触发器结构演变历程的基础上，重点介绍了边沿触发器的设计动机与实现原理，详细分析了 CMOS 传输门边沿 D 触发器的电路结构和工作过程，为后续学习时序电路（有限状态机）的分析方法奠定基础。

## 触发器结构的演变主线

从基本锁存器到边沿触发器，电路结构的改进始终围绕一个核心目标：**能够存储数据（能存能写），并不断缩短写入数据的时间，使存储的数据在单位时间内只变化一次**。

### 从基本锁存器到电平触发锁存器

基本 RS 锁存器可以通过 R、S 端写入数据。电平触发锁存器在此基础上增加时钟（clock）控制信号，数据必须经过时钟信号的控制才能写入触发器。时钟信号决定了**何时**放数据，但**不参与功能逻辑**。

> [!note] 时钟信号的角色
> 时钟信号虽然是输入信号，但它只控制数据写入的时机，不参与触发器输入与输出之间的逻辑关系。功能表中 clock 只管何时放数据，不管数据和它之间的逻辑关系。

### RS 触发器的约束条件

在 RS 电平触发器中，S 和 R 不能同时为 1。若 S 和 R 同时为 1，写 1 和写 0 的指令矛盾，电路输出进入**不定态**。当 clock 撤去（从 1 变 0）时，S 和 R 的组合被关在门外，输出状态不可确定。

### 解除约束的两种方式

为了解除 RS 触发器的约束条件，有两种改进路径。

#### D 触发器：将 S 和 R 合二为一

将 S 和 R 两个输入端合并为一个 D 端。触发后 $Q = D$，不再有同时输入矛盾的状况。

> [!info] D 触发器的取舍
> D 触发器牺牲了 RS 触发器中的直接保持功能。在 RS 触发器中，可以通过特定的输入组合让输出保持原值；而在 D 触发器中，触发后 Q 始终等于 D。若希望保持原值，只能将原值重新在 D 端输入一遍。

#### JK 触发器：引入大反馈线

在主从 RS 结构的基础上引入两条大反馈线，将原来的 S、R 信号变为 J、K 信号，从而解除约束条件。J 和 K 可以同时为 1。

$J = K = 1$ 时，触发器的次态与现态相反：
$$Q_{n+1} = \overline{Q_n}$$

> [!warning] 主从 JK 触发器的特殊问题
> 约束条件解除的同时带来一个新问题：主从 JK 触发器中，主触发器在 clock 高电平期间**只变化一次**。这一特性使电路分析变得更加复杂——功能表虽然给出了对应关系，但不能完全放心地直接查表使用。

## 边沿触发器（Edge-triggered Flip-Flop）

### 设计目标与优势

边沿触发器的提出是为了**提高可靠性**：

- 触发器的次态**仅取决于 clock 边沿（上升沿或下降沿）时刻的输入信号**
- 在边沿时刻读取数据端的值后直接写入 Q
- 如果实现这一理想特性，就可以直接使用功能表进行分析

### 主从 D 触发器作为边沿触发器

主从结构的脉冲触发 D 触发器本质上就是一种边沿 D 触发器。

> [!tip] 为什么主从 D 触发器是边沿的？
> 电平触发的 D 触发器不具备 RS 电平触发器的保持功能——Q 随时跟随 D 变化。因此，在 clock 有效电平的最后时刻读到的 D 值才是对数据起作用的有效值。前面虽可能有变化，但最终结果由最后时刻决定。

### CMOS 传输门边沿 D 触发器

#### 存储核心

两个反相器首尾相连形成**正反馈环**。正反馈的存在使电路必定处于两个稳态之一（高电平或低电平），而不会停留在亚稳态。

#### 数据写入方式

在正反馈环上加入 CMOS 传输门（CMOS 开关）作为数据通路的控制开关，需要写入数据时断开环路，数据放入后再闭合环路。

#### 电路结构与控制

电路中两组传输门（红色和绿色）的控制端相位相反：

| clock 电平 | 红色传输门 | 绿色传输门 | 电路状态 |
|:----------:|:----------:|:----------:|----------|
| clock = 1  | 闭合       | 断开       | 存储环保持数据，不从外部取数 |
| clock = 0  | 断开       | 闭合       | 从外部取数，数据传入存储环 |

#### 触发边沿分析

- clock = 0 时，从外部取数（相当于主触发器打开，从触发器保持）
- clock 从 0 跳变到 1 时，存储环与外部断开（保持），数据被锁存到输出
- 因此这是一个**上升沿（正边沿）触发的 D 触发器**

#### 符号规范

边沿触发器的符号中，clock 端用" > "标记表示边沿触发，不再使用主从脉冲触发的符号。两种符号不应同时出现在同一个触发器图上。

> [!warning] 传输门高阻态的使用注意事项
> CMOS 传输门断开时呈现高阻态。若高阻态直接接到 CMOS 逻辑门的输入端，会导致不确定的逻辑电平，这是不允许的。若接到 TTL 门电路的输入端，高阻态会被视为高电平。设计电路时需特别注意这一特性。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 触发器演变主线 | 基本锁存器 → 电平触发 → 主从结构 → 边沿触发 |
| RS 触发器约束 | S 和 R 不能同时为 1，否则进入不定态 |
| D 触发器特点 | 触发后 $Q = D$，牺牲了直接保持功能 |
| JK 触发器特点 | 引入大反馈线解除约束，$J=K=1$ 时翻转 |
| 主从 JK 问题 | 主触发器在 clock 高电平期间只变化一次，分析复杂 |
| 边沿触发器优势 | 次态仅取决于 clock 边沿时刻的输入，可靠性高 |
| CMOS 传输门 D 触发器 | 上升沿触发，利用两组传输门交替通断控制数据流 |

### 核心公式/结论

- D 触发器：$Q_{n+1} = D$（触发后输出跟随输入）
- JK 触发器（$J=K=1$）：$Q_{n+1} = \overline{Q_n}$（翻转模式）
- 边沿触发器目标是：次态仅由 clock 边沿时刻的输入决定
