# 施密特触发器的工作原理和应用

> [!abstract] 本讲定位
> 本讲是脉冲波形产生与整形章节的开篇，以施密特触发器为切入点讲解如何将门电路与电阻网络结合实现滞回电压传输特性。内容将第三章门电路的知识与电路原理中的等效和过渡过程相结合。

## 脉冲波形的产生与整形

### 本章背景

纯数字逻辑内容已基本结束，本章关注脉冲波形的产生和整形——即理想方波从何而来。本章将第三章（门电路）的内容与电路原理中的等效、过渡过程结合在一起。

### 脉冲波形的主要参数

对于一个脉冲波形，需要关注以下参数：

- **周期**：波形重复的时间间隔
- **占空比**：高电平持续时间与周期之比
- **斜率**：上升沿和下降沿的陡峭程度，越陡越好

### 本章的分析方法

分析本章电路时，关键原则是：**不到万不得已，绝不打开门电路的内部结构**。将门电路当作黑盒处理，切忌将内部 MOSFET 结构与外围电阻电容画在一起分析。

## 门电路的简化分析模型

### 输出特性

每个门电路的输出可视为一个**电压源**，输出为低电平或高电平。

### 输入特性

- **CMOS 工艺**：输入不取电流，但存在等效输入电容
- **TTL 工艺**：输入结构含三极管，低电平时从电源汲取较大电流，高电平时三极管发射结反偏

## 施密特触发器电路

### 电路结构

施密特触发器由两个 CMOS 反相器和两个电阻构成：

- 第一级反相器 INV1：输入 $V_i$，输出 $V_{o1} = \overline{V_i}$
- 电阻 $R_2$：连接 $V_{DD}$ 与节点 $V_a$
- 电阻 $R_1$：连接节点 $V_a$ 与 $V_{o1}$
- 第二级反相器 INV2：输入 $V_a$，输出 $V_o = \overline{V_a}$
- 电路条件：$R_1 < R_2$

节点 $V_a$ 的电压由 $V_{DD}$ 和 $V_{o1}$ 通过两个电阻分压决定：

$$
V_a = V_{DD} \cdot \frac{R_1}{R_1+R_2} + V_{o1} \cdot \frac{R_2}{R_1+R_2}
$$

### 静态工作状态

#### 输入为低电平（$V_i = 0$）

- $V_{o1} = V_{DD}$（INV1 输出高电平）
- $V_a = V_{DD} \cdot \frac{R_1}{R_1+R_2} + V_{DD} \cdot \frac{R_2}{R_1+R_2} = V_{DD}$
- $V_a$ 为高电平，INV2 输出 $V_o = 0$（逻辑低电平）

#### 输入为高电平（$V_i = V_{DD}$）

- $V_{o1} = 0$（INV1 输出低电平）
- $V_a = V_{DD} \cdot \frac{R_1}{R_1+R_2}$
- 由于 $R_1 < R_2$，有 $V_a < V_{DD}/2$，INV2 输出 $V_o = V_{DD}$（逻辑高电平）

### 电压传输特性与滞回现象

#### 正向阈值 $V_{T+}$（输入上升过程）

当 $V_i$ 从 0 逐渐上升：

1. $V_i$ 较小时，$V_{o1} = V_{DD}$，$V_a$ 为高电平，$V_o = 0$
2. $V_i$ 接近反相器阈值 $V_{TH} \approx V_{DD}/2$ 时，INV1 进入线性放大区，$V_{o1}$ 开始从 $V_{DD}$ 下降
3. $V_a = V_{DD} \cdot R_1/(R_1+R_2) + V_{o1} \cdot R_2/(R_1+R_2)$ 随之下降
4. 当 $V_a$ 降至 $V_{TH}$ 时，INV2 的输出 $V_o$ 开始上升
5. **正反馈形成**：$V_o \uparrow \rightarrow V_a \uparrow \rightarrow \cdots$ 但 $V_{o1}$ 的下降通过 $R_2$ 对 $V_a$ 的拉低作用更强（因为 $R_2 > R_1$），使得 $V_a$ 持续下降 $\rightarrow V_o$ 继续上升，最终 $V_o$ 迅速跳变至 $V_{DD}$

关键结论：**$V_{T+} > V_{DD}/2$**。这是因为在 $V_i = V_{DD}/2$ 时，$V_a$ 仍高于 INV2 的阈值，需要 $V_i$ 进一步升高才能使 $V_a$ 降至 $V_{TH}$。

#### 负向阈值 $V_{T-}$（输入下降过程）

当 $V_i$ 从 $V_{DD}$ 逐渐下降（此时 $V_o = V_{DD}$）：

1. $V_i$ 较高时，$V_{o1} = 0$，$V_a = V_{DD} \cdot R_1/(R_1+R_2) < V_{DD}/2$，$V_o = V_{DD}$
2. $V_i$ 下降至接近 $V_{DD}/2$ 时，INV1 输出 $V_{o1}$ 开始从 0 上升
3. $V_a = V_{DD} \cdot R_1/(R_1+R_2) + V_{o1} \cdot R_2/(R_1+R_2)$ 随之上升
4. 当 $V_a$ 升至 $V_{TH}$ 时触发正反馈，$V_o$ 迅速跳变回 0

关键结论：**$V_{T-} < V_{DD}/2$**。

### 滞回特性

正向阈值和负向阈值不相等，电压传输特性曲线呈现滞回环：

$$
V_{T+} > V_{DD}/2 > V_{T-}
$$

滞回宽度（回差电压）为：

$$
\Delta V = V_{T+} - V_{T-}
$$

该宽度由 $R_1$ 和 $R_2$ 的比值决定。这个熟悉的现象在模拟电路中用运算放大器实现，这里则是用数字电路（门电路加电阻网络）实现的。

### 阈值电压的计算方法

计算 $V_a$ 的电压时，可使用**叠加定理**：分别计算每个电压源单独作用时的贡献，然后叠加。计算时需特别注意电压基准点，这是最容易出错的地方。

当 $V_i$ 处于上升过程中且 $V_a$ 恰好降至 $V_{TH}$ 时，可倒推出对应的 $V_i$ 值，即 $V_{T+}$。同理可计算 $V_{T-}$。

### 电阻条件 $R_1 < R_2$ 的物理意义

条件 $R_1 < R_2$ 的必要性体现在以下两个静态状态：

- 当 $V_i = V_{DD}$ 时，$V_{o1} = 0$，需保证 $V_a = V_{DD} \cdot R_1/(R_1+R_2) < V_{DD}/2$，即 $R_1 < R_2$
- 当 $V_i = 0$ 时，$V_{o1} = V_{DD}$，需保证 $V_a = V_{DD}$（远大于 $V_{DD}/2$），自动满足

若 $R_1 > R_2$，则 $V_i = V_{DD}$ 时 $V_a > V_{DD}/2$，会导致 $V_o = 0$，电路逻辑功能完全错误。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 脉冲波形参数 | 周期、占空比、斜率 |
| 分析方法 | 不打开门电路内部，将输出视为电压源 |
| 施密特触发器结构 | 两个 CMOS 反相器 + 两个电阻（$R_1 < R_2$） |
| 节点电压 | $V_a = V_{DD} \cdot R_1/(R_1+R_2) + V_{o1} \cdot R_2/(R_1+R_2)$ |
| 正向阈值 $V_{T+}$ | 输入上升时的翻转电压，$V_{T+} > V_{DD}/2$ |
| 负向阈值 $V_{T-}$ | 输入下降时的翻转电压，$V_{T-} < V_{DD}/2$ |
| 滞回特性 | $V_{T+} \neq V_{T-}$，回差宽度由 $R_1/R_2$ 比值决定 |
| 正反馈 | 阈值附近的正反馈机制加速输出翻转 |
| 电阻条件 | $R_1 < R_2$ 保证静态逻辑状态正确 |

### 核心结论

- 施密特触发器具有滞回电压传输特性，输出翻转存在两个不同的阈值电压
- 输入上升和下降时的翻转阈值不同，这一特性可用于脉冲整形和噪声消除
- 正反馈在阈值附近加速翻转过程，使输出边沿更加陡峭
