# 单稳态触发器的工作原理和应用 第一讲

> [!abstract] 本讲定位
> 本讲首先回顾了施密特触发器的关键前提与TTL集成实现，随后引入第十章第二种重要脉冲电路——单稳态触发器，重点分析由TTL门电路构成的积分型单稳态触发器的工作原理、稳态与暂稳态的转换过程以及波形分析方法。

## 施密特触发器回顾

### 电阻条件的约束

在分析由门电路构成的施密特触发器时，电阻 $R_1$ 和 $R_2$ 的大小关系必须满足 $R_1 > R_2$。如果该条件不满足（$R_1$ 小、$R_2$ 大），即使输入信号上升到 $V_{DD}$，也无法使节点电压达到门电路的门槛电压，电路被"锁死"为一个基本的锁存器，正反馈关系不复存在，滞环特性也无从谈起。若将 $R_1$ 逐渐减小到零（相当于短路），电路就变成了一个正反馈锁死的结构，外界变化无法引起输出翻转。

分析的关键原则：**先定性分析**，确认电路工作条件成立，再**定量计算**。

### TTL集成施密特触发器

TTL工艺的集成施密特触发器是一个成熟设计，分析时应以理解其滞环特性为目标。

#### 电路结构

整个电路由四个部分组成：

1. **输入与门阵列**：四个二极管加上拉电阻构成与门。四个输入变量全为高时，节点才为高；只要有一个为低，节点即为低电平（加0.7V）。
2. **施密特滞环级**：由T1、T2复合管及相关电阻（R2、R3、R4）构成，决定VT正和VT负不同的滞环特性。
3. **电平移位级**：将门槛电压从1.4V平移到2.8V，使后端推拉式输出级正常驱动。
4. **推拉式输出级**：TTL典型输出结构（T4/T5管导通时输出低电平，T6管导通时输出高电平）。

#### 工作原理

输入为低电平时，T1管截止，T2管饱和导通，VE点电压由R3和R4分压决定：
$$V_{E(低)} = \frac{R_4}{R_3 + R_4}(V_{CC} - V_{CE(sat)})$$

输入为高电平时，T1管饱和导通，T2管截止，VE点电压由R2和R4分压决定：
$$V_{E(高)} = \frac{R_4}{R_2 + R_4}V_{CC}$$

由于 $R_2 \neq R_3$，$V_{E(低)} \neq V_{E(高)}$，从而形成滞环特性。

#### 正反馈转换过程

**低电平上升过程**（求 $V_{T+}$）：
- 输入从低电平上升，当 $V_{BE} > V_{E(低)} + 0.7V$ 时，T1管开始导通
- T1导通 $\rightarrow I_C$ 上升 $\rightarrow V_{CE}$ 下降 $\rightarrow V_E$ 下降 $\rightarrow V_{BE}$ 进一步上升
- 正反馈迅速将电路推向T1导通、T2截止的状态，输出变为高电平

**高电平下降过程**（求 $V_{T-}$）：
- 输入从高电平下降，当 $V_{BE} < V_{E(高)} + 0.7V$ 时，触发反向正反馈
- 正反馈迅速将电路推向T1截止、T2导通的状态，输出变为低电平

#### 输出电平特性

需要特别注意，输出高电平是由上拉直接拉出的较高电平，而输出低电平是T2管饱和导通电压叠加VE点电压的结果，并非理想的零电平。因此，实际传输特性中的低电平值会浮在中间位置，图示仅为示意。

#### 整体逻辑功能

该电路实现的是**四输入与非门**功能，附加了施密特滞环特性。滞环特性不影响电路的逻辑功能，仅表示 $V_{T+} \neq V_{T-}$ 以及边沿特性更好。

传输特性如下：
- 输入低 $\rightarrow$ 输出高（但低电平值不理想）
- 输入高 $\rightarrow$ 输出低
- 由于存在反相，滞环回线的方向与前面所述相反

### 施密特触发器小结

- **核心特点**：$V_{T+} \neq V_{T-}$，两个门槛电压值不同
- **关键机制**：电路转换过程伴随正反馈，边沿陡峭
- **主要用途**：波形整形（将质量不佳的波形变为干净的方波）、幅度监测
- **重要辨析**：施密特触发器（trigger）与第五章的触发器（flip-flop）不同，trigger 意为"触发"，不用于存储数据。施密特特性是附加在基本逻辑运算上的，不独立存在

### CMOS施密特触发器

课堂上未展开讲解，留给学生精读。分析方法与TTL相同：找出输入正向变化和负向变化时使电路状态发生变化的门槛电压 $V_{T+}$ 和 $V_{T-}$，找出两者之间的差异即可。

## 单稳态触发器概述

### 定义

单稳态触发器是一种具有**一个稳态**和**一个暂稳态**的脉冲电路。

### 工作特点

1. 在外界**触发信号**作用下，从稳态进入暂稳态
2. 维持**一段时间后**，自动返回稳态
3. 暂稳态维持时间的长短**仅取决于电路内部的参数**（电阻、电容），与触发信号无关

### 生活中的应用实例

- 楼道声控灯：跺一脚触发，亮一段时间后自动熄灭，再触发再亮
- 洗手间感应水龙头：手伸过去触发，出水一段时间后自动停止
- 门铃：按一下响一会儿后自动停止

单稳态的实现方式不限于半导体电路，机械弹簧式延时等也属于单稳态机制。

## 积分型单稳态触发器（TTL门电路）

### 电路结构

由TTL与非门、反相器（非门）、电阻 $R$ 和电容 $C$ 构成，电容的引入使得分析需关注电路的过渡过程。

> [!warning] 电阻值的约束
> 采用TTL门电路时，电阻 $R$ 的值不能太大。原因在于TTL电路的输入负载特性——若电阻值过大，低电平无法正常传递到输入端。

### 稳态分析

- 输入 $V_I = 0$（逻辑低电平）
- 与非门输出 $V_{O1} = 1$（逻辑高电平）
- 电容 $C$ 充电至稳态，$V_A$ 为高电平
- 反相器输出 $V_O = 0$（逻辑低电平）

### 触发与暂稳态

当输入 $V_I$ 发生正跳变（从 $0 \rightarrow 1$）时：

1. 与非门输出 $V_{O1}$ 从 $1$ 跳变为 $0$
2. 由于电容两端电压不能突变，$V_A$ 仍维持高电平
3. 反相器输出 $V_O$ 跳变为 $1$，电路进入**暂稳态**
4. 电容通过电阻 $R$ 开始放电，$V_A$ 逐渐下降
5. 当 $V_A$ 下降到门电路的门槛电压 $V_{TH}$ 时，反相器输出 $V_O$ 返回 $0$，暂稳态结束

### 波形分析

```
V_I         ┌───┐
       ─────┘   └─────────

V_O1        ┌────┐
       ─────┘    └─────────

V_A     ┌──────────┐
        │          │ ↘
        │          │  ↘ (RC放电)
        │          │   ↘
        ───────────┘   ──────
                    ↑VTH

V_O         ┌──────────┐
        ────┘          └───────
```

### 暂稳态持续时间的计算

暂稳态维持时间 $t_W$ 取决于电容从初始高电平 $V_{OH}$ 放电到门槛电压 $V_{TH}$ 所需的时间。对于RC放电回路：

$$v_A(t) = V_{OH} \cdot e^{-\frac{t}{RC}}$$

令 $v_A(t_W) = V_{TH}$，得：

$$t_W = RC \ln\left(\frac{V_{OH}}{V_{TH}}\right)$$

对于TTL门电路，$V_{TH} \approx 1.4V$，$V_{OH}$ 为高电平输出电压。

### 关键细节：放电持续与暂稳态结束的区别

当 $V_A$ 放电到 $V_{TH}$ 时，暂稳态过程**已经结束**（$V_O$ 返回低电平），但电容的放电**并未停止**。放电过程由前级决定，而非由最终输出决定。因此，在暂稳态结束后，电容会继续放电，直至触发脉冲返回。

### 恢复过程

1. 触发脉冲返回低电平（$V_I \rightarrow 0$）
2. 与非门输出 $V_{O1}$ 回到高电平
3. 电容开始重新充电，$V_A$ 逐渐恢复至高电平
4. 电路完全恢复稳态，为下一次触发做好准备

> [!warning] 恢复时间约束
> 在电容未充分充电至高电平之前，不应再次施加触发脉冲，否则暂稳态持续时间会发生变化（缩短）。

## 施密特触发器的应用：幅度监测

> [!example] 例：环境污染超标监测装置
> 设计一个装置，用于监测化工厂排污口是否超标排放，并记录超标次数和持续时间。
>
> **解：**
>
> **方案一——超标次数计数：**
> 使用传感器将污染浓度转换为电信号，经施密特触发器进行幅度判别。将 $V_{T+}$ 设为超标阈值，当信号超过 $V_{T+}$ 时输出翻转，产生计数脉冲。通过计数器记录一天内超标次数。
>
> **方案二——超标持续时间测量：**
> 将方案一中的脉冲接至计数器（如74161）的 EP/ET 控制端。计数器的时钟源设为固定频率（如1秒）。超标时计数器允许计数，不超标时停止。累计值即可精确反映一段时间内的超标总时长。
>
> **方案三——实时报警：**
> 超标信号触发报警模块（声音报警或短信模块），实现实时预警。
>
> 该例体现了施密特触发器在幅度监测中的核心作用：利用 $V_{T+}$ 作为判别阈值，将模拟信号转换为数字脉冲，再配合计数器进行量化统计。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 施密特触发器的电阻条件 | $R_1 > R_2$ 必须满足，否则电路被锁死为锁存器 |
| TTL施密特触发器构成 | 与门阵列 + 滞环级 + 电平移位 + 推拉输出 |
| 施密特核心特性 | $V_{T+} \neq V_{T-}$，转换伴随正反馈 |
| 施密特触发器用途 | 波形整形、幅度监测 |
| 单稳态触发器定义 | 一个稳态 + 一个暂稳态 |
| 单稳态工作过程 | 触发 $\rightarrow$ 进入暂稳态 $\rightarrow$ 自动返回稳态 |
| 暂稳态持续时间 | 仅取决于电路内部参数（RC常数），与触发信号无关 |
| 积分型单稳态 | TTL与非门 + RC，电容放电到 $V_{TH}$ 时返回稳态 |
| 恢复约束 | 电容充满前不可再次触发，否则暂稳时间会变化 |

### 核心概念

- 施密特特性是附加在基本逻辑运算上的修饰特性，不改变逻辑功能
- 单稳态触发器中，暂稳态维持时间由RC充放电参数决定，与触发脉冲宽度无关（前提是触发脉冲宽度大于暂稳时间）
- 第十章的特点是将门电路知识与电路原理中的过渡过程分析相结合
