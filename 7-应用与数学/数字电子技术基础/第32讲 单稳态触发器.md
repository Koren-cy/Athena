# 单稳态触发器的工作原理和应用 第二讲

> [!abstract] 本讲定位
> 本讲继续深入单稳态触发器的分析，重点讲解输出脉宽的计算方法——三要素法，以及微分型单稳态触发器的工作原理、波形分析和参数计算。随后引出可重复触发概念和多谐振荡器（环形振荡器）的基本原理。

## 波形分析方法与脉宽计算

### 波形分析的基本原则

在分析单稳态电路波形时，将门电路的输出直接当作高低电平处理，不要急于将电路内部结构展开。只有在需要计算具体参数（如输出脉宽）时，才将电路打开进行定量分析。

### 三要素法求脉宽

输出脉宽是单稳态触发器最重要的性能参数。脉宽对应暂稳态持续的时间，即电容从初始值充/放电到阈值电压 $V_{TH}$ 所需的过渡过程时间。

三要素法公式来自电路原理中的 RC 过渡过程分析：

$$
f(t) = f(\infty) + [f(0_+) - f(\infty)] e^{-t/RC}
$$

需要确定的三个关键值：
- **初始值** $f(0_+)$：暂稳态开始时电容上的电压
- **终了值** $f(\infty)$：若过渡过程一直进行下去，电容电压最终将达到的值
- **时间常数** $\tau = RC$

在单稳态分析中，我们已知 $f(t)$（即 $V_{TH}$），需反推时间 $t$：

$$
t = RC \ln \frac{f(\infty) - f(0_+)}{f(\infty) - f(t)}
$$

对于积分型单稳态电路，各值如下：
- 起始值：高电平 $V_{OH}$
- 终了值：低电平（放电最终状态）
- $f(t)$：阈值电压 $V_{TH}$

因此脉宽计算公式为：

$$
t_W = RC \ln \frac{V_{TH} - V_{OL}}{V_{OH} - V_{OL}}
$$

### 何时打开电路

遵循"不到万不得已不打开电路"的原则。定性分析波形时，将门输出视为理想高低电平。只有在用三要素法计算参数时，才需要将电路打开。

打开电路时的规则：
- **所有门电路的输出都当成一个有内阻的电压源**
- 输入端照常画出
- TTL 工艺与 CMOS 工艺的输入特性不同：TTL 输入会取电流，CMOS 输入不取电流（可忽略）
- 内阻值取决于工艺，数据手册中可查到典型值
- 与 RC 放电回路无关的部分可忽略

打开电路后，初始值和终了值可能会根据等效电路进行微调，并非理想的高电平或低电平。

> [!important] 核心思路
> 三要素公式可先写出，找出已知量，再打开电路确定与电路结构相关的参数。电路打开后，某些值可能需要进行修正，不能单纯地使用理想高低电平。

## 微分型单稳态触发器

### 设计目标

积分型单稳态触发器要求触发脉冲宽度比输出脉宽窄（若触发脉冲过宽，暂稳态宽度会受触发信号影响）。为解决此问题，设计了微分型单稳态触发器。其特点是对触发脉冲宽度不再敏感，适用于楼道灯控制等场景——只需短暂触发（跺一脚），电路自动维持固定时长。

### 电路结构特点

微分型单稳态触发器与积分型相比：
- **两套 RC**：一套耦合触发脉冲（输入端的微分环节），一套决定暂稳态时间
- 门电路采用 **CMOS 工艺**：
  - 输出高电平为 $V_{DD}$
  - 门槛电压 $V_{TH} = V_{DD} / 2$
  - 输入电阻极大，几乎不取电流
  - 输入端有保护二极管（上钳位至 $V_{DD} + 0.7V$，下钳位至 $-0.7V$）

### 稳态分析

输入 $V_I = 0$（低电平）时：

> [!note] 分析方法
> 分析稳态时，若不能一眼看出，可遍历输入为 0 和 1 两种情况。多数情况下需要两种都试一遍才能找到稳态。

稳态条件：$V_I = 0$，第一级 RC 隔直，故 $V_D = 0$。经两级反相器后，$V_{O1} = V_{DD}$，$V_{O2} = 0$。由于 $V_{O1} = V_{DD}$，电容两端压差近似为零（或很小），电路稳定。

| 节点 | 稳态电平 |
|------|----------|
| $V_I$ | 0 |
| $V_D$ | 0 |
| $V_{O1}$ | $V_{DD}$ |
| $V_{O2}$ | 0 |

### 触发与暂稳态过程

1. **触发**：$V_I$ 发生正跳变 $\to$ 电容两端压差不突变 $\to$ $V_D$ 也发生正跳变
2. **正反馈**：$V_D$ 上升 $\to$ $V_{O1}$ 下降 $\to$ 通过耦合电容 $V_{I2}$ 下降 $\to$ $V_{O2}$ 上升（进入暂稳态 $V_{O2} = 1$）
3. **自维持**：$V_{O2}$ 通过反馈线回到第一级，即使触发信号撤除，电路仍维持暂稳态
4. **充电过程**：$V_{I2}$ 为低电平，与 $V_{DD}$ 之间在电阻上形成电流，电容开始充电，$V_{I2}$ 逐渐上升
5. **阈值到达**：$V_{I2}$ 充电至 $V_{TH}$ 时，电路发生反转，返回稳态

### 波形分析要点

波形分析是本章的难点。各个波形本身是连续的，但它们相互之间作为起点，需要相互关联地画：

- $V_I$ 正跳变 $\to$ $V_D$ 正跳变（电容耦合）
- $V_D$ 正跳变 $\to$ $V_{O1}$ 下降
- $V_{O1}$ 下降 $\to$ $V_{I2}$ 下降（耦合）
- $V_{I2}$ 下降 $\to$ $V_{O2}$ 上升（暂稳态）
- 反馈线使 $V_{O2}$ 高电平维持第一级状态，即使触发脉冲消失
- 充电过程中 $V_{I2}$ 逐渐上升至 $V_{TH}$

#### 返回稳态时的跳变

$V_{I2}$ 充电至 $V_{TH}$ 后继续上升，触发连锁反应：

- $V_{I2}$ 超过 $V_{TH}$ $\to$ $V_{O2}$ 开始下降
- $V_{O2}$ 下降 $\to$ $V_{O1}$ 上升
- $V_{O1}$ 上升 $\to$ 电容耦合使 $V_{I2}$ 产生一个正跳变

**电容耦合的跳变幅度**：理想情况下，$V_{I2}$ 会从 $V_{TH}$ 跳至 $V_{TH} + V_{DD} = \frac{3}{2}V_{DD}$（CMOS 工艺）。

### 钳位二极管的影响

CMOS 反相器输入端有保护二极管，将输入电压钳位在 $V_{DD} + 0.7V$ 以内。因此，$V_{I2}$ 的实际跳变不会达到 $\frac{3}{2}V_{DD}$，而是被钳位至 $V_{DD} + 0.7V$。为简化分析，通常直接认为跳变到 $V_{DD} + 0.7V$。

### 微分型与积分型的对比

| 特性 | 积分型 | 微分型 |
|------|--------|--------|
| RC 作用 | 积分（缓慢放电） | 微分（耦合触发脉冲） |
| 触发脉冲宽度要求 | 必须比输出脉宽窄 | 无严格限制 |
| 适用场景 | 脉冲宽度较窄的场合 | 楼道灯等需要短触发的场合 |

> [!note] 命名由来
> 积分型的 RC 环节起到积分作用（缓慢放电），微分型的 RC 耦合环节起到微分作用（脉冲耦合），因此得名。

### 脉宽计算

对于微分型单稳态触发器，采用三要素法：

- 起始值 $V_{I2}(0_+) = 0$
- 终了值 $V_{I2}(\infty) = V_{DD}$
- $f(t) = V_{TH} = V_{DD}/2$
- 时间常数 $\tau = R_{ON}C$（需打开电路，将门输出视为有内阻的电压源）

$$
t_W = RC \ln \frac{V_{DD} - 0}{V_{DD} - V_{DD}/2} = RC \ln 2
$$

> [!warning] 不要死记公式
> 教材中会给出针对特定电路的 $\ln 2$、$\ln 3$ 等简化公式，但考试时电路稍作变化就会导致错误。必须理解三要素法的分析过程，而不是死记简化结果。

**常见变化举例**：
- 若将门电路换成具有回差特性的电路，充电和放电时的阈值电压 $V_{T+}$ 和 $V_{T-}$ 不同，需分别判断
- 若在充电回路中增加额外支路（如串接电阻到另一电源），终了值需用叠加原理计算

### 恢复时间

暂稳态结束后，电路需要一个恢复时间准备下一次触发。恢复时间通常为 **3~5 倍时间常数**，这是基于 $e$ 的指数衰减特性：

$$
e^{-t/\tau} \approx 0 \quad (t = 3\tau \to 5\tau)
$$

> [!tip] 过渡过程描述的是电容双极的电压差
> 电容的过渡过程描述的是电容两端压差的变化，而非单极电压。这是初学者容易出错的地方。

## 集成单稳态触发器

集成的单稳态触发器以微分型电路为核心，在前面增加一级触发器。利用触发器的特性可实现：
- **脉冲展宽**
- **正触发或负触发**（正跳变沿触发或负跳变沿触发）

集成单稳态触发器提供外接 RC 引脚，使用时应按器件手册给出的公式计算脉宽。对于这类器件，只能使用手册中的 $\ln 2$ 等公式。

## 可重复触发概念

### 定义

**可重复触发**：电路进入暂稳态后，仍可响应外部触发信号，且以最后一次触发的时间点作为暂稳态的起点重新计时。

### 与不可触发的对比

前文讨论的积分型和微分型单稳态电路均为**不可重复触发**——进入暂稳态后即对触发信号屏蔽。

### 实现思路

电容的过渡过程是时间衡量器，如同一个固定容量的水桶：
- 充电计时：水桶从空到满的时间
- 放电计时：水桶从满到空的时间

要实现可重复触发，需要在暂稳态期间能随时将"水桶"恢复到起始状态。这在积分型和微分型电路中无法实现，因为进入暂稳态后，触发信号无法中断过渡过程并回到起点。

## 多谐振荡器

### 基本概念

- **单稳态触发器**：产生一个脉冲（需外加触发）
- **多谐振荡器**：产生一串周期性脉冲（自激振荡，不需外加触发）

> [!tip] 区分方法
> 一眼判断：如果电路没有输入信号，大概率是振荡电路；如果有外界触发信号配合，则是单稳态电路。

### 环形振荡器

三个反相器首尾相连（奇数个）构成负反馈环形振荡器。

- 每个门的传输延迟时间为 $t_{PD}$
- 经过 3 个 $t_{PD}$ 信号返回，再经过 3 个 $t_{PD}$ 再次翻转
- 振荡周期：$T = 2n \cdot t_{PD}$（$n$ 为奇数反相器个数）

对于 3 个反相器，周期 $T = 6 t_{PD}$：

```
高电平持续 3 个 t_{PD} → 翻转
低电平持续 3 个 t_{PD} → 翻转
```

> [!warning] 环形振荡器的问题
> $t_{PD}$ 由硬件工艺决定，不可控，因此周期不稳定。设计电路时不应依赖具体的传输延迟时间。

### 引入 RC 积分环节的环形振荡器

在环形振荡器中加入一级 RC 积分环节，意图使用 RC 时间常数决定振荡周期，取代不可控的 $t_{PD}$。

#### 工作过程

1. 上电时，电容从 0 开始充电至 $V_{TH}$
2. 达到 $V_{TH}$ 后，信号沿反馈环路传播
3. 但电路稳定工作后，电容电压始终在 $V_{TH}$ 上下浮动，从未完全放电

#### 问题分析

上电后第一次充电时，电容从 0 充到 $V_{TH}$，看似可用 RC 确定周期。但后续循环中：

- 电容充电到 $V_{TH}$ 后，电路翻转，信号沿环路传播
- 在 3 个 $t_{PD}$ 的时间内，电容在 $V_{TH}$ 之上继续充电约 3 个 $t_{PD}$ 的幅度
- 然后开始放电，但只放到 $V_{TH}$ 就又触发翻转
- 电容电压始终在 $V_{TH}$ 附近小幅波动

**结论**：电容没有机会完全放电，实际振荡周期仍由 $t_{PD}$ 决定，与 RC 无关。这就是为什么此电路"看上去原理对，但工作起来与 RC 无关"。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 三要素法求脉宽 | 确定初始值、终了值、时间常数，反推 $t$ |
| 电路打开时机 | 仅在参数计算时打开，门输出视为有内阻的电压源 |
| 微分型单稳态 | 输入端微分耦合，CMOS 工艺，$V_{TH}=V_{DD}/2$ |
| 波形分析方法 | 各波形相互关联，不能孤立分析 |
| CMOS 钳位二极管 | 限制电压跳变不超过 $V_{DD}+0.7V$ |
| 微分型 vs 积分型 | 微分型解除对触发脉宽的要求 |
| 可重复触发 | 暂稳态期间可响应新触发并重新计时 |
| 环形振荡器 | 奇数反相器，周期 $T = 2n \cdot t_{PD}$ |
| RC 积分环形振荡器 | 电容无法完全放电，实际仍由 $t_{PD}$ 决定 |

### 核心公式

- **三要素法通式**：$f(t) = f(\infty) + [f(0_+) - f(\infty)] e^{-t/RC}$
- **反算时间**：$t = RC \ln \frac{f(\infty) - f(0_+)}{f(\infty) - f(t)}$
- **恢复时间**：$t_{rec} \approx 3\tau \sim 5\tau$
- **环形振荡器周期**：$T = 2n \cdot t_{PD}$（$n$ 为奇数）
