# 555定时器的工作原理和应用 第一讲

> [!abstract] 本讲定位
> 本讲先回顾多谐振荡器的工作过程与参数修正方法，再介绍石英晶体多谐振荡器的原理，最后引入 555 定时器——一款经典的数模混合集成电路，分析其内部结构、工作原理与功能表。

## 多谐振荡器工作过程回顾

在对称式多谐振荡器中，电路一旦进入工作状态，就会在两个高低电平状态之间来回切换，每次切换伴随一个过渡过程。过渡过程的根源在于电容两端的压差。

### 过渡过程的关键

整个正反馈过程的关键点是**门槛电压** $V_{TH}$。以某一电容 $C_1$ 的充电过程为例：

1. $V_{I2}$ 充电至 $V_{TH}$，引发正反馈：
   - $V_{I2} \uparrow \to V_{O2} \downarrow$（电容耦合使 $V_{I1}$ 下降）
   - $V_{I1} \downarrow \to V_{O1} \uparrow$
   - $V_{O1} \uparrow$ 加剧 $V_{I2}$ 的上升
2. 正反馈将输出推至极端：$V_{O2}$ 变为低电平，$V_{O1}$ 变为高电平。
3. 耦合电容使 $V_{I2}$ 在 $V_{TH}$ 基础上叠加一个跳变，幅度为高电平减去低电平。
4. 跳变后进入下一过渡过程（放电或充电）。

整个电路始终在这两个状态间来回切换，推动状态变化的触发点始终是 $V_{TH}$。

> [!note] 前位二极管的限制作用
> TTL 门电路输入端的保护二极管会将电压钳位在 **-0.7V** 以上，因此当电压向下跳变时，不会低于 $-0.7\text{V}$（记为 $V_{IK}$）。这个钳位作用简化了计算，因为放电过程不会完全放到 $V_{TH}$，而是在某个未确定的位置发生跳变，但已知跳变会越过零电平向下。

### RC 时间常数的修正

计算时间常数时必须打开电路图，围绕电容两端分析等效电路。不能简单地认为充电稳态就是门电路的高电平输出。

> [!warning] 稳态值的修正
> 如果电容充电回路中存在 $V_{CC}$ 和下拉电阻等其他路径，稳态值应是各路电源叠加后的结果。例如，电路中 $V_{CC}$ 和 $R_{ET}$ 共同决定稳态电压，需要重新计算等效戴维南电路。

在对称式多谐振荡器中，两个电容分别经历充放电过程，但实际只有充电过程决定了振荡周期。另一个电容主要起**耦合作用**。由于这对电容和电阻中有一半器件未在过渡过程中起核心作用，且多余的充放电会耗散功率，因此实际中更常使用**非对称式多谐振荡器**。

### 非对称式多谐振荡器（CMOS 工艺）

非对称式多谐振荡器去掉了一半的 RC 元件，耦合改用直接导线连接。

以 CMOS 门电路为例：

- CMOS 门电路输入不取电流，因此反馈电阻两端电位相同，工作点落在电压传输特性的转折区，显然不稳定。
- 一旦存在正扰动，正反馈迅速将输出推向高电平（$V_{O1}$ 为低电平，$V_{O2}$ 为高电平）。
- 此时电容进入**放电过程**，放到 $V_{TH}$ 时再次引发正反馈，使输出翻转为低电平。
- 然后电容开始**充电**，充电起始点为 $V_{TH}$ 减去一个跳变幅度，再次充到 $V_{TH}$ 时电路再次翻转。

三个关键工作点：

| 关键点 | 说明 |
|--------|------|
| $V_{TH}$ | 无论充放电，引起电路状态变化的触发点 |
| $V_{TH} - \Delta V$ | 充电起始点 |
| $V_{TH} + \Delta V$ | 放电起始点 |

> [!note] CMOS 门电路的输出内阻
> CMOS 门电路输出高电平时为 $V_{DD}$（通过 PMOS 管上拉），输出低电平时为 GND（通过 NMOS 管下拉）。导通管子的等效内阻记为 $R_{on}$（上管 $R_{on,p}$，下管 $R_{on,n}$）。由于 CMOS 输入不参与充放电，稳态值就是电源电压，计算相对 TTL 更为简单。

### 打开电路的原则

在参数计算中，**一直到最后一步才打开电路**围绕电容两端进行分析。门电路的输出视为带有内阻的电压源。

## 石英晶体多谐振荡器

### RC 振荡器的精度局限

前面讨论的 RC 多谐振荡器精度受限于：

- **电阻制造误差**：普通五环电阻误差约 5%
- **温度漂移**：RC 参数随温度变化
- **环境因素**：电源波动等

因此 RC 振荡器不适合作为精准时钟源。

### 石英晶体的特性

石英晶体（云母片）具有**选频特性**：它对某一特定的频率（晶体的固有谐振频率）阻抗近似为零，对其他频率的信号则呈现高阻抗。其阻抗-频率曲线在谐振点附近变化非常陡峭。

```
阻抗
  |
  |    \
  |     \
  |      \___________
  |       |  谐振频率
  |       |
  +-------------------> 频率
       (约 0Ω)
```

石英晶体本身不能直接产生方波，它只是一个**选频器件**。石英晶体多谐振荡器的结构是：将石英晶体接入能够振荡的多谐振荡器电路中，整个电路的主频由晶体决定。晶体选出的是**正弦波**，需要再经过一级**施密特触发器**整形为方波。

> [!tip] 石英晶体振荡器模块
> 市售的石英晶体振荡器有两种类型：一是单纯的石英晶体（两条腿或三条腿），需外接电路才能工作；二是集成好的石英晶体振荡器模块，内部已将所需电路设计好，可以直接使用。

### 方波的谐波构成

方波由基频正弦波和奇数次谐波叠加而成。当叠加到 5 到 7 次谐波时，波形已非常接近方波。

## 555 定时器

### 历史背景

555 定时器由瑞典裔美国工程师 **Hans Camenzind** 于 1970 年左右设计，1972 年在 Signetics 公司发布。这是一款在集成电路发展史上极少见的"长寿"器件——至今仍在广泛使用。仅 2003 年一年的产量就达 10 亿枚。

Hans Camenzind 是模拟集成电路设计大师，一生参与设计了约 150 款器件，著有《模拟半导体技术的设计》一书。

### 内部结构

555 定时器是一个**数模混合器件**，其内部包含三个主要部分：

1. **两个电压比较器**（单线比较器）
2. **一个基本 RS 触发器**
3. **一个集电极开路（OC）输出晶体管**

此外，内部还有一个由三个 5kΩ 电阻串联组成的分压网络，提供两个参考电压。

```
                    VCC
                     |
                    [R]
                     |
    THRES ---------+--*--- 比较器A 正端
                    |      2/3 VCC
                   [R]
                     |
    TRIG -----------+--*--- 比较器B 负端
                    |      1/3 VCC
                   [R]
                     |
                    GND

    比较器A 输出 ----+
                     |   RS 触发器
    比较器B 输出 ----+      |
                           +---- 输出缓冲 ---> OUT
                           |
                           集电极开路管 ---> DIS
```

### 分压网络

三个 5kΩ 电阻串联，产生两个参考电压：

- 比较器 A（上比较器）的负端接 **2/3 VCC**
- 比较器 B（下比较器）的正端接 **1/3 VCC**

两个比较器的输出分别接到 RS 触发器的置零（R）和置一（S）输入端。

### 输出级

输出级为**集电极开路（OC）结构**（对应 CMOS 工艺则为 OD 结构）。当输出为高电平时，内部晶体管不导通，DIS 引脚呈高阻态，需要外接上拉电阻；当输出为低电平时，内部晶体管导通饱和，DIS 引脚输出低电平。

### 复位端 ($\overline{RD}$)

$\overline{RD}$（低电平有效复位）直接作用于输出级，优先级最高。当 $\overline{RD}=0$ 时，无论其他输入如何，输出强制为 0。

### 功能表

555 定时器的输入信号是**模拟量**（电压值），输出是**数字量**，因此它是数模混合器件的典型代表。

| $\overline{RD}$ | THRES ($V_{TH}$) | TRIG ($V_{TR}$) | OUT | DIS |
|:---:|:---:|:---:|:---:|:---:|
| 0 | × | × | 0 | 导通 |
| 1 | < 2/3 VCC | < 1/3 VCC | 1 | 截止 |
| 1 | > 2/3 VCC | > 1/3 VCC | 0 | 导通 |
| 1 | < 2/3 VCC | > 1/3 VCC | 保持 | 保持 |
| 1 | > 2/3 VCC | < 1/3 VCC | **约束** | — |

功能表推导逻辑：

- **置一**（OUT=1）：$\overline{S}=0,\ \overline{R}=1$ → TRIG < 1/3 VCC 且 THRES < 2/3 VCC
- **置零**（OUT=0）：$\overline{S}=1,\ \overline{R}=0$ → TRIG > 1/3 VCC 且 THRES > 2/3 VCC
- **保持**：$\overline{S}=1,\ \overline{R}=1$ → TRIG > 1/3 VCC 且 THRES < 2/3 VCC
- **约束**（不允许出现）：$\overline{S}=0,\ \overline{R}=0$ → TRIG < 1/3 VCC 且 THRES > 2/3 VCC

> [!important] 核心思想
> 555 定时器通过比较输入电压与 1/3 VCC、2/3 VCC 两个阈值，控制 RS 触发器的状态，进而决定输出电平。利用这一基本原理，可以构成施密特触发器、单稳态触发器和多谐振荡器三种典型应用电路。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 多谐振荡器过渡过程 | 由电容压差引起，$V_{TH}$ 是状态翻转的触发点 |
| 参数修正 | 需打开电路图，围绕电容两端计算等效电路；稳态值为等效戴维南电压 |
| 非对称式多谐振荡器 | 去掉一半 RC，用导线耦合；仅充电过程决定振荡周期 |
| CMOS 门电路特点 | 输入不取电流；输出高电平为 $V_{DD}$，低电平为 GND；内阻为 $R_{on}$ |
| 石英晶体多谐振荡器 | 晶体为选频器件，输出正弦波，需施密特触发器整形为方波 |
| 555 定时器内部结构 | 两个比较器（参考电压 1/3 VCC、2/3 VCC）+ RS 触发器 + OC 输出管 |
| 555 功能表 | 三个正常态（置一、置零、保持）和一个约束态 |

### 核心公式/结论

- 比较器参考电压：$V_{REF1} = \frac{1}{3}V_{CC}$，$V_{REF2} = \frac{2}{3}V_{CC}$
- TRIG < $\frac{1}{3}V_{CC}$ 且 THRES < $\frac{2}{3}V_{CC}$ → OUT = 1
- TRIG > $\frac{1}{3}V_{CC}$ 且 THRES > $\frac{2}{3}V_{CC}$ → OUT = 0
- TRIG > $\frac{1}{3}V_{CC}$ 且 THRES < $\frac{2}{3}V_{CC}$ → OUT 保持
