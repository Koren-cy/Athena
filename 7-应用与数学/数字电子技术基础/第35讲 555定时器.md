# 555定时器的工作原理和应用 第二讲

> [!abstract] 本讲定位
> 本讲在上课分析 555 定时器内部结构的基础上，深入讲解如何用 555 定时器构成施密特触发器、多谐振荡器和单稳态触发器三种基本脉冲电路，并讨论阈值调整、占空比改进、触发脉冲宽度要求及可重复触发等实际设计问题。

## 555 定时器内部结构回顾

555 定时器是一个典型的数模混合器件，前端由两个电压比较器构成，能够处理模拟信号；后端是一个由与非门构成的基本 RS 触发器，具有置一、置零和保持三种状态。

**比较阈值**：
- 上比较器 C1 的同相端接参考电压 $2V_{CC}/3$，反相端为外接引脚 TH（$V_{I1}$）
- 下比较器 C2 的反相端接参考电压 $V_{CC}/3$，同相端为外接引脚 TR（$V_{I2}$）

**关键关系**：
- $V_{I1} > 2V_{CC}/3$ 时，C1 输出 0，触发器置零（$V_O = 0$）
- $V_{I2} < V_{CC}/3$ 时，C2 输出 0，触发器置一（$V_O = 1$）
- $V_{I1} < 2V_{CC}/3$ 且 $V_{I2} > V_{CC}/3$ 时，触发器保持原状态

| $V_{I1}$（TH） | $V_{I2}$（TR） | 触发器行为 | $V_O$ |
|---|---|---|---|
| $> 2V_{CC}/3$ | 任意 | 置零 | 0 |
| $< 2V_{CC}/3$ | $< V_{CC}/3$ | 置一 | 1 |
| $< 2V_{CC}/3$ | $> V_{CC}/3$ | 保持 | 不变 |

**输出级**：采用 OC 门（集电极开路）结构，使用时需外接上拉电阻 $R$ 和上拉电源 $V_{CC2}$。上拉电源应满足下一级接口的电压要求；上拉电阻的取值有上下限限制：上限需保证输出高电平足够高，下限需在低电平时起到限流作用。

## 用 555 定时器构成施密特触发器

将 $V_{I1}$ 和 $V_{I2}$ 两个输入端短接，555 定时器便具备了施密特触发特性。

### 工作原理

由于触发器置零和置一的阈值电压不同（分别为 $2V_{CC}/3$ 和 $V_{CC}/3$），输入电压上升和下降时引起输出状态变化的转折点不同，从而形成回差电压（滞环）：

- **VT+（正向阈值）** = $2V_{CC}/3$
- **VT-（负向阈值）** = $V_{CC}/3$
- **回差电压** $\Delta V_T = V_{T+} - V_{T-} = V_{CC}/3$

该电路为**反相器**结构：输入为高电平时输出为低电平，输入为低电平时输出为高电平。

### 阈值电压的调节

555 定时器有一个外接引脚 $V_{CO}$（控制电压端），通过该引脚可以改变比较器的参考电压：

- **不接** $V_{CO}$ 时：VT+ = $2V_{CC}/3$，VT- = $V_{CC}/3$
- **外接参考电压** $V_{REF}$ 时：VT+ = $V_{REF}$，VT- = $V_{REF}/2$

> [!note] 灵活调节施密特特性
> 与 TTL 集成施密特电路（阈值固定不可调）不同，555 定时器只需在外接 $V_{CO}$ 引脚进行相应处理，即可获得不同特性的施密特触发器。这是 555 定时器的一大优势。

## 用 555 定时器构成多谐振荡器

### 电路结构

在施密特触发器的基础上，将输出经 RC 反馈回路接回输入端，即可构成多谐振荡器：

- 施密特触发器的外接电容 $C$ 一端接地，另一端接 $V_{I1}$ 和 $V_{I2}$ 的短接点
- OC 门输出需外接上拉电阻 $R_1$
- 充电电阻 $R_2$ 连接在上拉电阻与电容之间
- $V_{CO}$ 引脚经 $0.01\mu F$ 小电容接地（滤波稳定用，不参与原理性工作）

> [!note]
> 多谐振荡器利用施密特触发器的滞环特性，使电容上的电压在两个阈值 $V_{T+}$ 和 $V_{T-}$ 之间来回充放电，从而产生周期性振荡。

### 工作过程

- **充电**：通过 $V_{CC} \to R_1 \to R_2 \to C$ 路径，电容电压从 $V_{CC}/3$ 上升至 $2V_{CC}/3$，充电时间常数 $\tau_{\text{charge}} = (R_1 + R_2)C$
- **放电**：通过 $C \to R_2 \to TD$ 管（内部放电管导通）接地，电容电压从 $2V_{CC}/3$ 下降至 $V_{CC}/3$，放电时间常数 $\tau_{\text{discharge}} = R_2 C$

### 周期与占空比

充电时间：
$$T_1 = (R_1 + R_2)C \ln 2$$

放电时间：
$$T_2 = R_2 C \ln 2$$

振荡周期：
$$T = T_1 + T_2 = (R_1 + 2R_2)C \ln 2$$

占空比：
$$D = \frac{T_1}{T} = \frac{R_1 + R_2}{R_1 + 2R_2} > 50\%$$

由于 $R_1$ 的存在，充电时间必然大于放电时间，因此占空比固定大于 50%。

### 占空比的改进方法

若需产生占空比可调（或小于 50%）的方波，可在 $R_2$ 两端并联二极管，利用二极管的单向导电性使充放电各走独立路径：

- **充电回路**：$V_{CC} \to R_1 \to \text{二极管} \to C$（旁路 $R_2$）
- **放电回路**：$C \to R_2 \to TD$ 管接地

## 用 555 定时器构成单稳态触发器

### 电路结构

与多谐振荡器不同，单稳态触发器将 $V_{I2}$（TR）端单独引出作为触发输入端，$V_{I1}$（TH）端仍接在 RC 定时回路上。

> [!note] OC 门输出的作用
> 555 内部使用 OC 门输出对电容进行充放电，而不直接使用逻辑输出端 $V_O$，这样做的好处是：在完成充放电原理实现的同时，不影响 $V_O$ 对后级电路的带负载能力。

### 稳态分析

**稳态条件**：无触发信号时，$V_I$（TR 端）为高电平（仅需 $> V_{CC}/3$）。

**情况一**：上电后 $Q = 0$
- TD 管导通，电容两端电压近似为零
- 两个比较器输出均为 1，触发器保持 $Q = 0$
- 输出 $V_O = 0$，电路稳定

**情况二**：上电后 $Q = 1$
- TD 管截止，电容开始充电
- 当电容电压充至 $2V_{CC}/3$ 时，C1 输出 0，触发器被置零
- $Q = 0$，TD 管导通，电容放电
- 电路自动回到稳态

因此，稳态时：$V_I > V_{CC}/3$，输出 $V_O = 0$，TD 管导通，电容上基本无电荷。

### 触发与暂稳态

**触发条件**：输入 $V_I$ 出现**下降沿**，电压降至 $V_{CC}/3$ 以下。

**暂稳态过程**：
1. $V_I$ 降至 $V_{CC}/3$ 以下 $\to$ C2 输出 0 $\to$ 触发器置一 $\to$ $V_O = 1$
2. $Q = 1$ $\to$ TD 管截止 $\to$ 电容开始通过 $R$ 从 $V_{CC}$ 充电
3. 电容电压从 0 上升，当升至 $2V_{CC}/3$ 时，C1 输出 0 $\to$ 触发器置零
4. $Q = 0$ $\to$ TD 管导通 $\to$ 电容放电 $\to$ 回到稳态

### 暂稳态持续时间

$$T_W = RC \ln 3 \approx 1.1 RC$$

推导基于充电方程：$v_C(t) = V_{CC}(1 - e^{-t/RC})$，令 $v_C(T_W) = 2V_{CC}/3$，解得 $T_W = RC \ln 3$。

> [!warning] 触发脉冲宽度要求
> 触发脉冲应为窄脉冲，其宽度必须**小于** $T_W$，即触发脉冲应在暂稳态结束之前回到高电平（$> V_{CC}/3$），否则当 C1 试图将触发器置零时，C2 仍处于置一状态，形成矛盾，无法正常返回稳态。

### 触发脉冲过宽的处理

若触发脉冲过宽，无法满足窄脉冲要求，可在输入端加入**微分电路**，将宽脉冲变为窄脉冲。

与 467 页积分型单稳态电路中的微分取边沿结构类似，但需注意：
- 本电路需要提取**下降沿**触发
- 微分电阻应上拉到 $V_{CC}$，稳态时输出高电平
- 耦合电容将下降沿向下跳变传递到 TR 端
- 要求输入跳变幅度大于 $2V_{CC}/3$，才能确保跳变后的电压低于 $V_{CC}/3$

### 阈值调节的通用性

与施密特触发器和多谐振荡器相同，通过 $V_{CO}$ 引脚外接参考电压，可以改变充放电的阈值，从而调整暂稳态时间 $T_W$。教材中给出的 $\ln 3$（$\ln 2$）等结论仅在固定电路图、固定阈值条件下成立，实际应用时应慎用固定结论。

## 可重复触发问题

### 重复触发的条件

所谓**可重复触发**，是指在暂稳态期间再次收到新的触发沿时，电路能够重新开始暂稳态过程（即定时电容从头开始充电）。

需要满足两个条件：
1. 暂稳态期间能响应外界的触发信号
2. 将用于定时的过渡过程（电容充电）清零，重新开始

### 基本电路能否重复触发

- **条件一满足**：进入暂稳态后 TD 管截止，再次触发时 TD 管仍然是截止，已经处于"响应"状态
- **条件二不满足**：电容上的电压存在累积效应，再次触发时不会自动清空

### 改进方法

在电容两端外接一个分立三极管（或开关管），使其受控于触发信号：

- 触发信号一方面进入 555 内部，使 TD 管截止、电容开始充电
- 触发信号同时控制外接三极管导通，为电容提供瞬间泄放通路
- 每次触发前先将电容上的电荷瞬间放掉，确保每次充电从零开始

这样，即使在暂稳态期间再次触发，电容上的电压也会立即被泄放至零，然后重新开始充电，从而实现可重复触发。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| 555 构成施密特触发器 | $V_{I1}$ 与 $V_{I2}$ 短接，VT+ = $2V_{CC}/3$，VT- = $V_{CC}/3$，可通过 $V_{CO}$ 调节 |
| 555 构成多谐振荡器 | 施密特 + RC 反馈，$T = (R_1 + 2R_2)C\ln 2$，占空比 > 50%，可加二极管改进 |
| 555 构成单稳态触发器 | 下降沿触发，$T_W = RC\ln 3 \approx 1.1RC$，触发脉冲应窄于 $T_W$ |
| 可重复触发 | 需外接泄放三极管，每次触发前将电容放电清零 |

### 核心公式

- 多谐振荡器周期：$T = (R_1 + 2R_2)C\ln 2$
- 单稳态暂稳态时间：$T_W = RC\ln 3 \approx 1.1RC$
- 施密特回差电压：$\Delta V_T = V_{T+} - V_{T-}$
