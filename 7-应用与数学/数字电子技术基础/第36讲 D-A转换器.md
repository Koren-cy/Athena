# D-A转换器的工作原理，转换精度和速度

> [!abstract] 本讲定位
> 任何数字系统在与现实世界交互时，都需要AD和DA作为模拟与数字之间的接口。本讲聚焦于D-A转换器（DAC），讲解其基本原理、权电阻网络和R-2R梯形网络两种典型电路结构，以及如何将单极性DAC改造为双极性输出。

## 一、DA转换的基本概念

### 数字系统与模拟世界的接口

在任何一个控制系统中，传感器和执行机构分别从现实世界采集和向现实世界输出物理量。数字处理器与这两者之间需要两个关键接口：从模拟到数字（ADC）和从数字到模拟（DAC）。ADC和DAC的精度与速度共同决定了整个系统的性能上限。

DA转换的核心思想是：数字量中的每一位二进制码具有特定的权重，将其转换为对应的电压或电流模拟量，经求和后得到输出。

### 精度与速度

- **精度**：由数字量的位数 $n$ 决定。位数越高，最小量化步长 $\Delta = V_{REF}/2^n$ 越小，输出波形越平滑。
- **速度**：数字量每次变化后，DAC需要稳定输出新的模拟值，前端数字量的变化频率必须与之匹配。

DA转换的输出必然是台阶化的，不可能做到完全连续，最小台阶即对应 $\Delta$。

> [!info] 采样定理的应用
> 以声音数字化为例，人耳可听上限约为20kHz。CD采用44kHz采样率（略高于上限的两倍），即遵循奈奎斯特采样定理。更高的采样率对听感改善有限，但数据量大幅增加。位数和通道数同样影响最终的数据量和还原质量。

## 二、权电阻网络DAC

### 电路结构

该电路由三部分构成：

1. **求和运算放大器**：接成负反馈形式，利用虚短和虚断特性进行分析
2. **模拟开关**：受数字量 $d_i$ 控制，为单刀双掷开关。当 $d_i=1$ 时，将对应电阻接至 $V_{REF}$；当 $d_i=0$ 时接至地
3. **权电阻网络**：各支路电阻呈二进制权重关系，低位对应阻值大，高位对应阻值小

### 工作原理

对于4位DAC，各支路电流为：

$$
I_3 = \frac{V_{REF}}{R} d_3,\quad I_2 = \frac{V_{REF}}{2R} d_2,\quad I_1 = \frac{V_{REF}}{4R} d_1,\quad I_0 = \frac{V_{REF}}{8R} d_0
$$

求和点总电流为：

$$
I_{sum} = I_3 + I_2 + I_1 + I_0 = \frac{V_{REF}}{R}\left(\frac{d_3}{2^0}+\frac{d_2}{2^1}+\frac{d_1}{2^2}+\frac{d_0}{2^3}\right)
$$

输出电压为：

$$
V_O = -R_f \cdot I_{sum}
$$

令 $R_f = \dfrac{R}{2}$，则：

$$
V_O = -\frac{V_{REF}}{R} \cdot \frac{R}{2} \cdot \frac{1}{2^3}(d_3 \times 2^3 + d_2 \times 2^2 + d_1 \times 2^1 + d_0 \times 2^0) = -\frac{V_{REF}}{2^4} \cdot D
$$

推广至 $n$ 位：

$$
V_O = -\frac{V_{REF}}{2^n} \cdot D
$$

其中 $D$ 为数字量的十进制数值。

核心公式反映出DAC的输出等于一个常数（$\Delta$）乘以数字量：

$$
\Delta = \frac{V_{REF}}{2^n}
$$

$\Delta$ 即为最小量化步长，对应输出波形中的一个最小台阶。

### 优缺点

| 优点 | 缺点 |
|------|------|
| 结构简单，原理直观 | 电阻值分散性大（高位与低位阻值呈 $2^n$ 关系） |
| 直接实现权重到电流的转换 | 位数增加时阻值范围急剧扩大，制造精度难以保证 |

例如4位DAC需要R、2R、4R、8R四种阻值；若扩展到10位，最大电阻为最小电阻的512倍，极难在芯片上精确制造。

## 三、R-2R梯形网络DAC

### 电路结构

该电路仅使用 $R$ 和 $2R$ 两种电阻值。模拟开关被放置在运放输入端的两侧。

### 工作原理

由于运放的虚短特性，开关无论接向运放的哪一侧，电位均等效为0。将开关两侧短接后分析电阻网络：

- 从任一节点向右看进去的等效电阻均为 $2R$
- 从 $V_{REF}$ 端看，总电流 $I = V_{REF} / R$
- 电流在每个节点处二分，形成权重电流

电流分配关系如下：

```
VREF ── R ──●── R ──●── R ──●── R ── ... 
            │       │       │
           2R      2R      2R
            │       │       │
           I/2     I/4     I/8
```

各支路上的权重电流经模拟开关选择后，流向求和点或流向地。流向求和点的电流表达式与权电阻型完全一致：

$$
V_O = -\frac{V_{REF}}{2^n} \cdot D
$$

### 优缺点

| 优点 | 缺点 |
|------|------|
| 仅需两种电阻值（R和2R），制造精度易于保证 | 分析过程相对复杂 |
| 扩展位数时只需将梯形网络向后延伸，结构不变化 | |
| 被广泛用于实际DAC芯片（如CB7520，10位DAC） | |

> [!note] 输出电压极性
> 由于求和运放的反相特性，若希望 $V_O$ 为正，则 $V_{REF}$ 应取负值，反之亦然。

### n位DAC的输出范围

输出起始值为0，步进值为 $\Delta = V_{REF}/2^n$，最大值为：

$$
V_{O,max} = \frac{2^n - 1}{2^n} \cdot V_{REF}
$$

注意输出最大值达不到 $V_{REF}$。

## 四、双极性DA转换

### 问题的提出

前面讨论的DAC将数字量视为无符号正数。但在实际应用中，数字量常以补码形式表示有符号数（正负数）。以3位补码为例，可表示 $-4 \sim +3$ 共8个数（负数比正数多一个，因为零占用了正数的一个位置）。

补码的最高位不仅是符号位，也具有权重 $-(2^{n-1})$：

| 补码 | 十进制值 |
|------|---------|
| 011 | +3 |
| 010 | +2 |
| 001 | +1 |
| 000 | 0 |
| 111 | -1 |
| 110 | -2 |
| 101 | -3 |
| 100 | -4 |

### 实现方法

无需专门设计双极性DAC，可在单极性DAC的基础上通过外加电路改造，关键操作有两步：

1. **最高位取反**：将符号位取反后送入DAC
2. **加偏移**：在求和点外加一路参考电压和电阻，产生偏移电流

### 偏移量的确定

偏移电流应等于最高位为1时对应的电流值，且极性相反：

$$
\frac{V_B}{R_B} = I_{MSB}
$$

通常取 $R_B = R$，然后确定 $V_B$。$V_B$ 的极性与 $V_{REF}$ 相反。

### 输入输出对应关系

以3位DAC为例，设 $\Delta = 1V$：

| 补码输入 | MSB取反后 | 无符号DA输出 | 偏移后输出 |
|---------|----------|-------------|-----------|
| 000 (0) | 100 | 4V | 0V |
| 001 (+1) | 101 | 5V | +1V |
| 010 (+2) | 110 | 6V | +2V |
| 011 (+3) | 111 | 7V | +3V |
| 100 (-4) | 000 | 0V | -4V |
| 101 (-3) | 001 | 1V | -3V |
| 110 (-2) | 010 | 2V | -2V |
| 111 (-1) | 011 | 3V | -1V |

> [!tip] 记忆要点
> 单极性DAC改造为双极性的两个关键操作：**最高位取反** 和 **加偏移**。偏移量为最高位权重对应的电流值，极性相反。

## 五、应用：波形发生器设计

利用DAC可以构建任意波形发生器，其基本结构为：

```mermaid
flowchart LR
    CLK[时钟] --> COUNTER[循环计数器]
    COUNTER --> ADDR[地址]
    ADDR --> MEM[RAM或ROM]
    MEM --> DAC[DA转换器]
    DAC --> OUT[模拟输出]
```

各模块的作用：
- **存储器**：存储波形的一个完整周期的数字采样值。可将RAM分为多个区域，分别存放不同波形数据
- **计数器**：循环输出地址，反复扫描存储区中的波形数据
- **DAC**：将读取的数字值转换为模拟电压

不同波形在存储器中的存储方式：
- **三角波**：从0递增到最大值，再递减到0
- **矩形波**：在最大值和最小值之间跳变
- **正弦波**：存储一个周期内的正弦函数采样值

**频率控制**：改变时钟频率或对时钟分频，即可改变输出波形的频率。

**任意波形**：使用RAM（而非ROM）存储波形数据，上电后由用户写入自定义数据，再循环输出。

## 本讲小结

| 知识点 | 要点 |
|--------|------|
| DAC基本原理 | 数字量按权重转换为模拟量，输出 $V_O = -\dfrac{V_{REF}}{2^n} \cdot D$ |
| 权电阻型DAC | 结构简单，但电阻值过于分散，高位时精度难保证 |
| R-2R梯形DAC | 仅需R和2R两种电阻，制造精度易保证，广泛实用 |
| 分辨率 | $\Delta = V_{REF}/2^n$，位数越多精度越高 |
| 双极性DAC | 单极性DAC + 最高位取反 + 偏移 |
| 波形发生器 | DAC + RAM/ROM + 计数器即可实现 |

### 核心公式

- $V_O = -\dfrac{V_{REF}}{2^n} \cdot D$（DAC输出与数字量的关系）
- $\Delta = \dfrac{V_{REF}}{2^n}$（最小量化步长）
- $V_{O,max} = \dfrac{2^n - 1}{2^n} \cdot V_{REF}$（最大输出电压）
