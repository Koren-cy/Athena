## 信道的定义与分类

### 什么是信道

信道是以传输媒质为基础的信号通道。

### 狭义信道与广义信道

| | 定义 | 例子 |
|------|------|------|
| **狭义信道** | 特指信号的传输媒质 | 有线：同轴电缆、光纤、双绞线；无线：微波视距传输、卫星中继、移动通信 |
| **广义信道** | 为研究问题方便而引入，不局限于传输媒质 | 调制信道、编码信道 |

广义信道的性能根本上仍取决于狭义信道（传输媒质的性能决定了信道的最终特性）。

在通信系统框图中：
- **调制信道**：从调制器输出 → 解调器输入（研究调制/解调性能）
- **编码信道**：从编码器输出 → 译码器输入（研究编码/译码性能）

### 恒参信道与随参信道

| | 传输特性 | 例子 |
|------|------|------|
| **恒参信道** | 随时间缓慢变化或不变化 | 有线信道、卫星中继、超短波、微波视距传输 |
| **随参信道** | 随时间随机且快速变化 | 短波电离层反射、散射信道、移动通信信道 |

随参信道需要用统计方法分析。

## 信道的数学模型

### 调制信道

调制信道研究调制制度的性能。将信道和噪声源封装为一个黑盒。

**四个特点**：
1. 有一对或多对输入输出端（可单入单出，也可多入多出）
2. 满足线性叠加原理 → 可视为线性网络
3. 对信号有固定或时变的延迟（影响相位）和损耗（影响幅度）
4. 无信号输入时仍可能有输出 → 此时输出即为**噪声**

数学模型：
$$e_o(t) = f[e_i(t)] + n(t)$$

其中 $f[\cdot]$ 表示信道特性，$n(t)$ 为加性噪声。该模型 = **叠加噪声的线性时变/时不变滤波器**。

$f[\cdot]$ 的两种简化形式：
- 乘性干扰：$f[e_i(t)] = k(t) \cdot e_i(t)$
- 线性时不变系统：$f[e_i(t)] = e_i(t) * h(t)$

> [!important] 加性噪声与乘性干扰的辨析
> 噪声永远是**加性**的（$+ n(t)$），不可能乘在输入信号上。乘性干扰 $k(t)$ 是对信道特性 $f[\cdot]$ 的简化表示，与输入信号共存共失，不是噪声。

**恒参信道**对应线性时不变滤波器：用冲激响应 $c(t)$ 描述，频域传递函数为 $C(\omega)$。

$$s_o(t) = s_i(t) * c(t), \quad S_o(\omega) = S_i(\omega) \cdot C(\omega)$$

这里 $C(\omega)$ 与输入信号是相乘关系，故称**乘性干扰**。

**特殊情形**：当 $C(\omega)$ 为常数（或信号频带内为常数）时，信道退化为**加性高斯白噪声（AWGN）信道**——这是后续抗噪声性能分析中最常用的信道模型。

**随参信道**对应线性时变滤波器：冲激响应还与时间差 $\tau$ 有关，乘性干扰变为 $C(\omega, \tau)$。

### 编码信道

编码信道研究信道编码和译码。传输的是离散码元，因此是**离散信道**。

关注**转移概率**（条件概率）。以二进制编码信道为例：

| 符号 | 含义 | 类型 |
|------|------|------|
| $P(0 \mid 0)$ | 发 0 收 0 | 正确传输 |
| $P(1 \mid 1)$ | 发 1 收 1 | 正确传输 |
| $P(1 \mid 0)$ | 发 0 收 1 | 传输差错 |
| $P(0 \mid 1)$ | 发 1 收 0 | 传输差错 |

正确概率与错误概率关系：$P(0|0) + P(1|0) = 1$，$P(1|1) + P(0|1) = 1$。

由此可得系统误码率：
$$P_e = P(0) \cdot P(1 \mid 0) + P(1) \cdot P(0 \mid 1)$$

编码信道又分为：
- **无记忆信道**：前后码元发生的错误相互独立
- **有记忆信道**：前后码元错误存在依赖关系（常用马尔可夫链描述）

> [!tip] 何时用哪种模型
> 研究调制/解调的性能 → 调制信道（连续信道）；
> 研究编码/译码 → 编码信道（离散信道）。
> 本课程大部分时间用调制信道模型。

## 信道特性对信号传输的影响

### 理想恒参信道——无失真传输

理想恒参信道等效为线性时不变网络，满足无失真传输特性。

**定义**：输出信号仅是输入信号的延时和幅度缩放，波形形状完全不变。
$$y(t) = k \cdot x(t - t_d)$$

**频域条件**：
$$H(\omega) = k \cdot e^{-j\omega t_d}$$

将 $H(\omega)$ 分解为幅频特性 $\vert H(\omega)\vert$ 和相频特性 $\varphi(\omega)$：

| 条件 | 表达式 | 物理含义 |
|------|--------|------|
| 幅频特性 | $\vert H(\omega)\vert = k$（常数） | 对信号所有频率分量**等比例放大/衰减** → 无幅度失真 |
| 相频特性 | $\varphi(\omega) = -\omega t_d$（过原点直线） | 不同频率分量到达输出端**时延相同** → 无相位失真 |

**群时延**：$\tau(\omega) = -\frac{d\varphi(\omega)}{d\omega}$。无失真时 $\tau(\omega) = t_d$（常数）。

**时域冲击响应**：$h(t) = k \cdot \delta(t - t_d)$。

### 实际恒参信道——线性失真

实际恒参信道的传输特性不满足理想条件：
- **幅频特性不是常数** → 不同频率分量衰减不同 → **幅频失真**
- **相频特性不是线性** → 群时延不是常数 → **相频失真（群时延失真）**

> [!info] 线性失真 vs 非线性失真
> 以上幅频失真和相频失真均不产生新的频率分量，称为**线性失真**。非线性失真（如正弦波经二极管变为半波）会产生新的频率分量。

**线性失真的影响**：

| 失真类型 | 对模拟信号 | 对数字信号 |
|------|------|------|
| 幅频失真 | 波形失真 → 信噪比下降 | 波形失真 → 码间干扰 → 误码率增大 |
| 相频失真 | 对语音影响不大（人耳不易分辨），对视频影响大 | 码间干扰 → 误码率增大 |

**改善方法**：均衡技术——目的是让实际传输特性向无失真传输特性靠拢。

> [!example] 例：分析两个恒参信道的失真
> **(1)** 纯电阻网络：$H(\omega) = \frac{R_2}{R_1 + R_2}$（正实数，与 $\omega$ 无关）
>
> 幅频：常数 $\frac{R_2}{R_1+R_2}$；相频：恒为零；群时延：0。
> → 无任何失真。
>
> **(2)** RC 低通网络：$H(\omega) = \frac{\frac{1}{j\omega C}}{R + \frac{1}{j\omega C}} = \frac{1}{1 + j\omega RC}$
>
> 幅频：$\vert H(\omega)\vert = \frac{1}{\sqrt{1 + (\omega RC)^2}}$（随 $\omega$ 变化，不是常数）
>
> 相频：$\varphi(\omega) = -\arctan(\omega RC)$（不是过原点的直线）
>
> 群时延：$\tau(\omega) = \frac{RC}{1 + (\omega RC)^2}$（不是常数）
> → 既有**幅频失真**，又有**相频失真（群时延失真）**。

### 随参信道——多径传播

随参信道用线性时变滤波器描述。主要有两个特性：**时变的衰减和时延**、**多径传播**。

#### 多径传播的数学模型

发送单频正弦波 $A\cos\omega_c t$，经 $n$ 条路径独立传播，每条路径有时变衰落 $A_i(t)$ 和时变时延 $\tau_i(t)$：

$$r(t) = \sum_{i=1}^n A_i(t) \cos\omega_c[t - \tau_i(t)]$$

令 $\phi_i(t) = -\omega_c\tau_i(t)$，将上式用两角和的余弦公式展开为同相/正交分量形式：

$$r(t) = \underbrace{\left[\sum A_i(t)\cos\phi_i(t)\right]}_{x(t)}\cos\omega_c t - \underbrace{\left[\sum A_i(t)\sin\phi_i(t)\right]}_{y(t)}\sin\omega_c t$$

写成包络-相位形式：
$$r(t) = v(t)\cos[\omega_c t + \varphi(t)]$$

其中 $v(t) = \sqrt{x^2(t) + y^2(t)}$，$\varphi(t) = \arctan\frac{y(t)}{x(t)}$。

> [!info] 结论
> 发送的是单频正弦波，接收的却是一个**包络和相位随机缓慢变化的窄带信号**——包络服从**瑞利分布**，相位服从**均匀分布**。这种衰落称为**瑞利衰落**。

**频率弥散**：在频域中，单频正弦波的单一谱线经多径传播后变为窄带频谱——从单根谱线弥散为一个频率范围。

#### 两径传播与频率选择性衰落

以最简单的两径模型分析——两条路径衰减相同（均为 $k$），相对时延差为 $\tau$：

$$r(t) = k \cdot s_i(t) + k \cdot s_i(t - \tau)$$

两边做傅里叶变换：
$$S_o(\omega) = k \cdot S_i(\omega) + k \cdot S_i(\omega) \cdot e^{-j\omega\tau}$$

传输函数：
$$H(\omega) = \frac{S_o(\omega)}{S_i(\omega)} = k(1 + e^{-j\omega\tau})$$

提出 $e^{-j\omega\tau/2}$ 并利用欧拉公式：
$$H(\omega) = k \cdot e^{-j\omega\tau/2} \cdot (e^{j\omega\tau/2} + e^{-j\omega\tau/2}) = 2k\cos\frac{\omega\tau}{2} \cdot e^{-j\omega\tau/2}$$

**幅频特性**：
$$\vert H(\omega)\vert = 2k\left\vert\cos\frac{\omega\tau}{2}\right\vert$$

> [!warning] 频率选择性衰落
> $\vert H(\omega)\vert$ 在 $\omega = (2n+1)\frac{\pi}{\tau}$ 处周期性地过零（**传输零点**——信号完全无法通过），在 $\omega = 2n\frac{\pi}{\tau}$ 处取最大值（**传输极点**）。不同频率分量受到的衰减不同——**频率选择性衰落**。

**过零点**（以频率 $f$ 表示）：$f = \frac{2k+1}{2\tau}$ Hz（$k = 0, 1, 2, \dots$）。

**相关带宽**：相邻两个传输零点之间的频率间隔。
$$\Delta f = \frac{1}{\tau}$$

为避免严重频率选择性衰落，信号带宽应**小于**相关带宽。工程上取相关带宽的 $1/5 \sim 1/3$：
$$B_s = \left(\frac{1}{5} \sim \frac{1}{3}\right) \Delta f$$

对应码元宽度：$T_B = (3 \sim 5)\tau$。

#### 多径推广

多条路径时，取最大多径时延差 $\tau_{\max}$：
$$\Delta f = \frac{1}{\tau_{\max}}$$

若信号带宽小于 $\Delta f$，则对任意路径时延差都满足条件。

#### 抗多径技术

- **OFDM**（正交频分复用）：将高速串行数据划分为 $n$ 路并行低速数据，分别调制到正交子载波上，使码长变大、带宽减小，最终小于相关带宽。
- **分集接收**：按一定方式分离成不相关的多路信号再合并（空间/频率/角度/极化分集）。
- **扩频、MIMO、均衡**等。

> [!example] 例：随参信道多径参数计算
> 某随参信道最大多径时延差 $\tau_{\max} = 20\mu\text{s}$，估算工程经验下的信号带宽和码元宽度。
>
> **解**：
> 相关带宽：$\Delta f = \frac{1}{\tau_{\max}} = \frac{1}{20 \times 10^{-6}} = 50\text{ kHz}$
>
> 信号带宽（$1/5 \sim 1/3$ 相关带宽）：$B_s = 10 \sim 16.7\text{ kHz}$
>
> 码元宽度（$3 \sim 5$ 倍 $\tau_{\max}$）：$T_B = 60 \sim 100\text{ }\mu\text{s}$

## 信道中的噪声与带宽

### 噪声分类

噪声是通信系统中各处噪声的集中表示，叠加在信号之上造成干扰——使模拟信号波形失真、数字信号码元错误。

按**来源**分类：人为噪声、自然噪声、内部噪声（典型：热噪声）。

按**性质**分类：脉冲噪声、窄带/单频噪声、**起伏噪声**（本课程主要研究对象）。

### 热噪声

热噪声来自一切电阻性元器件中电子的热运动，三大特点：

1. **功率谱**均匀分布在 $0 \sim 10^{12}$ Hz 范围内（范围极大 → 可视为白噪声）
2. **电压瞬时值**服从零均值高斯分布
3. 综合 → 可建模为**零均值高斯白噪声**

在通信系统分析中，典型的信道加性噪声以热噪声为原型，建模为：
- 概率密度：$f(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{x^2}{2\sigma^2}}$（零均值高斯）
- 功率谱密度：$P_n(f) = \frac{n_0}{2}$（双边），单位 W/Hz

### 等效噪声带宽

实际噪声功率谱一般不是理想矩形。为研究方便，用一个矩形带通滤波器等效替代。

**定义**：用一个宽度为 $B_n$ 的理想矩形滤波器来代替实际滤波器——通过矩形滤波器的噪声功率 = 通过实际滤波器的噪声功率。

| | 公式 |
|------|------|
| 单边 | $B_n = \dfrac{\int_0^\infty P_n(f)\,df}{P_n(f_0)}$ |
| 双边 | $B_n = \dfrac{\int_{-\infty}^\infty P_n(f)\,df}{2P_n(f_0)}$ |

其中 $P_n(f_0)$ 为功率谱在中心频率处的值。后续分析中带通滤波器的带宽一般均视为等效噪声带宽，在等效带宽内窄带噪声的功率谱可视为恒定值。

### 各类信号带宽

| 带宽类型 | 定义 |
|------|------|
| **绝对带宽** | 信号频谱存在的全部频率范围（低通：$0 \sim f_1$；带通：$f_1 \sim f_2$） |
| **3dB 带宽（半功率带宽）** | 功率降至峰值一半处的频率范围（幅度降至峰值的 $1/\sqrt{2} \approx 0.707$） |
| **等效带宽** | 用等面积的矩形替代实际频谱的宽度 |
| **谱零点带宽** | 频谱第一个过零点以内的频率范围（矩形脉冲即 $1/\tau$） |
| **6dB 带宽** | 幅度降至峰值一半处的频率范围（半幅度点） |

## 信道容量

信道容量指信道能够传输的**最大平均信息速率**（bps），是一个理论极限值。

### 互信息与平均互信息（离散信道基础）

**互信息**：收到 $y_j$ 后获得关于 $x_i$ 的信息量。

$$I(x_i; y_j) = \log_2\frac{P(x_i \mid y_j)}{P(x_i)} = I(x_i) - I(x_i \mid y_j)$$

物理意义：发送前对 $x_i$ 的不确定度 减去 收到 $y_j$ 后仍存在的不确定度 = 不确定度的**减小量**。

**平均互信息**：互信息的统计平均。

$$I(X;Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X)$$

- $H(X)$：发送前对 $X$ 的平均不确定度（信源熵）
- $H(X \mid Y)$：收到 $Y$ 后对 $X$ 仍存在的平均不确定度（**条件熵**，又称**噪声熵**——因为残留的不确定度完全由噪声引起）
- $I(X;Y)$：通信过程中 $X$ 平均不确定度的减小量

### 离散信道容量

信道容量是平均互信息在最佳输入分布下的最大值：

$$C = \max_{P(x)} I(X;Y) \quad \text{（bit/symbol）}$$

$$C_t = r \cdot C \quad \text{（bps，} r \text{为符号速率即波特率）}$$

#### 二进制对称信道（BSC）的信道容量

二进制对称信道：发端 $\{0,1\}$，收端 $\{0,1\}$，错误转移概率为 $\varepsilon$：

| | 收 0 | 收 1 |
|------|:--:|:--:|
| 发 0 | $1-\varepsilon$ | $\varepsilon$ |
| 发 1 | $\varepsilon$ | $1-\varepsilon$ |

**关键推导**（假设输入等概 $P(0)=P(1)=1/2$）：

1. 由全概率公式，输出也等概：$P(Y=0) = P(Y=1) = 1/2$
2. 输入等概时，前向转移概率 = 后验概率
3. 条件熵 $H(X \mid Y)$（噪声熵）与输入分布**无关**，只与 $\varepsilon$ 有关：

$$H(X \mid Y) = -[(1-\varepsilon)\log_2(1-\varepsilon) + \varepsilon\log_2\varepsilon]$$

4. 要使 $I(X;Y) = H(Y) - H(X \mid Y)$ 最大，需 $H(Y)$ 最大 → 输出等概时 $H(Y)$ 最大 → 输入等概时输出才等概 → **输入等概即为最佳分布**。

5. 此时 $H(Y) = \log_2 2 = 1$ bit/symbol：

$$C = 1 - H(X \mid Y) = 1 + (1-\varepsilon)\log_2(1-\varepsilon) + \varepsilon\log_2\varepsilon \quad \text{（bit/symbol）}$$

> [!tip] 结论
> 对称信道的信道容量在**输入等概**时达到，且噪声熵 $H(X|Y)$ 只取决于错误概率 $\varepsilon$。

> [!example] 例：BSC 信道容量计算
> 信源有 $\{0, 1\}$ 两种符号，等概出现。信道为二进制对称信道，错误转移概率 $\varepsilon = 1/128$，符号速率 $r = 1000$ 波特。求信道容量 $C$ 和 $C_t$。
>
> **解**：
> 输入等概即为最佳分布。$H(Y)_{\max} = \log_2 2 = 1$ bit/symbol。
>
> $$H(X \mid Y) = -\frac{127}{128}\log_2\frac{127}{128} - \frac{1}{128}\log_2\frac{1}{128} \approx 0.065 \text{ bit/symbol}$$
>
> $$C = 1 - 0.065 = 0.935 \text{ bit/symbol}$$
>
> $$C_t = r \cdot C = 1000 \times 0.935 = 935 \text{ bps}$$

### 连续信道容量，奈奎斯特定理（无扰信道）

理想无扰信道，带宽 $B$（Hz），信号电平数 $M$：

$$C_t = 2B \cdot \log_2 M \quad \text{（bps）}$$

无干扰时，增大 $M$ 或 $B$ 可无限增大信道容量——但实际上干扰总是存在。

### 连续信道容量，香农公式（有扰信道）

加性高斯白噪声（AWGN）信道，带宽 $B$，信号平均功率 $S$，噪声功率 $N = n_0 B$：

$$C_t = B \cdot \log_2\left(1 + \frac{S}{N}\right) = B \cdot \log_2\left(1 + \frac{S}{n_0 B}\right) \quad \text{（bps）}$$

记忆口诀：$C = B \cdot \log_2(1 + \text{信噪比})$。

**信道容量的三要素**：带宽 $B$、信号功率 $S$、噪声单边功率谱密度 $n_0$。

### dB 单位换算

| 量级 | 公式 | 适用 |
|------|------|------|
| 功率比 | $10 \cdot \log_{10}(P_2/P_1)$ | 信噪比、功率比 |
| 幅度比 | $20 \cdot \log_{10}(A_2/A_1)$ | 电压比、电流比 |

信噪比是功率比：$\text{SNR(dB)} = 10 \cdot \log_{10}(S/N)$。

常见换算：
- $10 \cdot \log_{10}(S/N) = 30\text{dB}$ → $S/N = 10^3 = 1000$
- $10 \cdot \log_{10}(S/N) = 20\text{dB}$ → $S/N = 10^2 = 100$
- $10 \cdot \log_{10}(S/N) = 3\text{dB}$ → $S/N \approx 2$（半功率点）

### 香农极限

$$\lim_{B \to \infty} C_t = \frac{S}{n_0} \log_2 e \approx 1.44 \frac{S}{n_0}$$

即使带宽无限增大，信道容量也存在有限上限——**香农极限**。

**证明**（利用重要极限 $\lim\limits_{x\to\infty}(1 + \frac{1}{x})^x = e$）：

凑 $x = \frac{n_0 B}{S}$，则 $B = \frac{S}{n_0}x$：
$$C_t = \frac{S}{n_0} \cdot x \cdot \log_2\left(1 + \frac{1}{x}\right) = \frac{S}{n_0}\log_2\left(1 + \frac{1}{x}\right)^x$$

当 $B \to \infty$ 时 $x \to \infty$，$(1 + \frac{1}{x})^x \to e$，故 $C_t \to \frac{S}{n_0}\log_2 e$。

### 信道编码定理

- 若实际信息速率 $R_b \leq C_t$，则总能找到一种信道编码方式实现无差错传输。
- 若 $R_b > C_t$，无论如何都不可能实现无差错传输。

信道容量是理论上无差错传输的信息速率上界。香农公式是**存在性定理**——只证明极限存在，没有给出具体实现方法。

### 增加信道容量的途径与三要素互换

| 途径 | 限制 | 应用场景 |
|------|------|------|
| 增大带宽 $B$ | $B \to \infty$ 时 $C_t \to 1.44 S/n_0$（有上限） | 扩频通信——以带宽换信噪比 |
| 增大信号功率 $S$ | 实际系统中功率不可能无穷大 | — |
| 减小噪声谱密度 $n_0$ | 噪声不可能完全消除 | — |

**带宽、信噪比、传输时间三者可以互换**：
- 提高带宽 → 可降低信噪比要求（弱信号接收、深空通信、扩频）
- 提高信噪比 → 可降低带宽要求（有线载波电话、频带拥挤场合）
- 信噪比不变时：提高带宽 → 降低传输时间（带宽是脉宽的倒数，带宽增大则脉宽缩小）

> [!example] 例：黑白数字相片传输时间
> 400 万像素，每像素 16 亮度等级（等概）。信道带宽 3 kHz，信噪比 20 dB。求传输时间。
>
> **解**：
> 每个像素信息量：$I = \log_2 16 = 4$ bit/像素
>
> 总信息量：$4 \times 4 \times 10^6 = 1.6 \times 10^7$ bit
>
> 信噪比：$10 \cdot \log_{10}(S/N) = 20$ → $S/N = 10^2 = 100$
>
> 信道容量：$C_t = 3000 \cdot \log_2(1 + 100) \approx 1.996 \times 10^4$ bps
>
> 传输时间：$t = \frac{1.6 \times 10^7}{1.996 \times 10^4} \approx 802$ 秒 $\approx 13.4$ 分钟

> [!example] 例：黑白电视图像传输带宽
> 每帧 30 万个像素，每个像素 8 个亮度电平（等概独立），每秒 25 帧。信噪比 30 dB，求所需传输带宽。
>
> **解**：
> 每个像素：$I = \log_2 8 = 3$ bit/像素
>
> 每帧：$3 \times 300{,}000 = 9 \times 10^5$ bit/帧
>
> 信息速率：$R_b = 9 \times 10^5 \times 25 = 2.25 \times 10^7$ bps
>
> $10 \cdot \log_{10}(S/N) = 30$ → $S/N = 1000$
>
> 由香农公式 $C_t = B \cdot \log_2(1 + S/N)$，令 $C_t = R_b$：
> $$B = \frac{2.25 \times 10^7}{\log_2(1 + 1000)} \approx 2.26 \text{ MHz}$$

> [!example] 例：联合奈奎斯特与香农公式求信号电平数
> 信道带宽 $B = 1$ MHz，信噪比 $S/N = 63$。
>
> **解**：
> 香农公式求信道容量：
> $$C_t = 10^6 \times \log_2(1 + 63) = 10^6 \times 6 = 6 \text{ Mbps}$$
>
> 若以 $R_b = C_t = 6$ Mbps 传输，由奈奎斯特定理 $C_t = 2B\log_2 M$：
> $$6 \times 10^6 = 2 \times 10^6 \times \log_2 M \quad \Rightarrow \quad \log_2 M = 3 \quad \Rightarrow \quad M = 8$$
>
> 若以 $R_b = 4$ Mbps（小于信道容量）传输：
> $$4 \times 10^6 = 2 \times 10^6 \times \log_2 M \quad \Rightarrow \quad \log_2 M = 2 \quad \Rightarrow \quad M = 4$$

> [!example] 例：电话信道容量
> 带宽 3.4 kHz。求：
> **(1)** 信噪比 30 dB 时的信道容量。
>
> $S/N = 1000$，$C_t = 3400 \cdot \log_2(1 + 1000) \approx 3.39 \times 10^4$ bps
>
> **(2)** 若要求以 4800 bps 传输，所需信噪比为多少 dB。
>
> $4800 = 3400 \cdot \log_2(1 + S/N)$ → $\log_2(1+S/N) \approx 1.412$ → $S/N \approx 1.66$
>
> $10 \cdot \log_{10}(1.66) \approx 2.2$ dB

## 本章小结

### 基本概念

| 知识点          | 要点                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------- |
| 狭义信道 vs 广义信道 | 狭义=传输媒质；<br>广义=为研究方便引入（调制信道、编码信道）                                                        |
| 恒参信道 vs 随参信道 | 恒参=特性缓慢变化/不变（LTI）；<br>随参=随机快速变化（LTV）                                                     |
| 调制信道         | 输出 = $f[e_i(t)] + n(t)$；<br>$f[\cdot]$ 可为乘性干扰 $k(t)$ 或线性卷积；<br>恒参→LTI、随参→LTV             |
| 编码信道         | 离散信道；关注转移概率；<br>可用马尔可夫链描述有记忆信道                                                           |
| 无失真传输        | $\vert H(\omega)\vert = k$（常数）+ $\varphi(\omega) = -\omega t_d$（过原点直线）                   |
| 线性失真         | 不产生新频率分量的失真（幅频失真+相频失真）；<br>数字信号→码间干扰                                                     |
| 多径传播         | 发送单频正弦波 → 接收窄带信号（包络瑞利分布）；<br>频率弥散 + 频率选择性衰落                                              |
| 相关带宽         | $\Delta f = 1/\tau_{\max}$；信号带宽取 $\Delta f$ 的 $1/5 \sim 1/3$；$T_B = (3\sim5)\tau_{\max}$ |
| 热噪声          | 零均值高斯白噪声；功率谱 $n_0/2$（双边）                                                                 |
| 等效噪声带宽       | 用等面积矩形滤波器替代实际功率谱；$B_n = \frac{\int P_n(f)df}{P_n(f_0)}$                                  |
| 互信息          | $I(x_i;y_j) = I(x_i) - I(x_i\mid y_j)$：收到 $y_j$ 后对 $x_i$ 不确定度的减小量                        |
| 平均互信息        | $I(X;Y) = H(X) - H(X\mid Y)$：条件熵 $H(X\mid Y)$ 又称噪声熵                                      |
| 离散信道容量       | $C = \max_{P(x)} I(X;Y)$ (bit/symbol)；BSC在输入等概时达到                                        |
| 奈奎斯特定理       | $C_t = 2B \cdot \log_2 M$（无扰信道）                                                          |
| 香农公式         | $C_t = B \cdot \log_2(1 + S/N)$（AWGN信道）                                                  |
| 香农极限         | $\lim_{B\to\infty} C_t = 1.44 S/n_0$                                                     |
| 信道编码定理       | $R_b \leq C_t$ 才能无差错传输                                                                   |
| OFDM         | 将高速串行数据分 $n$ 路并行的低速数据，使带宽减小至相关带宽内                                                        |

### 核心公式

| 公式 | 说明 |
|------|------|
| $e_o(t) = f[e_i(t)] + n(t)$ | 调制信道模型 |
| $H(\omega) = k \cdot e^{-j\omega t_d}$ | 无失真传输系统函数 |
| $\tau(\omega) = -\frac{d\varphi(\omega)}{d\omega}$ | 群时延 |
| $\vert H(\omega)\vert = 2k\vert\cos(\omega\tau/2)\vert$ | 两径信道的幅频特性 |
| $\Delta f = 1/\tau_{\max}$ | 多径相关带宽 |
| $B_n = \frac{\int_{-\infty}^\infty P_n(f)\,df}{2P_n(f_0)}$ | 等效噪声带宽（双边） |
| $I(X;Y) = H(X) - H(X \mid Y)$ | 平均互信息 |
| $C = 1 + (1-\varepsilon)\log_2(1-\varepsilon) + \varepsilon\log_2\varepsilon$ | BSC 信道容量 (bit/symbol) |
| $C_t = 2B \cdot \log_2 M$ | 奈奎斯特定理 |
| $C_t = B \cdot \log_2(1 + S/N)$ | 香农公式 |
| $\lim_{B\to\infty} C_t = 1.44 S/n_0$ | 香农极限 |
| $10 \cdot \log_{10}(P_2/P_1)$ | 功率比的 dB 表示 |
| $20 \cdot \log_{10}(A_2/A_1)$ | 幅度比的 dB 表示 |

### 注意事项

| 注意 | 说明 |
|------|------|
| 香农公式中 $S/N$ 是线性值 | 题目给 dB 时先换算：$S/N = 10^{\text{dB}/10}$ |
| 噪声加性 | 噪声永远是加性的（$+n(t)$），乘性的是信道特性简化 |
| 恒参→LTI、随参→LTV | 模型的时变/时不变属性对应信道类型 |
| 线性失真 ≠ 非线性失真 | 线性失真不产生新频率分量（幅频+相频）；非线性失真产生新频率 |
| 频率选择性衰落 | 多径幅频响应呈 $\vert\cos(\omega\tau/2)\vert$ 形状，周期过零 |
| 工程带宽取值 | 信号带宽取相关带宽的 $1/5\sim1/3$，码元宽度取 $3\sim5$ 倍 $\tau_{\max}$ |
| 三要素互换 | 带宽、信噪比、传输时间可互换——扩频以带宽换信噪比，深空通信以时间换一切 |
