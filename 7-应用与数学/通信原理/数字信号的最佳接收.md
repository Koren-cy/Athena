## 8.1 匹配滤波器

### 两类最佳线性滤波器

| 对比项 | 维纳滤波器 | 匹配滤波器 |
|------|------------|------------|
| 设计准则 | 输出与发送信号波形**均方误差最小** | 输出信噪比在**某一特定时刻最大** |
| 追求目标 | 波形保真度 | 抽样时刻信噪比最大 |
| 适用范围 | **模拟信号**接收 | **数字信号**接收 |
| 原因 | 数字信号只看抽样判决，对波形失真不敏感 | 信号通过后波形失真严重，不适合模拟 |

> [!tip] 记忆
> 维纳 → 波形保真 → 模拟；匹配 → 匹配抽样时刻 → 数字。四个字概括滤波器作用：**传信滤噪**。

### 数字信号接收等效原理图

输入信号 $s(t)$ 与加性高斯白噪声 $n(t)$（双边功率谱密度 $\frac{n_0}{2}$）叠加 → 合成 $r(t)$ → 线性滤波器 $H(\omega)$ / $h(t)$ → 输出 $y(t)$ → $t = T_0$ 时刻抽样 → 判决器 → 输出。

研究目的：在高斯白噪声干扰下，使差错概率最小化，等价于使抽样时刻输出信噪比 $r_o$ 达到最大值 $r_{o\max}$。

### 匹配滤波器传输函数的推导

设输入信号 $s(t)$，加性噪声 $n(t)$，匹配滤波器传输函数 $H(\omega)$，冲激响应 $h(t)$。

输出信号 $s_o(t) = s(t) * h(t)$，频谱 $S_o(\omega) = S(\omega) H(\omega)$。

抽样时刻 $t = T_0$，信号平均功率：

$$|s_o(T_0)|^2 = \left| \frac{1}{2\pi} \int_{-\infty}^{+\infty} S(\omega) H(\omega) e^{j\omega T_0} d\omega \right|^2$$

噪声平均功率（利用随机过程通过线性系统的结论 $P_{no}(\omega) = \frac{n_0}{2} |H(\omega)|^2$）：

$$N_o = \frac{1}{2\pi} \int_{-\infty}^{+\infty} \frac{n_0}{2} |H(\omega)|^2 d\omega$$

因此输出信噪比：

$$r_o = \frac{|s_o(T_0)|^2}{N_o} = \frac{\left| \frac{1}{2\pi} \int_{-\infty}^{+\infty} S(\omega) H(\omega) e^{j\omega T_0} d\omega \right|^2}{\frac{n_0}{2} \cdot \frac{1}{2\pi} \int_{-\infty}^{+\infty} |H(\omega)|^2 d\omega}$$

> [!warning] 许瓦尔兹（Schwarz）不等式
> $$\left| \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(\omega) Y(\omega) d\omega \right|^2 \leq \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(\omega)|^2 d\omega \cdot \frac{1}{2\pi} \int_{-\infty}^{+\infty} |Y(\omega)|^2 d\omega$$
>
> 取等条件：$X(\omega) = k Y^*(\omega)$（$k$ 为常数，$*$ 表示共轭）

令 $X(\omega) = H(\omega)$，$Y(\omega) = S(\omega) e^{j\omega T_0}$，对分子应用许瓦尔兹不等式：

$$r_o \leq \frac{\frac{1}{2\pi} \int |H(\omega)|^2 d\omega \cdot \frac{1}{2\pi} \int |S(\omega) e^{j\omega T_0}|^2 d\omega}{\frac{n_0}{2} \cdot \frac{1}{2\pi} \int |H(\omega)|^2 d\omega}$$

分子分母同除以 $\frac{1}{2\pi} \int |H(\omega)|^2 d\omega$，且 $|e^{j\omega T_0}| = 1$：

$$r_{o\max} = \frac{\frac{1}{2\pi} \int_{-\infty}^{+\infty} |S(\omega)|^2 d\omega}{\frac{n_0}{2}} = \frac{E}{\frac{n_0}{2}} = \frac{2E}{n_0}$$

其中 $E$ 为输入码元信号能量（由帕斯瓦尔定理：$E = \frac{1}{2\pi}\int |S(\omega)|^2 d\omega = \int s^2(t) dt$）。

取等条件即匹配滤波器传输函数（常取 $k = 1$）：

$$H(\omega) = S^*(\omega) e^{-j\omega T_0}$$

### 匹配滤波器的物理意义

设 $S(\omega) = |S(\omega)| e^{j\varphi(\omega)}$，则：

- **幅频特性**：$|H(\omega)| = |S(\omega)|$——匹配滤波器的幅频响应与信号幅度谱**一致**
- **相频特性**：$\angle H(\omega) = -\varphi(\omega) - \omega T_0$——**抵消**输入信号的相频特性，只留下时延因子 $-\omega T_0$

**"匹配"的两层含义**：

1. **幅频匹配**：对信号的重要频率分量赋予较大权重，对次要分量赋予较小权重；对白噪声则尽可能抑制带外噪声，输出噪声功率谱近似低通
2. **相频匹配**：抵消信号相频特性后，所有频率分量具有相同的群时延 $T_0$，在抽样时刻**同相叠加**达到最大值；而噪声各频率分量相位随机，无法同相叠加

### 单位冲激响应

对 $H(\omega) = S^*(\omega) e^{-j\omega T_0}$ 做傅里叶反变换：

$$h(t) = s(T_0 - t)$$

即 $s(t)$ 先**镜像**（$s(-t)$）再**右移** $T_0$。

> [!warning] 必背公式
> $$h(t) = s(T_0 - t)$$
> $$r_{o\max} = \frac{2E}{n_0}$$

### 因果性与抽样时刻

因果系统要求 $h(t) = 0 \ (t < 0)$，因此必须 $T_0 \geq T_b$（$T_b$ 为码元终止时刻）。

为尽早判决，通常取 $T_0 = T_b$，即**每个码元的终止时刻为最佳抽样时刻**：

$$h(t) = s(T_b - t)$$

此时输出最大信噪比的时刻在输入信号**结束之后**。

### 输出信号 = 自相关函数

$$s_o(t) = s(t) * h(t) = \int_{-\infty}^{+\infty} s(\tau) s(T_0 - t + \tau) d\tau$$

根据确知信号自相关函数定义 $R(\tau) = \int s(t) s(t + \tau) dt$：

$$s_o(t) = R(t - T_0)$$

即**匹配滤波器的输出等于输入信号的自相关函数**，匹配滤波器可视为一个**相关器**。

在抽样时刻 $t = T_0$：$s_o(T_0) = R(0) = E$（码元能量）。

> [!tip] 结论链
> $h(t) = s(T_b - t)$ → 输出 $s_o(t) = R(t - T_b)$ → $s_o(T_b) = E$ → $r_{o\max} = 2E/n_0$

### 提高 $r_{o\max}$ 的方法

1. 提高信号幅度 $A$
2. 延长信号作用时间 $T_b$

$r_{o\max} = 2E/n_0$ 与信号波形**无关**，仅与码元能量和噪声功率谱密度有关。

### 清零操作（复位操作）

在 $t = T_b$ 之后将输出**强制清零**，为后续码元的抽样判决腾出空间。这一操作保证每个码元的匹配滤波输出互不干扰。

> [!example] 例1：全占空与半占空矩形脉冲的匹配滤波器
> $s_1(t)$：$0 \sim T_b$、幅度 $A$ 的全占空矩形；$s_2(t)$：$0 \sim T_b/2$、幅度 $A$ 的半占空矩形。
> 求各自的 $h(t)$、输出波形 $s_o(t)$、最佳抽样时刻 $T_0$ 和 $r_{o\max}$。
>
> **解**：
>
> **$s_1(t)$ 的匹配滤波器**：取 $T_0 = T_b$，$h_1(t) = s_1(T_b - t)$。$s_1(t)$ 镜像后仍为 $0 \sim T_b$ 的矩形脉冲，右移 $T_b$ 后回到 $0 \sim T_b$，与 $s_1(t)$ **波形相同**。
>
> 输出 $s_{o1}(t) = s_1(t) * h_1(t)$：两个宽度 $T_b$ 的等宽矩形卷积 → **等腰三角形**（$0 \sim 2T_b$），在 $t = T_b$ 处达峰值 $A^2 T_b$。
>
> $T_0 = T_b$，$r_{o\max} = \frac{2E_1}{n_0} = \frac{2A^2 T_b}{n_0}$。
>
> **$s_2(t)$ 的匹配滤波器**：$h_2(t) = s_2(T_b - t)$，先镜像到 $T_b/2 \sim T_b$，右移 $T_b$ 后位于 $T_b/2 \sim T_b$ 的矩形脉冲。
>
> 输出：两个宽度 $T_b/2$ 的等宽矩形卷积 → 等腰三角形（$\frac{T_b}{2} \sim \frac{3T_b}{2}$），在 $t = T_b$ 处达峰值 $\frac{A^2 T_b}{2}$。
>
> $T_0 = T_b$，$r_{o\max} = \frac{2E_2}{n_0} = \frac{A^2 T_b}{n_0}$。
>
> 半占空因持续时间减半，能量减半，输出信噪比也相应减小。

> [!example] 例2：PSK/FSK 正弦码元的匹配滤波器
> $s(t) = 2\cos(2\pi f_0 t)$，持续 $0 \sim T_b$。求 $h(t)$、$s_o(t)$、$T_0$ 和 $r_{o\max}$。
>
> **解**：
> 取 $T_0 = T_b$，$h(t) = s(T_b - t) = 2\cos[2\pi f_0 (T_b - t)]$。当 $f_0 T_b$ 为整数时（即码元内包含整数个载波周期，这是典型通信系统的基本假设），$\cos[2\pi f_0(T_b - t)] = \cos(2\pi f_0 T_b - 2\pi f_0 t) = \cos(2\pi f_0 t)$，此时 $h(t)$ 波形与 $s(t)$ 相同。
>
> 输出 $s_o(t) = s(t) * h(t)$：包络为等腰三角形（$0 \sim 2T_b$）的振荡波形，$t = T_b$ 处包络峰值 = $\frac{A^2 T_b}{2}$（注意正弦波功率为 $\frac{A^2}{2}$，$A = 2$，故能量 $E = \frac{4 \cdot T_b}{2} = 2T_b$）。
>
> $T_0 = T_b$，$r_{o\max} = \frac{2E}{n_0}$。

## 8.2 数字信号接收的统计模型与最佳接收准则

### 噪声空间的统计特性

用 $k$ 维矢量 $\vec{n} = (n_1, n_2, \ldots, n_k)$ 表示一个码元内噪声的 $k$ 个抽样值。

噪声抽样值统计独立，均为零均值、方差 $\sigma_n^2$ 的高斯变量：

$$f(n_i) = \frac{1}{\sqrt{2\pi}\sigma_n} \exp\left(-\frac{n_i^2}{2\sigma_n^2}\right)$$

$k$ 维联合概率密度（独立故连乘）：

$$f(\vec{n}) = \frac{1}{(\sqrt{2\pi}\sigma_n)^k} \exp\left(-\frac{1}{2\sigma_n^2} \sum_{i=1}^{k} n_i^2\right)$$

设信号带限于 $0 \sim f_H$，取奈奎斯特采样频率 $f_s = 2f_H$，则 $k = 2f_H T_b$。

利用 $\frac{1}{2\sigma_n^2} \sum n_i^2 = \frac{1}{n_0} \int_0^{T_b} n^2(t) dt$，推导如下：由 Nyquist 采样定理，以 $f_s = 2f_H$ 对带限噪声采样，采样值方差 $\sigma_n^2 = n_0 f_H$，码元内采样点数 $k = 2f_H T_b$。则 $\sum n_i^2 = \frac{1}{2f_H} \cdot 2f_H \int_0^{T_b} n^2(t) dt$（采样值平方和与连续积分的关系），代入 $\frac{1}{2\sigma_n^2} = \frac{1}{2n_0 f_H}$ 即得。

$$f(\vec{n}) = \frac{1}{(\sqrt{2\pi}\sigma_n)^k} \exp\left(-\frac{1}{n_0} \int_0^{T_b} n^2(t) dt\right)$$

### 似然函数

当发送码元 $s_i(t)$ 时，接收电压 $r(t) = s_i(t) + n(t)$，其 $k$ 维联合概率密度称为**似然函数**：

$$f_i(\vec{r}) = \frac{1}{(\sqrt{2\pi}\sigma_n)^k} \exp\left(-\frac{1}{n_0} \int_0^{T_b} [r(t) - s_i(t)]^2 dt\right)$$

> [!info] 似然函数的物理意义
> 似然函数表示**当发送信号 $s_i(t)$ 确定时，接收到观察值 $\vec{r}$ 的可能性**。对于二进制：发 $s_0(t)$ 时似然函数为 $f_0(\vec{r})$，发 $s_1(t)$ 时似然函数为 $f_1(\vec{r})$。

### 似然比准则（最小差错概率准则）

设发 $s_0(t)$ 先验概率 $P_0$，发 $s_1(t)$ 先验概率 $P_1$。令判决门限（似然比门限）为 $\lambda_0'$：

总误码率 $P_e = P_0 \cdot P(\text{判 }1 \mid \text{发 }0) + P_1 \cdot P(\text{判 }0 \mid \text{发 }1)$

其中 $P(\text{判 }1 \mid \text{发 }0) = \int_{\lambda_0'}^{+\infty} f_0(r) dr$，$P(\text{判 }0 \mid \text{发 }1) = \int_{-\infty}^{\lambda_0'} f_1(r) dr$（此处简化为在似然比标量空间中的积分）。

令 $\frac{\partial P_e}{\partial \lambda_0'} = 0$，得**似然比准则**：

$$\frac{f_0(\vec{r}_0)}{f_1(\vec{r}_0)} = \frac{P_1}{P_0}$$

- 若 $\frac{f_0(\vec{r})}{f_1(\vec{r})} < \frac{P_1}{P_0}$，判为 $s_1(t)$
- 若 $\frac{f_0(\vec{r})}{f_1(\vec{r})} > \frac{P_1}{P_0}$，判为 $s_0(t)$

### 最大似然准则

当符号**先验等概**（$P_0 = P_1$）时，$\frac{P_1}{P_0} = 1$，简化为**最大似然准则**：

- 若 $f_0(\vec{r}) > f_1(\vec{r})$，判为 $s_0(t)$
- 若 $f_0(\vec{r}) < f_1(\vec{r})$，判为 $s_1(t)$

即：**哪个似然函数大，判为哪个对应的信号**。

推广至 $M$ 进制：若 $f_i(\vec{r}) > f_j(\vec{r})\ (\forall j \neq i)$，则判为 $s_i(t)$。

> [!important] 重要等价关系
> 在加性高斯白噪声条件下：**似然比准则** $\Leftrightarrow$ **最小差错概率准则** $\Leftrightarrow$ **最大信噪比准则**

## 8.3 确知信号的最佳接收机

> [!info] 确知信号
> 信号出现后，所有参数（幅度、频率、相位、到达时刻等）都确知的信号。注意区别于"已知信号"——实际中发送端可能从多个信号中选发一个，接收端事先并不知晓具体发送的是哪一个。

### 最佳接收机的数学推导

假设 $s_0(t)$ 和 $s_1(t)$ **等能量**（$E_0 = E_1 = E$）。

将似然函数代入似然比准则，消去公共因子（$\frac{1}{(\sqrt{2\pi}\sigma_n)^k}$ 和 $s_0^2$、$s_1^2$、$r^2$ 的积分），两端取对数：

$$U_0 + \int_0^{T_b} r(t) s_0(t) dt \quad \text{vs} \quad U_1 + \int_0^{T_b} r(t) s_1(t) dt$$

其中 $U_0 = \frac{n_0}{2} \ln P_0$，$U_1 = \frac{n_0}{2} \ln P_1$。

- 若左端 > 右端，判为 $s_0(t)$
- 若左端 < 右端，判为 $s_1(t)$

**先验等概时**（$P_0 = P_1$），$U_0 = U_1$ 可抵消：

- 若 $\int_0^{T_b} r(t) s_0(t) dt > \int_0^{T_b} r(t) s_1(t) dt$，判为 $s_0(t)$
- 若 $\int_0^{T_b} r(t) s_0(t) dt < \int_0^{T_b} r(t) s_1(t) dt$，判为 $s_1(t)$

即比较 $r(t)$ 与 $s_0(t)$、$s_1(t)$ 的**相关性**，哪路相关性强判为哪个。

### 相关接收机结构

$r(t)$ 分上下两路 → 分别与 $s_0(t)$ 和 $s_1(t)$ **相乘** → 分别**积分** → （先验不等概时附加 $U_0$、$U_1$）→ 在 $t = T_b$ 时刻**比较判决**。

> [!tip] 相关接收机
> 本质是比较 $r(t)$ 与 $s_0(t)$、$s_1(t)$ 的**互相关**。上下支路的相乘+积分构成一个**相关器**。属于**相干接收**（需要提供相干信号 $s_0(t)$、$s_1(t)$）。

### 匹配滤波器形式的最佳接收机

利用匹配滤波器在抽样时刻 $t = T_b$ 的输出等于相关器输出：

$$u_o(T_b) = \int_0^{T_b} r(\tau) s(\tau) d\tau$$

因此可用匹配滤波器替代相关器：

- 上支路：$h_0(t) = s_0(T_b - t)$（匹配 $s_0(t)$）
- 下支路：$h_1(t) = s_1(T_b - t)$（匹配 $s_1(t)$）

在 $t = T_b$ 抽样比较：哪路输出大，判为对应的信号。

> [!warning] 注意
> 匹配滤波器和相关器**仅在抽样时刻 $t = T_b$ 具有相同输出**，其他时刻波形不同。

> [!example] 例3：相关接收与匹配接收各点波形
> 二进制基带系统，$s_0(t)$ 为 $0 \sim T_b/2$ 幅度 $A_0$ 的矩形，$s_1(t)$ 为 $T_b/2 \sim T_b$ 幅度 $A_0$ 的矩形，先验等概。构成相关器形式和匹配滤波器形式的最佳接收机，并画各点波形。
>
> **解**：
>
> **相关接收机**：上支路 $\times s_0(t)$ + 积分 → $C$ 点；下支路 $\times s_1(t)$ + 积分 → $E$ 点。输入 $s_0, s_0, s_1$ 序列。
> - $B$ 点（上乘法器）：$s_0 \times s_0$ → 幅度 $A_0^2$ 矩形；$s_0 \times s_0$ → 同上；$s_1 \times s_0$（不相关）→ $0$
> - $D$ 点（下乘法器）：$s_0 \times s_1$（不相关）→ $0$；$s_1 \times s_1$ → 幅度 $A_0^2$ 矩形
> - $C$ 点（上积分）：矩形积分后上升→平顶→$T_b$ 后强制清零
> - $E$ 点（下积分）：同理
> - 判决：比较 $C$ 和 $E$ 在 $t = kT_b$ 的抽样值，大者判为对应信号
>
> **匹配接收机**：$h_0(t) = s_0(T_b - t)$（$T_b/2 \sim T_b$ 的矩形），$h_1(t) = s_1(T_b - t)$（$0 \sim T_b/2$ 的矩形）。同样在 $t = kT_b$ 比较两路输出大小。
>
> 两种结构的判决结果一致：$s_0, s_0, s_1$。

### 确知信号最佳接收机的误码性能

#### 发零错判为一的概率推导

假设两信号等能、先验等概。发 $s_0(t)$，$r(t) = s_0(t) + n(t)$。

错判为 $s_1(t)$ 意味着上支路 < 下支路，经代数整理得：

$$\int_0^{T_b} n(t) [s_0(t) - s_1(t)] dt < -\frac{1}{2} \int_0^{T_b} [s_0(t) - s_1(t)]^2 dt$$

左端记作随机变量 $\xi$（高斯白噪声的线性变换，仍为高斯变量），右端记作常量 $a$。

$\xi$ 的统计特性：
- 均值：$E[\xi] = 0$
- 方差：$\sigma_\xi^2 = \frac{n_0}{2} \int_0^{T_b} [s_0(t) - s_1(t)]^2 dt$

发零错判为一概率 $P(0 \to 1) = P(\xi < a)$，代高斯分布并换元积分得：

$$P(0 \to 1) = \frac{1}{\sqrt{2\pi}} \int_b^{+\infty} e^{-x^2/2} dx$$

其中积分下限 $b = \frac{-a}{\sigma_\xi} = \sqrt{\frac{1}{2n_0} \int_0^{T_b} [s_0(t) - s_1(t)]^2 dt}$。

同理 $P(1 \to 0)$ 与 $P(0 \to 1)$ 对称，积分下限相同（先验等概时 $b = b'$）。

#### 总误码率公式

$$P_e = P_0 \cdot P(0 \to 1) + P_1 \cdot P(1 \to 0)$$

先验等概时 $P_0 = P_1 = \frac{1}{2}$，设 $\gamma = b = b'$：

$$P_e = \frac{1}{2} \text{erfc}\left(\frac{\gamma}{\sqrt{2}}\right)$$

其中 $\gamma = \sqrt{\frac{1}{2n_0} \int_0^{T_b} [s_0(t) - s_1(t)]^2 dt}$。

> [!important] 关键结论
> $P_e$ 只与 $s_0(t)$ 和 $s_1(t)$ **差的能量**有关。两信号差异越大，$\gamma$ 越大，误码率越低。

#### 互相关系数 $\rho$

定义信号间的互相关系数：

$$\rho = \frac{\int_0^{T_b} s_0(t) s_1(t) dt}{\sqrt{E_0 E_1}}$$

等能时（$E_0 = E_1 = E_b$）：$\rho = \frac{\int_0^{T_b} s_0(t) s_1(t) dt}{E_b}$，$\rho \in [-1, 1]$。

用 $\rho$ 表达 $A$：

$$A = \sqrt{\frac{E_b}{n_0} (1 - \rho)}$$

代入得**等概等能条件下二进制确知信号最佳接收误码率**：

$$P_e = \frac{1}{2} \text{erfc} \sqrt{\frac{E_b (1 - \rho)}{2 n_0}}$$

> [!warning] 结论
> $\rho$ 越小，$P_e$ 越小。信号设计应使**互相关系数尽可能小**（正交或超正交）。

### 二进制信号形式比较

| $\rho$ | 信号关系 | 基带 | 频带 | $P_e$ |
|--------|----------|------|------|-------|
| $-1$ | $s_0 = -s_1$（超正交） | 双极性基带 | 2PSK / 2DPSK | $\frac{1}{2}\text{erfc}\sqrt{\frac{E_b}{n_0}}$（**最小**） |
| $0$ | 正交且等能 | — | 等能 2FSK | $\frac{1}{2}\text{erfc}\sqrt{\frac{E_b}{2n_0}}$ |
| $0$ | 正交但不等能（$E_0=0, E_1=E$） | 单极性基带 | 2ASK | $\frac{1}{2}\text{erfc}\sqrt{\frac{E}{4n_0}}$（注意 $E_b = \frac{E}{2}$） |
| $1$ | $s_0 = s_1$（完全相关） | — | — | $\frac{1}{2}$（随机猜测，无效通信） |

> [!important] 最佳信号形式
> **基带**：双极性信号；**频带**：2PSK（或 2DPSK）。$\rho = -1$ 时达到最小误码率。
>
> 在相同误码率下，2PSK 所需 $E_b/n_0$ 比正交 2FSK/2ASK **低 3dB**（因为 2FSK/2ASK 分母为 $2n_0$，信号能量差一半）。

## 8.4 随相信号的最佳接收机

> [!info] 随相信号
> 通过随参信道（如无线信道）后，信号相位具有随机性。以**随机相位 2FSK** 为典型代表。

### 二进制随相信号模型

两个发送信号（频率 $\omega_0$、$\omega_1$ 确知，满足正交条件 $\rho = 0$）：

$$s_0(t, \varphi_0) = A\cos(\omega_0 t + \varphi_0), \quad s_1(t, \varphi_1) = A\cos(\omega_1 t + \varphi_1)$$

随机相位 $\varphi_0, \varphi_1 \sim U(0, 2\pi)$，概率密度 $f(\varphi_0) = f(\varphi_1) = \frac{1}{2\pi}$。

两信号等能量：$E_0 = E_1 = E_b = \frac{A^2 T_b}{2}$。

### 似然函数与最佳接收准则

先求条件似然函数（给定 $\varphi_0$ 或 $\varphi_1$ 时退化为确知信号），再对随机相位求边缘分布，经复杂推导得：

$$f_0(\vec{r}) = K \cdot I_0\left(\frac{2A}{n_0} M_0\right), \quad f_1(\vec{r}) = K \cdot I_0\left(\frac{2A}{n_0} M_1\right)$$

其中 $I_0(x)$ 为零阶修正贝塞尔函数（单调递增），而：

$$M_0 = \sqrt{X_0^2 + Y_0^2}, \quad M_1 = \sqrt{X_1^2 + Y_1^2}$$

$$\begin{aligned} X_0 &= \int_0^{T_b} r(t) \cos\omega_0 t \, dt, \quad Y_0 = \int_0^{T_b} r(t) \sin\omega_0 t \, dt \\ X_1 &= \int_0^{T_b} r(t) \cos\omega_1 t \, dt, \quad Y_1 = \int_0^{T_b} r(t) \sin\omega_1 t \, dt \end{aligned}$$

先验等概时，比较 $f_0$ 与 $f_1$ 等价于比较 $M_0$ 与 $M_1$：

- 若 $M_0 > M_1$，判为 $s_0(t, \varphi_0)$
- 若 $M_0 < M_1$，判为 $s_1(t, \varphi_1)$

### 相关接收机结构（4 相关器）

$r(t)$ 分上下两大支路，每支路再分两路：
- 上支路：$\times \cos\omega_0 t$ + 积分 → $X_0$；$\times \sin\omega_0 t$ + 积分 → $Y_0$
- 下支路：$\times \cos\omega_1 t$ + 积分 → $X_1$；$\times \sin\omega_1 t$ + 积分 → $Y_1$

然后各自平方相加得 $M_0^2$、$M_1^2$，再比较判决。

### 匹配滤波 + 包络检波结构（非相干接收）

由于随机相位无法匹配，只能匹配频谱而不匹配相位：

$$h_0(t) = \cos\omega_0(T_b - t), \quad h_1(t) = \cos\omega_1(T_b - t)$$

输出可通过包络检波解出包络 $M_0$、$M_1$：

$$y_0(t) = M_0 \cos[\omega_0(T_b - t) + \theta_0] \xrightarrow{\text{包络检波}} M_0$$

**结构**：$r(t)$ → 匹配滤波器 $h_0(t)$ / $h_1(t)$ → **包络检波器** → 比较 $M_0$ 和 $M_1$ → 判决。

> [!tip] 非相干接收
> 随向信号最佳接收**不利用相位信息**（相位随机无法匹配），因此属于**非相干接收**方式。

### 误码性能

借用 2FSK 非相干解调的结论（$P_e = \frac{1}{2} e^{-r/2}$），将 $r$ 替换为 $E_b/n_0$：

$$P_e = \frac{1}{2} e^{-E_b / (2n_0)}$$

若 $E_b = \frac{A^2 T_b}{2}$，则 $P_e = \frac{1}{2} \exp\left(-\frac{A^2 T_b}{4n_0}\right)$。

## 8.5 最佳接收小结

### 实际接收机 vs 最佳接收机性能比较

| 调制方式 | 实际接收机 $P_e$ | 最佳接收机 $P_e$ |
|----------|-----------------|-----------------|
| 相干 2PSK | $\frac{1}{2}\text{erfc}\sqrt{r}$ | $\frac{1}{2}\text{erfc}\sqrt{\frac{E_b}{n_0}}$ |
| 相干 2FSK | $\frac{1}{2}\text{erfc}\sqrt{\frac{r}{2}}$ | $\frac{1}{2}\text{erfc}\sqrt{\frac{E_b}{2n_0}}$ |
| 相干 2ASK | $\frac{1}{2}\text{erfc}\sqrt{\frac{r}{4}}$ | $\frac{1}{2}\text{erfc}\sqrt{\frac{E_b}{4n_0}}$（注意 $E_b = \frac{E}{2}$） |
| 非相干 2FSK | $\frac{1}{2} e^{-r/2}$ | $\frac{1}{2} e^{-E_b / (2n_0)}$ |

> [!warning] 关键比较
> 两种接收机误码率**数学形式相似**，差别在于实际接收机用信噪比 $r = \frac{S}{n_0 B}$，最佳接收机用归一化信噪比 $\frac{E_b}{n_0} = \frac{S}{n_0 \cdot (1/T_b)}$。
>
> 实际上 $B > 1/T_b = R_B$（如 2PSK 的 $B = 2R_B$），故 $r < E_b/n_0$，因此**最佳接收机性能总是优于实际接收机**。

> [!example] 例4：2PSK 最佳接收 vs 实际接收
> 2PSK 信号，$E_b/n_0 = 10\text{dB}$（线性值 $10$），实际接收机带通滤波器带宽 $B = \frac{6}{T_b}$ Hz。比较两种接收机性能。
>
> **解**：
> $r = \frac{S}{n_0 B} = \frac{S}{n_0 \cdot 6/T_b} = \frac{S T_b}{6 n_0} = \frac{E_b}{6 n_0} = \frac{10}{6} = \frac{5}{3}$。
>
> 最佳接收：$P_{e1} = \frac{1}{2}\text{erfc}\sqrt{10} \approx 4 \times 10^{-6}$。
>
> 实际接收：$P_{e2} = \frac{1}{2}\text{erfc}\sqrt{5/3} \approx 3.4 \times 10^{-2}$。
>
> 比值：$P_{e2} / P_{e1} \approx 8500$。最佳接收性能远优于实际接收（差约 4 个数量级）。

## 8.6 最佳基带传输系统

### 理想信道下的最佳基带系统

基带系统总特性：$H(\omega) = G_T(\omega) \cdot C(\omega) \cdot G_R(\omega)$。

理想信道 $C(\omega) = 1$，故 $H(\omega) = G_T(\omega) \cdot G_R(\omega)$。

最佳化需满足两个条件：
1. $H(\omega)$ 满足**奈奎斯特第一准则**（无码间干扰）
2. 误码率最低（收滤波器为匹配滤波器）

设发送滤波器输入为 $\delta(t)$ 冲击序列，则到达收滤波器的信号频谱 $S_i(\omega) = G_T(\omega)$。收滤波器为匹配滤波器：

$$G_R(\omega) = S_i^*(\omega) e^{-j\omega T_0} = G_T^*(\omega) e^{-j\omega T_0}$$

联立得 $|G_R(\omega)|^2 = |H(\omega)|$（忽略相位），故：

> [!warning] 理想信道最佳基带系统结论
> $$G_T(\omega) = G_R(\omega) = \sqrt{H(\omega)} = H^{1/2}(\omega)$$
>
> 即收发滤波器传递函数**各承担总特性的平方根**。

框图：发滤波器 $H^{1/2}(\omega)$ → 理想信道 $C(\omega) = 1$ → 收滤波器 $H^{1/2}(\omega)$ → 抽样判决。

### $M$ 进制基带最佳接收误码率

设 $M$ 种电平：$\pm d, \pm 3d, \ldots, \pm (M-1)d$（电平间隔 $2d$）。

经推导（利用 $a$ 的均方值 = $\frac{d^2}{3}(M^2 - 1)$，$S = \frac{E[\overline{a_n^2}]}{T_b}$）：

$$P_e = \left(1 - \frac{1}{M}\right) \text{erfc}\left(\frac{d}{\sqrt{2}\sigma}\right)$$

其中 $\sigma^2 = n_0/2$ 为匹配滤波器输出端噪声方差。

代入 $d^2 = \frac{3S T_b}{M^2 - 1} = \frac{3E}{M^2 - 1}$：

$$P_e = \left(1 - \frac{1}{M}\right) \text{erfc} \sqrt{\frac{3E}{(M^2 - 1)n_0}}$$

当 $M = 2$ 时退化为二进制双极性最佳接收：$P_e = \frac{1}{2}\text{erfc}\sqrt{\frac{E}{n_0}}$。

> [!tip] 误码率曲线规律
> 在低误码率区，$M$ 增大两倍（如 2→4），为保持相同 $P_e$，$E_b/n_0$ 约需增大 **7dB**。

### 非理想信道下的最佳基带系统

非理想信道 $C(\omega) \neq 1$，收滤波器需匹配到达信号 $G_T(\omega) C(\omega)$：

$$G_R'(\omega) = G_T^*(\omega) C^*(\omega)$$

总特性 $H(\omega) = |G_T(\omega)|^2 |C(\omega)|^2$ 一般不满足奈奎斯特准则。需在接收端**级联均衡器** $T(\omega)$：

$$T(\omega) = \frac{T_b}{\sum_i H\left(\omega + \frac{2\pi i}{T_b}\right)} \quad \left(|\omega| \leq \frac{\pi}{T_b}\right)$$

框图：$G_T(\omega)$ → $C(\omega)$（非理想信道） → $G_R'(\omega)$（匹配滤波器） → $T(\omega)$（均衡器） → 抽样判决。

> [!info] 收滤波器组成
> 非理想信道下，收端滤波器 = **匹配滤波器** $G_R'(\omega)$ + **均衡器** $T(\omega)$，共同构成最佳接收滤波器。

### 考试注意事项

| 注意 | 说明 |
|------|------|
| 先镜像后平移 | $h(t) = s(T_b - t)$，不能简单地照搬输入波形！只有全占空矩形才恰好相同 |
| $T_b$ 的选取 | 保证 $h(t)$ 因果（$t \geq 0$ 才有值），常取 $T_0 = T_b$ |
| 框图区分 | 匹配滤波用 $h_0/h_1$ → 比较；相关接收用相乘+积分 → 比较 |
| 等效条件 | 相关接收与匹配接收**仅在抽样时刻 $t = T_b$** 等效 |
| 清零 | $T_b$ 后强制清零，为后续码元留出空间 |
| 能量 $E$ | $E = \int s^2(t) dt$，正弦波 $E = A^2 T_b / 2$（注意除以 2！） |
| $\rho$ 与信号对应 | $\rho = -1$ → 2PSK/双极性；$\rho = 0$ → 2FSK/2ASK/单极性 |
| 随向接收 | 用包络检波，非相干方式，不利用相位信息 |
| 实际 vs 最佳 | 形式相同，$r \leftrightarrow E_b/n_0$；因 $B > 1/T_b$，最佳接收性能更优 |
| 不等能修正 | 2ASK/单极性：$E_b = \frac{E_0 + E_1}{2} = \frac{E}{2}$（平均能量代换） |
