## 最佳接收准则

数字信号最佳接收的准则：**误码率最低**，等价于**抽样时刻输出信噪比最大**。

---

## 匹配滤波法

### 核心结论

匹配滤波器是一种线性滤波器，使输出端在抽样时刻的信噪比最大。

**结论一**：若输入信号为 $s(t)$，匹配滤波器的单位冲激响应为：

$$h(t) = s(T_b - t)$$

即 $s(t)$ 的镜像 $s(-t)$ 沿时间轴向右平移 $T_b$。$T_b$ 的选取应使 $h(t)$ 为因果系统（$t \geq 0$ 时才有值）。

**结论二**：匹配滤波器输出端能达到的最大信噪比为：

$$r_{\max} = \frac{2E}{n_0}$$

其中 $E$ 为信号码元的能量，$n_0$ 为噪声单边功率谱密度。最佳抽样时刻为 $t = T_b$。

> [!warning] 必背
> $h(t) = s(T_b - t)$，先镜像再右移 $T_b$；$r_{\max} = 2E/n_0$。

### 矩形脉冲卷积结论

两个一般矩形脉冲的卷积结果为梯形脉冲：

| 时间点 | 位置 | 公式 |
|--------|------|------|
| 起点 | $t_1 + t_3$ | 小加小 |
| 左拐点 | $\min(t_1+t_4,\; t_2+t_3)$ | 小加大 / 大加小中较小者 |
| 右拐点 | $\max(t_1+t_4,\; t_2+t_3)$ | 小加大 / 大加小中较大者 |
| 终点 | $t_2 + t_4$ | 大加大 |
| 梯形高度 | | $E_1 \cdot E_2 \cdot$（较短脉宽） |

两等宽矩形脉冲卷积退化为**三角脉冲**，拐点重合于中点。

### 最佳接收机结构

接收信号 $r(t)$ 分上下两路，分别用针对 $s_0(t)$ 和 $s_1(t)$ 设计的匹配滤波器 $h_0(t) = s_0(T_b - t)$ 和 $h_1(t) = s_1(T_b - t)$，在 $t = T_b$ 时刻比较两路输出，幅度大者判为对应码元。

---

## 相关接收法

匹配滤波法的等价实现。将匹配滤波器替换为**相乘器 + 积分器**，相乘信号分别为 $s_0(t)$ 和 $s_1(t)$，其余结构与匹配滤波法相同。

> [!tip] 框图对应
> 匹配滤波：分上下两路 → $h_0(t)$ / $h_1(t)$ → 比较判决。
> 相关接收：分上下两路 → $\times s_0(t)$ + 积分 / $\times s_1(t)$ + 积分 → 比较判决。

---

> [!example] 例：全占空与半占空矩形脉冲
> $s_1(t)$ 为全占空（$0 \sim T_b$，幅度 $A$），$s_2(t)$ 为半占空（$0 \sim T_b/2$，幅度 $A$）。
>
> **解**：
> **$s_1(t)$ 的匹配滤波器**：$h_1(t)$ 与 $s_1(t)$ 波形相同（先镜像到 $-T_b \sim 0$，再右移 $T_b$ 到 $0 \sim T_b$）。
> 输出 $s_o(t)$：两等宽矩形卷积 → 三角脉冲（$0 \sim 2T_b$，峰值 $A^2 T_b$ 在 $T_b$ 处）。
> $r_{\max} = 2E_1/n_0 = 2A^2 T_b / n_0$。
>
> **$s_2(t)$ 的匹配滤波器**：$h_2(t)$ 为 $T_b/2 \sim T_b$、幅度 $A$ 的矩形脉冲。
> 输出：梯形退化为三角脉冲（$T_b/2 \sim 3T_b/2$，峰值 $A^2 T_b/2$ 在 $T_b$ 处）。
> $r_{\max} = 2E_2/n_0 = A^2 T_b / n_0$。

> [!example] 例：正负对称脉冲的匹配滤波器
> $f(t)$ 为 $0 \sim T_b/2$ 幅度 $+A$、$T_b/2 \sim T_b$ 幅度 $-A$ 的脉冲。
>
> $h(t)$：先镜像（$-T_b \sim -T_b/2$ 为 $-A$，$-T_b/2 \sim 0$ 为 $+A$），再右移 $T_b$ → $0 \sim T_b/2$ 为 $-A$，$T_b/2 \sim T_b$ 为 $+A$。
>
> **解**：
> 输出波形：用导数-积分法求卷积，得四段直线构成的对称波形，峰值在 $t = T_b$ 处为 $A^2 T_b$。
>
> $E = A^2 T_b$，$r_{\max} = 2A^2 T_b / n_0$。

> [!example] 例：匹配滤波与相关接收框图
> $s_1(t)$：$0 \sim T_b/2$ 幅度 $A_0$ 的矩形；$s_2(t)$：$T_b/2 \sim T_b$ 幅度 $A_0$ 的矩形。
>
> **解**：
> 画出匹配滤波形式的最佳接收机：分两路，$h_1 = s_1(T_b-t)$（$T_b/2 \sim T_b$ 的矩形），$h_2 = s_2(T_b-t)$（$0 \sim T_b/2$ 的矩形）。
>
> 等效相关接收机：匹配滤波器替换为 $\times s_1(t) + \int$ 和 $\times s_2(t) + \int$。
>
> 误码率（建议作为特例记忆）：$P_e = \frac{1}{2}\mathrm{erfc}\sqrt{\frac{E_b}{2n_0}}$，其中 $E_b = A_0^2 T_b / 2$（两信号能量相同）。
> 代入得 $P_e = \frac{1}{2}\mathrm{erfc}\sqrt{\frac{A_0^2 T_b}{4n_0}}$。

## 本章小结

### 基本概念

| 知识点 | 要点 |
|--------|------|
| 最佳接收准则 | 误码率最低 = 抽样时刻信噪比最大 |
| 匹配滤波器 | $h(t) = s(T_b - t)$，先镜像后右移 $T_b$ |
| 最大输出信噪比 | $r_{\max} = 2E/n_0$ |
| 抽样时刻 | $t = T_b$ |
| 相关接收法 | 匹配滤波的等价实现：相乘 + 积分替代匹配滤波器 |
| 矩形卷积结论 | 一宽一窄 → 梯形；等宽 → 三角。高度 = 两幅度积 × 较短脉宽 |

### 核心公式

| 公式 | 说明 |
|------|------|
| $h(t) = s(T_b - t)$ | 匹配滤波器冲击响应 |
| $r_{\max} = 2E/n_0$ | 最大输出信噪比 |
| $t_{\text{抽样}} = T_b$ | 最佳抽样时刻 |

### 考试注意事项

| 注意 | 说明 |
|------|------|
| 先镜像后平移 | $h(t) = s(T_b - t)$ 不是直接抄 $s(t)$，只有全占空矩形才碰巧一样 |
| $T_b$ 的选取 | 要保证 $h(t)$ 因果（$t \geq 0$ 才有值） |
| 框图区分 | 匹配滤波用 $h_0/h_1$，相关接收用相乘积分 |
| 能量 $E$ | 信号平方后沿时间轴积分，勿忘平方 |
| 例 误码率 | 建议作为特例记忆，考原题概率高 |
