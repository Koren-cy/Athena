# 通信原理 EP6 数字基带传输系统

## 数字基带信号的波形

六种基本波形（以二进制为例）：

| 波形 | 特点 |
|------|------|
| 单极性不归零 | 0→0 电平，1→+1 电平，占满整个码元周期 |
| 双极性不归零 | 0→-1 电平，1→+1 电平，占满整个码元周期 |
| 单极性归零 | 0→0 电平，1→+1 电平持续 $\tau$ 后归零 |
| 双极性归零 | 0→-1 电平，1→+1 电平持续 $\tau$ 后归零 |
| 差分波形 | 信息反映在相邻码元的变化上（变→1/不变→0） |
| 多电平波形 | 多进制，如四电平 |

不归零 = NRZ，归零 = RZ。占空比 $= \tau / T_b$。

差分波形的思想贯穿后续 DPSK，极其重要。

### 二进制基带信号的功率谱密度

以 0/1 等概为前提，四种 NRZ/RZ 波形的功率谱特征：

| 特征 | 说明 |
|------|------|
| 连续谱 | 始终存在，呈 Sa 函数形状 |
| 离散谱 | 可能存在，可能不存在 |
| 带宽 | NRZ：$B = 1/T_b = R_B$；RZ（50%占空比）：$B = 2/T_b = 2R_B$ |
| 直流分量 | 单极性波形有（$f=0$ 处有冲激），双极性波形无 |
| 定时分量 | **仅单极性归零波形**有（$f = R_B$ 处的离散谱线） |

> [!tip] 直观理解
> 单极性波形的均值不是零（有直流），双极性均值为零（无直流）。单极性归零每个码元内有一个向下的跳变沿，可提取定时信息；双极性归零中正负跳变沿等概抵消，提不出定时分量。

> [!info] 简答题常考
> 四种波形中，哪些有直流分量？哪些有定时分量？——单极性有直流，仅单极性归零有定时分量。

## 基带传输常用码型

### 线路码选择原则

不含直流、含丰富定时信息、带宽窄、不受信源统计特性影响。

### AMI 码

编码规则：0 不变，1 交替编为 +1 和 -1。

优点：无直流分量。缺点：长连零时电平不跳变，无法提取定时信息。

### HDB3 码

AMI 的改进，解决长连零问题。编码口诀：

1. 先编成 AMI 码
2. 找 4 个连零分节，每节结尾写 V
3. **V 前同，V 交替**：V 的极性与前一非零脉冲相同；相邻 V 码极性交替
4. 若不满足 V 交替 → 改 V 符号，添 B（**节内 BV 同符号**）
5. **V 后符号也相反**：V 后的传号码与 V 极性相反

> [!warning] 考试必考
> HDB3 编码几乎 99% 会出题。HDB3 编码的四道例题务必亲手练一遍。

> [!example] 例：HDB3 编码
> 详见视频讲解。按口诀逐步编码：AMI → 分节 → 写 V（V 前同 V 交替）→ 添 B（节内 BV 同符号）→ V 后符号相反。

### 双向码

零用 01 表示，一用 10 表示。又称曼彻斯特码。

## 系统模型与码间串扰

### 数字基带传输系统模型

输入为一串 delta 函数序列 $\sum a_n \delta(t - nT_b)$（软件定义，非真实物理波形）→ 发送滤波器 $G_T(\omega)$ → 信道 $C(\omega)$ → 接收滤波器 $G_R(\omega)$ → 抽样判决 → 输出。

定义基带传输总特性：$H(\omega) = G_T(\omega) \cdot C(\omega) \cdot G_R(\omega)$

对应单位冲激响应 $h(t)$。

接收滤波器输出：
$$r(t) = \sum_{n} a_n h(t - nT_b) + n_R(t)$$

在 $t = kT_b + t_0$ 时刻抽样：
$$r(kT_b + t_0) = a_k h(t_0) + \sum_{n \neq k} a_n h[(k-n)T_b + t_0] + n_R(kT_b + t_0)$$

三项依次为：本码元抽样值、**码间串扰**、噪声抽样值。

### 码间串扰

码间串扰是因系统总特性不理想，前后码元波形展宽拖尾蔓延到当前抽样时刻，对判决造成干扰。消除码间串扰 = 让 $n \neq k$ 的求和项为零。

## 无码间串扰的基带传输特性

### 时域条件

$$h(kT_b + t_0) = \begin{cases} 1, & k = 0 \\ 0, & k \neq 0 \end{cases}$$

本码元抽样时刻有值，其他码元抽样时刻恰好过零。

### 频域条件

将 $H(\omega)$ 在 $\omega$ 轴上以 $\frac{2\pi}{T_b}$ 为间隔切开，分段平移到 $[-\frac{\pi}{T_b}, \frac{\pi}{T_b}]$ 内叠加，结果应为常数 $T_b$：

$$\sum_i H\left(\omega + \frac{2\pi i}{T_b}\right) = T_b, \quad |\omega| \leq \frac{\pi}{T_b}$$

以频率 $f$ 为横轴时：以 $\frac{1}{T_b}$ 为间隔切开，平移到 $[-\frac{1}{2T_b}, \frac{1}{2T_b}]$ 内叠加为常数。

> [!warning] 核心条件
> $H(\omega)$ 在 $\pm\frac{\pi}{T_b}$ 处**奇对称**即可满足奈奎斯特第一准则。这是后续余弦滚降的理论基础。

## 理想低通与余弦滚降

### 理想低通特性

$$H(\omega) = \begin{cases} T_b, & |\omega| \leq \frac{\pi}{T_b} \\ 0, & \text{else} \end{cases}$$

| 参数 | 值 |
|------|:--:|
| 奈奎斯特带宽 $f_N$ | $\frac{1}{2T_b}$ |
| 奈奎斯特速率 $R_B$ | $\frac{1}{T_b} = 2f_N$ |
| 频带利用率 $\eta$ | $\frac{R_B}{B} = 2$ Baud/Hz |

理想低通物理不可实现（时域 Sa 函数拖尾衰减太慢）。

### 余弦滚降特性

在理想低通基础上增加滚降段（$\alpha \in [0,1]$）：

| 参数 | 公式 |
|------|------|
| 带宽 | $B = (1 + \alpha)f_N = \frac{1+\alpha}{2T_b}$ |
| 频带利用率 | $\eta = \frac{R_B}{B} = \frac{2}{1+\alpha}$ Baud/Hz |

- $\alpha = 0$：退化为理想低通，$\eta = 2$
- $\alpha = 1$：升余弦特性，$\eta = 1$
- $\alpha \in (0,1)$：余弦滚降，$1 < \eta < 2$

> [!tip] 注意
> $f_N = \frac{1}{2T_b}$ 是理想低通的带宽，不要与余弦滚降的带宽 $(1+\alpha)f_N$ 混淆。

### 无 ISI 传输的整数倍结论

若系统最大无码间串扰码元速率为 $R_{B\max}$，则以 $R_B = R_{B\max} / n$（$n$ 为正整数）传输时同样无 ISI；若 $n$ 不是整数，则有 ISI。

---

> [!example] 例：三角形传输特性
> $H(\omega)$ 为频域三角脉冲。用对偶性质求 $h(t)$。
>
> **解**：根据奈奎斯特定则判断：在 $\pm\omega_0$ 处画虚线，外部为零，内部三角形叠加不是常数 → 无法实现无 ISI。

> [!example] 例：四种 $H(\omega)$ 的 ISI 判断
> 码速率 $2/T_b$ 波特
>
> **解**：虚线在 $\pm 2\pi/T_b$ 处。对四种频谱分别平移叠加，只有 c（阶梯形）满足叠加为常数。a、b、d 均不满足。

> [!example] 例：三种特性比较
> $R_B = 10^3$ 波特，虚线在 $\pm\pi \times 10^3$。
>
> **解**：a、b、c 均无 ISI。b 是理想低通（不可实现），排除。a 和 c 中 c 带宽更小、频带利用率更高 → 选 c。

> [!example] 例：余弦滚降参数反求
> $H(\omega)$ 在 $\pm\omega_0$ 处画虚线，求 $R_B$、带宽和 $\eta$。
>
> **解**：$\omega_0 = \pi R_B$ → $R_B = \omega_0/\pi$。带宽 $= \frac{1+\alpha}{2\pi}\omega_0$，$\eta = \frac{2}{1+\alpha}$。

> [!example] 例：四电平余弦滚降
> 四电平 → 每码元 2 bit。$R_b = 2400$ bps → $R_B = 1200$ 波特。
>
> **解**：
> $\alpha = 0.4$：$f_N = 600\text{Hz}$，$B = (1+0.4) \times 600 = 840\text{Hz}$，$\eta = 1200/840 \approx 1.43$
>
> $\alpha = 1$：$B = 2 \times 600 = 1200\text{Hz}$，$\eta = 1$
>
> 以 $R_b = 800$ bps 传输 → $R_B = 400$ 波特。$400 = 1200/3$（整数倍）→ 无 ISI。

> [!example] 例：给定 $H(f)$ 求最大波特率
> $H(f)$ 中虚线在 $\pm 2400$ Hz → $1/(2T_b) = 2400$ → $R_{B\max} = 4800$ 波特。
>
> **解**：
> 八电平信号，$R_b = 7200$ bps → $R_B = 7200/3 = 2400$。$2400 = 4800/2$（整数倍）→ 无 ISI。

> [!example] 例：64 进制余弦滚降
> 64 进制 → 每码元 $\log_2 64 = 6$ bit。
>
> **解**：$R_b = 8000$ → $R_B = 8000/6 \approx 1333.3$ 波特。
>
> $\alpha = 0.4$：$B = \frac{1+\alpha}{2}R_B = 0.7 \times 1333.3 \approx 933.3$ Hz。

> [!example] 例：二进制滚降系统
> 二进制 → $R_B = R_b = 64\text{k}$。
>
> **解**：$\alpha = 0.25$，$B = \frac{1+\alpha}{2}R_B = 0.625 \times 64\text{k} = 40\text{kHz}$。

> [!example] 例：升余弦表达式
> $H(\omega) = \frac{1}{2}[1+\cos(\omega\tau_0/2)], |\omega| \leq \pi/\tau_0$。$\alpha = 1$（升余弦）。
>
> **解**：
> 虚线在 $\pi/(2\tau_0) = \pi/T_b$ → $R_B = 1/(2\tau_0)$。$\eta = 1$ Baud/Hz。

> [!example] 例：多速率 ISI 判断
> $f_N = 3/(2T_b)$ → $R_{B\max} = 3/T_b$。
>
> **解**：
> $R_B = 1/T_b = R_{B\max}/3$ → 无 ISI；$2/T_b = 2R_{B\max}/3$ → 不是整数倍 → 有 ISI；$3/T_b = R_{B\max}$ → 无 ISI。

## 基带系统抗噪声性能

双极性：最佳判决门限 0，正负电平间距 $2A$，抗噪声优于单极性（间距仅 $A$）。

误码率均含 $\frac{1}{2}\mathrm{erfc}(\cdot)$。erfc 是减函数，括号内数值越大误码率越低。双极性括号内数值更大 → 误码率更低。

本小节了解即可，不要求记公式。

## 本章小结

### 基本概念

| 知识点 | 要点 |
|--------|------|
| NRZ vs RZ | NRZ 带宽 $=R_B$，RZ 带宽 $=2R_B$（50% 占空比） |
| 直流分量 | 单极性有，双极性无 |
| 定时分量 | 仅单极性归零有 |
| HDB3 | V 前同 V 交替，节内 BV 同符号，V 后符号也相反 |
| 码间串扰 | 总特性 $H(\omega)$ 不理想导致前后码元拖尾干扰 |
| 奈奎斯特第一准则 | $H(\omega)$ 以 $2\pi/T_b$ 为周期平移叠加为常数 |
| 奈奎斯特带宽 $f_N$ | $1/(2T_b)$，仅指理想低通带宽 |
| 余弦滚降带宽 | $B = (1+\alpha)f_N$ |
| 频带利用率 | 理想低通 $\eta=2$，余弦滚降 $\eta=2/(1+\alpha)$ |
| 升余弦 | $\alpha=1$ 的特例，$\eta=1$ |

> [!info] 注意区分
> 本章的"奈奎斯特速率"（$R_B = 1/T_b$）与[[信源编码]]中的"奈奎斯特抽样速率"（$f_s \ge 2f_H$）是不同的概念。基带系统的无码间串扰条件在带通系统中同样适用，详见[[数字带通传输系统]]。

### 核心公式

| 公式 | 说明 |
|------|------|
| $B_{\text{NRZ}} = R_B$ | NRZ 带宽 |
| $B_{\text{RZ}} = 2R_B$ | RZ 带宽（50%占空比） |
| $f_N = \frac{1}{2T_b}$ | 奈奎斯特带宽 |
| $R_B = \frac{1}{T_b} = 2f_N$ | 奈奎斯特速率 |
| $B = (1+\alpha)f_N$ | 余弦滚降带宽 |
| $\eta = \frac{2}{1+\alpha}$ | 余弦滚降频带利用率 |
| $R_B = R_{B\max}/n$（$n$ 整数） | 无 ISI 的子速率条件 |

### 考试注意事项

| 注意 | 说明 |
|------|------|
| HDB3 编码 | 严格按口诀逐节处理，V 后符号也相反极易漏 |
| 奈奎斯特带宽 | 仅指理想低通带宽 $1/(2T_b)$，不用于余弦滚降 |
| $\omega$ 与 $f$ | 奈奎斯特定则平移间隔：角频率 $\frac{2\pi}{T_b}$，频率 $\frac{1}{T_b}$ |
| 频带利用率 | $\eta = R_B/B$，单位 Baud/Hz；勿与 bps/Hz 混淆 |
| 最高无 ISI 速率 | 若 $R_{B\max}$ 可以通过，$R_{B\max}/n$（$n$ 整数）也可通过 |
