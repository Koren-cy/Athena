## 二进制数字调制原理

### 2ASK（二进制振幅键控）

用载波**幅度**传信息：发 1 → $A\cos\omega_c t$，发 0 → 0（载波断开）。又称 **OOK**（On-Off Keying，通断键控）。

$$s_{\text{2ASK}}(t) = s(t) \cdot \cos\omega_c t$$

其中 $s(t) = \sum a_n g(t - nT_b)$ 为**单极性**不归零基带信号（$a_n$ 取值 0 或 1）。

**产生方法**：
- **模拟调制法**：$s(t)$ 直接与载波相乘
- **键控法**：开关电路——$s(t)$ 控制开关接向载波（发 1）或接地（发 0）

**解调方法**：

| 方式 | 框图 | 特点 |
|------|------|------|
| **包络检波**（非相干） | BPF → 全波整流 → LPF → 抽样判决 | 无需相干载波，简单 |
| **相干解调**（同步检波） | BPF → 与 $\cos\omega_c t$ 相乘 → LPF → 抽样判决 | 需同频同相相干载波 |

包络检波信号流程：2ASK 信号（A 点有/无载波）→ 全波整流（B 点负半周翻正）→ LPF 平滑（C 点）→ 抽样判决（抽样值为高→判 1，为低→判 0）。

相干解调数学推导：$s_{\text{2ASK}}(t) \times \cos\omega_c t = s(t)\cos^2\omega_c t = \frac{1}{2}s(t)(1+\cos 2\omega_c t)$，LPF 滤除 $2\omega_c$ 项 → 输出 $\frac{1}{2}s(t)$。

若本地载波相位不同步（载波为 $\cos(\omega_c t + \phi)$），则会引入 $\cos\phi$ 的幅度衰减因子。

**带宽**：$B_{\text{2ASK}} = 2R_B$（基带 $B_{\text{基带}} = R_B$ → 调制后带宽翻倍）。使用余弦滚降时 $B = (1+\alpha)R_B$。

### 2FSK（二进制频移键控）

用两个不同**频率**传信息：发 1 → $f_1$，发 0 → $f_2$。

$$s_{\text{2FSK}}(t) = s_1(t)\cos\omega_1 t + s_2(t)\cos\omega_2 t$$

其中 $s_1(t)$ 和 $s_2(t)$ 互为反向（$s_2 = \overline{s_1}$），本质为**两路 2ASK 叠加**。

**产生**：两路振荡器 + 选通开关，$s(t)$ 控制哪路接通。

**解调**：分上下两路（各经中心频率不同的 BPF）→ 各自按 2ASK 包络检波或相干解调 → 比较判决（哪路输出大判为哪路对应的码元）。

**带宽**：$B_{\text{2FSK}} = 2R_B + |f_2 - f_1| = R_B + |f_2 - f_1| + R_B$（两路 2ASK 带宽之和=两倍基带带宽加载频差）。

### 2PSK（二进制相移键控）

用载波**绝对相位**传信息：如 0 相位 → 发 0，$\pi$ 相位 → 发 1。

$$s_{\text{2PSK}}(t) = s(t) \cdot \cos\omega_c t$$

其中 $s(t)$ 为**双极性**不归零基带信号（$a_n$ 取值 +1 或 -1）。$a_n = +1$ → $\cos\omega_c t$（0 相位）；$a_n = -1$ → $-\cos\omega_c t$（$\pi$ 相位，相当于载波反向）。

**等效形式**：$s_{\text{2PSK}}(t) = A\cos(\omega_c t + \varphi_n)$，$\varphi_n \in \{0, \pi\}$。

**相位波形画法**：画一个完整周期的正弦波 → 起点为 0 相位，1/4 周期为 $\pi/2$，半周期为 $\pi$ 相位（波形翻转至负半周），3/4 周期为 $3\pi/2$，一周终点即下一周期起点 $2\pi \equiv 0$。

**产生**：键控法——开关接两路，一路 $\cos\omega_c t$（0 相位），一路 $-\cos\omega_c t$（$\pi$ 相位），由 $s(t)$ 控制选通。

**解调**：**仅相干解调**。不能采用包络检波（因为其幅度恒定）。

> [!warning] 2PSK 解调的判决规则
> 2PSK 解调输出 = $\frac{1}{2}s(t)$。抽样值为**正** → 载波与码元同相 → 0 相位 → 判为 **0**；抽样值为**负** → 载波与码元反向 → $\pi$ 相位 → 判为 **1**。与 2ASK/2FSK 不同——正判 0、负判 1，是**反直觉**的。

> [!warning] 倒 π 现象
> 接收端载波恢复存在 180° 相位模糊 → 恢复出的本地载波可能反相 → 解调出的 0/1 **全部翻转**（原 0 变 1、原 1 变 0）。这是 2PSK 的主要缺陷，由此引入 2DPSK。

### 2DPSK（二进制差分相移键控）

用**相邻码元的相位差**传信息：$\Delta\varphi = 0$ → 发 0，$\Delta\varphi = \pi$ → 发 1。不依赖绝对相位，解决了 2PSK 的倒 π 问题。

**发送流程**：
1. 绝对码 $\{a_n\}$ → 相对码 $\{b_n\}$：$b_n = a_n \oplus b_{n-1}$（模二加/异或，$b_0$ 可设为 0 作为参考）
2. 对相对码 $\{b_n\}$ 进行绝对调相（2PSK）：$b_n=0$ → 0 相位，$b_n=1$ → $\pi$ 相位

**解调方式一：相干解调 + 码反变换**。先按 2PSK 相干解调恢复相对码 $\{b_n\}$，再 $a_n = b_n \oplus b_{n-1}$ 恢复绝对码。即使本地载波反相 → 相对码全反 → 码反变换后绝对码不变。

**解调方式二：差分相干解调**（本质非相干）。已调信号自身延迟 $T_b$ 后与自身相乘 → LPF → 抽样判决。无需本地载波，电路简单。

**功率谱**：与 2PSK 完全相同，带宽 $B = 2R_B$。

### 四种调制对比

| 对比项 | 2ASK | 2FSK | 2PSK | 2DPSK |
|------|:--:|:--:|:--:|:--:|
| 调制参量 | 幅度 | 频率 | 绝对相位 | 相对相位差 |
| $s(t)$ 类型 | 单极性 NRZ | 单极性 NRZ | 双极性 NRZ | 双极性 NRZ |
| 带宽 | $2R_B$ | $2R_B + \lvert f_2-f_1\rvert$ | $2R_B$ | $2R_B$ |
| 相干解调 | 可 | 可 | **仅** | 可（+码反变换） |
| 非相干解调 | 可（包络检波） | 可（包络检波） | 无 | 可（差分相干） |
| 功率谱载波分量 | 有（单极性有直流） | — | 无（双极性等概无直流） | 无 |

## 二进制已调信号的功率谱

### 2ASK 功率谱

$$P_{\text{2ASK}}(f) = \frac{1}{4}[P_s(f+f_c) + P_s(f-f_c)]$$

基带信号 $s(t)$ 为单极性 NRZ → $P_s(f)$ 含直流分量（$f=0$ 处冲激）→ 搬移至 $\pm f_c$ 处 → **2ASK 含载波分量**。2ASK 为**线性调制**（频谱线性搬移）。

### 2PSK / 2DPSK 功率谱

表达式与 2ASK 相同（$P(f) = \frac{1}{4}[P_s(f+f_c) + P_s(f-f_c)]$），但 $s(t)$ 为双极性 NRZ → 0/1 等概时无直流 → **2PSK/2DPSK 不含载波分量**。带宽与 2ASK 相同，$B = 2R_B$。也是线性调制。

### 2FSK 功率谱

2FSK 可看作两路 2ASK 的合成 → 功率谱为两路 2ASK 功率谱的叠加。带宽 $B = 2R_B + |f_2 - f_1|$。

> [!example] 例：2ASK/2PSK 带宽
> 二进制系统，信息速率 $R_b = 2400$ bps。
> 求：(1) 默认 NRZ 矩形脉冲时的主瓣带宽和频带利用率；
> (2) 若基带采用 $\alpha = 0.4$ 余弦滚降滤波预处理，再进行 2ASK/2PSK 调制时的带宽和频带利用率。
>
> **解**：$R_B = R_b = 2400$ 波特（二进制）。
>
> (1) 基带 NRZ 带宽 $= R_B = 2400$ Hz → 调制后 $B = 2R_B = 4800$ Hz，$\eta_b = 2400/4800 = 0.5$ bps/Hz。
>
> (2) 余弦滚降基带带宽 $= \frac{1+\alpha}{2}R_B = \frac{1.4}{2}\times2400 = 1680$ Hz → 调制后 $B = (1+\alpha)R_B = 1.4\times2400 = 3360$ Hz，$\eta_b = 2400/3360 \approx 0.71$ bps/Hz。

> [!example] 例：QPSK 带通滤波器频率范围
> 某数字微波通信系统传送 $R_b = 34$ Mbps 的数字信号，采用 QPSK 调制，载频 $f_c = 2$ GHz，基带采用 $\alpha = 0.5$ 的余弦滚降滤波。求接收端带通滤波器的频率范围。
>
> **解**：QPSK → $R_B = R_b/2 = 17$ MBaud。$B = (1+\alpha)R_B = (1+0.5)\times 17 = 25.5$ MHz。BPF 范围 = $f_c \pm B/2 = 2\text{ GHz} \pm 12.75\text{ MHz}$，即 $[1.98725\text{ GHz},\; 2.01275\text{ GHz}]$。

> [!example] 例：电话信道 QPSK/8PSK
> 某电话信道可用传输频带为 600~3000 Hz，载波频率取 1800 Hz（中点）。
> 求：(1) 采用 $\alpha = 1$ 的余弦滚降基带信号进行 QPSK 调制时的最大信息速率；
> (2) 采用 $\alpha = 0.5$ 的余弦滚降基带信号进行 8PSK 调制时的最大信息速率。
>
> **解**：可用带宽 $B_{\text{通道}} = 3000 - 600 = 2400$ Hz。
>
> (1) $\alpha = 1$ 时 $B = 2R_B$（升余弦），$2R_B = 2400$ → $R_B = 1200$ 波特。QPSK（每码元 2 bit）→ $R_b = 2400$ bps。
>
> (2) $\alpha = 0.5$ 时 $B = (1+0.5)R_B = 1.5R_B = 2400$ → $R_B = 1600$ 波特。8PSK（每码元 3 bit）→ $R_b = 4800$ bps。

## 二进制调制的抗噪声性能

### 分析模型

已调信号经恒参信道（乘常数 $k$）+ AWGN → BPF（传信滤噪）→ 解调器 → 抽样判决。

BPF 输出噪声：$n(t) = n_c(t)\cos\omega_c t - n_s(t)\sin\omega_c t$（窄带高斯噪声），$n_c$、$n_s$ 为零均值高斯变量，方差 $\sigma_n^2 = n_0 B$。

### 2ASK 相干解调误码率推导

发 1 时 BPF 输出：$y(t) = a\cos\omega_c t + n(t) = [a + n_c(t)]\cos\omega_c t - n_s(t)\sin\omega_c t$

发 0 时 BPF 输出：$y(t) = n(t) = n_c(t)\cos\omega_c t - n_s(t)\sin\omega_c t$

经 $\times 2\cos\omega_c t$（乘 2 是为了抵消倍角公式的 1/2）→ LPF 后：

发 1 时 $x(t) = a + n_c(t)$，发 0 时 $x(t) = n_c(t)$。$n_c \sim N(0, \sigma_n^2)$。

抽样值 $x$ 的条件概率密度：
- 发 1：$f_1(x) = \frac{1}{\sqrt{2\pi}\sigma_n}e^{-(x-a)^2/(2\sigma_n^2)}$
- 发 0：$f_0(x) = \frac{1}{\sqrt{2\pi}\sigma_n}e^{-x^2/(2\sigma_n^2)}$

最佳判决门限为 $a/2$。等概时总误码率：

$$P_e = \frac{1}{2}\mathrm{erfc}\!\left(\frac{a}{2\sqrt{2}\sigma_n}\right)$$

令 $r = \frac{a^2/2}{\sigma_n^2}$（BPF 输出信噪比）：

$$P_e = \frac{1}{2}\mathrm{erfc}\!\left(\sqrt{\frac{r}{4}}\right)$$

### 误码率公式汇总（4211 / 421）

$r$ 为接收端 BPF 输出信噪比。记忆规律：相干列分母 4→2→1→1（4211），非相干列分母 4→2→1（421）。

| 调制方式 | 相干解调 | 非相干解调 |
|------|------|------|
| 2ASK | $\frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{4}}$ | $\frac{1}{2}e^{-r/4}$ |
| 2FSK | $\frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{2}}$ | $\frac{1}{2}e^{-r/2}$ |
| 2PSK | $\frac{1}{2}\mathrm{erfc}\sqrt{r}$ | — |
| 2DPSK | $\mathrm{erfc}\sqrt{r}$（**无 1/2**） | $\frac{1}{2}e^{-r}$（差分相干解调） |

> [!tip] 记忆要点
> 所有公式有 1/2 系数，**唯独 2DPSK 相干解调没有 1/2**。非相干列：指数 $e^{-r/\text{分母}}$。

$\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$（$x > 2$），用于数值计算。

### 信噪比 $r$ 的含义

$r = \frac{S}{N}$：$S$ 为接收端 BPF 输出信号功率，$N = n_0 B$ 为 BPF 输出噪声功率。注意区分"信道输出端信噪比"与"BPF 输出信噪比"——经过 BPF 后噪声带宽缩小，信噪比得以提升。

> [!example] 例：2FSK 误码率（含 SNR 换算）
> 采用 2FSK 方式在噪声等效带宽为 2400 Hz 的信道上传输二进制数字。2FSK 信号频率 $f_1, f_2$，码元速率 $R_B = 300$ 波特。接收端输入（信道输出端）信噪比为 6 dB。
> 求：(1) 2FSK 信号带宽；(2) 包络检波时的误码率；(3) 相干解调时的误码率。
>
> **解**：
> (1) 2FSK 带宽 $B_{\text{2FSK}} = 2R_B + |f_2 - f_1|$。已知 $|f_2 - f_1| = 600$ Hz → $B = 2\times300 + 600 = 1200$ Hz。
>
> (2)(3) 信道输出 SNR = 6 dB → $r_{\text{信道}} = 10^{0.6} \approx 3.98$。BPF 带宽 $B_{\text{BPF}} = 2R_B = 600$ Hz，而信道等效噪声带宽 2400 Hz → 噪声功率缩小 $4$ 倍 → BPF 输出 $r = 3.98 \times 4 \approx 16$。代入 $P_{e,\text{非相干}} = \frac{1}{2}e^{-r/2}$、$P_{e,\text{相干}} = \frac{1}{2}\mathrm{erfc}\sqrt{r/2}$ 计算即可。

> [!example] 例：2DPSK 反向求信噪比
> 采用 2DPSK 方式传输二进制数字信息，码元速率 $R_B = 300$ 波特。信道中高斯白噪声单边功率谱密度为 $n_0$。要求误码率不大于 $10^{-4}$。
> 求：(1) 差分相干解调时所需信噪比 $r$；
> (2) 相干解调+码反变换时所需信噪比 $r$。
>
> **解**：
>
> (1) 差分相干（非相干）：$P_e = \frac{1}{2}e^{-r} \leq 10^{-4}$ → $e^{-r} = 2\times 10^{-4}$ → $r = -\ln(2\times 10^{-4}) \approx 8.52$。
>
> (2) 相干+码反变换：$P_e = \mathrm{erfc}\sqrt{r}$（无 $\frac{1}{2}$）≤ $10^{-4}$ → 代入 $\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$ 得超越方程。令初值 $r=10$，卡西欧 SOLVE 迭代 → $r \approx 7.56$。

## 性能比较

在相同 $R_B$、$r$、解调方式下：

| 对比项 | 2ASK | 2FSK | 2PSK | 2DPSK |
|------|:--:|:--:|:--:|:--:|
| 带宽（$R_B$ 的倍数） | 2 | $2 + |f_2-f_1|/R_B$ | 2 | 2 |
| 误码率（同 $r$） | 最差 | 较差 | **最好** | 次好 |
| 解调复杂度 | 简单 | 较复杂 | 需相干 | 可非相干 |
| 主要缺陷 | 抗噪声差 | 带宽大 | 倒 π | 略复杂 |

**综合排名**（同条件下）：2PSK > 2DPSK > 2FSK > 2ASK。

## 多进制数字调制

### 概述——为什么要用多进制

$M$ 进制码元携带 $\log_2 M$ 比特。$R_B = R_b / \log_2 M$。

**优点**：给定 $R_b$ 时增大 $M$ → $R_B$ 减小 → 带宽减小，频带利用率提高；给定 $R_B$ 时增大 $M$ → $R_b$ 增大。

**代价**：信号矢量增多 → 相邻信号点距离减小 → 判决范围缩小 → 噪声容限降低 → 误码率增大 + 系统复杂度增加。

以 2PSK vs 4PSK 为例：2PSK 仅 2 个信号矢量（夹角 180°），4PSK 有 4 个矢量（夹角 90°）→ 4PSK 判决范围更小。

### MASK（多进制振幅键控）

$M$ 种载波幅度，每个码元 $\log_2 M$ 比特。$s_{\text{MASK}}(t) = s(t)\cos\omega_c t$，$s(t)$ 为多电平基带信号（$a_n \in \{0, 1, \dots, M-1\}$）。

产生：二进制基带信号 → 2/M 电平转换 → 成型滤波 → × 载波。

带宽：$B_{\text{MASK}} = 2R_B$，与 $M$ **无关**（仅取决于 $R_B$）。

### MFSK（多进制频移键控）

$M$ 种频率，各频率相互正交。带宽随 $M$ 增大而显著增大。

### MPSK / MDPSK（多进制相移键控）

$M$ 种相位，信号矢量均匀分布在圆周上。4PSK 又称 **QPSK**（Quadrature PSK）。

**MPSK 带宽**：$B = (1+\alpha)R_B$，与 $M$ **无关**。但 $M$ 增大时每个码元携带更多比特 → 在相同带宽下信息速率更高。

### QAM（正交振幅调制）

振幅与相位**联合**键控，星座图为二维平面上的点阵。比单纯 MPSK 信号点间距更大 → 抗噪声性能更优。常用：16QAM、64QAM。

**设计思想**：不增大发射功率，而是重新安排星座点位置来增大信号点间距。

## 现代调制方式简介

### OFDM（正交频分复用）

将高速串行数据划分为 $N$ 路并行低速数据，分别调制到正交子载波上 → 每个子信道码长变大、带宽减小 → 抗多径，频带利用率高。

### MSK（最小频移键控）

2FSK 的改进：$|f_2 - f_1| = R_B/2$（最小频率间隔保证正交），相位连续变化，功率谱旁瓣衰减快。

## 本章小结

### 基本概念

| 知识点 | 要点 |
|------|------|
| 2ASK | $s(t)\cos\omega_c t$，$s(t)$ 单极性 NRZ，$B = 2R_B$，OOK，含载波分量 |
| 2FSK | 两路 2ASK 叠加，$B = 2R_B + \lvert f_2-f_1\rvert$，非相干解调常用 |
| 2PSK | $s(t)\cos\omega_c t$，$s(t)$ 双极性 NRZ，仅相干解调；<br>正判 0、负判 1；<br>倒 π 现象 |
| 2DPSK | 绝对码 → 相对码 → 绝对调相；解决倒 π；<br>差分相干：信号延迟 $T_b$ 后与自身相乘 |
| 倒 π 现象 | 载波恢复 180° 模糊导致 0/1 全反；<br>2DPSK 通过差分编码解决 |
| 功率谱 | 2ASK/2PSK/2DPSK 均为线性调制；<br>2ASK 含载波、2PSK/2DPSK 等概无载波 |
| 4211 / 421 | 相干列 erfc 分母 4→2→1→1；<br>非相干列 $e^{-r/\text{分母}}$ 分母 4→2→1 |
| 2DPSK 相干无 1/2 | $P_e = \mathrm{erfc}\sqrt{r}$ |
| MASK/MPSK 带宽 | 与进制 $M$ 无关，仅取决于 $R_B$ 和 $\alpha$ |
| QAM | 振幅+相位联合键控，星座图二维布局，比 MPSK 噪声容限大 |
| OFDM | 串行→N 路并行，正交子载波，抗多径 |
| MSK | $\vert f_2-f_1\vert = R_B/2$，相位连续，旁瓣衰减快 |

### 核心公式

| 公式 | 说明 |
|------|------|
| $B_{\text{2ASK}} = B_{\text{2PSK}} = 2R_B$ | 二进制 ASK/PSK 带宽 |
| $B_{\text{2FSK}} = 2R_B + \lvert f_2-f_1\rvert$ | 2FSK 带宽 |
| $B = (1+\alpha)R_B$ | 余弦滚降时的带通信号带宽 |
| $b_n = a_n \oplus b_{n-1}$ | 绝对码 → 相对码（模二加） |
| $a_n = b_n \oplus b_{n-1}$ | 相对码 → 绝对码（码反变换） |
| $P_{e,\text{2ASK}} = \frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{4}}$ | 2ASK 相干误码率 |
| $P_{e,\text{2FSK}} = \frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{2}}$ | 2FSK 相干误码率 |
| $P_{e,\text{2PSK}} = \frac{1}{2}\mathrm{erfc}\sqrt{r}$ | 2PSK 相干误码率 |
| $P_{e,\text{2DPSK}} = \mathrm{erfc}\sqrt{r}$ | 2DPSK 相干误码率（无 $\frac{1}{2}$） |
| $P_{e,\text{2DPSK}} = \frac{1}{2}e^{-r}$ | 2DPSK 差分相干误码率 |
| $\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$ | erfc 近似（$x>2$） |

### 注意事项

| 注意 | 说明 |
|------|------|
| 2PSK 判决反直觉 | 抽样为正 → 判 0；抽样为负 → 判 1（看的是相位比较关系） |
| 2DPSK 相干公式无 1/2 | $P_e = \mathrm{erfc}\sqrt{r}$，极易漏写 |
| 信噪比 $r$ 的位置 | 是 BPF 输出信噪比，非信道输出；经 BPF 带宽缩小后 $r$ 会提升 |
| 2PSK 仅相干解调 | 无非相干方式，表格中以横线表示 |
| 多进制不改变 ASK/PSK 带宽 | $B$ 仅取决于 $R_B$ 和 $\alpha$，但增大 $M$ 可提高 $R_b$ |
| 绝对码 ↔ 相对码 | 双向转换均为模二加：$b_n = a_n \oplus b_{n-1}$，$a_n = b_n \oplus b_{n-1}$ |
| 2ASK 含载波分量 | 单极性有直流 → 搬移到 $f_c$ → 含载波分量；2PSK 双极性等概无载波 |
