## 二进制数字调制原理

### 2ASK

用载波幅度传信息：发 1 → $A\cos\omega_c t$，发 0 → 0。又称 OOK。

$$s_{\text{2ASK}}(t) = s(t) \cdot \cos\omega_c t$$

其中 $s(t)$ 为单极性不归零基带信号（取值 0 或 1）。

产生：数字键控法（开关切换载波/地）、模拟相乘法。

解调：相干解调（× $\cos\omega_c t$ → LPF → 判决）、包络检波（非相干）。

功率谱：$s(t)$ 的功率谱左搬右搬乘 $1/4$。$s(t)$ 为单极性 → 有直流分量（搬到 $\pm f_c$ 处有冲激）。

**带宽**：$B_{\text{2ASK}} = 2R_B$（默认单极性 NRZ 基带信号，$B_{\text{基带}} = R_B$）。一般结论：**2ASK 带宽 = 基带信号带宽的两倍**。使用余弦滚降时 $B = (1+\alpha)R_B$。

### 2FSK

用两个不同频率传信息：发 1 → $f_1$，发 0 → $f_2$。

$$s_{\text{2FSK}}(t) = s_1(t)\cos\omega_1 t + s_2(t)\cos\omega_2 t$$

其中 $s_1(t)$ 和 $s_2(t)$ 互为反向（$s_2 = \overline{s_1}$），本质为两路 2ASK 叠加。

产生：两路振荡器 + 选通开关，叠加输出。

解调：分上下两路（不同中心频率的 BPF）→ 各自按 2ASK 解调 → 判决。

**带宽**：$B_{\text{2FSK}} = 2R_B + |f_2 - f_1|$（两倍基带带宽加载频差）。

### 2PSK

用载波**绝对相位**传信息：如 0 相位 → 0，$\pi$ 相位 → 1。

$$s_{\text{2PSK}}(t) = s(t) \cdot \cos\omega_c t$$

其中 $s(t)$ 为**双极性**不归零基带信号（取值 +1 或 -1）。

解调：**仅有相干解调**（× $\cos\omega_c t$ → LPF → 判决）。

> [!warning] 倒 π 现象
> 接收端载波恢复存在 180° 相位模糊 → 恢复出的本地载波可能反相 → 解调出的 0/1 全部翻转。这是 2PSK 的致命缺陷，由此引入 2DPSK。简答题常考：解释倒 π 现象。

功率谱：无直流分量（$s(t)$ 双极性），带宽同 2ASK = $2R_B$。

### 2DPSK

用**相邻码元的相位差**传信息：$\Delta\phi = 0$ → 0，$\Delta\phi = \pi$ → 1。

流程：绝对码 $\{a_n\}$ → 相对码 $\{b_n\}$（$b_n = a_n \oplus b_{n-1}$，异或/模二加）→ 对相对码进行绝对调相（2PSK）→ 得 2DPSK 信号。

解调方式一：**相干解调 + 码反变换**。先按 2PSK 相干解调得相对码，再 $a_n = b_n \oplus b_{n-1}$ 恢复绝对码。即使本地载波反相，相对码全反，码反变换后绝对码不变——解决了倒 π。

解调方式二：**差分相干解调**（本质非相干）。信号自身延迟 $T_b$ 后与自身相乘 → LPF → 判决。无需本地载波。

功率谱：与 2PSK 完全相同，带宽相同。

### 四种调制对比

| 对比项 | 2ASK | 2FSK | 2PSK | 2DPSK |
|------|:--:|:--:|:--:|:--:|
| 调制参量 | 幅度 | 频率 | 绝对相位 | 相对相位差 |
| $s(t)$ 类型 | 单极性 NRZ | 单极性 NRZ | 双极性 NRZ | 双极性 NRZ |
| 带宽 | $2R_B$ | $2R_B + \lvert f_2-f_1\rvert$ | $2R_B$ | $2R_B$ |
| 相干解调 | 可 | 可 | **仅** | 可（+码反变换） |
| 非相干解调 | 可 | 可 | 无 | 可（差分相干） |


> [!example] 例：2ASK 带宽
> $R_b = 2400$ bps（二进制 → $R_B = 2400$ 波特）。
>
> **解**：
> 默认情况：$B = 2R_B = 4800$ Hz，$\eta = 2400/4800 = 0.5$ bps/Hz。
>
> $\alpha = 0.4$ 余弦滚降：基带 $B = \frac{1+\alpha}{2}R_B = 0.7 \times 2400 = 1680$ Hz，调制后 $B = 2 \times 1680 = 3360$ Hz。$\eta = 2400/3360 \approx 0.71$ bps/Hz。

> [!example] 例：2PSK 带宽
> 2PSK 带宽与 2ASK 相同 = $2R_B$。$\alpha = 0.4$ 时 $B = 3360$ Hz。
>
> **解**：
> 第三问：带宽不变，信息速率增 3 倍 → 将 2PSK 升级为 8PSK（多进制 PSK 不改变带宽，每个码元从 1 bit 增至 3 bit）。


## 二进制调制的抗噪声性能

### 误码率公式表

$r$ 为接收端 BPF 输出信噪比。公式规律：**4211 / 421**。

| 调制方式 | 相干解调 | 非相干解调 |
|------|------|------|
| 2ASK | $\frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{4}}$ | $\frac{1}{2}e^{-r/4}$ |
| 2FSK | $\frac{1}{2}\mathrm{erfc}\sqrt{\frac{r}{2}}$ | $\frac{1}{2}e^{-r/2}$ |
| 2PSK | $\frac{1}{2}\mathrm{erfc}\sqrt{r}$ | — |
| 2DPSK | $\mathrm{erfc}\sqrt{r}$（**无 1/2**） | $\frac{1}{2}e^{-r}$ |

> [!tip] 记忆规律
> 相干列：erfc 开根号，分母依次 4→2→1→1（4211）。非相干列：$e^{-r/\text{分母}}$，分母依次 4→2→1（421）。所有公式有 1/2 系数，**唯独 2DPSK 相干解调没有 1/2**。
>
> $\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$（$x > 2$），用于数值计算。

### 信噪比 $r$ 的含义

$r = \frac{S}{N}$，$S$ 为接收端 BPF 输出的信号功率，$N = n_0 B$ 为 BPF 输出噪声功率。注意区分题目给的"信道输出端信噪比"与"BPF 输出信噪比"——经过 BPF 后噪声带宽缩小，信噪比会提升。

> [!example] 例：2ASK 误码率
> $R_B = 4.8 \times 10^6$ 波特，$A = 1\text{mV}$，$n_0$ 已知。$B = 2R_B$，$N = n_0 B$，$r = \frac{A^2/2}{N} \approx 26$。
>
> **解**：
> 相干：$P_e = \frac{1}{2}\mathrm{erfc}\sqrt{26/4}$，代入近似公式。非相干：$P_e = \frac{1}{2}e^{-26/4}$。

> [!example] 例：2FSK 误码率
> $f_1, f_2$ 已知，$R_B = 300$，信道输出 SNR = 6dB。
>
> **解**：
> $B_{\text{2FSK}} = 2 \times 300 + |f_2 - f_1| = 1200$ Hz。
>
> 信道输出 SNR = 6dB → $r_{\text{信道}} \approx 4$。题目给等效噪声带宽 2400 Hz，BPF 带宽 600 Hz → 噪声功率缩小 4 倍 → BPF 输出 $r = 4 \times 4 = 16$。代入公式即可。

> [!example] 例：2DPSK 反向求功率
> $R_B = 300$ 波特，$n_0$ 已知，要求 $P_e \leq 10^{-4}$，反求信号功率。
>
> **解**：
> 差分相干（非相干）：$P_e = \frac{1}{2}e^{-r} \leq 10^{-4}$ → 取 ln → $r \approx 8.52$ → $S = r \cdot N$。
>
> 相干解调+码反变换：$P_e = \mathrm{erfc}\sqrt{r}$（**无 1/2**）。代入近似公式后为超越方程，需用计算器 Newton 迭代求解 → $r \approx 7.56$。

> [!example] 例：MPSK 带宽
> $R_b = 4800$ bps，$\alpha = 1$。4PSK：每码元 2 bit → $R_B = 2400$ → $B = (1+1)R_B = 4800$ Hz。8PSK：每码元 3 bit → $R_B = 1600$ → $B = 3200$ Hz。

> [!example] 例：8ASK 改 2ASK
> 8ASK：$R_B = 200$ → $B = 400$ Hz，$R_b = 600$ bps。改为 2ASK 保持 $R_b = 600$ → $R_B = 600$ → $B = 1200$ Hz。

> [!example] 例：2PSK/2DPSK 波形与框图
> 给绝对码 10010110 → 画 2PSK 波形（0 相→1，$\pi$ 相→0）→ 求相对码（$b_n = a_n \oplus b_{n-1}$，参考 0）→ 对相对码绝对调相得 2DPSK 波形。画两种解调框图。

> [!example] 例：QPSK 带通滤波器频率范围
> $R_b = 34\text{Mbps}$，QPSK → $R_B = 17\text{M}$。$\alpha = 0.5$ → $B = (1+0.5)R_B = 25.5\text{MHz}$。$f_c = 2\text{GHz}$，BPF 范围：$2\text{G} \pm 12.75\text{M}$。

> [!example] 例：电话信道 QPSK/8PSK
> 可用频带 600~3000 Hz → $B_{\text{通道}} = 2400$ Hz。
>
> **解**：
> $\alpha = 1$，QPSK：$B = (1+1)R_B = 2400$ → $R_B = 1200$ → $R_b = 2400$ bps。
>
> $\alpha = 0.5$，8PSK：$B = (1+0.5)R_B = 2400$ → $R_B = 1600$ → $R_b = 4800$ bps。

## 性能比较

| 对比项 | 2ASK | 2FSK | 2PSK | 2DPSK |
|------|:--:|:--:|:--:|:--:|
| 带宽（$R_B$ 的倍数） | 2 | $2 + \Delta f/R_B$ | 2 | 2 |
| 误码率（同 $r$） | 最差 | 较差 | 最好 | 次好 |
| 解调复杂度 | 简单 | 较复杂 | 需相干 | 可非相干 |
| 主要缺陷 | 抗噪声差 | 带宽大 | 倒 π | 略复杂 |

## 多进制数字调制

目的：提高频带利用率（每个码元携带 $\log_2 M$ 比特）。

- MASK：$M$ 种振幅。$B$ 与 2ASK 相同。
- MFSK：$M$ 种频率。
- MPSK：$M$ 种相位。4PSK 又称 QPSK（四个矢量相互正交）。
- MDPSK：相对相位差。
- QAM：振幅与相位联合键控，星座图表示。

关键结论：MASK 和 MPSK 的带宽与进制数 $M$ 无关，仅取决于 $R_B$ 和滚降系数。


## 本章小结

### 基本概念

| 知识点 | 要点 |
|--------|------|
| 2ASK | $s(t)\cos\omega_c t$，$s(t)$ 单极性 NRZ，$B = 2R_B$ |
| 2FSK | 两路 2ASK 叠加，$B = 2R_B + \lvert f_2-f_1\rvert$ |
| 2PSK | $s(t)\cos\omega_c t$，$s(t)$ 双极性 NRZ，仅相干解调，有倒 π 现象 |
| 2DPSK | 绝对码→相对码→绝对调相，解决倒 π |
| 倒 π 现象 | 载波恢复 180° 模糊导致 0/1 全反 |
| 差分相干解调 | 2DPSK 信号延迟 $T_b$ 后与自身相乘（非相干） |
| 4211 / 421 | 误码率公式记忆规律 |
| MPSK 带宽 | 与进制数 $M$ 无关，$B = (1+\alpha)R_B$ |

> [!info] 与最佳接收的关系
> 关于如何设计接收机使误码率最低，详见[[数字信号的最佳接收]]。

### 核心公式

| 公式 | 说明 |
|------|------|
| $B = 2R_B$ | 2ASK/2PSK/2DPSK 默认带宽 |
| $B = 2R_B + \lvert f_2-f_1\rvert$ | 2FSK 带宽 |
| $B = (1+\alpha)R_B$ | 余弦滚降时的带通信号带宽 |
| $b_n = a_n \oplus b_{n-1}$ | 绝对码→相对码（异或） |
| $P_{e,\text{2PSK}} = \frac{1}{2}\mathrm{erfc}\sqrt{r}$ | 2PSK 相干误码率 |
| $P_{e,\text{2DPSK}} = \frac{1}{2}e^{-r}$ | 2DPSK 差分相干误码率 |

### 考试注意事项

| 注意 | 说明 |
|------|------|
| 2DPSK 相干公式无 1/2 | $P_e = \mathrm{erfc}\sqrt{r}$，极易漏写 |
| 信噪比 $r$ 的位置 | 是 BPF 输出信噪比，非信道输出；经过 BPF 带宽缩小后 $r$ 会提升 |
| 2PSK 仅相干解调 | 无非相干方式，表格打斜杠 |
| 多进制不改变 ASK/PSK 带宽 | 带宽仅取决于 $R_B$ 和 $\alpha$ |
| 绝对码 ↔ 相对码 | 用异或（模二加），$b_n = a_n \oplus b_{n-1}$ |
