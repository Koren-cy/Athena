# 通信原理 EP5 模拟调制系统

> [!abstract] 本章定位
> 本章讨论模拟调制的原理和抗噪声性能。幅度调制四种（AM、DSB、SSB、VSB），角度调制两种（FM、PM）。重点：各调制的表达式、带宽、功率、调制制度增益，以及卡森公式。

## 预备知识

消息信号用 $m(t)$ 表示，默认不含直流分量。$m(t)$ 的功率为 $\overline{m^2(t)}$。$m(t)$ 乘 $\cos\omega_c t$（调制）后功率为 $\frac{1}{2}\overline{m^2(t)}$。

调制的通用公式：$y = kx + b$。$b$ 是载波被调制的那个参量的原始值（振幅 $A_0$、角频率 $\omega_c$ 或相位），$x$ 是调制信号 $m(t)$，$k$ 是灵敏度。

## 幅度调制

### AM 普通调幅

用 $m(t)$ 控制载波振幅。$y = kx + b$ 中 $b = A_0$，$x = m(t)$，取 $k = 1$：

$$s_{\text{AM}}(t) = [A_0 + m(t)]\cos\omega_c t$$

频谱：$m(t)$ 的频谱 $M(\omega)$ 左搬右搬乘 $1/2$，加上载波的冲激 $\pi A_0[\delta(\omega+\omega_c) + \delta(\omega-\omega_c)]$。

$$B_{\text{AM}} = 2f_m$$

若 $m(t) = A_m\cos\omega_m t$（单音调制），定义调幅系数 $m = A_m / A_0$。为防止过调制（包络失真），$m \leq 1$ 即 $A_0 \geq A_m$。

功率分配（单音，单位电阻）：

| 功率 | 表达式 |
|------|--------|
| 载波功率 $P_c$ | $A_0^2/2$ |
| 边带功率 $P_s$ | $A_m^2/4 = m^2 A_0^2/4$ |
| 总功率 | $P_c + P_s$ |

调制效率 $\eta = P_s / (P_c + P_s) \leq 1/3$（$m=1$ 时取等号）。AM 效率低，大部分功率浪费在载波上。

解调：**包络检波**（仅 AM 可用）。利用二极管 + RC 电路提取包络，再用隔直电容去掉 $A_0$ 得到 $m(t)$。

### DSB 抑制载波双边带

去掉 AM 中的载波分量，直接传 $m(t)\cos\omega_c t$：

$$s_{\text{DSB}}(t) = m(t)\cos\omega_c t$$

频谱：$M(\omega)$ 左搬右搬乘 $1/2$，无载波冲激。$B_{\text{DSB}} = 2f_m$。效率 100%。

缺点：不能用包络检波，必须用**相干解调**。

### SSB 单边带

DSB 的上下边带对称，只传一个即可，带宽减半：$B_{\text{SSB}} = f_m$。

产生方法：
- **滤波法**：先产生 DSB，再用理想滤波器保留一个边带。
- **相移法**：利用希尔伯特变换。$m(t)$ 经希尔伯特滤波器（幅度不变，所有频率移相 $-\pi/2$）得 $\hat{m}(t)$。$\cos\omega t$ 的希尔伯特变换为 $\sin\omega t$。

$$s_{\text{SSB}}(t) = \frac{1}{2}m(t)\cos\omega_c t \mp \frac{1}{2}\hat{m}(t)\sin\omega_c t$$

减号对应上边带，加号对应下边带。

优点：节省载波功率 + 节省一半带宽。缺点：设备复杂，必须相干解调。

### VSB 残留边带

介于 DSB 和 SSB 之间，滤波器不需要理想陡峭，保留一个边带的大部和另一边带的残留。了解即可。

### 相干解调

适用于所有幅度调制。步骤：已调信号 $\times \cos\omega_c t$ → 低通滤波。

原理：已调信号的频谱在 $\pm\omega_c$ 处，乘 $\cos\omega_c t$ 相当于再次左搬右搬，低频处恢复出 $M(\omega)$，高频分量（$2\omega_c$）被 LPF 滤除。相干解调要求本地载波与发送载波**严格同频同相**。


> [!example] 例：AM 信号功率计算
> 发射 AM 信号，负载 50Ω。未调载波峰值 100V，载频 50kHz。用 1kHz 余弦调制，调制度 $m = 60\%$。
> **解**：
>
> $A_0 = 100\text{V}$，$m = A_m/A_0 = 0.6$ → $A_m = 60\text{V}$
>
> $s_{\text{AM}}(t) = (100 + 60\cos 2\pi\cdot10^3 t)\cos 2\pi\cdot5\times10^4 t$
>
> 载波功率：$P_c = \frac{(100)^2}{2 \times 50} = 100\text{W}$
>
> 边带功率（积化和差得幅度 30V 的上下边带）：$P_s = 2 \times \frac{30^2}{2 \times 50} = 18\text{W}$
>
> 总功率 $= 118\text{W}$，效率 $= 18/118 \approx 15.3\%$
>
> $m=0$ 时纯载波，$P = P_c = 100\text{W}$。

## 幅度调制的抗噪声性能

### 分析模型

已调信号 $s_m(t)$ 经信道加性高斯白噪声 → 接收端 BPF（带宽 = 已调信号带宽，滤除带外噪声）→ 解调器（相干解调或包络检波）→ 输出。

BPF 输出噪声为窄带高斯噪声：$n(t) = n_c(t)\cos\omega_c t - n_s(t)\sin\omega_c t$，功率 $N_i = n_0 B$（$n_0$ 为单边功率谱密度）。

两个性能指标：

$$\text{输出信噪比} = \frac{S_o}{N_o}, \quad \text{调制制度增益} \; G = \frac{S_o/N_o}{S_i/N_i}$$

### 相干解调的关键规律

信号和噪声经 $\times\cos\omega_c t$ → LPF 后，**只保留含 $\cos\omega_c t$ 项的包络，并乘 $1/2$**：

| 输入 | 输出（LPF 后） |
|------|------|
| $m(t)\cos\omega_c t$（DSB） | $\frac{1}{2}m(t)$ |
| SSB 信号 | $\frac{1}{4}m(t)$ |
| 窄带噪声 | $\frac{1}{2}n_c(t)$ |

### DSB 性能

$S_i = \frac{1}{2}\overline{m^2(t)}$，$N_i = n_0 B = 2n_0 f_m$，$S_o = \frac{1}{4}\overline{m^2(t)}$，$N_o = \frac{1}{4}n_0 B$

$$G_{\text{DSB}} = 2$$

### SSB 性能

$S_i = \frac{1}{4}\overline{m^2(t)}$，$S_o = \frac{1}{16}\overline{m^2(t)}$，噪声同 DSB

$$G_{\text{SSB}} = 1$$

> [!tip] 注意
> $G_{\text{DSB}} = 2$ 不代表 DSB 抗噪声能力强于 SSB——两者输出信噪比实际相同，因为 SSB 的输入信噪比计算中 $S_i$ 和 $N_i$ 都减半了。
> 
> 噪声模型与分析的数学基础详见[[随机过程]]。

### AM 包络检波性能

$S_i = \frac{1}{2}A_0^2 + \frac{1}{2}\overline{m^2(t)}$，$S_o = \overline{m^2(t)}$，噪声全通（$N_o = N_i = n_0 B$）

$$G_{\text{AM}} = \frac{2\overline{m^2(t)}}{A_0^2 + \overline{m^2(t)}} < 1$$

包络检波对噪声无抑制能力，调制制度增益小于 1。

---

> [!example] 例：DSB 系统，已知 $m(t)$ 功率谱求性能
> DSB 调制，接收端输入噪声为 $n_0/2$ 的高斯白噪声。$m(t)$ 功率谱在 $[-f_m, f_m]$ 呈三角形（$f=0$ 为 0，$f=\pm f_m$ 为 $\alpha$）。
>
> **解**：
> **输入信号功率**：$S_i = \frac{1}{2}\overline{m^2(t)} = \frac{1}{2} \times 2 \times \frac{1}{2}f_m \alpha = \frac{1}{2}f_m\alpha$
>
> **输出信号功率**（相干解调）：$S_o = \frac{1}{4}\overline{m^2(t)} = \frac{1}{4}f_m\alpha$
>
> **输出噪声功率**：$N_o = \frac{1}{4}n_0 B = \frac{1}{4}n_0 \cdot 2f_m = \frac{1}{2}n_0 f_m$
>
> **输出信噪比**：$\frac{S_o}{N_o} = \frac{\alpha}{2n_0}$

> [!example] 例：DSB/SSB，已知输出 SNR 求发射功率
> 输出信噪比 $20\text{dB}$（即 $S_o/N_o = 100$），$N_o = 10^{-9}\text{W}$，发射到接收传输损耗 $100\text{dB}$（功率衰减 $10^{10}$ 倍）。
>
> **解**：
> **DSB**：$G=2$ → $S_i/N_i = 50$。$N_o = \frac{1}{4}N_i$ → $N_i = 4 \times 10^{-9}$。$S_i = 50 \times 4 \times 10^{-9} = 2 \times 10^{-7}$。发射功率 $= S_i \times 10^{10} = 2 \times 10^3\text{W}$。
>
> **SSB**：$G=1$ → $S_i/N_i = 100$。$S_i = 100 \times 4 \times 10^{-9} = 4 \times 10^{-7}$。发射功率 $= 4 \times 10^3\text{W}$。

> [!example] 例：AM 包络检波性能
> AM 系统，$n_0$ 已知，$m(t)$ 带宽 5kHz，载频 100kHz。解调输入端边带功率 1W，载波功率 4W。
> **解**：
>
> $B_{\text{AM}} = 10\text{kHz}$，$N_i = N_o = n_0 \times 10^4$
>
> $S_i = P_c + P_s = 4 + 1 = 5\text{W}$ → 输入 SNR $= 5 / N_i$
>
> $\frac{1}{2}\overline{m^2(t)} = P_s = 1$ → $\overline{m^2(t)} = 2\text{W}$ → $S_o = 2\text{W}$
>
> 输出 SNR $= 2 / N_i$，$G = (2/N_i) / (5/N_i) = 0.4$

## 角度调制

### 相位与频率的关系

$\cos[\theta(t)]$ 中，$\theta(t)$ 的整体称为**瞬时相位**。瞬时角频率 = 相位的导数：$\omega(t) = d\theta(t)/dt$。相位 = 角频率的积分。

**调频必调相，调相必调频**——二者统称角度调制。

### FM 频率调制

用 $m(t)$ 控制载波频率。$y = kx + b$ 中 $b = \omega_c$（载波角频率），$k = k_f$（调频灵敏度，单位 Hz/V 须乘 $2\pi$ 转为角频率）：

$$\omega(t) = \omega_c + k_f \cdot m(t)$$

积分得相位，代入得 FM 信号：
$$s_{\text{FM}}(t) = A\cos\left[\omega_c t + k_f \int_{-\infty}^t m(\tau)d\tau\right]$$

若 $m(t) = A_m\cos\omega_m t$（单音）：

$$s_{\text{FM}}(t) = A\cos\left[\omega_c t + m_f \sin\omega_m t\right]$$

调频指数：$m_f = \frac{k_f A_m}{\omega_m} = \frac{\Delta f_{\max}}{f_m} = \text{最大相偏}$

最大频偏：$\Delta f_{\max} = k_f A_m$

> [!warning] 卡森公式
> $$B_{\text{FM}} = 2(m_f + 1)f_m = 2(\Delta f_{\max} + f_m)$$

FM 信号功率 $= A^2/2$，等于载波功率。

### PM 相位调制

用 $m(t)$ 控制载波相位。$y = kx + b$ 中 $b = \omega_c t$（载波相位），$k = k_p$：

$$s_{\text{PM}}(t) = A\cos\left[\omega_c t + k_p \cdot m(t)\right]$$

若单音调制：$s_{\text{PM}}(t) = A\cos\left[\omega_c t + m_p \cos\omega_m t\right]$

调相指数：$m_p = k_p A_m = \text{最大相偏}$

PM 带宽同样用卡森公式：$B_{\text{PM}} = 2(m_p + 1)f_m$。功率 $= A^2/2$。

> [!tip] 核心记忆
> FM 和 PM 的 $m_f$、$m_p$ 都表示**最大相位偏移（最大相偏）**。看表达式：$\cos$ 里 $\sin$ 或 $\cos$ 前面的系数就是 $m$。

若不知道 $m(t)$ 的表达式，仅从已调波形无法区分 FM 和 PM。

> [!example] 例：角调波参数分析
> $u(t) = 10\cos[2\pi \times 10^6 t + 10\cos 2000\pi t]$
>
> 瞬时相位：$\theta(t) = 2\pi\times10^6 t + 10\cos 2000\pi t$
>
> 最大相偏：$10$ 弧度
>
> 瞬时角频率（求导）：$\omega(t) = 2\pi\times10^6 - 10 \times 2000\pi \sin 2000\pi t = 2\pi\times10^6 - 20000\pi\sin 2000\pi t$
>
> 最大角频偏 $= 20000\pi$ → 最大频偏 $= 10000\text{Hz} = 10\text{kHz}$
>
> $f_m = 1000\text{Hz}$，$m = 10$，卡森带宽 $= 2(10+1) \times 1000 = 22\text{kHz}$
>
> 单位电阻功率：$P = 10^2/2 = 50\text{W}$
>
> 不能确定是 FM 还是 PM（不知道 $m(t)$ 表达式）。

> [!example] 例：FM 电路计算
> $k_f = 2\text{kHz/V}$（注意：乘以 $2\pi$ 转为角频率 $k_f = 4000\pi$），$m(t) = 5\cos(2\pi\times10^3 t)$，载波 $2\cos(10\pi\times10^6 t)$。
>
> **解**：
> 瞬时角频率：$\omega(t) = 10\pi\times10^6 + 4000\pi \times 5\cos(2\pi\times10^3 t)$
>
> 最大角频偏 $= 20000\pi$ → 最大频偏 $= 10000\text{Hz} = 10\text{kHz}$
>
> 瞬时相位（积分）：$\theta(t) = 10\pi\times10^6 t + \frac{20000\pi}{2\pi\times10^3}\sin(2\pi\times10^3 t) = 10\pi\times10^6 t + 10\sin(2\pi\times10^3 t)$
>
> $m_f = 10$，$f_m = 1\text{kHz}$ → 卡森带宽 $= 2(10+1) \times 1000 = 22\text{kHz}$
>
> $s_{\text{FM}}(t) = 2\cos[10\pi\times10^6 t + 10\sin(2\pi\times10^3 t)]$

## 调频系统抗噪声性能

大信噪比时：$G_{\text{FM}} = 3m_f^2(m_f+1)$，远大于 1（如 $m_f=10$ 时 $G \approx 3300$）。FM 是所有模拟调制中抗噪声性能最好的。

小信噪比时出现**门限效应**：解调器输入信噪比低于某个门限值时，输出信噪比急剧恶化。本质原因是鉴频器的非线性。

> [!warning] 简答题常考
> 什么是门限效应？当解调器输入信噪比低于一定门限时，输出信噪比急剧恶化的现象。由鉴频器的非线性引起。

## 本章小结

### 基本概念

| 知识点 | 要点 |
|--------|------|
| AM | $[A_0+m(t)]\cos\omega_c t$，$B=2f_m$，效率 $\leq 1/3$，包络检波 |
| DSB | $m(t)\cos\omega_c t$，$B=2f_m$，效率 100%，相干解调 |
| SSB | 单边带，$B=f_m$，希尔伯特变换，相干解调 |
| 相干解调 | $\times\cos\omega_c t$ → LPF，信号和噪声各留 $\cos$ 项的包络乘 $1/2$ |
| $G_{\text{DSB}}$ | $= 2$ |
| $G_{\text{SSB}}$ | $= 1$ |
| 角度调制 | FM 调频率，PM 调相位，调频必调相 |
| $m_f, m_p$ | 最大相偏（$\cos$ 括号里 $\sin$ 或 $\cos$ 前的系数） |
| 卡森公式 | $B = 2(m+1)f_m$，必背 |
| FM/PM 功率 | $= A^2/2$，等于载波功率 |
| 门限效应 | 输入 SNR 低于门限 → 输出 SNR 急剧恶化 |

### 核心公式

| 公式 | 说明 |
|------|------|
| $s_{\text{AM}} = [A_0 + m(t)]\cos\omega_c t$ | AM 表达式 |
| $s_{\text{DSB}} = m(t)\cos\omega_c t$ | DSB 表达式 |
| $B_{\text{AM}} = B_{\text{DSB}} = 2f_m$ | AM/DSB 带宽 |
| $B_{\text{SSB}} = f_m$ | SSB 带宽 |
| $G_{\text{DSB}} = 2$ | DSB 调制制度增益 |
| $G_{\text{SSB}} = 1$ | SSB 调制制度增益 |
| $\omega(t) = d\theta(t)/dt$ | 瞬时角频率 = 相位导数 |
| $\Delta f_{\max} = k_f A_m$ | 最大频偏 |
| $m_f = \Delta f_{\max} / f_m$ | 调频指数 = 最大相偏 |
| $B = 2(m+1)f_m$ | 卡森公式 |
| $P = A^2/2$ | 角度调制功率 |

### 考试注意事项

| 注意 | 说明 |
|------|------|
| 功率计算除以电阻 | 题目给负载电阻时不要忘记 $P = U^2/(2R)$ |
| $k_f$ 单位换算 | 若给 Hz/V，求瞬时角频率须乘 $2\pi$ |
| $m_f$ 是最大相偏 | 直接看 $\cos$ 括号里 $\sin/\cos$ 前面的系数；也是 $\Delta f_{\max}/f_m$ |
| 卡森公式的 $f_m$ | 是基带信号带宽，不是载波频率 |
| 相干解调规律 | 输入 × $\cos\omega_c t$ → LPF → 只留含 $\cos$ 项的包络，乘 $1/2$ |
