## 统一符号说明

| 符号 | 含义 | 首次出现 |
|------|------|:------:|
| $T_b$ | 码元周期/码元长度（本课程统一用法，涵盖所有进制） | EP1 |
| $R_B$ | 码元传输速率（波特率），单位 Baud | EP1 |
| $R_b$ | 信息传输速率（比特率），单位 bps | EP1 |
| $M$ | 进制数（M 进制码元） | EP1 |
| $\tau$ | 脉冲宽度 | EP1 |
| $\omega_0$ | 基频角频率 | EP2 |
| $f_m$ | 基带信号最高频率 | EP5 |
| $f_c$ / $\omega_c$ | 载波频率/角频率 | EP5 |
| $f_H$ | 信号最高频率（抽样定理） | EP9 |
| $f_N$ | 奈奎斯特带宽（仅指理想低通 $1/(2T_b)$） | EP6 |
| $n_0$ | 噪声单边功率谱密度 | EP3 |
| $r$ | 信噪比（接收端 BPF 输出） | EP7 |
| $\alpha$ | 余弦滚降系数（0~1） | EP6 |
| $\Delta$ | 最小量化间隔（A 律 PCM $=1/2048$） | EP9 |

## 各章依赖关系

- **EP1**：独立，全课程入口，定义所有基本概念
- **EP2**：依赖信号与系统基础，为 EP3 提供数学工具
- **EP3**：依赖 EP2 的谱密度/自相关概念，为 EP4~EP7 提供噪声分析框架
- **EP4**：依赖 EP3 的噪声模型，独立的概念章节
- **EP5**：依赖 EP3 的噪声分析和 EP4 的信道概念
- **EP6**：依赖 EP1 的码元概念，数字通信的基带基础
- **EP7**：依赖 EP5 的调制思想和 EP6 的基带信号概念
- **EP8**：依赖 EP7 的数字调制信号模型
- **EP9**：依赖 EP1 的信息量和 EP6 的速率概念
