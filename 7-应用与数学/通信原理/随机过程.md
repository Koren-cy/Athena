## 概率论预备知识

随机过程的分析大量依赖概率论。以下对必备知识做简要回顾。

### 一维随机变量

设连续型随机变量 $X$，分布函数 $F_X(x) = P(X \leq x)$，概率密度 $f_X(x) = \frac{d}{dx}F_X(x)$。

均值：$E[X] = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$

方差：$D[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2$

> [!tip] 方差记忆口诀
> 平方的平均 减去 平均的平方。

随机变量函数的期望：$E[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f(x)\,dx$

**期望的线性性**：$E[aX + bY^2 + cZ^3] = aE[X] + bE[Y^2] + cE[Z^3]$

**随机变量期望的三条性质**：

| 性质 | 公式 |
|------|------|
| 常数期望 | $E[C] = C$ |
| 线性组合 | $E[aX + bY] = aE[X] + bE[Y]$ |
| 独立乘积 | 若 $X,Y$ 统计独立，则 $E[XY] = E[X] \cdot E[Y]$ |

**随机变量方差的三条性质**：

| 性质 | 公式 |
|------|------|
| 常数方差 | $D[C] = 0$ |
| 乘常数 | $D[cX] = c^2 D[X]$ |
| 加常数 | $D[X + c] = D[X]$（加常数方差不改变） |

**两随机变量线性组合的方差**：

一般情况：$D[aX_1 + bX_2] = a^2D[X_1] + b^2D[X_2] + 2ab\,\mathrm{Cov}(X_1, X_2)$

若 $X_1, X_2$ **不相关**：$D[aX_1 + bX_2] = a^2 D[X_1] + b^2 D[X_2]$

> [!warning] 常见陷阱：$X_1 - X_2$ 的方差
> $D[X_1 - X_2] = D[X_1] + D[X_2]$，不是减号！因为 $b=-1$，$b^2 = 1$，负号平方后变正。

### 二维随机变量

$X$ 与 $Y$ 独立时：$E[XY] = E[X] \cdot E[Y]$

独立与不相关的关系：
- 独立 → 一定不相关
- 不相关 → 不一定独立（例外：$X,Y$ 联合高斯时，两者等价）

### 高斯分布

$X \sim N(\mu, \sigma^2)$，概率密度：
$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

线性变换：若 $X \sim N(\mu, \sigma^2)$，则 $aX + b \sim N(a\mu + b,\; a^2\sigma^2)$

## 随机过程的基本概念

### 什么是随机过程

通信系统中信号和噪声都具有随机性——发送端器件内部有热噪声，信号进入信道后又叠加干扰，每时每刻幅度值不可预知。需要用随机过程来描述。

**定义**：随机过程是一组时间函数的集合 $\{x_1(t), x_2(t), x_3(t), \dots\}$，其中每个时间函数称为随机过程的一个**样本函数**（或一个**实现**）。

### 两个观察角度

| 角度 | 视角 | 作用 |
|------|------|------|
| 角度一 | 沿时间 $t$ 记录，得到一个样本函数（一次实现） | 建立直观认知 |
| 角度二 | 固定时刻 $t_1$，所有样本函数在该时刻的取值构成一个随机变量 $\xi(t_1)$ | 适合数学描述 |

> [!tip] 本质
> **随机过程 = 随机变量在连续时间上的升维。** 取一个时刻得到一个随机变量，时间连续往前走，得到无穷多个随机变量。

**生活实例**：一家饭店一天 24 小时的顾客数是一个随机过程。沿时间记录某一天的顾客数变化 → 一个样本函数。固定每天上午 10 点看店内人数 → 一个随机变量（1 号、2 号……每天 10 点的人数各不相同，有各自的概率分布）。

### 数学描述

取定 $t_1$，$\xi(t_1)$ 是随机变量，其统计特性由概率密度描述：

- **一维分布函数** $F_1(x_1, t_1) = P[\xi(t_1) \leq x_1]$：固定时刻 $t_1$，随机过程取值不超过 $x_1$ 的概率。
- **一维概率密度** $f_1(x_1, t_1) = \frac{\partial}{\partial x_1}F_1(x_1, t_1)$：一维分布函数对 $x_1$ 的偏导数。
- **二维概率密度** $f_2(x_1, x_2; t_1, t_2)$：描述两个不同时刻的联合统计特性。
- 可推广至 $n$ 维。$n$ 越大描述越充分；工程上掌握一维和二维即可。

一维概率密度的性质：
1. $f_1(x_1, t_1) \geq 0$（非负）
2. $\int_{-\infty}^{\infty} f_1(x_1, t_1)\,dx_1 = 1$（归一性）
3. $P[a_1 < \xi(t_1) \leq a_2] = \int_{a_1}^{a_2} f_1(x_1, t_1)\,dx_1$（区间概率 = 面积）

### 数字特征

**均值（数学期望）**：
$$E[\xi(t)] = \int_{-\infty}^{\infty} x \cdot f_1(x, t)\,dx = a(t)$$

是时间 $t$ 的确定函数，表示随机过程的摆动中心。又称**期望函数**。

**方差**：
$$D[\xi(t)] = E[(\xi(t) - a(t))^2] = E[\xi^2(t)] - a^2(t)$$

表示随机过程在 $t$ 时刻偏离均值的程度。

**自相关函数**：衡量 **同一随机过程** 在 $t_1$ 和 $t_2$ 两个不同时刻取值之间的关联程度。
$$R(t_1, t_2) = E[\xi(t_1) \cdot \xi(t_2)]$$

$R(t_1, t_2)$ 可写作 $R(t_1, t_1 + \tau)$，其中 $\tau = t_2 - t_1$。一般情况下，时间间隔 $\tau$ 越大，相关性越小。

**自协方差函数**：衡量两个不同时刻的统计相关性。
$$B(t_1, t_2) = E\{[\xi(t_1) - a(t_1)] \cdot [\xi(t_2) - a(t_2)]\}$$

自协方差与自相关的关系：
$$B(t_1, t_2) = R(t_1, t_2) - a(t_1) \cdot a(t_2)$$

若均值为零（$a(t)=0$），则自协方差 = 自相关。

### 互相关与互协方差

当涉及 **两个不同随机过程** $\xi(t)$ 和 $\eta(t)$ 时，需要跨过程度量：

**互相关函数**（有顺序，先 $\xi$ 后 $\eta$）：
$$R_{\xi\eta}(t_1, t_2) = E[\xi(t_1) \cdot \eta(t_2)]$$

**互协方差函数**：
$$B_{\xi\eta}(t_1, t_2) = E\{[\xi(t_1) - a_\xi(t_1)] \cdot [\eta(t_2) - a_\eta(t_2)]\}$$

这两个量在实际计算中很少用到，但了解其定义有助于理解后续「不相关」的概念。

## 平稳随机过程

### 定义

统计特性不随时间推移而变化。

具体来说：
- **一维分布与时间 $t$ 无关**：$f_1(x, t) = f_1(x, t+h) = f_1(x)$，概率密度中可以不写 $t$。
- **二维分布只与时间间隔 $\tau$ 有关**：$f_2(x_1, x_2; t_1, t_2) = f_2(x_1, x_2; \tau)$，其中 $\tau = t_2 - t_1$。

由此推得数字特征：
- **均值与 $t$ 无关** → $E[\xi(t)] = a$（常数）
- **方差与 $t$ 无关** → $D[\xi(t)] = \sigma^2$（常数）
- **自相关函数只与时间间隔有关** → $R(t, t+\tau) = R(\tau)$，与时间起点 $t$ 无关

### 严平稳

统计特性与时间起点无关：对于**任意** $n$ 和任意 $\Delta$，

$$f_n(x_1,\dots,x_n; t_1,\dots,t_n) = f_n(x_1,\dots,x_n; t_1+\Delta,\dots,t_n+\Delta)$$

条件极其苛刻（所有阶都要满足），一般难以达到。

### 宽平稳

只要求 $n=1$ 和 $n=2$ 满足时间平移不变性。一个**二阶矩过程**（二阶矩有界）若满足：

1. **均值为常数**：$E[\xi(t)] = a$
2. **自相关函数仅与 $\tau$ 有关**：$R(t, t+\tau) = R(\tau)$

则称为**宽平稳（广义平稳）随机过程**。

> [!warning] 宽平稳的数字特征
> **均值为常数，自相关函数仅与时间差 $\tau$ 有关。** 判定是否宽平稳只需验证这两条。

由于均值为常数且二阶矩有界，方差也必然是常数（$D[\xi(t)] = E[\xi^2(t)] - a^2$），自动满足。

通信系统中大多数信号和噪声都可视为宽平稳过程。以后「平稳」默认指广义平稳。

### 严平稳与宽平稳的关系

- 严平稳 → 宽平稳（一定成立）
- 宽平稳 → 严平稳（不一定，但**对高斯过程成立**）

### 各态历经性

宽平稳过程在满足一定条件下，具有**各态历经性**——可用一个样本的**时间平均**代替**统计平均**（集合平均）。

| | 时间均值 | 时间相关函数 |
|------|------|------|
| 定义 | $\overline{a} = \lim\limits_{T\to\infty} \frac{1}{T}\int_{-T/2}^{T/2} x(t)\,dt$ | $\overline{R(\tau)} = \lim\limits_{T\to\infty} \frac{1}{T}\int_{-T/2}^{T/2} x(t)x(t+\tau)\,dt$ |

若以概率 1 满足：$\overline{a} = a$（时间均值 = 统计均值）且 $\overline{R(\tau)} = R(\tau)$（时间相关 = 统计相关），则称具有各态历经性。

- 各态历经 ⊂ 宽平稳（各态历经的一定是宽平稳，反之不然）
- 意义：实验时只需采集一个样本即可估计整个随机过程的均值和自相关函数——**化统计平均为时间平均**。

### 平稳过程自相关函数的五条性质

对于平稳过程 $\xi(t)$，$R(\tau) = E[\xi(t)\,\xi(t+\tau)]$：

| 性质 | 表达式 | 物理含义 |
|------|--------|------|
| ① | $R(0) = E[\xi^2(t)]$ | **平均功率** |
| ② | $R(\tau) = R(-\tau)$ | 偶函数 |
| ③ | $\vert R(\tau)\vert \leq R(0)$ | $R(0)$ 是最大值（上界）——自己和自己相关性最大 |
| ④ | $R(\infty) = E^2[\xi(t)] = a^2$ | **直流功率**（$a$ 为均值） |
| ⑤ | $R(0) - R(\infty) = \sigma^2$ | **交流功率 = 方差** |

> [!tip] 记忆：三功率（平均/直流/交流）+ 一偶 + 一上界。

**性质④的推导**：当 $\tau \to \infty$ 时，$\xi(t)$ 与 $\xi(t+\tau)$ 趋于独立（或不相关）。由于平稳，两者的均值相同且为常数，$R(\infty) = E[\xi(t)] \cdot E[\xi(t+\tau)] = a^2$。

> [!info] 均值为零时的简化
> 若 $a=0$，则 $R(\infty) = 0$，$R(0) = \sigma^2$（平均功率 = 方差 = 交流功率）。在高斯噪声中常用。

### 维纳-辛钦定理

**对于平稳随机过程**，自相关函数与功率谱密度构成一对傅里叶变换：

$$P_\xi(\omega) = \int_{-\infty}^{\infty} R(\tau)\,e^{-j\omega\tau}\,d\tau, \quad R(\tau) = \frac{1}{2\pi}\int_{-\infty}^{\infty} P_\xi(\omega)\,e^{j\omega\tau}\,d\omega$$

以频率 $f$ 为自变量（$\omega = 2\pi f$，$d\omega = 2\pi\,df$，$\frac{1}{2\pi}$ 消除）：

$$P_\xi(f) = \int_{-\infty}^{\infty} R(\tau)\,e^{-j2\pi f\tau}\,d\tau, \quad R(\tau) = \int_{-\infty}^{\infty} P_\xi(f)\,e^{j2\pi f\tau}\,df$$

> [!important] 与确知信号的区别
> 维纳-辛钦定理的前提是**平稳随机过程**。确知信号的自相关函数与功率谱密度也是 FT 对，但不叫维纳-辛钦定理。

由于 $R(\tau)$ 是实偶函数，其 FT $P_\xi(\omega)$ 也必为**实偶函数**。

**功率谱密度的性质**：
1. $P_\xi(\omega) \geq 0$（非负）
2. $P_\xi(\omega)$ 是偶函数（因为 $R(\tau)$ 是实偶函数）
3. 单边功率谱 $= 2 \times$ 双边功率谱（仅在正频率部分）

**平均功率的两种求法**：
$$P = R(0) = \frac{1}{2\pi}\int_{-\infty}^{\infty} P_\xi(\omega)\,d\omega = \int_{-\infty}^{\infty} P_\xi(f)\,df$$

> [!warning] $\omega$ 与 $f$ 的差别
> 以 $\omega$ 为积分变量时前面有 $\frac{1}{2\pi}$，以 $f$ 为积分变量时没有。题目给的是什么横轴就用对应的公式。

> [!example] 例：随机相位正弦波
> $\xi(t) = A\cos(\omega_c t + \theta)$，$A,\omega_c$ 为常数，$\theta$ 在 $[0, 2\pi]$ 均匀分布，$f(\theta) = \frac{1}{2\pi}$。
>
> **(1) 证明宽平稳：**
>
> **求均值**：$E[\xi(t)] = \int_0^{2\pi} A\cos(\omega_c t + \theta) \cdot \frac{1}{2\pi}\,d\theta$。用两角和余弦展开：
> $$\cos(\omega_c t + \theta) = \cos\omega_c t\cos\theta - \sin\omega_c t\sin\theta$$
> 积分变量是 $\theta$，$\cos\omega_c t$、$\sin\omega_c t$ 可提出积分号外。$\cos\theta$ 和 $\sin\theta$ 在 $[0, 2\pi]$ 上积分为零 → $E[\xi(t)] = 0$（常数）。✓
>
> **求自相关函数**：
> $$R(t, t+\tau) = E[A\cos(\omega_c t + \theta) \cdot A\cos(\omega_c(t+\tau) + \theta)]$$
> 积化和差后：
> $$= \frac{A^2}{2}E[\cos\omega_c\tau] + \frac{A^2}{2}E[\cos(2\omega_c t + \omega_c\tau + 2\theta)]$$
> **和频项**含 $2\theta$，在一个周期内积分为零；**差频项**不含随机变量，期望为其本身。
> $$R(\tau) = \frac{A^2}{2}\cos(\omega_c\tau)$$
> 仅与 $\tau$ 有关。✓ 两个条件满足 → 宽平稳。
>
> **(2) 功率谱密度**：对 $R(\tau)$ 做 FT。
> $\cos(\omega_c\tau) \leftrightarrow \pi[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)]$
> $$P(\omega) = \frac{\pi A^2}{2}[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)]$$
>
> **(3) 平均功率**：$P = R(0) = \frac{A^2}{2}\cos 0 = \frac{A^2}{2}$。
> 也可从 $P(\omega)$ 积分验证：两个冲激各强度 $\frac{\pi A^2}{2}$，乘 $\frac{1}{2\pi}$ → 每个贡献 $\frac{A^2}{4}$，两个共 $\frac{A^2}{2}$。✓
>
> **(4) 判断各态历经性**：
> 时间均值：$\lim\limits_{T\to\infty} \frac{1}{T}\int_{-T/2}^{T/2} A\cos(\omega_c t + \theta)\,dt = 0$（在一个周期内余弦积分为零）。与统计均值 $E[\xi(t)] = 0$ 一致。
> 时间相关函数（过程略，与统计相关函数计算类似）：得到 $\frac{A^2}{2}\cos(\omega_c\tau)$，与 $R(\tau)$ 一致。
> → 具有各态历经性。

> [!example] 例：两独立平稳过程之和
> $X(t), Y(t)$ 统计独立且各自平稳，均值 $a_X, a_Y$，自相关 $R_X(\tau), R_Y(\tau)$。判断 $Z(t) = X(t) + Y(t)$ 是否平稳。
>
> **解**：
> 均值：$E[Z] = E[X] + E[Y] = a_X + a_Y$（常数）✓
>
> 自相关：$R_Z = E[(X_t+Y_t)(X_{t+\tau}+Y_{t+\tau})]$
> 展开四项，交叉项利用独立性：$E[X_t Y_{t+\tau}] = E[X_t] \cdot E[Y_{t+\tau}] = a_X a_Y$（平稳使 $Y_{t+\tau}$ 的均值也是 $a_Y$）
> $$R_Z(\tau) = R_X(\tau) + R_Y(\tau) + 2a_X a_Y$$
> 仅与 $\tau$ 有关。✓ → 平稳。

> [!example] 例：随机过程乘余弦（调制）
> $Z(t) = M(t)\cos(\omega_0 t + \theta)$，$M(t)$ 宽平稳（自相关 $R_M(\tau)$），$\theta$ 在 $[0,2\pi]$ 均匀分布且与 $M(t)$ 独立。
>
> **(1) 证 $Z(t)$ 宽平稳：**
>
> 均值：$E[Z] = E[M] \cdot E[\cos(\omega_0 t + \theta)] = a_M \cdot 0 = 0$（常数）✓
>
> 自相关：利用 $M$ 与 $\theta$ 独立，积化和差，和频项均值为零：
> $$R_Z(\tau) = \frac{1}{2}R_M(\tau)\cos(\omega_0\tau)$$
> 仅与 $\tau$ 有关。✓ → 平稳。
>
> **(2) 波形特点**：$R_Z(\tau)$ 以 $R_M(\tau)$ 为包络（缓慢变化）、$\cos\omega_0\tau$ 为填充（快速振荡）。
>
> **(3) 功率谱密度**：时域 $R_M(\tau) \times \cos\omega_0\tau$ → 频域卷积（利用频域卷积定理）：
> $P_Z(\omega) = \frac{1}{4}[P_M(\omega-\omega_0) + P_M(\omega+\omega_0)]$
>
> **(4) 平均功率**：$P_Z = R_Z(0) = \frac{1}{2}R_M(0)$
>
> > [!important] 调制三结论
> > | | 结论 |
> > |------|------|
> > | **幅度谱** | $S(f)$ 左搬右搬，各乘 $1/2$：$\frac{1}{2}[S(f-f_c) + S(f+f_c)]$ |
> > | **功率谱** | $P_s(f)$ 左搬右搬，各乘 $1/4$：$\frac{1}{4}[P_s(f-f_c) + P_s(f+f_c)]$ |
> > | **调制后功率** | 原功率除以 2：$P_{\text{mod}} = \frac{1}{2}\overline{s^2(t)}$ |

> [!example] 例：调制信号的功率谱
> $M(t)$ 自相关 $R_M(\tau)$ 在 $[-1, 1]$ 上呈三角形（$\tau=0$ 处顶点 $\frac{1}{2}$），求 $Z(t) = M(t)\cos\omega_c t$ 的功率谱和平均功率。
>
> **求功率谱**：
>
> **第一步**：求 $\frac{1}{2}R_M(\tau)$ 的 FT。三角脉冲可视为两个等宽门函数的卷积：幅度 $\sqrt{\frac{1}{2}}$、宽度为 1 的门函数自卷积 → 幅度 $\frac{1}{2}$、底宽为 2 的三角波。
>
> 门函数的 FT：$1 \cdot \mathrm{Sa}(\frac{\omega}{2})$。时域卷积 = 频域相乘：
> $$\mathcal{F}\left[\frac{1}{2}R_M(\tau)\right] = \frac{1}{2}\mathrm{Sa}^2\!\left(\frac{\omega}{2}\right)$$
>
> **第二步**：$R_Z(\tau) = \frac{1}{2}R_M(\tau) \cdot \cos\omega_c\tau$。由频域卷积定理（时域相乘 ↔ 频域卷积除以 $2\pi$）：
> $$P_Z(\omega) = \frac{1}{2\pi} \cdot \frac{1}{2}\mathrm{Sa}^2\!\left(\frac{\omega}{2}\right) * \pi[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)]$$
> $$= \frac{1}{4}\left[\mathrm{Sa}^2\!\left(\frac{\omega-\omega_c}{2}\right) + \mathrm{Sa}^2\!\left(\frac{\omega+\omega_c}{2}\right)\right]$$
>
> **平均功率**：$P_Z = R_Z(0) = \frac{1}{2}R_M(0) = \frac{1}{4}$（$R_M(0) = \frac{1}{2}$ 为三角波顶点）。

> [!example] 例：自相关为周期三角脉冲时的功率谱密度
> $X(t)$ 的自相关 $R_X(\tau)$ 是周期 $T=2$ 的周期三角脉冲（单周期：$1 - \vert\tau\vert,\; \vert\tau\vert \leq 1$）。求 $P_X(\omega)$。
>
> **解**：利用结论——已知单脉冲 FT 时，周期延拓后的傅里叶级数系数 $F_n = \frac{1}{T}F(\omega)\big|_{\omega = n\omega_1}$，再套用周期信号的 FT 公式 $2\pi\sum F_n\delta(\omega-n\omega_1)$。
>
> 单三角脉冲 FT：$F(\omega) = 1 \cdot \mathrm{Sa}^2(\frac{\omega}{2})$（$E=1, \tau=2$ 代入三角脉冲 FT 公式）
>
> $F_n = \frac{1}{2}\mathrm{Sa}^2(\frac{n\pi}{2})$（$\omega_1 = 2\pi/T = \pi$）
>
> $$P_X(\omega) = 2\pi\sum_{n=-\infty}^{\infty} \frac{1}{2}\mathrm{Sa}^2\!\left(\frac{n\pi}{2}\right)\delta(\omega - n\pi) = \pi\sum_{n=-\infty}^{\infty} \mathrm{Sa}^2\!\left(\frac{n\pi}{2}\right)\delta(\omega - n\pi)$$
>
> $n=0$ 时 $\mathrm{Sa}(0)=1$ → 幅度 $\pi$；$n$ 为偶数时 $\mathrm{Sa}(n\pi/2)=0$ → 偶数次谐波过零。

## 高斯随机过程

### 定义

若随机过程的任意 $n$ 维分布都服从正态分布，则称为**高斯随机过程**（正态过程）。其 $n$ 维概率密度由各变量的均值、方差和两两之间的归一化协方差唯一确定。

我们重点掌握**一维**高斯概率密度：

$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-a)^2}{2\sigma^2}}, \quad X \sim N(a, \sigma^2)$$

其中 $a$ 为均值，$\sigma^2$ 为方差，$\sigma$ 为标准差。

### 一维高斯概率密度的性质

1. **关于 $x = a$ 对称**
2. $\int_{-\infty}^{\infty} f(x)\,dx = 1$（归一性）
3. **以均值为分界**，左右面积各占 $\frac{1}{2}$（后续推导常用）
4. $a$ 反映分布中心，$\sigma^2$ 反映集中程度：$\sigma$ 小 → 曲线高而瘦（集中）；$\sigma$ 大 → 曲线矮而胖（分散）
5. $a=0$、$\sigma^2=1$ 时为**标准正态分布** $N(0,1)$

### 高斯变量的标准化（归一化）

任意高斯变量 $X \sim N(a, \sigma^2)$，通过减去均值再除以标准差，可转换为标准正态分布：

$$Y = \frac{X - a}{\sigma} \sim N(0,1)$$

因此任意高斯分布的概率计算都可以统一到标准正态分布：
$$P(X \leq x) = P\!\left(Y \leq \frac{x-a}{\sigma}\right)$$

### 四条重要性质

| 性质 | 内容 |
|------|------|
| ① | 知道均值和方差，即可完全确定统计特性（写出 $n$ 维概率密度） |
| ② | 宽平稳与严平稳**等价**（对高斯过程特有） |
| ③ | 不相关与独立**等价**（对高斯变量特有） |
| ④ | 高斯过程经过线性系统后**仍为高斯过程**（数字特征发生改变） |

> [!info] 性质四的均值/方差计算
> 若 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$，则 $aX + bY \sim N(a\mu_1 + b\mu_2,\; a^2\sigma_1^2 + b^2\sigma_2^2)$。
> 若干高斯过程的代数和仍为高斯过程——这与概率论中高斯变量的线性变换性质一致。

### 正态分布函数

对于一般高斯变量 $X \sim N(a, \sigma^2)$：
$$\Phi(x) = P(X \leq x) = \int_{-\infty}^x \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(t-a)^2}{2\sigma^2}}\,dt$$

该积分**没有闭合形式**（只有数值解），需通过标准化后查表。

标准化后：
$$P(X \leq x) = \Phi\!\left(\frac{x-a}{\sigma}\right) = \int_{-\infty}^{\frac{x-a}{\sigma}} \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}}\,dt$$

### Q 函数

积分线从 $x$ 到 $+\infty$（与分布函数互补）：

$$Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^\infty e^{-\frac{t^2}{2}}\,dt$$

对于标准正态分布：$Q(x) = 1 - \Phi(x)$。对于一般高斯变量：$P(X > x) = Q\!\left(\frac{x-a}{\sigma}\right)$。

**Q 函数的两个性质**（结合图像理解——标准正态曲线下的面积）：

| 性质 | 公式 | 含义 |
|------|------|------|
| $x=0$ 的值 | $Q(0) = 0.5$ | 均值以右面积 = 一半 |
| 对称性 | $Q(-x) = 1 - Q(x)$ | 左边尾部面积 = 1 减去右边尾部面积 |

### 误差函数 erf 与互补误差函数 erfc

误差函数（增函数）：
$$\mathrm{erf}(x) = \frac{2}{\sqrt{\pi}}\int_0^x e^{-t^2}\,dt$$

性质：$\mathrm{erf}(0) = 0$，$\mathrm{erf}(\infty) = 1$，$\mathrm{erf}(-x) = -\mathrm{erf}(x)$（奇函数）。

互补误差函数（减函数）：
$$\mathrm{erfc}(x) = 1 - \mathrm{erf}(x) = \frac{2}{\sqrt{\pi}}\int_x^\infty e^{-t^2}\,dt$$

性质：$\mathrm{erfc}(0) = 1$，$\mathrm{erfc}(\infty) = 0$，$\mathrm{erfc}(-x) = 2 - \mathrm{erfc}(x)$。

### 正态分布与 erf/erfc 的关系

设 $X \sim N(a, \sigma^2)$，通过变量代换 $u = \frac{t-a}{\sqrt{2}\sigma}$ 可导出：

$$P(X \leq x) = \begin{cases} \dfrac{1}{2} + \dfrac{1}{2}\,\mathrm{erf}\!\left(\dfrac{x-a}{\sqrt{2}\sigma}\right), & x \geq a \\[8pt] \dfrac{1}{2} - \dfrac{1}{2}\,\mathrm{erf}\!\left(\dfrac{a-x}{\sqrt{2}\sigma}\right) = \dfrac{1}{2}\,\mathrm{erfc}\!\left(\dfrac{a-x}{\sqrt{2}\sigma}\right), & x < a \end{cases}$$

> [!tip] 换元思路
> 将积分区间拆分为「负无穷到 $a$」（面积 $=1/2$）和「$a$ 到 $x$」（用换元 $u = \frac{t-a}{\sqrt{2}\sigma}$ 凑成 erf 形式）。这是后续抗噪声性能推导中的常用技巧。

**近似公式**（当 $x > 2$ 时）：
$$\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}} e^{-x^2}$$

> [!example] 例：两独立高斯变量构成的随机过程
> $Y(t) = X_1\cos\omega_0 t - X_2\sin\omega_0 t$，$X_1, X_2$ 互相独立，且均为 $N(0, \sigma^2)$。
>
> **(1) 求 $E[Y(t)]$ 和 $E[Y^2(t)]$：**
>
> $E[Y] = \cos\omega_0 t \cdot E[X_1] - \sin\omega_0 t \cdot E[X_2] = 0$（零均值）
>
> $E[Y^2] = \cos^2\omega_0 t \cdot E[X_1^2] - 2\cos\omega_0 t\sin\omega_0 t \cdot E[X_1X_2] + \sin^2\omega_0 t \cdot E[X_2^2]$
>
> 交叉项：$X_1, X_2$ 独立 → $E[X_1X_2] = E[X_1]E[X_2] = 0$
>
> $E[X_1^2]$：由 $D[X_1] = E[X_1^2] - (E[X_1])^2$ 且 $E[X_1]=0$ → $E[X_1^2] = \sigma^2$。同理 $E[X_2^2] = \sigma^2$。
>
> $E[Y^2] = \sigma^2(\cos^2\omega_0 t + \sin^2\omega_0 t) = \sigma^2$
>
> **(2) 求一维概率密度 $f_Y(y)$：**
>
> $Y(t)$ 是两个高斯变量的线性组合 → 仍为高斯变量。由 (1) 知均值为 0，方差为 $\sigma^2$。
> $$f_Y(y) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{y^2}{2\sigma^2}}$$
>
> **(3) 求自相关函数和协方差函数：**
> $$R(t_1, t_2) = E[Y(t_1)Y(t_2)] = \cdots = \sigma^2\cos\omega_0(t_2 - t_1) = \sigma^2\cos(\omega_0\tau)$$
> 仅与 $\tau$ 有关、均值为常数 → 宽平稳。
>
> 由于均值为零，协方差 = 自相关 = $\sigma^2\cos(\omega_0\tau)$。

## 平稳随机过程通过线性系统

### 基本设定

确知信号通过线性时不变系统：$v_o(t) = v_i(t) * h(t)$，$V_o(f) = V_i(f) \cdot H(f)$。将其推广至平稳随机过程输入。

设输入 $\xi_i(t)$ 平稳，系统冲击响应 $h(t)$，频率响应 $H(\omega)$（或 $H(f)$），则输出：
$$\xi_o(t) = \int_0^\infty h(\alpha)\,\xi_i(t-\alpha)\,d\alpha$$

### 结论

若输入 $\xi_i(t)$ 平稳，则输出 $\xi_o(t)$ 也是平稳过程。

| 输出量 | 公式 | 说明 |
|--------|------|------|
| 均值 | $E[\xi_o(t)] = a_i \cdot H(0)$ | 输入均值 × 系统直流增益 |
| 功率谱密度 | $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$ | 输入功率谱 × 系统功率增益 |
| 自相关函数 | $R_o(\tau) = \mathcal{F}^{-1}[P_o(f)]$ | 先求功率谱，再逆 FT |

**均值的证明思路**：将期望算子移入积分号，利用输入平稳（均值 $a_i$ 为常数），提取 $a_i$，剩余积分 $\int_0^\infty h(\alpha)\,d\alpha$ 恰为 $H(0)$（FT 定义式中令 $\omega=0$）。

**自相关函数的证明思路**：写二重积分 → 换元 → 输入平稳使内部变为 $R_i(\tau + \alpha - \beta)$ → 积分后仅剩 $\tau$。

**功率谱密度的证明思路**：对 $R_o(\tau)$ 做 FT → 三重积分 → 令 $u = \tau + \alpha - \beta$ 换元 → 分离变量 → 出现 $\int h(\alpha)e^{j\omega\alpha}d\alpha \cdot \int h(\beta)e^{-j\omega\beta}d\beta = |H(\omega)|^2$。

> [!tip] 自相关函数的求法
> 直接算 $R_o(\tau)$ 需要两次卷积，极其繁琐。实际做法：**先求 $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$，再做逆 FT 得到 $R_o(\tau)$**。

**特殊情形**：若输入为**高斯过程**，经过线性系统后输出仍为高斯过程，但数字特征发生改变（均值 = $a_i \cdot H(0)$，方差从功率谱积分求得）。

> [!example] 例：延迟相加系统
> $Y(t) = X(t) + X(t - T)$，$X(t)$ 平稳，均值为 $a$，自相关 $R_X(\tau)$。求 $Y(t)$ 的自相关函数和功率谱密度。
>
> **解**：令 $X(t) = \delta(t)$ → $h(t) = \delta(t) + \delta(t - T)$
>
> $H(\omega) = 1 + e^{-j\omega T}$，模平方：
> $\vert H(\omega)\vert^2 = (1+e^{-j\omega T})(1+e^{j\omega T}) = 2 + 2\cos\omega T = 2(1 + \cos\omega T)$
>
> $P_Y(\omega) = P_X(\omega) \cdot 2(1 + \cos\omega T)$
>
> 逆 FT（利用 $\cos\omega T = \frac{1}{2}(e^{j\omega T}+e^{-j\omega T})$ 和时移性质）：
> $$R_Y(\tau) = 2R_X(\tau) + R_X(\tau - T) + R_X(\tau + T)$$
>
> 平均功率：$R_Y(0) = 2R_X(0) + 2R_X(T)$（偶函数）。

> [!example] 例：延迟相加 + 微分
> $X(t)$ 通过延迟相加后再经微分器。求 $Y(t)$ 的功率谱密度。
>
> **解**：微分在频域对应乘 $j\omega$。总传递函数：
> $$H(\omega) = j\omega(1 + e^{-j\omega T})$$
>
> $\vert H(\omega)\vert^2 = \omega^2 \cdot 2(1 + \cos\omega T)$
>
> $P_Y(\omega) = P_X(\omega) \cdot 2\omega^2(1 + \cos\omega T)$

> [!example] 例：RC 低通滤波器
> RC 低通滤波器，输入均值为零、功率谱密度为 $n_0/2$ 的高斯白噪声。求输出功率谱密度、自相关函数和一维概率密度。
>
> **解**：
> **求 $H(\omega)$**：RC 电路——电容阻抗 $\frac{1}{j\omega C}$，分压：
> $$H(\omega) = \frac{\frac{1}{j\omega C}}{R + \frac{1}{j\omega C}} = \frac{1}{1 + j\omega RC}$$
> $$\vert H(\omega)\vert^2 = \frac{1}{1 + (\omega RC)^2}$$
>
> **输出功率谱密度**：
> $$P_o(\omega) = \frac{n_0}{2} \cdot \frac{1}{1 + (\omega RC)^2}$$
>
> **自相关函数**：利用已知 FT 对 $e^{-\alpha\vert t\vert} \leftrightarrow \frac{2\alpha}{\alpha^2 + \omega^2}$：
> $$R_o(\tau) = \frac{n_0}{4RC} e^{-\vert\tau\vert/RC}$$
>
> **一维概率密度**：输出是高斯过程。均值：输入零均值 × $H(0) = 1$ → 仍为零。方差 = $R_o(0) - R_o(\infty) = \frac{n_0}{4RC} - 0 = \frac{n_0}{4RC}$。
> $$f(x) = \sqrt{\frac{2RC}{\pi n_0}} e^{-\frac{2RC}{n_0}x^2}$$

## 窄带随机过程

### 低通过程与带通过程

从功率谱密度的分布范围来分类：

| 类型 | 功率谱密度分布 | 特点 |
|------|------|------|
| **低通过程** | $P(f)$ 仅存在于 $\vert f\vert \leq f_0$ 内 | 频谱集中在零频附近 |
| **带通过程** | $P(f)$ 存在于 $f_c \pm f_0$（及负频率对称部分）内 | 频谱集中在 $\pm f_c$ 附近 |

### 窄带过程的定义

若带通过程的通带宽度 $\Delta f$ 远小于中心频率 $f_c$（$\Delta f \ll f_c$），且 $f_c$ 远离零频，则称为**窄带随机过程**。

时域波形特征：如同一个**包络和相位随机缓慢变化的正弦波**——包络 $a_\xi(t)$ 变化慢，内部振荡频率约为 $f_c$。

实际通信系统接收端经过带通滤波器后，信号和噪声大多是窄带的。

### 两种表示形式

**形式一（包络-相位）**：
$$\xi(t) = a_\xi(t)\cos[\omega_c t + \varphi_\xi(t)]$$

其中 $a_\xi(t)$ 为随机包络，$\varphi_\xi(t)$ 为随机相位，$\omega_c$ 为中心角频率。

**形式二（同相-正交）**，将上式用两角和的余弦公式展开：
$$\xi(t) = \xi_c(t)\cos\omega_c t - \xi_s(t)\sin\omega_c t$$

其中：
- $\xi_c(t) = a_\xi(t)\cos\varphi_\xi(t)$ — **同相分量**（乘 $\cos\omega_c t$ 的项）
- $\xi_s(t) = a_\xi(t)\sin\varphi_\xi(t)$ — **正交分量**（乘 $\sin\omega_c t$ 的项）

> [!warning] 注意符号
> 中间是**减号**，不要写成加号。

**两种表示的关系**——用直角三角形理解：

| 量 | 表达式 | 几何含义 |
|------|------|------|
| 包络 | $a_\xi = \sqrt{\xi_c^2 + \xi_s^2}$ | 斜边 |
| 相位 | $\varphi_\xi = \arctan(\xi_s / \xi_c)$ | 角 |
| 同相分量 | $\xi_c = a_\xi\cos\varphi_\xi$ | 邻边 |
| 正交分量 | $\xi_s = a_\xi\sin\varphi_\xi$ | 对边 |

### 同相分量和正交分量的统计特性

设 $\xi(t)$ 是均值为零、方差为 $\sigma_\xi^2$ 的平稳窄带高斯噪声：

| 结论 | 内容 |
|------|------|
| 均值 | $E[\xi_c] = E[\xi_s] = 0$ |
| 平稳性 | $\xi_c(t)$ 和 $\xi_s(t)$ 都是平稳高斯过程 |
| 方差 | $D[\xi_c] = D[\xi_s] = \sigma_\xi^2$（与原始过程方差相同） |
| 自相关 | 两者自相关函数相同 |
| 独立性 | 同一时刻，$\xi_c$ 与 $\xi_s$ **统计独立**（高斯过程 + 不相关 = 独立） |

> [!tip] 一句话记住
> $\xi_c(t)$ 和 $\xi_s(t)$ 均为**零均值、等方差、不相关、独立的平稳高斯过程**。

### 随机包络和随机相位的统计特性

| 结论 | 分布 |
|------|------|
| 包络 $a_\xi(t)$ | **瑞利分布** |
| 相位 $\varphi_\xi(t)$ | 在 $[0, 2\pi]$ **均匀分布** |
| 包络与相位的关系 | **统计独立** |

瑞利分布的概率密度（了解即可）：
$$f(a) = \frac{a}{\sigma_\xi^2} e^{-\frac{a^2}{2\sigma_\xi^2}}, \quad a \geq 0$$

## 正弦波加窄带高斯噪声

### 研究意义

接收端最前端放置带通滤波器——滤除带外噪声，提高信噪比。输出 = 有用正弦信号 + 窄带高斯噪声。这是分析各类调制系统抗噪声性能的标准模型。

### 信号模型

$$r(t) = A\cos(\omega_c t + \theta) + n(t)$$

其中 $n(t)$ 是均值为零、方差为 $\sigma_n^2$ 的窄带高斯噪声，$\theta$ 在 $[0,2\pi]$ 均匀分布。

将噪声分解为同相/正交分量 $n(t) = n_c(t)\cos\omega_c t - n_s(t)\sin\omega_c t$，再将正弦波用两角和公式展开，合并同类项：

$$r(t) = \underbrace{[A\cos\theta + n_c(t)]}_{z_c(t)}\cos\omega_c t - \underbrace{[A\sin\theta + n_s(t)]}_{z_s(t)}\sin\omega_c t$$

其中 $z_c(t)$ 和 $z_s(t)$ 分别是合成信号的**同相分量**和**正交分量**。

用直角三角形理解：斜边 = 包络 $z(t)$，角 = $\varphi(t)$，邻边 = $z_c(t)$，对边 = $z_s(t)$。

### 信噪比

$$\gamma = \frac{\text{正弦信号功率}}{\text{噪声功率}} = \frac{A^2/2}{\sigma_n^2}$$

信号功率来自正弦波 $A\cos\omega_c t$ 的平均功率 $A^2/2$，噪声功率 = 方差 $\sigma_n^2$（零均值时）。

### 同相分量和正交分量的统计特性

当随机相位 $\theta$ 给定时，$z_c(t)$ 和 $z_s(t)$ 是不相关、独立、同分布的高斯变量，但其**均值不再是零**：

| | 均值 | 方差 |
|------|------|------|
| $z_c(t)$ | $A\cos\theta$ | $\sigma_n^2$ |
| $z_s(t)$ | $A\sin\theta$ | $\sigma_n^2$ |

与纯窄带高斯噪声（同相/正交分量均值为零）相比，多了正弦信号贡献的直流偏置。

### 包络的统计特性

$r(t)$ 的包络服从**广义瑞利分布**（又称莱斯分布）。

两种极限情况：

| 条件 | 退化为 | 说明 |
|------|--------|------|
| 信噪比极低（$\gamma \to 0$，即 $A \to 0$） | 瑞利分布 | 纯窄带高斯噪声——正弦信号几乎消失 |
| 信噪比较高（$\gamma$ 大） | 近似高斯分布 $N(A, \sigma_n^2)$ | 信号主导，噪声为扰动 |

### 随机相位的统计特性

| 条件 | 分布 |
|------|------|
| 小信噪比 | $[0, 2\pi]$ 均匀分布 |
| 大信噪比 | 集中在有用信号相位 $\theta$ 附近 |

> [!tip] 记忆
> 正弦波加窄带高斯过程在小信噪比下**退化**为纯窄带高斯过程，所有统计特性退化为上一节结论——包络从广义瑞利 → 瑞利，相位从与 SNR 有关 → 均匀分布。

## 高斯白噪声和带限白噪声

### 白噪声

**定义**：功率谱密度在所有频率上为常数。

| | 双边功率谱密度 | 单边功率谱密度 |
|------|:---:|:---:|
| 数值 | $\frac{n_0}{2}$ | $n_0$ |
| 频率范围 | $(-\infty, +\infty)$ | $[0, +\infty)$ |

自相关函数：$R(\tau) = \frac{n_0}{2}\delta(\tau)$——仅在 $\tau = 0$ 处有值。

> [!info] 白噪声是理想模型
> 真实白噪声不存在——若带宽无限，平均功率 $\to \infty$。但实际器件热噪声的频谱范围（达 THz 量级）远超关心信号带宽，故在工作频带内功率谱近似平坦，可视为白噪声。通常建模为**高斯白噪声**（白噪声 + 高斯分布）。

由于 $R(\tau) \propto \delta(\tau)$，高斯白噪声在任意两个不同时刻（$\tau \neq 0$）的取值**互不相关且统计独立**（不相关 + 高斯 = 独立）。

### 低通白噪声

高斯白噪声通过理想矩形低通滤波器（截止频率 $f_H$，幅度 1）：

功率谱密度：$P(f) = \begin{cases} \frac{n_0}{2}, & \vert f\vert \leq f_H \\ 0, & \text{else} \end{cases}$

**自相关函数的推导**：将 $P(f)$ 写成门函数形式 $\frac{n_0}{2} \cdot G_{2f_H}(f)$。门函数的逆 FT 为 $2f_H \cdot \mathrm{Sa}(2\pi f_H \tau)$（用 FT 对称性）：
$$R(\tau) = n_0 f_H \cdot \mathrm{Sa}(2\pi f_H \tau)$$

平均功率：$R(0) = n_0 f_H = \frac{n_0 \omega_H}{2\pi}$。

> [!tip] 抽样定理的应用
> $R(\tau)$ 在 $\tau = \frac{k}{2f_H}$（$k = \pm 1, \pm 2, \dots$）处过零。若以 $T_s = \frac{1}{2f_H}$ 的间隔抽样，抽样值之间互不相关。

### 带通白噪声

高斯白噪声通过理想矩形带通滤波器（中心频率 $f_c$，带宽 $B$，幅度 1）：

功率谱密度：低通白噪声的 $P(f)$ 左右搬移到 $\pm f_c$ 处。
$$P(f) = \begin{cases} \frac{n_0}{2}, & f_c - \frac{B}{2} \leq \vert f\vert \leq f_c + \frac{B}{2} \\ 0, & \text{else} \end{cases}$$

自相关函数：低通自相关 $\times \cos(2\pi f_c\tau)$（时域乘余弦 ↔ 频域搬移）：
$$R(\tau) = n_0 B \cdot \mathrm{Sa}(\pi B\tau) \cdot \cos(2\pi f_c \tau)$$

平均功率：$R(0) = n_0 B$（也就是两个矩形面积之和，每个宽度 $B$、高度 $\frac{n_0}{2}$，共两个）。

低通白噪声和带通白噪声统称为**带限白噪声**。

> [!example] 例：理想带通滤波器
> 中心频率 $f_c$、带宽 $B$ 的理想带通滤波器，输入均值为零、功率谱密度为 $n_0/2$ 的高斯白噪声。求输出自相关函数、平均功率和一维概率密度。
>
> **解**：
> 自相关函数：$R(\tau) = n_0 B \cdot \mathrm{Sa}(\pi B\tau) \cdot \cos(2\pi f_c \tau)$
>
> 平均功率：$R(0) = n_0 B$
>
> 一维概率密度：输出仍为高斯过程，均值仍为零，方差 $= n_0 B$。
> $$f(x) = \frac{1}{\sqrt{2\pi n_0 B}} e^{-\frac{x^2}{2n_0 B}}$$

## 本章小结

### 基本概念

| 知识点        | 要点                                                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 随机过程       | 在随机变量基础上多一个时间维度。<br>沿时间记录就是样本函数；固定时刻就是随机变量                                                                                                     |
| 宽平稳        | 均值为常数 + 自相关仅与 $\tau$ 有关（默认「平稳」= 宽平稳）                                                                                                           |
| 严平稳        | 任意 $n$ 维概率密度与时间起点无关；条件苛刻                                                                                                                       |
| 各态历经性      | 化统计平均为时间平均；用任一样本可刻画整个随机过程                                                                                                                      |
| 自相关函数性质    | $R(0)$=平均功率，$R(\infty)$=直流功率，$R(0)-R(\infty)$=交流功率=方差，偶函数，$R(0)$ 最大                                                                            |
| 维纳-辛钦定理    | 平稳过程的 $R(\tau)$ 与 $P(\omega)$ 为 FT 对                                                                                                           |
| 高斯过程       | 宽平稳 ⇔ 严平稳；<br>不相关 ⇔ 独立；<br>高斯经过线性系统仍为高斯过程                                                                                                      |
| 高斯变量标准化    | $Y = \frac{X-a}{\sigma} \sim N(0,1)$；Q 函数、erf/erfc 均基于标准正态分布                                                                                   |
| 窄带高斯噪声     | 同相/正交分量：零均值、等方差、独立、平稳高斯过程。<br>包络：瑞利分布<br>相位：均匀分布                                                                                               |
| 正弦波加窄带高斯噪声 | 包络：广义瑞利分布（莱斯分布）。<br>小 SNR → 退化为纯窄带高斯                                                                                                           |
| 白噪声        | 功率谱为常数，理想模型；自相关为 $\frac{n_0}{2}\delta(\tau)$                                                                                                   |
| 带限白噪声      | 低通：$P(f)$ 单矩形，$R(\tau) = n_0 f_H \mathrm{Sa}(2\pi f_H\tau)$。<br>带通：双矩形，$R(\tau) = n_0 B \cdot \mathrm{Sa}(\pi B\tau) \cdot \cos(2\pi f_c\tau)$ |

### 核心公式

| 公式 | 说明 |
|------|------|
| $E[\xi(t)] = a$（常数） | 宽平稳条件一 |
| $R(\tau) = E[\xi(t)\xi(t+\tau)]$ | 宽平稳条件二 |
| $R(0) = E[\xi^2(t)]$ | 平均功率 |
| $R(\infty) = a^2$ | 直流功率 |
| $R(0) - R(\infty) = \sigma^2$ | 交流功率 = 方差 |
| $B(t_1, t_2) = R(t_1, t_2) - a(t_1)a(t_2)$ | 自协方差与自相关的关系 |
| $P_\xi(\omega) = \mathcal{F}[R(\tau)]$ | 维纳-辛钦定理 |
| $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$ | 平稳过程通过线性系统的输出功率谱 |
| $E[\xi_o] = a_i \cdot H(0)$ | 输出均值 = 输入均值 × 系统直流增益 |
| $Y = \frac{X-a}{\sigma} \sim N(0,1)$ | 高斯变量标准化 |
| $\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$（$x>2$） | 互补误差函数近似 |
| $\gamma = \frac{A^2/2}{\sigma^2}$ | 正弦波加窄带高斯噪声的信噪比 |
| $R(\tau) = \frac{n_0}{2}\delta(\tau)$ | 白噪声自相关函数 |
| $n_0 B$ | 带限白噪声平均功率 |
| 调制三结论 | 幅度谱乘 $1/2$，功率谱乘 $1/4$，调制后功率除以 2 |

### 注意事项

| 注意             | 说明                                                     |
| -------------- | ------------------------------------------------------ |
| 判断平稳           | 均值是否为常数，自相关是否仅与 $\tau$ 有关                              |
| 维纳-辛钦前提        | 必须是平稳随机过程；确知信号的 $R \leftrightarrow P$ 对不叫维纳-辛钦定理       |
| 求自相关           | 优先走频域（$P_o = P_i\cdot\vert H\vert^2$ → 逆 FT），不要直接算两次卷积 |
| $\omega$ 与 $f$ | 以 $\omega$ 积分时前面有 $\frac{1}{2\pi}$，以 $f$ 积分时没有         |
| 窄带表示           | 中间是减号：$\xi_c\cos\omega_c t - \xi_s\sin\omega_c t$      |
| erfc 近似条件      | $x > 2$ 时才成立                                           |
| 调制三结论          | 幅度谱乘 $1/2$，功率谱乘 $1/4$，调制后功率除以 2                        |
| 高斯变量不相关=独立     | 仅对联合高斯分布成立；一般随机变量不相关≠独立                                |
| $D[X_1 - X_2]$ | 等于 $D[X_1] + D[X_2]$，不是减号                              |
