## 概率论预备知识

### 一维随机变量

设连续型随机变量 $X$，分布函数 $F(x)$，概率密度 $f(x)$。

均值：$E[X] = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$

方差：$D[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2$

> [!tip] 方差记忆口诀
> 平方的平均 减去 平均的平方。

随机变量函数的期望：$E[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f(x)\,dx$

期望的线性性：$E[aX + bY^2 + cZ^3] = aE[X] + bE[Y^2] + cE[Z^3]$

### 二维随机变量

$X$ 与 $Y$ 独立时：$E[XY] = E[X] \cdot E[Y]$

独立与不相关的关系：
- 独立 → 一定不相关
- 不相关 → 不一定独立（例外：$X,Y$ 联合高斯时，两者等价）

### 高斯分布

$X \sim N(\mu, \sigma^2)$，概率密度：
$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

线性变换：若 $X \sim N(\mu, \sigma^2)$，则 $aX + b \sim N(a\mu + b,\; a^2\sigma^2)$

## 随机过程的基本概念

### 什么是随机过程

通信系统中信号和噪声都具有随机性——发送端器件内部有热噪声，信号进入信道后又叠加干扰，每时每刻幅度值不可预知。需要用随机过程来描述。

### 两个观察角度

| 角度 | 视角 | 作用 |
|------|------|------|
| 角度一 | 看作所有样本函数的集合 $\{x_1(t), x_2(t), \dots\}$ | 建立直观认知 |
| 角度二 | 取定时刻 $t_1$，得到一个随机变量 $\xi(t_1)$ | 适合数学描述 |

**本质**：随机过程 = 在随机变量的基础上多了一个**时间维度**。取一个时刻得到一个随机变量，时间连续往前走，得到无穷多个随机变量。

### 数学描述

取定 $t_1$，$\xi(t_1)$ 是随机变量，其统计特性由概率密度描述：

- **一维概率密度** $f_1(x_1, t_1)$：描述单一时刻的统计特性
- **二维概率密度** $f_2(x_1, x_2; t_1, t_2)$：描述两个时刻的联合统计特性
- 可推广至 $n$ 维。$n$ 越大描述越充分；工程上掌握一维和二维即可。

### 数字特征

**均值（数学期望）**：
$$E[\xi(t)] = \int_{-\infty}^{\infty} x \cdot f_1(x, t)\,dx = a(t)$$

是时间 $t$ 的确定函数，表示随机过程的摆动中心。

**方差**：
$$D[\xi(t)] = E[(\xi(t) - a(t))^2] = E[\xi^2(t)] - a^2(t)$$

表示偏离均值的程度。

**自相关函数**，衡量 $t_1$ 和 $t_2$ 两个时刻取值之间的关联程度：
$$R(t_1, t_2) = E[\xi(t_1) \cdot \xi(t_2)]$$

若两个随机变量来自不同随机过程 $\xi$ 和 $\eta$，则称互相关函数（几乎不用）。

$R(t_1, t_2)$ 可写作 $R(t_1, t_1 + \tau)$，其中 $\tau = t_2 - t_1$。

## 平稳随机过程

### 严平稳

统计特性与时间起点无关：对于**任意** $n$ 和任意 $\Delta$，

$$f_n(x_1,\dots,x_n; t_1,\dots,t_n) = f_n(x_1,\dots,x_n; t_1+\Delta,\dots,t_n+\Delta)$$

条件极其苛刻（所有阶都要满足），一般难以达到。

### 宽平稳

只要求 $n=1$ 和 $n=2$ 满足时间平移不变性，由此推出：

- 一维概率密度与 $t$ 无关 → **均值为常数**：$E[\xi(t)] = a$
- 二维概率密度只与时间差 $\tau$ 有关 → **自相关函数仅与 $\tau$ 有关**：$R(t_1, t_2) = R(\tau)$

> [!warning] 宽平稳的数字特征
> **均值为常数，自相关函数仅与时间差 $\tau$ 有关。**

通信系统中大多数信号和噪声都可视为宽平稳过程。以后「平稳」默认指广义平稳。

### 严平稳与宽平稳的关系

- 严平稳 → 宽平稳（一定成立）
- 宽平稳 → 严平稳（不一定，但**对高斯过程成立**）
- 考研复试面试高频考点：说出两者的定义和区别

### 各态历经性

宽平稳过程在满足一定条件下，具有**各态历经性**——可用一个样本的时间平均代替统计平均。

- 条件：各态历经 ⊂ 宽平稳（各态历经的一定是宽平稳，反之不然）
- 意义：实验时只需采集一个样本即可估计均值和自相关函数
- 做题几乎不涉及

### 平稳过程自相关函数的五条性质

对于平稳过程 $\xi(t)$，$R(\tau) = E[\xi(t)\,\xi(t+\tau)]$：

| 性质 | 表达式 | 含义 |
|------|--------|------|
| ① | $R(0) = E[\xi^2(t)]$ | **平均功率** |
| ② | $R(\tau) = R(-\tau)$ | 偶函数 |
| ③ | $\vert R(\tau)\vert \leq R(0)$ | $R(0)$ 是最大值（上界） |
| ④ | $R(\infty) = a^2$ | **直流功率**（$a$ 为均值） |
| ⑤ | $R(0) - R(\infty) = \sigma^2$ | **交流功率 = 方差** |

> [!tip] 记忆：三功率（平均/直流/交流）+ 一偶 + 一上界。

> [!info] 均值为零时的简化
> 若 $a=0$，则 $R(\infty) = 0$，$R(0) = \sigma^2$（平均功率 = 方差 = 交流功率）。在高斯噪声中常用。

> [!warning] 简答题常考
> 写出平稳随机过程自相关函数的性质。（直接列出以上五条）

### 维纳-辛钦定理

**对于平稳随机过程**，自相关函数与功率谱密度构成一对傅里叶变换：

$$P_\xi(\omega) = \int_{-\infty}^{\infty} R(\tau)\,e^{-j\omega\tau}\,d\tau, \quad R(\tau) = \frac{1}{2\pi}\int_{-\infty}^{\infty} P_\xi(\omega)\,e^{j\omega\tau}\,d\omega$$

> [!important] 与确知信号的区别
> 维纳-辛钦定理的前提是**平稳随机过程**。确知信号的自相关函数与功率谱密度也是 FT 对，但不叫维纳-辛钦定理。

由于 $R(\tau)$ 是实偶函数，其 FT $P_\xi(\omega)$ 也必为**实偶函数**。

平均功率的两种求法：$P = R(0)$，或 $P = \frac{1}{2\pi}\int_{-\infty}^{\infty} P_\xi(\omega)\,d\omega = \int_{-\infty}^{\infty} P_\xi(f)\,df$

> [!example] 例：随机相位正弦波
> $\xi(t) = A\cos(\omega_c t + \theta)$，$A,\omega_c$ 为常数，$\theta$ 在 $[0, 2\pi]$ 均匀分布。判断是否平稳，求功率谱密度和平均功率。
>
> **解**：
> 均值：$E[\xi(t)] = A\cdot E[\cos(\omega_c t + \theta)]$。$\theta$ 均匀分布，$\cos$ 和 $\sin$ 在一个周期积分均值为零 → $E[\xi(t)] = 0$（常数）。
>
> 自相关函数：$R(t_1, t_2) = E[A\cos(\omega_c t_1 + \theta) \cdot A\cos(\omega_c t_2 + \theta)]$。积化和差：
> $$= \frac{A^2}{2}E[\cos\omega_c(t_2 - t_1)] + \frac{A^2}{2}E[\cos(\omega_c(t_2 + t_1) + 2\theta)]$$
> 和频项含 $2\theta$，在一个周期积分为零。差频项无随机变量，保留：
> $$R(\tau) = \frac{A^2}{2}\cos(\omega_c\tau), \quad \tau = t_2 - t_1$$
>
> 均值为常数、自相关仅与 $\tau$ 有关 → 平稳。
>
> 功率谱密度：$P(\omega) = \frac{\pi A^2}{2}[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)]$
>
> 平均功率：$R(0) = A^2/2$

> [!example] 例：两独立平稳过程之和
> $X(t), Y(t)$ 统计独立且各自平稳，均值 $a_X, a_Y$，自相关 $R_X(\tau), R_Y(\tau)$。判断 $Z(t) = X(t) + Y(t)$ 是否平稳。
>
> **解**：
> 均值：$E[Z] = E[X] + E[Y] = a_X + a_Y$（常数）
>
> 自相关：$R_Z = E[(X_1+Y_1)(X_2+Y_2)]$，展开四项，利用独立性：
> $$R_Z(\tau) = R_X(\tau) + R_Y(\tau) + 2a_X a_Y$$
>
> 均值为常数、自相关仅与 $\tau$ 有关 → 平稳。

> [!example] 例：随机过程乘余弦（调制）
> $Z(t) = M(t)\cos(\omega_0 t + \theta)$，$M(t)$ 宽平稳（自相关 $R_M(\tau)$），$\theta$ 在 $[0,2\pi]$ 均匀分布且与 $M(t)$ 独立。证 $Z(t)$ 宽平稳。
>
> **解**：
> 均值：$E[Z] = E[M] \cdot E[\cos(\omega_0 t + \theta)] = 0$（常数）
>
> 自相关：利用 $M$ 与 $\theta$ 独立，积化和差，和频项均值为零：
> $$R_Z(\tau) = \frac{1}{2}R_M(\tau)\cos(\omega_0\tau)$$
>
> 均值为常数、自相关仅与 $\tau$ 有关 → 平稳。自相关波形以 $R_M(\tau)$ 为包络、$\cos\omega_0\tau$ 填充。
>
> 功率谱密度：时域 $R_M(\tau) \times \cos\omega_0\tau$ → 频域卷积：
> $P_Z(\omega) = \frac{1}{4}[P_M(\omega-\omega_0) + P_M(\omega+\omega_0)]$
>
> 平均功率：$R_Z(0) = \frac{1}{2}R_M(0)$

> [!example] 例：调制信号的三个结论
> $s(t)$ 为平稳随机脉冲序列，$P_s(f)$ 已知。求 $e(t) = s(t)\cos\omega_c t$ 的功率谱密度。
>
> **解**：
> 求自相关 $R_e(\tau)$ 后做 FT，得到三个重要结论：
>
> | | 结论 |
> |------|------|
> | **幅度谱** | $S(f)$ 左搬右搬，各乘 $1/2$：$\frac{1}{2}[S(f-f_c) + S(f+f_c)]$ |
> | **功率谱** | $P_s(f)$ 左搬右搬，各乘 $1/4$：$\frac{1}{4}[P_s(f-f_c) + P_s(f+f_c)]$ |
> | **调制后功率** | 原功率除以 2：$P_e = \frac{1}{2}\overline{s^2(t)}$ |
>
> 这三个结论在后续调制章节反复使用。


## 高斯随机过程

### 直观理解

任取一个时刻 $t$，得到的随机变量服从**正态分布** $N(\mu(t), \sigma^2(t))$。均值和方差可随时间变化。

### 四条性质

| 性质 | 内容 |
|------|------|
| ① | 知道均值和方差，即可完全确定统计特性（写出概率密度） |
| ② | 宽平稳与严平稳**等价**（对高斯过程特有） |
| ③ | 不相关与独立**等价**（对高斯过程特有） |
| ④ | 高斯过程经过线性系统后**仍为高斯过程** |

> [!info] 性质④的均值/方差计算
> 与概率论中线性变换规则一致：$E[aX+b] = a\mu + b$，$D[aX+b] = a^2\sigma^2$。

### 互补误差函数 erfc

定义：$\displaystyle \mathrm{erfc}(x) = 1 - \mathrm{erf}(x) = \frac{2}{\sqrt{\pi}}\int_x^{\infty} e^{-t^2}dt$

需要记住：
- $\mathrm{erfc}(x)$ 是**减函数**（$x$ 越大值越小）
- 当 $x > 2$ 时，近似公式：$\displaystyle \mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}} e^{-x^2}$（后续计算误码率常用）

## 平稳随机过程通过线性系统

### 基本设定

确知信号通过线性时不变系统：$v_o(t) = v_i(t) * h(t)$，$V_o(f) = V_i(f) \cdot H(f)$

现在输入是平稳随机过程，研究输出的统计特性。

### 结论

若输入 $\xi_i(t)$ 平稳，则输出 $\xi_o(t)$ 也是平稳过程。

| 输出量 | 公式 |
|--------|------|
| 均值 | $E[\xi_o(t)] = a_i \cdot H(0)$（输入均值 × 系统直流增益） |
| 功率谱密度 | $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$ |
| 自相关函数 | $R_o(\tau) = \mathcal{F}^{-1}[P_o(f)]$（先求功率谱，再逆 FT） |

> [!tip] 自相关函数的求法
> 直接算 $R_o(\tau)$ 需要两次卷积，极其繁琐。实际做法：**先求 $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$，再做逆 FT 得到 $R_o(\tau)$**。

> [!example] 例：延迟相加系统
> $Y(t) = X(t) + X(t - T)$，$X(t)$ 平稳，均值为 $a$，自相关 $R_X(\tau)$。求 $Y(t)$ 的自相关函数和功率谱密度。
>
> **解**：令 $X(t) = \delta(t)$ → $h(t) = \delta(t) + \delta(t - T)$
>
> $H(\omega) = 1 + e^{-j\omega T}$，模平方：
> $\vert H(\omega)\vert^2 = (1+e^{-j\omega T})(1+e^{j\omega T}) = 2 + 2\cos\omega T$
>
> $P_Y(\omega) = P_X(\omega) \cdot 2(1 + \cos\omega T)$
>
> 逆 FT（利用 $\cos\omega T = \frac{1}{2}(e^{j\omega T}+e^{-j\omega T})$ 和时移性质）：
> $$R_Y(\tau) = 2R_X(\tau) + R_X(\tau - T) + R_X(\tau + T)$$
>
> 平均功率：$R_Y(0) = 2R_X(0) + 2R_X(T)$（偶函数）

> [!example] 例：延迟相加 + 微分
> $X(t)$ 通过延迟相加后再经微分器。求 $Y(t)$ 的功率谱密度。
>
> **解**：微分在频域对应乘 $j\omega$。总传递函数：
> $$H(\omega) = j\omega(1 + e^{-j\omega T})$$
>
> $\vert H(\omega)\vert^2 = \omega^2 \cdot 2(1 + \cos\omega T)$
>
> $P_Y(\omega) = P_X(\omega) \cdot 2\omega^2(1 + \cos\omega T)$

> [!example] 例：自相关为周期三角脉冲时的功率谱密度
> $X(t)$ 的自相关 $R_X(\tau)$ 是周期 $T=2$ 的周期三角脉冲（单周期：$1 - \vert\tau\vert,\; \vert\tau\vert \leq 1$）。求 $P_X(\omega)$。
>
> **解**：利用结论——已知单脉冲 FT 时，周期延拓后的傅里叶级数系数 $F_n = \frac{1}{T}F(\omega)\big|_{\omega = n\omega_1}$
>
> 单三角脉冲 FT：$F(\omega) = 1 \cdot \mathrm{Sa}^2(\frac{\omega}{2})$（$E=1, \tau=2$ 代入三角脉冲 FT 公式）
>
> $F_n = \frac{1}{2}\mathrm{Sa}^2(\frac{n\pi}{2})$（$\omega_1 = 2\pi/T = \pi$）
>
> $$P_X(\omega) = 2\pi\sum_{n=-\infty}^{\infty} F_n\,\delta(\omega - n\omega_1) = \pi\sum_{n=-\infty}^{\infty} \mathrm{Sa}^2\!\left(\frac{n\pi}{2}\right)\delta(\omega - n\pi)$$
>
> $n=0$ 时 $\mathrm{Sa}(0)=1$ → 幅度 $\pi$；$n$ 为偶数时 $\mathrm{Sa}(n\pi/2)=0$ → 偶数次谐波过零。

## 窄带随机过程

### 定义

频谱集中在中心频率 $f_c$ 附近、带宽 $\Delta f$ 很窄的随机过程（$\Delta f \ll f_c$，$f_c$ 远离零频）。实际通信系统大多是窄带的。

时域波形：如同一个**包络和相位随机缓慢变化的正弦波**。

### 两种表示形式

**形式一（包络-相位）**：
$$\xi(t) = a_\xi(t)\cos[\omega_c t + \varphi_\xi(t)]$$

**形式二（同相-正交）**，将上式三角展开：
$$\xi(t) = \xi_c(t)\cos\omega_c t - \xi_s(t)\sin\omega_c t$$

其中：
- $\xi_c(t) = a_\xi(t)\cos\varphi_\xi(t)$ — **同相分量**
- $\xi_s(t) = a_\xi(t)\sin\varphi_\xi(t)$ — **正交分量**

> [!warning] 注意符号
> 中间是**减号**，不要写成加号。

### 两个重要结论

设 $\xi(t)$ 是均值为零、方差为 $\sigma^2$ 的平稳窄带高斯噪声。

**结论一（同相/正交分量）**：
$\xi_c(t)$ 和 $\xi_s(t)$ 同样都是平稳高斯过程，均值均为零，方差均为 $\sigma^2$。且在同一时刻，$\xi_c$ 与 $\xi_s$ **统计独立**（高斯过程 + 不相关 = 独立）。

**结论二（包络/相位）**：
- 包络 $a_\xi(t)$ 服从**瑞利分布**
- 相位 $\varphi_\xi(t)$ 在 $[0, 2\pi]$ **均匀分布**
- 包络与相位**统计独立**

## 正弦波加窄带高斯噪声

### 研究意义

接收端最前端放置带通滤波器——滤除带外噪声，提高信噪比。输出 = 有用正弦信号 + 窄带高斯噪声。

### 信号模型

$$r(t) = A\cos(\omega_c t + \theta) + n(t)$$

其中 $n(t)$ 是均值为零、方差为 $\sigma^2$ 的窄带高斯噪声，$\theta$ 在 $[0,2\pi]$ 均匀分布。

### 信噪比

$$\gamma = \frac{\text{有用信号功率}}{\text{噪声功率}} = \frac{A^2/2}{\sigma^2}$$

信号功率来自例 结论（$A^2/2$），噪声功率 = 方差 $\sigma^2$（均值为零时平均功率=交流功率=方差）。

### 包络的统计特性

$r(t)$ 的包络服从**广义瑞利分布**（莱斯分布）。

两种极限情况：

| 条件 | 退化为 |
|------|--------|
| 信噪比极低（$\gamma \to 0$，几乎没有信号） | 瑞利分布（纯窄带高斯噪声的包络） |
| 信噪比较高（$\gamma$ 大） | 近似高斯分布 $N(A, \sigma^2)$ |

## 高斯白噪声和带限白噪声

### 白噪声

**定义**：功率谱密度在所有频率上为常数。

| | 双边功率谱密度 | 单边功率谱密度 |
|------|:---:|:---:|
| 数值 | $\frac{n_0}{2}$ | $n_0$ |
| 频率范围 | $(-\infty, +\infty)$ | $[0, +\infty)$ |

自相关函数：$R(\tau) = \frac{n_0}{2}\delta(\tau)$（仅在 $\tau = 0$ 处有值）

> [!info] 白噪声是理想模型
> 真实白噪声不存在——若带宽无限，平均功率 $\to \infty$。但实际器件热噪声的频谱范围（达 THz 量级）远超关心信号带宽，故可近似为白噪声。通常建模为**高斯白噪声**。

由于 $R(\tau) \propto \delta(\tau)$，高斯白噪声在任意两个不同时刻的取值**统计独立**（不相关 + 高斯 = 独立）。

### 低通白噪声

高斯白噪声通过理想矩形低通滤波器（截止频率 $f_H$，幅度 1）：

功率谱密度：$P(f) = \begin{cases} \frac{n_0}{2}, & \vert f\vert \leq f_H \\ 0, & \text{else} \end{cases}$

自相关函数（利用对偶性质从矩形谱反变换）：$R(\tau) = n_0 f_H \cdot \mathrm{Sa}(2\pi f_H \tau)$

平均功率：$R(0) = n_0 f_H$

### 带通白噪声

高斯白噪声通过理想矩形带通滤波器（中心频率 $f_c$，带宽 $B$，幅度 1）：

功率谱密度：低通白噪声的 $P(f)$ 左右搬移到 $\pm f_c$ 处。

自相关函数：$R(\tau) = n_0 B \cdot \mathrm{Sa}(\pi B\tau) \cdot \cos(2\pi f_c \tau)$

平均功率：$R(0) = n_0 B$

> [!tip] 推导思路
> 带通白噪声的功率谱 = 低通功率谱左搬右搬。时域乘 $\cos\omega_c\tau$ 对应频域搬移 → 自相关函数 = 低通自相关 × $\cos\omega_c\tau$（系数调整）。

低通白噪声和带通白噪声统称为**带限白噪声**。

> [!example] 例：理想带通滤波器
> 中心频率 $f_c$、带宽 $B$ 的理想带通滤波器，输入均值为零、功率谱密度为 $n_0/2$ 的高斯白噪声。求输出自相关函数、平均功率和一维概率密度。
>
> **解**：
> 自相关函数：$R(\tau) = n_0 B \cdot \mathrm{Sa}(\pi B\tau) \cdot \cos(2\pi f_c \tau)$
>
> 平均功率：$R(0) = n_0 B$
>
> 一维概率密度：输出仍为高斯过程，均值仍为零，方差 $= n_0 B$。
> $$f(x) = \frac{1}{\sqrt{2\pi n_0 B}} e^{-\frac{x^2}{2n_0 B}}$$

> [!example] 例：RC 低通滤波器（期末高频考题）
> RC 低通滤波器，输入均值为零、功率谱密度为 $n_0/2$ 的高斯白噪声。求输出功率谱密度、自相关函数和一维概率密度。
>
> **解**：
> RC 低通传递函数：$H(f) = \frac{1}{1 + j 2\pi f RC}$，$\vert H(f)\vert^2 = \frac{1}{1 + (2\pi f RC)^2}$
>
> 输出功率谱密度：$P_o(f) = \frac{n_0}{2} \cdot \frac{1}{1 + (2\pi f RC)^2}$
>
> 自相关函数（逆 FT，利用 $e^{-\alpha\vert t\vert} \leftrightarrow \frac{2\alpha}{\alpha^2 + \omega^2}$）：
> $$R_o(\tau) = \frac{n_0}{4RC} e^{-\vert\tau\vert/RC}$$
>
> 平均功率（= 方差）：$R_o(0) = \frac{n_0}{4RC}$
>
> 一维概率密度：输出是高斯过程，均值零，方差 $\frac{n_0}{4RC}$。
> $$f(x) = \sqrt{\frac{2RC}{\pi n_0}} e^{-\frac{2RC}{n_0}x^2}$$

## 本章小结

### 基本概念

| 知识点 | 要点 |
|--------|------|
| 随机过程 | 在随机变量基础上多一个时间维度；两个视角（样本集合 / 逐时刻随机变量） |
| 宽平稳 | 均值为常数 + 自相关仅与 $\tau$ 有关（默认「平稳」= 宽平稳） |
| 严平稳 | 任意 $n$ 维概率密度与时间起点无关；条件苛刻 |
| 自相关函数性质 | $R(0)$=平均功率，$R(\infty)$=直流功率，$R(0)-R(\infty)$=交流功率，偶函数，$R(0)$ 最大 |
| 维纳-辛钦定理 | 平稳过程的 $R(\tau)$ 与 $P(\omega)$ 为 FT 对（前提必须是平稳随机过程） |
| 高斯过程 | 宽平稳 ⇔ 严平稳；不相关 ⇔ 独立；经过线性系统仍为高斯 |
| 窄带高斯噪声 | 同相/正交分量独立同分布；包络瑞利分布、相位均匀分布 |
| 白噪声 | 功率谱为常数，理想模型；自相关为冲激函数 |
| 带限白噪声 | 白噪声通过滤波器后带宽受限；低通（单矩形）和带通（双矩形）两类 |

### 核心公式

| 公式 | 说明 |
|------|------|
| $E[\xi(t)] = a$（常数） | 宽平稳条件一 |
| $R(\tau) = E[\xi(t)\xi(t+\tau)]$ | 宽平稳条件二（自相关仅与 $\tau$ 有关） |
| $R(0) = E[\xi^2(t)]$ | 平均功率 |
| $R(\infty) = a^2$ | 直流功率 |
| $R(0) - R(\infty) = \sigma^2$ | 交流功率 = 方差 |
| $P_\xi(\omega) = \mathcal{F}[R(\tau)]$ | 维纳-辛钦定理 |
| $P_o(f) = P_i(f) \cdot \vert H(f)\vert^2$ | 平稳过程通过线性系统的输出功率谱 |
| $\gamma = \frac{A^2/2}{\sigma^2}$ | 正弦波加窄带高斯噪声的信噪比 |
| $R(\tau) = \frac{n_0}{2}\delta(\tau)$ | 白噪声自相关函数 |
| $n_0 B$ | 带限白噪声平均功率 |
| $\mathrm{erfc}(x) \approx \frac{1}{x\sqrt{\pi}}e^{-x^2}$（$x>2$） | 互补误差函数近似（误码率常用） |

### 考试注意事项

| 注意 | 说明 |
|------|------|
| 判断平稳 | 两步走：均值是否为常数，自相关是否仅与 $\tau$ 有关 |
| 维纳-辛钦前提 | 必须是平稳随机过程；确知信号的 $R \leftrightarrow P$ 对不叫维纳-辛钦定理 |
| 求自相关 | 优先走频域（$P_o = P_i\cdot\vert H\vert^2$ → 逆 FT），不要直接算两次卷积 |
| 窄带表示 | 中间是减号：$\xi_c\cos\omega_c t - \xi_s\sin\omega_c t$ |
| erfc 近似条件 | $x > 2$ 时才成立 |
| 调制三结论 | 幅度谱乘 $1/2$，功率谱乘 $1/4$，调制后功率除以 2 |
