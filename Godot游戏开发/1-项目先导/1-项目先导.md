## 1.1 项目简介

本项目是一款像素风格的八向射击游戏，玩家在地图上自由移动，进行八方向射击，与不同机制的敌人战斗，拾取随机掉落的强化道具，完成最终关卡流程。

游戏体量不大，但足以串联 Godot 开发中最常用、最容易上手的核心知识。

## 1.3 工程实践理念

教程中不只是"跟着抄代码"，而是落地以下专业工程实践：

### 场景结构规范

用规范的组织方式管理玩家、敌人、子弹和道具，避免节点层次混乱。良好的场景结构直接影响后续扩展和维护的难度。

### 资源配置复用

通过 Godot 的 **Resource** 系统配置和复用不同敌人的数据（如血量、速度、行为参数），实现数据驱动的设计模式。

### 动态机制实现

涵盖动态瓦片掉落、增益效果等在不同游戏类型中高频出现的功能。

## 1.4 教学方法

- **架构剖析**：自顶向下讲解设计决策，讲清"为什么这样做"和"该遵循的方法论"
- **概念动画**：配合动画直观演示抽象概念与专业知识
- **举一反三**：扩展讲解更多敌人、道具、关卡机制的设计与实现思路

> **核心理念**：很多同学跟完教程后只会做手把手演示过的内容，想做自己的东西就无从下手。本教程致力于解决这一问题——不只教"这里点哪里、那里填什么"，而是讲清**命名规范、工程结构、资源组织**这些影响日后开发上限的内容。

## 1.5 玩家移动实现

本节展示项目中玩家角色的移动核心代码。

### 代码

```gdscript
extends CharacterBody2D

# 玩家移动速度，单位是像素/秒
@export var move_speed: float = 120.0

func _physics_process(_delta: float) -> void:
    # 读取四个方向输入，并得到标准化后的八向输入向量
    var move_input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    # CharacterBody2D 通过 velocity 配合 move_and_slide() 完成移动
    velocity = move_input * move_speed
    move_and_slide()
```

### 代码解析

| 要素 | 说明 |
|------|------|
| `extends CharacterBody2D` | 继承 Godot 的 2D 物理角色节点，自带碰撞与移动支持 |
| `@export` | 将变量暴露到 Inspector 面板，可在编辑器中直接调整而无需改代码 |
| `_physics_process()` | 物理帧回调，固定频率执行，适合处理物理相关的移动逻辑 |
| `Input.get_vector()` | 读取四个方向输入并返回标准化向量，支持八方向移动（含对角线） |
| `velocity` | CharacterBody2D 的内置属性，设置角色速度 |
| `move_and_slide()` | 根据 `velocity` 自动移动并处理碰撞滑动，无需手动写碰撞检测 |

### CharacterBody2D 关键属性

Inspector 面板中可配置的关键属性：

- **Motion Mode**：运动模式（Grounded / Floating）
- **Up Direction**：指定"上"方向，默认 `(0, -1)`
- **Slide on Ceiling**：碰到天花板时是否滑动
- **Floor / Moving Platform**：地板与移动平台相关配置
- **Collision**：碰撞层与碰撞掩码设置
