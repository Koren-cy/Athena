# Ubuntu环境搭建

## 环境概览与VMware安装

C语言编程全部在Linux环境下进行，具体使用Ubuntu发行版（Ubuntu是Linux的一种桌面发行版）。环境搭建采用VMware虚拟机，需先后安装两个软件：**VMware Workstation Player** 和 **Ubuntu桌面版**。

VMware的安装过程较为简单，下载安装包后保持默认选项，一路点击“下一步”即可完成。

![keyframe_001_39.6s](img/vmware_install_39.6.jpg)

---

## 创建Ubuntu虚拟机

安装完成后，VMware快捷方式会出现在桌面。打开VMware，进入主页，按照以下步骤创建虚拟机：

1. 点击“创建新虚拟机”。  
   ![keyframe_004_51.0s](img/create_vm_51.0.jpg)  
   ![keyframe_007_77.2s](img/vmware_home_77.2.jpg)

2. 在向导中选择提前下载好的Ubuntu镜像文件（ISO格式）。

3. 输入用户信息：
   - **全名**：可任意填写。
   - **用户名**：Linux是多用户操作系统，此处设置的即登录账户。示例中填写 `murphy`。
   - **密码** / **确认密码**：需牢记该密码，后续执行提权操作（如 `sudo`）时需验证。

4. 指定虚拟机名称和存储位置，可按需修改或保持默认。

5. 设置磁盘大小。默认值为20 GB，本课程实验足够使用。若后续需编译Linux内核等大型项目，可按需调大。

6. 在摘要页面点击“**自定义硬件**”，优化性能：
   - 内存：从默认2 GB改为 **4 GB**（4096 MB）。
   - 处理器核心数：改为 **2 核**。  
   ![keyframe_009_232.4s](img/hardware_settings_232.4.jpg)

7. 确认无误后点击“完成”，虚拟机将自动安装Ubuntu系统。

## 桌面环境与终端

Ubuntu桌面与Windows类似，左侧任务栏包含浏览器、文件管理器等常用应用。但在Linux下进行编程，绝大部分操作通过**命令行终端**完成，图形化文本编辑器很少使用。后续课程将使用Vim编辑器进行代码编写。

频繁使用终端，可通过以下三种方式打开：

1. **从菜单启动**  
   点击桌面左下角“菜单”按钮（或按Super键），输入 `term` 搜索，或在应用列表中找到 **Terminal** 图标，单击打开。  
   ![keyframe_017_370.9s](img/terminal_menu_370.9.jpg)

2. **右键快捷菜单**  
   在桌面空白处点击右键，选择 “Open Terminal”。

3. **快捷键**  
   同时按下 `Ctrl + Alt + T`。

打开终端后，提示符格式类似 `murphy@ubuntu:~$`：  
- `murphy`：当前登录的用户名。  
- `ubuntu`：主机名。  
- `~`：表示用户的家目录（home目录）。  
- `$`：表示当前为普通用户权限。

## 基本命令演示

### 列出文件：`ls`

`ls` 命令用于查看目录中的文件和子目录。

```bash
ls        # 列出非隐藏文件与文件夹
ls -a     # 列出所有文件（含 . 开头的隐藏文件）
ls -l     # 以长格式显示详细信息（权限、所有者、大小、时间等）
ls -la    # 组合 -l 与 -a，显示所有文件的详细属性
```

**输出示例**  
执行 `ls -a` 可看到 `.bashrc`、`.config` 等隐藏目录和文件。  
![keyframe_018_474.1s](img/ls_a_output_474.1.jpg)

执行 `ls -l` 后，每行列出了文件类型与权限、链接数、所有者、用户组、大小、日期和文件名。  
![keyframe_019_508.0s](img/ls_l_output_508.0.jpg)

执行 `ls -la` 同时显示隐藏文件及其详细属性。  
![keyframe_021_542.7s](img/ls_la_output_542.7.jpg)

### 切换目录：`cd`

`cd` 命令用于切换工作目录。

```bash
cd Videos   # 进入 Videos 目录（可用 Tab 键自动补全）
ls          # 查看当前目录内容
cd ..       # 返回上一级目录
cd          # 直接回车，返回用户家目录
```

![keyframe_020_534.5s](img/cd_command_534.5.jpg)

### 清屏：`clear`

当终端内容过多时，输入 `clear` 可清空屏幕，保持界面整洁。

### 创建目录：`mkdir`

`mkdir` 命令用于创建新目录。

```bash
mkdir 123   # 创建名为 123 的目录
ls          # 查看确认，可看到新增的 123 目录
cd 123      # 进入该目录
ls          # 空目录，无输出
```

### 安装软件：以Vim为例

在Ubuntu中，使用包管理工具 `apt` 安装软件。以安装Vim编辑器为例：

```bash
sudo apt-get install vim
```

**命令解析**
1. `sudo`：以超级用户（root）权限执行命令，安装系统软件需要此权限。
2. `apt-get`：Ubuntu下的包管理工具，用于管理软件包。
3. `install`：`apt-get`的子命令，表示安装操作。
4. `vim`：要安装的软件包名称，即Vim编辑器。

执行后系统提示输入当前用户的密码（密码输入时不显示字符），验证通过后自动下载并安装。若已是最新版本，则提示 `vim is already the newest version`。

## 小结

- 开发环境由VMware虚拟机与Ubuntu操作系统构成。
- 创建虚拟机时需注意用户名、密码设置，以及适当分配内存（4GB）和CPU核心（2核）。
- 终端是与Linux交互的主要界面，可通过菜单、右键或快捷键 `Ctrl+Alt+T` 打开。
- 常用基础命令：`ls`（查看文件）、`cd`（切换目录）、`clear`（清屏）、`mkdir`（创建目录）。
- 使用 `sudo apt-get install` 可安装所需软件包，如Vim编辑器。
