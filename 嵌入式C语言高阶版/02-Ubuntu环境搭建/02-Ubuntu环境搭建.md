## 2.1 创建 Ubuntu 虚拟机

1. **启动 VMware 并新建虚拟机**  
   安装完成后双击桌面图标打开 VMware，进入主界面后点击 **“创建新虚拟机(N)”**。

   ![VMware 主界面](img/keyframe_007_77.2s.jpg)
   ![新建虚拟机向导](img/keyframe_002_43.8s.jpg)

2. **选择安装镜像**  
   在弹出的向导中，选择事先准备好的 Ubuntu 系统镜像文件（ISO 格式），然后点击“下一步”。

   ![选择安装镜像](img/keyframe_004_51.0s.jpg)

3. **填写用户信息**  
   系统会提示设置以下信息：
   - **全名**：可随意填写，不影响系统使用。
   - **用户名**：即登录系统的账号，示例中设置为 `murphy`。
   - **密码**：需要牢记。后续在终端中执行 `sudo` 等提权操作时，必须输入该密码以验证身份。

4. **指定名称与位置**  
   虚拟机名称可保留默认，存储位置可根据磁盘空间自行指定（示例中创建了 `Linux2` 文件夹）。

5. **配置硬件**  
   进入硬件配置环节，重点调整以下三项：
   - **磁盘大小**：默认 20 GB，对于本课程的学习内容已足够；若计划编译 Linux 内核等大型工程，可适当增大。
   - **内存**：建议设置为 **4 GB**（4096 MB），以保证系统运行流畅。
   - **处理器**：建议核心数设置为 **2**。

   设置完成后点击“完成”，虚拟机将自动开始创建并进入系统安装流程。

   ![完成虚拟机创建](img/keyframe_009_232.4s.jpg)

## 2.3 桌面环境与终端

登录后的桌面布局与常见桌面操作系统类似，左侧任务栏提供常用应用入口（如浏览器、文件管理器等）。在 Linux 下编写代码时，几乎不使用图形化文本编辑器，而是借助命令行下的编辑器（如 Vim），因此熟练掌握终端的使用至关重要。

打开终端（Terminal）共有三种常用方式：

1. **通过应用菜单**：点击桌面左下角的“显示应用程序”菜单（九宫格图标），在列表中找到并点击 **Terminal**。
   ![终端图标](img/keyframe_016_368.4s.jpg)
2. **通过桌面右键菜单**：在桌面空白处单击鼠标右键，选择 **Open Terminal**。
3. **通过快捷键**：按下 `Ctrl + Alt + T` 组合键。

终端窗口打开后，会显示形如 `murphy@ubuntu:~$` 的提示符。其中 `murphy` 为当前用户名，`ubuntu` 为主机名，`~` 表示当前位于用户的家目录，`$` 是普通用户的命令提示符。在此之后即可输入各种 Shell 命令。

## 2.4 基本 Shell 命令

### 2.4.1 列出文件与目录：`ls`

`ls` 是最常用的命令之一，用于查看指定目录下的文件与子目录。

- **基本用法**：`ls`  
  列出当前目录下的非隐藏文件和目录。

- **显示隐藏文件**：`ls -a`  
  所谓隐藏文件是指以 `.` 开头的文件或目录，默认不会显示。`-a` 选项可将其一并列出。

  ![ls -a 输出示例](img/keyframe_018_474.1s.jpg)

- **长格式显示**：`ls -l`  
  以列表形式展示每个条目的详细属性，如权限、所有者、大小、修改时间等。

- **组合选项**：`ls -la`  
  同时显示所有文件（含隐藏文件）及其详细属性。

  ![ls -la 输出示例](img/keyframe_020_534.5s.jpg)

在 `ls -la` 的输出中，第一列字符串（如 `drwxr-xr-x`）表示文件类型与访问权限：第一个字符 `d` 代表目录（`-` 代表普通文件），后续每三个字符为一组，分别代表所有者、所属组、其他用户的**读（r）**、**写（w）**、**执行（x）** 权限。其余各列依次为链接数、所有者、所属组、文件大小（字节）、最后修改时间和名称。

| 命令示例 | 作用 |
|----------|------|
| `ls -a` | 列出所有文件，包括隐藏文件 |
| `ls -l` | 以长格式列出文件详细属性 |
| `ls -la` | 组合以上两种选项，显示完整信息 |

### 2.4.2 切换目录：`cd`

使用 `cd` 命令可在目录树中移动。

- **进入子目录**：`cd Videos`  
  进入当前目录下的 `Videos` 文件夹，提示符路径会随之更新。

- **返回上一级目录**：`cd ..`  
  `..` 代表父目录，该命令用于回退到当前目录的上一层。

### 2.4.3 清屏与创建目录：`clear` / `mkdir`

- **清屏**：`clear`  
  当终端内容过多时，使用此命令可清空当前屏幕，便于后续操作。

- **创建目录**：`mkdir 目录名`  
  在当前路径下新建一个目录。例如 `mkdir 123` 会创建一个名为 `123` 的空目录，随后可用 `ls` 确认其存在，并通过 `cd 123` 进入。

以上命令虽基础，却是后续编程工作中最频繁使用的操作，需熟练掌握。

## 2.5 安装 Vim 编辑器

Ubuntu 默认不一定包含完整的 Vim 编辑器（或仅预装最小版本），而本课程后续需要用它编写 C 代码，因此需通过包管理工具进行安装。在终端中执行以下命令：

```bash
sudo apt-get install vim
```

| 命令片段 | 说明 |
|----------|------|
| `sudo` | 以超级用户（root）权限执行命令，安装软件需要系统级改动 |
| `apt-get` | Ubuntu 的软件包管理工具，用于查询、安装、升级和卸载软件 |
| `install` | 操作指令，表示安装软件包 |
| `vim` | 目标软件包的名称 |

执行后会提示输入用户密码（输入时不会回显任何字符），回车后 `apt-get` 会自动解析依赖并下载安装。如示例中系统提示 `vim is already the newest version`，则表示 Vim 已为最新，无需重复安装。

![在终端中安装 Vim](img/keyframe_022_741.2s.jpg)

至此，Ubuntu 下的基本开发环境搭建完毕，可以在此基础上进行后续的 C 语言编程学习。

## 小结

- 在 VMware 中创建 Ubuntu 虚拟机时，需重点关注内存、处理器核心数等硬件资源的分配。
- 登录系统后，可通过应用菜单、右键菜单或快捷键 `Ctrl+Alt+T` 打开终端；终端提示符反映了当前用户、主机及路径信息。
- 基本文件与目录操作命令包括 `ls`（列出）、`cd`（切换）、`clear`（清屏）、`mkdir`（创建目录），灵活组合选项可实现更精细的控制。
- 使用 `sudo apt-get install` 可以方便地安装 Vim 等开发工具，是 Ubuntu 系统下软件管理的基本方式。
