## 1. 环境概览与VMware安装
本课程的C语言编程全部在Linux环境下进行，具体使用Ubuntu发行版（可以认为Ubuntu就是Linux的一种）。我们选择在VMware虚拟机中搭建整套环境，因此需要先后安装两个软件：VMware Workstation Player 和 Ubuntu 桌面版。

VMware的安装过程非常简单，下载安装包后保持默认选项一路点击“下一步”即可完成。  
![keyframe_001_39.6s](img/vmware_install_39.6.jpg)

## 2. 创建Ubuntu虚拟机
安装完VMware后，桌面上会出现该软件的快捷方式。打开VMware，进入主页，点击“创建新虚拟机”。  
![keyframe_004_51.0s](img/create_vm_51.0.jpg)  
![keyframe_007_77.2s](img/vmware_home_77.2.jpg)

在向导中，首先选择提前下载好的Ubuntu镜像文件。

接着输入用户信息。这里的“全名”可以随意填写，而下方三个字段较为关键：**用户名**、**密码**、**确认密码**。  
- **用户名**：Linux是多用户操作系统，这里的用户名就是向系统注册的登录账户。例如本演示中填写了 `murphy`。  
- **密码**：请务必牢记该密码，因为后续在系统中执行提权操作（如 `sudo`）时会要求输入。

下一步是指定虚拟机名称和存储位置，这里保持默认或按个人习惯修改即可。

然后设置磁盘大小，默认值为 20 GB。在本课程的全部实验中，20 GB 已经足够使用。注意：如果后续有编译 Linux 内核等需求，20 GB 可能不够，届时可根据需要调整。

在最终摘要页面，需要**自定义硬件**，调整以下两项以获得更流畅的体验：
- **内存**：从默认的 2 GB 改为 **4 GB** (4096 MB)
- **处理器核心数**：改为 **2 核**

![keyframe_009_232.4s](img/hardware_settings_232.4.jpg)

确认无误后点击“完成”，虚拟机便开始自动安装 Ubuntu 系统。

## 3. 系统启动与登录
安装完成后，虚拟机会自动重启并进入登录界面。输入之前设置的用户密码即可登录。  
![keyframe_015_350.3s](img/login_screen_350.3.jpg)

首次进入桌面可能稍慢，等待片刻后便会看到完整的 Ubuntu 图形桌面环境。

## 4. 桌面环境与终端打开方式
Ubuntu 的桌面与 Windows 类似，左侧有任务栏，包含浏览器、文件管理器等常用应用。不过在 Linux 下进行编程，绝大部分操作都通过**命令行终端**完成，图形化的文本编辑器等很少使用（后续课程会使用 Vim/vim 进行代码编写）。

本课程需要频繁使用终端，下面介绍三种打开终端的方法：

1. **从菜单启动**  
   点击桌面左下角的“菜单”按钮（或按键盘上的 Super 键），在搜索框中输入 `term`，或在“All”应用列表中找到 **Terminal** 图标，单击即可打开。  
   ![keyframe_017_370.9s](img/terminal_menu_370.9.jpg)

2. **右键快捷菜单**  
   在桌面空白处点击鼠标右键，选择 “Open Terminal”。

3. **快捷键**  
   同时按下 `Ctrl` + `Alt` + `T`，这是最便捷的方式。

打开终端后，可以看到提示符格式类似：`murphy@ubuntu:~$`  
其中 `murphy` 是当前登录的用户名，`@` 后面是主机名，`~` 代表用户的家目录，`$` 表示当前是普通用户权限。

## 5. 基本命令演示
下面通过几个常用命令来感受 Linux 命令行的交互方式。

### 5.1 列出文件：`ls`
- `ls`：列出当前目录下的非隐藏文件与文件夹。  
- `ls -a`：列出**所有**文件（包含以 `.` 开头的隐藏文件）。  
- `ls -l`：以长格式展示详细信息，包括权限、所有者、文件大小、修改时间等。  
- `ls -la`：组合效果，显示所有文件的详细属性。

实际终端中的操作示例如下：  
![keyframe_018_474.1s](img/ls_a_output_474.1.jpg)  
执行 `ls -a` 后，可以看到 `.bashrc`、`.config` 等隐藏目录和文件。  

![keyframe_019_508.0s](img/ls_l_output_508.0.jpg)  
执行 `ls -l` 后，每一行列出了文件类型与权限、链接数、所有者、用户组、大小、日期和文件名。

![keyframe_021_542.7s](img/ls_la_output_542.7.jpg)  
执行 `ls -la` 可以同时看到隐藏文件及其详细属性。

### 5.2 切换目录：`cd`
- `cd 目录名`：进入指定目录（可使用 Tab 键自动补全）。  
- `cd ..`：返回上一级目录。  
- 直接输入 `cd` 回车，会回到当前用户的家目录。

例如，当前在家目录下，想进入 `Videos` 目录：
```bash
cd Videos
ls          # 查看 Videos 目录内容
cd ..       # 退回上一级
```
![keyframe_020_534.5s](img/cd_command_534.5.jpg)

### 5.3 清屏：`clear`
当终端中信息过多时，输入 `clear` 即可清空屏幕，使界面整洁。

### 5.4 创建目录：`mkdir`
- `mkdir 目录名`：在当前路径下新建一个文件夹。

例如，创建一个名为 `123` 的目录并进入：
```bash
mkdir 123
ls          # 可以看到新增的 123 目录
cd 123
ls          # 空目录，无输出
```

### 5.5 安装软件：以 Vim 为例
在 Linux 下，可以通过包管理工具 `apt` 来安装软件。例如安装 Vim 编辑器：
```bash
sudo apt-get install vim
```
系统提示输入当前用户的密码（输入的密码不会显示出来），然后会自动下载并安装。如果软件已经是最新版本，会提示 `vim is already the newest version`。

![keyframe_022_741.2s](img/install_vim_741.2.jpg)
