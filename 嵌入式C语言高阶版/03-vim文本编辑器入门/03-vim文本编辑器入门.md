## Vim简介

Vim（Vi IMproved）是从传统的Vi编辑器发展而来的增强型文本编辑器，在Linux和Unix系统上被广泛使用。它支持代码补全、快速跳转、查找与替换等高效功能，是程序开发和系统管理的常用工具。

---

## Vim的三种工作模式

Vim的核心操作基于三种模式，与常见的图形化文本编辑器（如Windows记事本）的交互方式不同。理解这些模式是使用Vim的关键。

| 模式 | 用途 | 进入方式 | 退出/切换方式 |
| :--- | :--- | :--- | :--- |
| **正常模式 (Normal Mode)** | 浏览文件、执行查找、替换、复制、删除等操作；默认启动模式 | 打开Vim时自动进入；从其他模式按`Esc`返回 | 不可直接退出，需进入命令行模式 |
| **输入模式 (Insert Mode)** | 插入、修改文本内容 | 在正常模式下按`i`、`a`或`o`等键 | 按`Esc`返回正常模式 |
| **命令行模式 (Command-line Mode)** | 执行保存(`:w`)、退出(`:q`)、查找替换等命令 | 在正常模式下输入冒号`:` | 命令执行后自动返回正常模式，或按`Esc`取消 |

三种模式的切换关系如下图所示：

在正常模式下，屏幕左下角通常无特殊提示；进入输入模式后，左下角会显示`INSERT`字样；进入命令行模式时，左下角会出现`:`提示符并等待输入命令。

## 安装Vim

在Ubuntu等Debian系Linux发行版中，若系统未预装Vim，可通过以下命令安装：

```bash
sudo apt-get install vim
```

- `sudo`：以超级用户权限执行命令，安装软件需要管理员权限。
- `apt-get`：Debian系系统的包管理工具（Advanced Package Tool），用于安装、更新和删除软件。
- `install vim`：指定安装Vim软件包。

输入命令并回车后，根据提示输入管理员密码，系统将自动完成下载和安装。若已安装最新版本，则会提示无需更新。

## 使用Vim编辑文件

### 打开文件

在终端中输入`vim`并后跟文件名，即可打开或创建文件。若文件不存在，Vim会创建一个新文件。

例如，创建一个C语言源文件`1.c`：

```bash
vim 1.c
```

执行后进入Vim界面，此时处于**正常模式**，文件内容为空，左下角无模式提示。

### 进入输入模式并编写代码

在正常模式下按`i`键（意为insert），切换至输入模式。左下角出现`INSERT`字样，表明可以输入文本。

输入以下简单的C程序：

```c
#include <stdio.h>

int main(void)
{
    printf("hello world\n");
}
```

输入过程中可使用`Enter`换行、`Backspace`删除等常规操作。

### 保存与退出

编写完成后，按以下步骤保存文件并退出Vim：

1. 按`Esc`键返回正常模式，左下角的`INSERT`字样消失。
2. 输入冒号`:`进入命令行模式，左下角出现`:`光标。
3. 输入`wq`（write and quit）后按`Enter`执行。

```
:wq
```

| 命令 | 功能 | 说明 |
| :--- | :--- | :--- |
| `:w` | 保存文件 | 将当前内容写入磁盘 |
| `:q` | 退出编辑器 | 若文件未保存会提示 |
| `:wq` | 保存并退出 | 等效于执行`:w`后再执行`:q` |

执行后终端返回普通命令行提示符，文件`1.c`已保存在当前目录中。

## 正常模式下的文本查找

保存退出后，可再次使用`vim 1.c`打开文件，验证内容已保存。在查看文件时，可以在正常模式下直接进行文本查找。

例如，要查找字符串`hello`：

- 按`/`键，左下角出现`/`提示符。
- 输入待查找的文本`hello`，按`Enter`确认。
- Vim会高亮第一个匹配项（若有）。
- 按`n`键跳转到下一个匹配项。

查找功能完全在正常模式下进行，无需切换到输入模式或命令行模式。

## 进阶学习：vimtutor

Vim功能丰富，入门后若希望系统学习更多操作（如光标快速移动、文本块编辑等），可利用系统自带的互动教程`vimtutor`。

在终端输入以下命令启动英文教程：

```bash
vimtutor
```

或启动中文教程：

```bash
vimtutor zh
```

该命令会打开一份Vim教程文档的副本，读者可按照提示逐步练习。完成全部内容大约需要25–30分钟，是快速掌握Vim核心技巧的有效途径。

![vimtutor启动界面](img/vimtutor_start_480.8.jpg)

*图：vimtutor启动后的界面，教程从光标移动等基本操作开始引导。*

## 小结

- Vim包含**正常模式**、**输入模式**和**命令行模式**三种工作模式，通过`i`、`Esc`、`:`等键相互切换。
- 使用`vim 文件名`打开或创建文件，`i`进入输入模式编写内容，`Esc`回到正常模式，`:wq`保存并退出。
- 在正常模式下可按`/`进行文本查找，并用`n`跳转至下一个匹配项。
- 通过`vimtutor`命令可跟随交互式教程系统学习Vim的更多操作。
