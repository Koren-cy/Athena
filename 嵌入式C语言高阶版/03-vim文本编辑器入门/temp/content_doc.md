## 1. vim 简介
vim 是从传统的 vi 编辑器发展而来的一个文本编辑器。vi 是 Unix 系列操作系统中常用的编辑器，而经过多年演进，vim 已经具备了代码补全、快速跳转、查找等强大功能，在 Linux 系统中被广泛使用。

## 2. vim 的三种工作模式
vim 拥有三种核心模式，可以类比常见的图形化文本编辑器（如 Notepad）来理解：

- **正常模式 (Normal Mode)**  
  打开 vim 后默认进入的模式。在该模式下可以进行阅读、查找、替换等操作。例如在 Notepad 中按 `Ctrl+F` 进行查找，或使用替换对话框进行文本替换，对应的就是在 vim 的正常模式下执行类似任务。在正常模式下不能直接输入文本，但可以通过快捷键执行复制、粘贴、删除、移动光标等操作。

- **输入模式 (Insert Mode)**  
  用于文本输入。在 Notepad 中，直接点击编辑区域即可开始输入；在 vim 中，需要从正常模式切换到输入模式才能键入内容。进入输入模式后，屏幕左下角会显示 `INSERT` 字样。

- **命令行模式 (Command-line Mode)**  
  用于执行保存、退出、设置等操作。在 Notepad 中，保存、另存为等功能通过菜单或快捷键触发；在 vim 中，这些功能主要在命令行模式中通过输入命令完成，例如保存为 `:w`，退出为 `:q`。

三种模式之间的切换关系与按键如下：
- **正常模式 → 输入模式**：按 `i`、`a` 或 `o` 键。
- **输入模式 → 正常模式**：按 `ESC` 键。
- **正常模式 → 命令行模式**：输入冒号 `:`。
- **命令行模式 → 正常模式**：执行完命令后自动返回，或按 `ESC` 键取消。

## 3. 安装 vim
在 Ubuntu 等 Debian 系 Linux 发行版中，若系统未预装 vim，可通过以下命令安装：
```bash
sudo apt-get install vim
```
其中 `apt` 是 Application Package Tool（软件包工具）的缩写。执行后需要输入管理员密码，系统会自动完成下载和安装。若已安装，则会提示没有需要更新的软件包。

## 4. 使用 vim 编辑文件

### 4.1 打开文件
在终端中输入 `vim` 后跟文件名即可打开文件。若文件不存在，vim 会创建一个新文件。例如，创建一个 C 语言源文件 `1.c`：
```bash
vim 1.c
```
执行后进入 vim 主界面，此时处于**正常模式**，屏幕左下角无特殊提示，文件内容为空。

### 4.2 进入输入模式并编写代码
在正常模式下按 `i` 键（i 为 insert 的首字母）切换到输入模式，左下角出现 `INSERT` 单词，表示当前可以输入文本。接下来可以键入一段简单的 C 代码：
```c
#include <stdio.h>

int main(void)
{
    printf("hello world\n");
}
```
输入过程中按回车换行，按退格删除，与普通编辑器的操作习惯相似。

### 4.3 保存与退出
1. 输入完代码后，需要从输入模式返回正常模式：按 `ESC` 键。此时左下角的 `INSERT` 字样消失，表示已回到正常模式。
2. 在正常模式下输入冒号 `:`，左下角出现 `:` 提示符，光标闪烁，表示已进入命令行模式。
3. 输入 `wq`（`w` 代表 write，写入文件；`q` 代表 quit，退出编辑器），然后按回车，vim 便会将文件保存并退出。
   ```
   :wq
   ```
执行后终端会回到普通命令行提示符，且文件已成功保存在磁盘上。

## 5. 查看文件与正常模式下的查找
再次使用 `vim 1.c` 打开刚刚保存的文件，可以看到之前输入的代码再次呈现在屏幕上，说明保存成功。

在正常模式下，可以进行文本查找。例如，要查找字符串 `hello`：
- 输入斜杠 `/`，左下角出现 `/` 提示符。
- 继续输入 `hello` 然后按回车，vim 会高亮第一个匹配项。
- 按小写 `n` 键可以跳转到下一个匹配项（若只有一个匹配则停留在原处）。

查找功能是正常模式的典型用法之一，无需进入输入模式或命令行模式。

## 6. vimtutor 练习工具
vim 功能十分丰富，入门后若想进一步掌握更多操作（如移动光标、高级编辑等），可以使用 Linux 系统自带的交互式教程工具 `vimtutor`。在终端直接输入：
```bash
vimtutor
```
或使用中文版教程：
```bash
vimtutor zh
```
该工具会打开一份教程文档，读者可以在副本中按照提示逐步练习，完成全部内容大约需要 25–30 分钟，是快速上手 vim 的有效途径。
