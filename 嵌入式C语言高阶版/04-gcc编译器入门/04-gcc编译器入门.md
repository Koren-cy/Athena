## GCC 简介

GCC（GNU Compiler Collection）是 GNU 项目推出的编译器套件，最初专为编译 C 语言而设计，如今已扩展为支持 C++、Objective-C、Java、Fortran 等多种编程语言的编译集合。GCC 遵循 GPL 许可证，是开源生态的基石之一；Linux 操作系统本身正是依托 GCC 构建其编译系统。

## 安装 GCC 编译环境

在 Debian/Ubuntu 类的 Linux 环境中，可通过安装 `build-essential` 元包一次性获取 GCC 及相关基础编译工具（如 g++、make 等）。在终端中执行：

```bash
sudo apt-get install build-essential
```

若系统中已存在该包，系统会提示“已经是最新版本”。

![keyframe_002_90.4s](img/install_build_essential_90.4.jpg)

*安装 build-essential 工具包*

安装完成后，使用以下命令验证 GCC 是否可用并查看版本信息：

```bash
gcc -v
```

命令输出中会显示目标架构、线程模型以及 GCC 版本号。示例环境中的版本为 **9.4.0**（实际版本会随系统更新而不同）。

| 命令部分 | 说明 |
|----------|------|
| `gcc` | 调用 GNU C 编译器 |
| `-v` | 输出详细的配置、版本等信息，用于诊断或确认安装 |

## GCC 命令基本格式

GCC 的标准命令结构如下：

```bash
gcc -o <输出文件名> <要被编译的源文件> [编译选项]
```

- **`-o`**：指定最终生成的可执行文件的名称（可以任意命名）；
- **源文件**：紧随其后，可同时列出多个 C 源文件；
- **编译选项**：附加的控制参数（如优化级别、调试信息等），可省略，此时 GCC 按默认设置编译。

建议在实战中严格遵循“`-o` 输出文件 输入文件”的顺序，以避免因选项错位导致编译异常。

## 编译并运行 Hello World 程序

以下步骤演示如何用 GCC 将一个简单的 C 程序编译为可执行文件并运行。

1. 准备工作：用任意文本编辑器（如 vim）创建 C 源文件 `1.c`，内容如下：
   ```c
   #include <stdio.h>
   int main() {
       printf("Hello");
       return 0;
   }
   ```

   | 代码行 | 说明 |
   |--------|------|
   | `#include <stdio.h>` | 包含标准输入输出头文件，为 `printf` 函数提供声明 |
   | `int main() { ... }` | 程序的主函数入口，所有可执行 C 程序均从此处开始执行 |
   | `printf("Hello");` | 向终端输出字符串 `Hello` |
   | `return 0;` | 程序正常结束，返回数值 0 表示成功 |

2. 在终端中执行编译命令：
   ```bash
   gcc -o bin 1.c
   ```
   该命令将 `1.c` 编译为名为 `bin` 的可执行文件，且未附加其他编译选项。

   | 参数/选项 | 说明 |
   |-----------|------|
   | `gcc` | 调用 C 编译器 |
   | `-o bin` | 指定输出文件名为 `bin`（若省略，默认生成 `a.out`） |
   | `1.c` | 待编译的 C 源代码文件 |

3. 检查当前目录，确认生成了新的可执行文件 `bin`。

4. 运行该程序：
   ```bash
   ./bin
   ```
   终端输出 `Hello`，表明编译和运行均成功。

## 编译选项：以 `-g` 为例

GCC 提供了丰富的编译选项以精细控制编译行为。其中，`-g` 是一个常用选项，它指示编译器在生成的可执行文件中嵌入专门的调试信息（如符号表、行号映射等），供 GDB 等调试器使用。

一个直观的对比是文件体积：在未使用 `-g` 时，上面生成的 `bin` 文件大小约为 **17 KB**；添加 `-g` 后，由于额外载入调试数据，文件尺寸会明显增大。

| 特性 | 无 `-g` 编译 | 带 `-g` 编译 |
|------|-------------|-------------|
| 文件大小 | 较小（示例中约 17 KB） | 明显增大 |
| 包含调试信息 | 否 | 是（符号表、行号等） |
| 适用场景 | 最终发布、生产环境 | 开发调试、问题排查 |

在后续开发中，当需要调试程序时，编译命令只需在源文件后添加 `-g` 即可，例如：
```bash
gcc -o bin_debug 1.c -g
```
更多高级选项将在后续专题中深入讲解。

## 小结

- GCC 是 GNU 编译器套装，支持多种语言，构成了 Linux 下 C/C++ 编译的核心工具。
- 使用 `sudo apt-get install build-essential` 可一键安装 GCC 及基础开发工具链。
- GCC 的基本编译命令格式为 `gcc -o 输出文件 源文件`，可灵活附加选项。
- 选项 `-g` 用于在可执行文件中嵌入调试信息，虽增加文件体积，但对开发调试至关重要。
- 通过编译、运行一个简单的 C 程序，可以验证开发环境是否搭建成功。
