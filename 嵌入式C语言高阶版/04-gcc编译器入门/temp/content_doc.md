## 1. GCC 简介
GCC 是 GNU Compiler Collection 的简称，属于 GNU 开源项目的编译器套件。  
它最初是为 GNU 操作系统专门编写的、用于编译 C 代码的编译器。经过多年发展，GCC 已扩展为支持 C++、Java、Objective‑C 等多种编程语言的编译集合。  
GCC 本身遵循 GPL 许可证，Linux 操作系统就是基于 GCC 构建其编译系统的。

## 2. 安装 GCC 编译环境
在 Linux 终端中，使用以下命令安装基础编译工具链：
```bash
sudo apt-get install build-essential
```
该命令会安装 GCC 及相关编译组件。若已安装，系统会提示“已经是最新版本”。

![keyframe_002_90.4s](img/install_build_essential_90.4.jpg)

安装完成后，通过 `gcc -v` 检查是否安装成功，并查看当前版本：
```bash
gcc -v
```
示例输出中可以看到目标架构、线程模型以及版本号 – 视频中安装的版本为 **9.4.0** (Ubuntu 9.4.0-1ubuntu1~20.04.2)。

![keyframe_003_99.3s](img/build_essential_installed_99.3.jpg)

## 3. GCC 命令基本格式
GCC 的标准命令结构如下：
```bash
gcc -o <输出文件名> <要被编译的源文件> [编译选项]
```
- `-o` 指定输出的可执行文件名称；
- 随后紧跟需要编译的源文件（可以多个）；
- 最后可以添加各种选项（例如优化级别、调试信息等），选项也可以省略，此时 GCC 按默认方式编译。

建议在后续使用中严格遵循 `-o output input` 的顺序，避免混淆。

## 4. 编译并运行 Hello World 程序
以下操作演示如何用 GCC 将源代码编译为可执行文件。

1. 源代码文件 **1.c** 已事先用文本编辑器（如 vim）写好，其内容为：
   ```c
   #include <stdio.h>
   int main() {
       printf("Hello");
       return 0;
   }
   ```
2. 在终端中执行编译命令：
   ```bash
   gcc -o bin 1.c
   ```
   - 这里将输出文件命名为 **bin**（可以任意取名）。
   - 命令中暂未附加任何选项，GCC 直接生成二进制可执行文件。

3. 查看当前目录，确认 **bin** 文件已生成。
4. 运行生成的程序：
   ```bash
   ./bin
   ```
   终端会输出 `Hello`，表明编译和运行均成功。

## 5. 编译选项简介（以 `-g` 为例）
GCC 支持众多编译选项，用以控制编译行为的细节。  
在实际开发中，当需要对程序进行调试时，通常会加入 **`-g`** 选项。该选项会在生成的可执行文件中嵌入调试信息（如符号表、行号映射等）。  
一个直观的影响就是文件大小：不加 `-g` 编译出的 **bin** 文件大小约为 17 KB；添加 `-g` 后，文件体积会明显增加（因包含了额外的调试数据）。  
更多高级选项将在后续编译专题中展开讨论。
